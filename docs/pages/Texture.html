Texture

所有纹理的基类。

注意：初次使用纹理后，其尺寸、格式和类型 无法更改。相反，在纹理上调用 Texture#dispose 并实例化一个新的。

构造函数

new Texture( image : Object, mapping : number, wrapS : number, wrapT : number, magFilter : number, minFilter : number, format : number, type : number, anisotropy : number, colorSpace : string )

构造一个新的纹理。

image

保存纹理数据的图像。

默认为 Texture.DEFAULT_IMAGE.
mapping

纹理映射.

默认为 Texture.DEFAULT_MAPPING.
wrapS

wrapS 值.

默认为ClampToEdgeWrapping.
wrapT

wrapT 值.

默认为ClampToEdgeWrapping.
magFilter

mag 滤镜值.

默认为LinearFilter.
minFilter

最小滤镜值.

默认为LinearMipmapLinearFilter.
format

纹理格式.

默认为RGBAFormat.
type

纹理类型.

默认为UnsignedByteType.
anisotropy

各向异性值.

默认为Texture.DEFAULT_ANISOTROPY.
colorSpace

颜色空间.

默认为NoColorSpace.

属性

.anisotropy : number

沿用的样本数通过像素的轴具有 纹理像素的最高密度。默认情况下，该值为 1。更高的价值 与基本 mipmap 相比，给出的结果不太模糊，但代价是 正在使用的纹理样本。

默认为Texture.DEFAULT_ANISOTROPY.

.center : Vector2

发生旋转的点。 (0.5, 0.5) 的值对应 到纹理的中心。默认为 (0, 0)，左下角。

默认为 (0,0).

.channel : number

允许您选择要将纹理映射到的 uv 属性。 0 对于 uv， 1 为 uv1，2 为 uv2，3 为uv3.

默认为0.

.colorSpace : string

包含颜色数据的纹理应使用 SRGBColorSpace 或 LinearSRGBColorSpace.

默认为NoColorSpace.

.depth

中纹理的深度进行注释Pixels.

.flipY : boolean

如果设置为true，纹理沿垂直轴翻转时 上传到GPU.

请注意，使用 ImageBitmap 时，此属性不起作用。你需要 改为配置位图创建时的翻转。

默认为true.

.format : number

纹理的格式。

默认为RGBAFormat.

.generateMipmaps : boolean

是否为纹理生成 mipmap（如果可能）。

如果您手动创建 mipmap，请将其设置为 false。

默认为true.

.height

纹理的高度像素.

.id : number (readonly)

纹理的ID.

.image : Object

保存纹理数据的图像对象.

.internalFormat : string

默认内部格式源自Texture#format和Texture#type和 定义纹理数据如何存储在 GPU 上。

此属性允许覆盖默认格式。

默认为null.

.isArrayTexture : boolean (readonly)

指示纹理是否应像纹理数组一样处理。

默认为 false.

.isRenderTargetTexture : boolean (readonly)

指示纹理是否属于渲染目标或不是.

默认为 false.

.isTexture : boolean (readonly)

该标志可用于类型测试。

默认为true.

.magFilter : NearestFilter | NearestMipmapNearestFilter | NearestMipmapLinearFilter | LinearFilter | LinearMipmapNearestFilter | LinearMipmapLinearFilter

当一个纹理元素覆盖多个纹理时，纹理如何采样Pixel.

默认为LinearFilter.

.mapping : UVMapping | CubeReflectionMapping | CubeRefractionMapping | EquirectangularReflectionMapping | EquirectangularRefractionMapping | CubeUVReflectionMapping

纹理如何应用到对象上。值 UVMapping 是默认值，其中纹理或 uv 坐标用于应用贴图。

默认为 UVMapping.

.matrix : Matrix3

纹理的 uv 变换矩阵。

.matrixAutoUpdate : boolean

是否更新纹理的 UV 变换 Texture#matrix 来自属性 Texture#offset、Texture#repeat、Texture#rotation 和 Texture#center。

如果直接指定 uv 变换矩阵，请将其设置为 false。

默认为true.

.minFilter : NearestFilter | NearestMipmapNearestFilter | NearestMipmapLinearFilter | LinearFilter | LinearMipmapNearestFilter | LinearMipmapLinearFilter

当纹素覆盖较少时纹理如何采样超过一个像素。

默认为LinearMipmapLinearFilter.

.mipmaps : Array.<Object>

保存用户定义的数组mipmaps.

.name : string

纹理的名称.

.needsPMREMUpdate : boolean

将此属性设置为true表示引擎为PMREM 必须重新生成。

默认为 false.

.needsUpdate : boolean

将此属性设置为true表示引擎纹理 必须在下一次渲染中更新。这会触发纹理上传 到 GPU 并确保正确的纹理参数配置。

默认为 false.

.normalized : boolean

纹理是否应使用标准化的 16 位整数格式之一 采样时为 [0, 1] 或 [-1, 1]（取决于有符号/无符号）。

默认为 false.

.offset : Vector2

纹理的单个重复相对于开头的偏移量， 在每个方向 U 和 V 上。典型范围是 0.0 到 1.0.

默认为 (0,0).

.onUpdate : function

A 回调函数，在纹理更新时调用（例如，当 Texture#needsUpdate 已设置为 true，然后使用该纹理）.

默认为null.

.pmremVersion : number (readonly)

指示该纹理是否应由 PMREMGenerator 处理 （仅与渲染目标纹理相关）.

默认为0.

.premultiplyAlpha : boolean

如果设置为 true，则 Alpha 通道（如果存在）将乘以 纹理上传到 GPU 时的颜色通道。

请注意，使用 ImageBitmap 时，此属性无效。你需要 在创建位图时配置预乘 alpha。

默认为 false.

.renderTarget : RenderTarget | WebGLRenderTarget

对纹理渲染目标的可选反向引用。

默认为null.

.repeat : Vector2

纹理在每个表面上重复多少次 U 和 V 方向。如果在任一方向上重复设置大于 1， 相应的wrap参数也应设置为RepeatWrapping 或 MirroredRepeatWrapping 以实现所需的平铺效果。

默认为 (1,1).

.rotation : number

纹理围绕中心点旋转的程度（以弧度为单位）。 正值是逆时针方向。

默认为0.

.source : TextureSource

纹理的数据定义。对数据源的引用可以是 跨纹理共享。这在精灵表的上下文中通常很有用 其中多个纹理渲染相同的数据但具有不同的纹理 变换.

.type : number

纹理的数据类型.

默认为UnsignedByteType.

.unpackAlignment : number

指定内存中每个像素行开头的对齐要求。 允许的值为 1 （字节对齐）、 2 （行与偶数字节对齐）、 4（字对齐）和 8（行从双字边界开始）。

默认为4.

.updateRanges : Array.<Object>

这可用于仅更新纹理的子区域或特定行（例如，仅更新 前 3 行）。使用 addUpdateRange() 函数将范围添加到此数组。

.userData : Object

可用于存储有关纹理的自定义数据的对象。它 不应保存对函数的引用，因为它们不会被克隆。

.uuid : string (readonly)

纹理的 UUID。

.version : number (readonly)

这从 0 开始，并计算 Texture#needsUpdate 设置为的次数true.

默认为0.

.width

纹理的宽度（以像素为单位）。

.wrapS : RepeatWrapping | ClampToEdgeWrapping | MirroredRepeatWrapping

这定义了纹理如何水平包裹并对应于 UV 映射中的 U。

默认为ClampToEdgeWrapping.

.wrapT : RepeatWrapping | ClampToEdgeWrapping | MirroredRepeatWrapping

这定义了纹理如何水平包裹并对应于 UV 映射中的 V。

默认为ClampToEdgeWrapping.

.DEFAULT_ANISOTROPY : number

所有纹理的默认各向异性值。

默认为1.

.DEFAULT_IMAGE : Image

所有纹理的默认图像。

默认为null.

.DEFAULT_MAPPING : number

所有纹理的默认映射。

默认为 UVMapping.

方法

.addUpdateRange( start : number, count : number )

在数据纹理中添加一系列数据要在 GPU 上更新。

start

开始更新的位置。
count

要更新的组件数量update.

.clearUpdateRanges()

清除更新范围。

.clone() : Texture

返回具有从此实例复制的值的新纹理。

返回：此克隆instance.

.copy( source : Texture ) : Texture

将给定纹理的值复制到此实例.

source

纹理复制.
返回：对此实例的引用。

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

values

meta

使用纹理uv变换矩阵变换给定的uv向量。

uv
