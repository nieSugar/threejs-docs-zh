LightsNode

该节点代表场景的照明并管理照明模型的生命周期 对于当前构建的 3D 对象。它负责计算总输出 给定光照上下文中的灯光。

构造函数

new LightsNode()

构造一个新的灯光节点。

属性

.global : boolean

LightsNode 默认情况下将此属性设置为 true。

默认为true.

覆盖： Node#global

.hasLights : boolean

场景是否有灯光或not.

.outgoingLightNode : Node.<vec3>

表示出射光的节点。

.totalDiffuseNode : Node.<vec3>

表示总漫射光的节点。

.totalSpecularNode : Node.<vec3>

表示总镜面反射光的节点。

方法

.analyze( builder : NodeBuilder )

通过构建所有嵌套的轻节点来分析节点的依赖关系 和输出节点。

builder

对当前节点构建器的引用。
覆盖： Node#analyze

.customCacheKey() : number

通过包含覆盖默认的 Node#customCacheKey 实现 将灯光数据写入缓存键。

覆盖： Node#customCacheKey
返回： 自定义缓存键。

.getBuiltinLights() : Array.<Light>

返回场景的数组light.

灯光变化取决于着色器； 如果此数组发生更改，则需要重新创建着色器。

返回：场景的灯光。

.getHash( builder : NodeBuilder ) : string

计算用于标识当前灯光节点设置的哈希值。

builder

对当前节点构建器的引用。
覆盖： Node#getHash
返回：计算出的值hash.

.getLights() : Array.<Light>

返回场景的数组light.

返回：场景的灯光。

.setLights( lights : Array.<Light> ) : LightsNode

使用灯光数组配置此节点。

lights

灯光数组。
返回：对此节点的引用.

.setup( builder : NodeBuilder ) : Node.<vec3>

该实现确保场景中的每个灯光 有一个对应的轻节点。通过构建轻节点 并评估照明模型，计算出射光。

builder

对当前节点构建器的引用。
覆盖： Node#setup
返回： 代表出射光的节点。

.setupDirectLight( builder : Object, lightNode : Object, lightData : Object )

在照明模型中设置直接光。

builder

包含上下文和堆栈的构建器对象。
lightNode

灯光节点。
lightData

包含颜色和方向属性的灯光对象。

.setupDirectRectAreaLight( builder : Object, lightNode : Object, lightData : Object )

在照明模型中设置直接矩形区域光。

builder

包含上下文和堆栈的构建器对象。
lightNode

灯光节点。
lightData

包含颜色和区域光的灯光对象属性.

.setupLights( builder : NodeBuilder, lightNodes : Array.<LightingNode> )

通过构建所有相应的内部灯光来设置内部灯光 灯光节点。

builder

对当前节点构建器的引用。
lightNodes

灯光节点数组。

.setupLightsNode( builder : NodeBuilder ) : Array.<LightingNode>

为每个场景灯光创建灯光节点。这使得可以进一步 处理节点系统中的灯光。

builder

对当前节点构建器的引用。
返回：照明节点数组。
