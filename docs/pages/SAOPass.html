SAOPass

SAO 实现灵感来自 @bhouston 之前的 SAO 工作。

SAOPass 提供比 SSAOPass 更好的质量，但也更昂贵。

代码示例

const saoPass = new SAOPass( scene, camera );
composer.addPass( saoPass );

导入

SAOPass 是一个插件，必须显式导入，请参阅Installation#Addons.

import { SAOPass } from 'three/addons/postprocessing/SAOPass.js';

构造函数

new SAOPass( scene : Scene, camera : Camera, resolution : Vector2 )

构造一个新的SAO pass.

scene

计算AO的场景.
camera

相机.
resolution

效果的分辨率。

属性

.camera : Camera

相机.

.clear : boolean

默认覆盖以执行清除操作。

默认为true.

覆盖： Pass#clear

.needsSwap : boolean

覆盖以禁用交换.

默认为 false.

覆盖： Pass#needsSwap

.params : Object

SAO参数.

.resolution : Vector2

效果的分辨率。

默认为(256,256).

.scene : Scene

渲染AO的场景for.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行SAO pass.

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize
