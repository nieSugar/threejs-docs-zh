TextureSource

表示纹理的数据源。

该类的主要目的是将数据定义与纹理解耦 定义，以便相同的数据可以用于多个纹理实例。

构造函数

new TextureSource( data : any )

构造一个新的纹理源。

data

纹理的数据定义。

默认为null.

属性

.data : any

纹理的数据定义。

.dataReady : boolean

此属性仅在 TextureSource#needsUpdate 设置为 true 且 提供对如何处理纹理数据的更多控制。当设置 dataReady 时 到false，引擎执行内存分配（如果需要）但不传输 将数据写入GPU内存。

默认为true.

.id : number (readonly)

源的ID。

.isTextureSource : boolean (readonly)

该标志可用于类型测试。

默认为true.

.needsUpdate : boolean

当该属性设置为true时，引擎分配内存 用于纹理（如果需要）并触发实际的纹理上传 下次使用源时发送给 GPU。

默认为 false.

.uuid : string (readonly)

源的 UUID。

.version : number (readonly)

这从 0 开始，并计算 TextureSource#needsUpdate 设置为的次数true.

默认为0.

方法

.getSize( target : Vector2 | Vector3 ) : Vector2 | Vector3

将源的维度返回到给定的目标向量中。

target

结果写入的目标对象.
返回： source.

.toJSON( meta : Object | string ) : Object

将源序列化为 JSON.

meta

保存有关雾的元信息的可选值序列化.
参见：
  • ObjectLoader#parse
返回： 表示序列化源的 JSON 对象。
