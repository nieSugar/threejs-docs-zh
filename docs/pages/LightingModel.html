LightingModel

用于实现照明模型的抽象类。该模块定义 具体照明模型可以实现多种方法。这些 方法在光评估期间的不同点执行 process.

构造函数

new LightingModel()

方法

.ambientOcclusion( builder : NodeBuilder ) (abstract)

此方法用于实现环境光遮挡项。 与其他方法不同，该方法必须由光照手动调用 间接项中的模型。

builder

当前节点构建器.

.direct( lightData : Object, builder : NodeBuilder ) (abstract)

此方法旨在实现直接光项和 在定向、点和聚光灯节点的构建过程中执行。

lightData

灯光数据。
builder

当前节点构建器.

.directRectArea( lightData : Object, builder : NodeBuilder ) (abstract)

此方法旨在实现直接光术语 矩形区域光节点。

lightData

灯光数据。
builder

当前节点构建器.

.finish( builder : NodeBuilder ) (abstract)

此方法用于执行最终更新等最终任务 到出射光。

builder

当前节点构建器.

.indirect( builder : NodeBuilder ) (abstract)

此方法用于实现间接光术语。

builder

当前节点构建器.

.start( builder : NodeBuilder ) (abstract)

此方法用于设置照明模型和上下文数据 稍后在评估过程中使用。

builder

当前节点构建器.
