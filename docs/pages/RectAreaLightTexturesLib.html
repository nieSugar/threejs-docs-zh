RectAreaLightTexturesLib

RectAreaLight 的纹理库。此类保存 LTC BRDF 数据 在数据纹理中以供在渲染器中进一步使用。

参考：具有线性变换余弦的实时多边形光着色 作者：Eric Heitz、Jonathan Dupuy、Stephen Hill 和 David Neubelt。 代码.

注意：这是 BRDF 近似纹理数据的临时位置 基于 Eric Heitz 的作品（见引文）。 BRDF 数据为 RectAreaLight 当前使用预先计算的纹理进行近似 大小约为 80kb。希望能找到更好的方式来包容 在包含完整的 RectAreaLight 实现之前的大纹理数据 在主构建文件中。

导入

RectAreaLightTexturesLib 是一个插件，必须显式导入，请参阅Installation#Addons.

import { RectAreaLightTexturesLib } from 'three/addons/lights/RectAreaLightTexturesLib.js';

属性

.LTC_FLOAT_1 : DataTexture

第一个 LTC FP32 数据纹理.

默认为null.

.LTC_FLOAT_2 : DataTexture

第二个 LTC FP32 数据纹理.

默认为null.

.LTC_HALF_1 : DataTexture

第一个 LTC FP16 数据纹理.

默认为null.

.LTC_HALF_2 : DataTexture

第二个 LTC FP16 数据纹理.

默认为null.

静态方法

.init() : RectAreaLightTexturesLib

初始化纹理库.
