import * as BufferGeometryUtils from 'three/addons/utils/BufferGeometryUtils.js';

方法

.computeMikkTSpaceTangents( geometry : BufferGeometry, MikkTSpace : Object, negateSign : boolean ) : BufferGeometry (inner)

使用 MikkTSpace 算法计算顶点切线。 MikkTSpace 始终生成相同的切线， 并用于大多数建模工具和法线贴图烘焙程序。对带有法线贴图的材质使用 MikkTSpace， 因为不一致的切线可能会导致法线贴图中出现微妙的视觉问题，特别是在镜像周围 UV 接缝.

与此方法相比，BufferGeometry#computeTangents（自定义算法）生成的切线 可能与其他软件中的切线不匹配。自定义算法足以满足一般用途 自定义材质，并且可能比 MikkTSpace 更快。

返回原始 BufferGeometry。索引几何图形将被取消索引。需要位置、法线和 uv 属性。

geometry

用于计算切线的几何图形。
MikkTSpace

examples/jsm/libs/mikktspace.module.js 或 mikktspace npm 包的实例。 使用前等待MikkTSpace.ready。
negateSign

是否对每条切线的符号分量(.w)取反。 某些格式的法线贴图约定是必需的，包括 glTF.

默认为true.
返回： 更新的几何图形。

.computeMorphedAttributes( object : Mesh | Line | Points ) : Object (inner)

计算变形/蒙皮 BufferGeometry 的变形属性。

对于光线跟踪或贴花很有帮助（即将 DecalGeometry 应用于具有 BufferGeometry 的变形对象 将使用原始的 BufferGeometry，而不是变形/蒙皮的，从而生成不正确的结果。 使用此函数创建阴影Object3D可以正确生成DecalGeometry).

object

要计算变形属性的3D对象。
返回：具有原始位置/正常属性和变形属性的对象。

.interleaveAttributes( attributes : Array.<BufferAttribute> ) : Array.<InterleavedBufferAttribute> (inner)

交错一组属性和返回共享属性的新数组 单个 InterleavedBuffer 实例。所有属性必须具有兼容的类型。

返回：交错属性的数组。如果交错不成功，该方法将返回 null.

.mergeAttributes( attributes : Array.<BufferAttribute> ) : BufferAttribute (inner)

要合并的属性。
返回： 合并的属性。如果合并不成功，则返回 null。

.mergeGeometries( geometries : Array.<BufferGeometry>, useGroups : boolean ) : BufferGeometry (inner)

默认为 false.
返回：合并的几何图形。如果合并不成功，则返回 null。

.mergeVertices( geometry : BufferGeometry, tolerance : number ) : BufferGeometry (inner)

返回一个新几何体，其顶点的所有相似顶点属性（在公差范围内）都被合并。

geometry

要合并顶点的几何体.
tolerance

公差值。

默认为1e-4.
返回：
  • 具有合并顶点的新几何图形。

.toCreasedNormals( geometry : BufferGeometry, creaseAngle : number ) : BufferGeometry (inner)

修改提供的几何图形（如果它是非索引的），否则创建一个新的， 非索引几何。返回除 以大于折痕角度的角度相交的面。

geometry

要修改的几何图形。
creaseAngle

以弧度表示的折痕角度。

默认为Math.PI/3.
返回：
  • 更新后的几何图形

.toTrianglesDrawMode( geometry : BufferGeometry, drawMode : number ) : BufferGeometry (inner)

将给定几何体转换为 TrianglesDrawMode 绘制模式，该模式 对应于 WebGL 中的 gl.TRIANGLES 原语。仅转换 重写索引，因此几何图形就地修改并返回。

geometry

要转换的几何图形。
drawMode

当前绘制模式。
返回：使用转换后的几何图形TrianglesDrawMode.
