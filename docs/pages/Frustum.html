Frustum

Frustum 用于确定相机视野内的内容。 它们有助于加快渲染过程 - 位于相机范围之外的对象 可以安全地从渲染中排除视锥体。

此类主要供渲染器内部使用。

构造函数

new Frustum( p0 : Plane, p1 : Plane, p2 : Plane, p3 : Plane, p4 : Plane, p5 : Plane )

构造一个新的视锥体。

p0

包围平截头体的第一个平面.
p1

包围平截头体的第二个平面.
p2

包围平截头体的第三个平面.
p3

包围平截头体的第四个平面.
p4

The包围平截头体的第五个平面。
p5

包围平截头体的第六个平面。

属性

.planes : Array.<Plane>

此数组保存包围平截头体的平面。

方法

.clone() : Frustum

返回一个新的平截头体，其中包含从中复制的值实例.

返回：此克隆instance.

.containsPoint( point : Vector3 ) : boolean

如果给定点位于视锥体内，则返回true。

point

要测试的点。
返回：该点是否位于该视锥体内。

.copy( frustum : Frustum ) : Frustum

将给定视锥体的值复制到此实例.

frustum

要复制的平截头体.
返回：对此平截头体的引用.

.intersectsBox( box : Box3 ) : boolean

如果给定的边界框与此相交，则返回true frustum.

这是一种快速、保守的测试，更注重性能而不是精度。它可以 报告位于截锥体外但不在截锥体内的大盒子的误报 由单个截锥体平面隔开。它从不报告假阴性，所以它是 剔除安全。

box

要测试的边界框。
返回：边界框是否与此平截头体相交。

.intersectsObject( object : Object3D ) : boolean

如果 3D 对象的边界球体与此平截头体相交，则返回 true。

请注意，3D 对象必须具有几何形状，以便可以计算边界球体。

object

要测试的 3D 对象.
返回： 3D 对象的边界球体是否与该平截头体相交。

.intersectsSphere( sphere : Sphere ) : boolean

如果给定的边界球体是，则返回 true与这个平截头体相交。

这是一个快速、保守的测试，更注重性能而不是精度。它可以 报告位于截锥体外但未分离的球体的误报 由单个截锥体平面。它从不报告漏报，因此剔除是安全的。

sphere

要测试的边界球.
返回：边界球体是否与此截头体相交。

.intersectsSprite( sprite : Sprite ) : boolean

如果给定的精灵与此截头体相交，则返回 true平截头体.

sprite

要测试的精灵.
返回： 精灵是否与此平截头体相交。

.set( p0 : Plane, p1 : Plane, p2 : Plane, p3 : Plane, p4 : Plane, p5 : Plane ) : Frustum

通过复制给定的平截头体平面平面.

p0

包围平截头体的第一个平面.
p1

包围平截头体的第二个平面.
p2

包围平截头体的第三个平面.
p3

包围平截头体的第四个平面.
p4

The包围平截头体的第五个平面。
p5

包围平截头体的第六个平面。
返回：对此平截头体的引用.

.setFromProjectionMatrix( m : Matrix4, coordinateSystem : WebGLCoordinateSystem | WebGPUCoordinateSystem, reversedDepth : boolean ) : Frustum

根据给定的投影矩阵设置平截头体平面。

m

投影矩阵.
coordinateSystem

坐标系.
reversedDepth

是否使用反转深度.

默认为 false.
返回：对此平截头体的引用.
