PDBLoader

PDB 格式的加载器。

蛋白质数据库 文件格式是描述分子三维结构的文本文件。

代码示例

const loader = new PDBLoader();
const pdb = await loader.loadAsync( 'models/pdb/ethanol.pdb' );
const geometryAtoms = pdb.geometryAtoms;
const geometryBonds = pdb.geometryBonds;
const json = pdb.json;

导入

PDBLoader 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { PDBLoader } from 'three/addons/loaders/PDBLoader.js';

构造函数

new PDBLoader( manager : LoadingManager )

构造一个新的 PDB 加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的 URL 加载并传递加载的 PDB 资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( text : string ) : Object

解析给定的 PDB 数据并返回一个包含原子的对象， 键几何结构以及 JSON 形式的原始原子数据。

text

字符串形式的原始 PDB 数据.
覆盖： Loader#parse
返回： 结果对象.
