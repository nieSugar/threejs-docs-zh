WebGPUTextureUtils

导入

WebGPUTextureUtils 是一个插件，必须显式导入，请参阅 安装#Addons.

import * as WebGPUTextureUtils from 'three/addons/utils/WebGPUTextureUtils.js';

静态方法

.decompress( blitTexture : CompressedTexture, maxTextureSize : number, renderer : WebGPURenderer ) : Promise.<CanvasTexture> (async)

返回给定压缩纹理的未压缩版本。

此模块只能与WebGPURenderer一起使用。当使用WebGLRenderer时， 从 module:WebGLTextureUtils.

blitTexture

压缩纹理.
maxTextureSize

未压缩纹理的最大大小.

默认为 Infinity.
renderer

对a的引用渲染器.

默认为null.
导入函数返回： 使用未压缩纹理解析的 Promise.
