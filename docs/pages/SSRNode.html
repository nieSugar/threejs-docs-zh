SSRNode

用于计算屏幕空间反射（SSR）的后处理节点。

参考： https://lettier.github.io/3d-game-shaders-for-beginners/screen-space-reflection.html

导入

SSRNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ssr } from 'three/addons/tsl/display/SSRNode.js';

构造函数

new SSRNode( colorNode : Node.<vec4>, depthNode : Node.<float>, normalNode : Node.<vec3>, options : SSRNodeOptions )

构造一个新的SSR节点。

colorNode

代表美容通道的节点。
depthNode

代表美丽通道深度的节点。
normalNode

代表美容通道法线的节点。
options

材质的可选输入和环境数据。

属性

._binaryRefine : boolean

启用检测到的命中的子步骤二分搜索细化。打开时，粗 十字路口被平分到精确的交叉点（更锐利的打击，更少的步数 混叠）以额外深度样本为代价。烘焙到着色器中作为 编译时常量；分配新值会重建 SSR 材质。

默认为 false.

._blurQuality : number

模糊的质量。必须是 [1,3].

范围内的整数作为编译时常量烘焙到模糊着色器中，因此 (size*2+1)² 样品环展开；分配新值会重新编译模糊材质。

默认为2.

._reflectNonMetals : boolean

仅在 SSRNode#stochastic 为 false 时使用。当false时，非金属 表面被丢弃以获得显着的性能提升；将 true 设置为也 反射电介质。作为编译时常量烘焙到着色器中；分配一个 新值重新编译 SSR 材质。

默认为 false.

._screenEdgeFadeBlack : boolean

当 true 时，SSR 在屏幕边界附近淡入零，而不是混合到 环境地图。反射样本 UV 使命中值变淡；错过的是 由表面像素 UV 淡出。

作为编译时常量烘焙到着色器中，因此未使用的淡入淡出分支为 被淘汰；分配新值会重新编译 SSR 材料。

默认为 false.

._stepExponent : number

非线性阶跃分布指数。 1 =统一步骤； > 1 浓缩液 射线原点附近的样本（大多数短程反射被遗漏）以及 将它们间隔到 maxDistance，如 s = (i / steps) ^ stepExponent.

作为编译时常量烘焙到着色器中，因此 pow() 折叠为几个 乘以；分配新值会重新编译 SSR 材料。仅由使用 随机反射路径.

默认为2.

.binaryRefine : boolean

是否启用子步二分搜索命中细化（编译时常量）。 分配新值会重建 SSR 材料。

.blurQuality : number

Blur 内核大小（编译时常量）。分配一个新值重新编译 模糊材质。

.camera : Camera

渲染场景的相机。

.colorNode : Node.<vec4>

代表美容通道的节点。

.depthNode : Node.<float>

代表美丽通道深度的节点。

.diffuseNode : Node.<vec4>

表示场景漫反射颜色的节点（通常是 MRT diffuseColor 附件）。 当null时，着色器使用vec3(1).

.envImportanceSampling : boolean

当true时，构建环境亮度CDF表并使用MIS来处理环境未命中。 在构建时修复。

.envMapIntensity : UniformNode.<float>

重要性采样环境贡献的强度乘数。 仅在调用 setEnvMap 后可用。

.environmentIntensity : UniformNode.<float>

应用于屏幕空间上的环境贴图反射的强度乘数 未命中和屏幕边缘。默认为 π 以匹配以前的硬编码乘数。

默认为 Math.PI.

.environmentNode : Texture

屏幕空间未命中的 HDR 环境贴图。

.historyTexture : Texture

表示多次反射的历史纹理的节点。

.intensity : UniformNode.<float>

整体反射强度的乘数。 1 离开 反射不变，较低的值会使它们变暗，较高的值会增强它们。

默认为1.

.maxDistance : UniformNode.<float>

控制片段可以反射的距离。增加该值会导致更多 计算开销，但也增加了反射距离。

.maxLuminance : UniformNode.<float>

绝对环境亮度上限。在此之上的 HDR 环境样本按比例缩小（保留色调）。

默认为10.

.metalnessNode : Node.<float>

每像素金属性，用于驱动 GGX 反射采样和非金属 早出。当null时，着色器将表面视为非金属。

.mirrorBias : UniformNode.<float>

随机GGX采样的镜像偏差。将反射光线集中到 波瓣的狭窄（近镜面）核心，用少量的偏差换取更少的噪音。 0 对整个 VNDF 波瓣进行采样；值朝向 1 拧紧锥体。范围 [0,1].

默认为0.5.

.normalNode : Node.<vec3>

代表美容通道法线的节点。

.quality : UniformNode.<float>

此参数控制光线行进过程的详细程度。 值范围为 [0,1]，其中 1 表示最佳质量（最大数量 raymarching 迭代/样本）和 0 意味着根本没有样本。

0.5 的质量通常足以满足大多数用例。尝试保留 这个参数越低越好。值越大，效果越显着

.reflectNonMetals : boolean

电介质是否反映在非随机路径中（编译时常数）。 分配新值会重建 SSR 材质。

.resolutionScale : number

分辨率比例。有效值范围为 [0,1]。1 表示最佳质量，但也会导致更多的计算开销。设置为 0.5 表示效果以半分辨率计算。

默认为1.

.roughnessNode : Node.<float>

每像素粗糙度，用于驱动 GGX 反射采样和模糊 mip 选择。当null时，着色器将表面视为完全平滑。

.screenEdgeFade : UniformNode.<float>

屏幕边缘淡入淡出宽度（以UV单位为单位）。当屏幕空间撞击接近屏幕时 边界，反射在这段距离内减弱——要么朝向环境 反射 (SSRNode#screenEdgeFadeBlack false) 或为零强度 (true)。 0 禁用它。

默认为0.2.

.screenEdgeFadeBlack : boolean

SSR 是否在屏幕边框附近淡入黑色（编译时常量）。分配 新值重新编译 SSR 材料。

.stepExponent : number

非线性步长分布指数（编译时常数）。看背衬 字段了解详细信息。分配新值会重新编译 SSR 材质。

.stochastic : boolean

当 true 时，每个像素的反射方向随随机 GGX 射线而变化 （第二代SSR）。当false时，追踪单个镜面反射并 通过模糊通道软化粗糙度（第一代 SSR）。

.thickness : UniformNode.<float>

控制什么算作可能的反射命中和什么不算作反射命中之间的截止。

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.velocityTexture : Node.<vec2>

表示重投影的速度纹理的节点。

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setEnvMap( hdr : Texture | null )

设置重要采样环境光照的环境贴图 屏幕空间光线未命中。每当场景的环境图发生变化时调用此函数。

使用ImportanceSampledEnvironment（CDF + MIS改编自 三-gpu-pathtracer).

hdr

等距矩形HDR环境贴图，或为空以禁用。
参见：
  • https://github.com/gkjohnson/three-gpu-pathtracer

.setHistory( history : Texture, velocity : Node.<vec2> )

连接多次反射的反馈输入：之前的框架的 去噪结果 (history) 以及用于重新投影它的速度缓冲区 (velocity)。 history 接受生成节点（例如 RecurrentDenoiseNode) — 使用其输出渲染目标 — 或原始 纹理。为两者传递 null 以禁用多次反弹。

history
velocity

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
