ConvexObjectBreaker

该类可用于将凸几何对象细分为多个部分。

使用函数prepareBreakableObject 准备要破碎的Mesh 对象。 然后，调用各种函数来细分对象（subdivideByImpact、cutByPlane）。 作为细分产物的子对象不需要对其调用prepareBreakableObject。

对象的必备条件：

  • Mesh 对象必须有一个缓冲几何体和材质。
  • 顶点法线必须是平面的（不能平滑处理）。
  • 几何体必须是凸的（库中未检查此项）。你可以使用 ConvexGeometry 创建凸几何体。BoxGeometry、SphereGeometry 以及其他凸的原始几何体也可以使用。

注意：此库将成员变量添加到对象的userData成员（请参阅prepareBreakableObject函数） 与其他库一起使用时请谨慎使用并阅读代码。

导入

ConvexObjectBreaker 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ConvexObjectBreaker } from 'three/addons/misc/ConvexObjectBreaker.js';

构造函数

new ConvexObjectBreaker( minSizeForBreak : number, smallDelta : number )

构造一个新的凸形物体破碎机。

minSizeForBreak

碎片必须破碎的最小尺寸。

默认为1.4.
smallDelta

考虑一个点属于一个平面的最大距离。

默认为0.0001.

方法

.cutByPlane( object : Object3D, plane : Plane, output : Object ) : number

将给定的3D对象细分为几块平面.

object

要细分的3D对象.
plane

要切割3D对象的平面.
output

存储碎片的对象.
返回：

.prepareBreakableObject( object : Object3D, mass : number, velocity : Vector3, angularVelocity : Vector3, breakable : boolean )

必须为所有可破坏的 3D 对象调用。

object

3D 对象。它必须具有凸几何形状。
mass

3D 对象的质量（以千克为单位）。必须大于0.
velocity

3D物体的速度.
angularVelocity

3D物体的角速度.
breakable

3D物体是否是可破坏的或not.

.subdivideByImpact( object : Object3D, pointOfImpact : Vector3, normal : Vector3, maxRadialIterations : number, maxRandomIterations : number ) : Array.<Object3D>

通过撞击将给定的 3D 对象细分为碎片（意味着另一个对象撞击 给定 3D 对象在某个表面点）。

object

要细分的3D对象.
pointOfImpact

撞击点。
normal

撞击法线。
maxRadialIterations

径向切割的迭代次数。
maxRandomIterations

非径向的最大随机迭代次数切割.
返回： 碎片数组.
