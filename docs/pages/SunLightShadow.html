SunLightShadow

表示SunLight的阴影配置，使用两个 级联阴影贴图 (CSM).

阴影相机投影自动适合视图切片 截锥体，最大距离为 camera.far （或视图相机的远平面， 以较小者为准），并且相邻的级联在一段时间内相互混合 深度范围小。 camera.left/right/top/bottom 被忽略。

默认 mapSize 是每个级联 1024x1024。

导入

SunLightShadow 是一个插件，必须显式导入，请参阅Installation#Addons。

import { SunLightShadow } from 'three/addons/lights/SunLightShadow.js';

构造函数

new SunLightShadow()

构造一个新的太阳光阴影。

属性

.isSunLightShadow : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.getCamera( cascadeIndex : number ) : OrthographicCamera

返回给定的阴影相机cascade.

cascadeIndex

级联索引.

默认为0.
覆盖： LightShadow#getCamera
返回： 阴影相机。

.getFrustum( cascadeIndex : number ) : Frustum

返回给定级联的阴影相机平截头体。内部使用由 渲染器剔除对象。

cascadeIndex

级联索引.

默认为0.
覆盖： LightShadow#getFrustum
返回： 阴影摄像机视锥体。

.getMatrix( cascadeIndex : number ) : Matrix4

返回给定级联的阴影矩阵。

cascadeIndex

级联索引.

默认为0.
返回： 阴影

.updateMatrices( light : Light, viewCamera : Camera )

更新级联相机和阴影的矩阵，内部使用 由渲染器.

light

正在渲染阴影的灯光.
viewCamera

渲染场景的相机。
覆盖： LightShadow#updateMatrices
