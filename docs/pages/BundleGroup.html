BundleGroup

允许应用程序访问 WebGPU 的渲染捆绑 API。该组及其所有后代节点 被视为一个渲染包并按如下方式处理 渲染器.

捆绑组中仅允许可渲染的 3D 对象。其他 不支持灯光等类型，必须将其添加到场景中 组外。

此模块仅受具有 WebGPU 后端的 WebGPURenderer 完全支持。 使用 WebGL 后端，从技术上讲可以渲染该组，但无需 任何性能改进。

构造函数

new BundleGroup()

构造新的捆绑包组。

属性

.isBundleGroup : boolean (readonly)

该标志可用于类型测试。

默认为true.

.needsUpdate : boolean

当捆绑包组更改时，将此属性设置为true。

默认为 false.

.static : boolean

捆绑包是否是静态的。当设置为 true 时，结构体 假设是静态的并且不会改变。例如。没有新对象 添加到组中。

如果需要更改，仍然可以通过设置强制更新 needsUpdate 标志到 true.

默认为true.

覆盖： Group#static

.type : string (readonly)

此属性仅与检测类型相关 在序列化/反序列化期间。应该总是 匹配类名。

默认为 'BundleGroup'.

覆盖： Group#type

.version : number (readonly)

捆绑组的版本.

默认为0.
