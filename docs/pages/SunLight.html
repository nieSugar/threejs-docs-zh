SunLight

向特定方向发射的类似太阳的光，其光线 都是并行的，并通过 SunLightShadow 投射级联阴影贴图， 适合照亮大场景。

与DirectionalLight不同，灯光没有目标：例如 HemisphereLight，其方向由其位置定义。的 光线从其所在位置射向原点并笔直指向 默认向下。

const sun = new SunLight( 0xfff2e3, 3 );
sun.position.set( 1, 1, 1 );
sun.castShadow = true;
scene.add( sun );

与WebGPURenderer一起使用时，灯光必须注册到 首先渲染器的节点库：

renderer.library.addLight( SunLightNode, SunLight );

导入

SunLight 是一个插件，必须显式导入，请参见 Installation#Addons.

import { SunLight } from 'three/addons/lights/SunLight.js';

构造函数

new SunLight( color : number | Color | string, intensity : number )

Constructs新的阳光.

color

灯光的颜色.

默认为0xffffff.
intensity

灯光的强度/强度.

默认为1.

属性

.isSunLight : boolean (readonly)

该标志可用于类型测试。

默认为true.

.shadow : SunLightShadow

此属性保存灯光的阴影配置.
