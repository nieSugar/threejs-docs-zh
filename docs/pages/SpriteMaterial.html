SpriteMaterial

用于渲染Sprite实例的材质__.

代码示例

const map = new THREE.TextureLoader().load( 'textures/sprite.png' );
const material = new THREE.SpriteMaterial( { map: map, color: 0xffffff } );
const sprite = new THREE.Sprite( material );
sprite.scale.set(200, 200, 1)
scene.add( sprite );

构造函数

new SpriteMaterial( parameters : Object )

构造一个新的精灵材质.

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.alphaMap : Texture

Alpha 贴图是一个灰度纹理，用于控制整个网格的不透明度 表面（黑色：完全透明；白色：完全不透明）.

仅使用纹理的颜色，如果有则忽略 alpha 通道 存在。对于 RGB 和 RGBA 纹理，渲染器将使用绿色通道 当采样该纹理时，由于提供了额外的精度 DXT 压缩和未压缩 RGB 565 格式中为绿色。仅亮度和 亮度/alpha 纹理也仍将按预期工作。

alphaMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.color : Color

材质的颜色。

默认为(1,1,1).

.fog : boolean

材质是否受雾影响。

默认为true.

.isSpriteMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.map : Texture

颜色图。可以选择包含 alpha 通道，通常是组合的 与 Material#transparent 或 Material#alphaTest。纹理贴图 颜色由漫反射color.

map 表示颜色数据，并且必须为纹理分配一个 Texture#colorSpace。大多数 map 纹理设置 texture.colorSpace = SRGBColorSpace。

默认为null.

.rotation : number

旋转精灵的弧度。

默认为0.

.sizeAttenuation : boolean

指定精灵的大小是否因相机深度而衰减（仅限透视相机）。

默认为true.

.transparent : boolean

由于精灵材质是透明的而被覆盖 默认情况下.

默认为true.

覆盖： Material#transparent
