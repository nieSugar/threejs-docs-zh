TextureUtils

包含实用程序函数的类纹理.

静态方法

.contain( texture : Texture, aspect : number ) : Texture

在其表面内尽可能大地缩放纹理而不裁剪 或拉伸纹理。该方法保留了原始长宽比 纹理。类似于CSS object-fit: contain

texture

纹理.
aspect

纹理的长宽比.
返回：更新的纹理.

.cover( texture : Texture, aspect : number ) : Texture

将纹理缩放到尽可能小的尺寸以填充表面，留下 没有空闲空间。该方法保留了纹理的原始长宽比。 类似于CSS object-fit: cover.

texture

纹理.
aspect

纹理的长宽比.
返回：更新的纹理.

.fill( texture : Texture ) : Texture

配置纹理到默认变换。类似于 CSS object-fit: fill.

texture

纹理.
返回：更新的纹理.

.getByteLength( width : number, height : number, format : number, type : number ) : number

确定必须使用多少字节来表示纹理.

width

纹理的宽度.
height

纹理的高度.
format

纹理的格式.
type

纹理的类型.
返回：字节长度.
