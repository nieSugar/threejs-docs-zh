BufferAttribute

此类存储属性的数据（例如顶点位置、面 索引、法线、颜色、UV 和任何自定义属性）关联 几何图形，允许更有效地将数据传递到 GPU。

当处理类似矢量的数据时，fromBufferAttribute( attribute, index ) 矢量和颜色类的辅助方法可能会有所帮助。例如。 Vector3#fromBufferAttribute.

构造函数

new BufferAttribute( array : TypedArray, itemSize : number, normalized : boolean )

构造一个新的缓冲区属性。

array

保存属性数据的数组。
itemSize

项目大小。
normalized

数据是否标准化或不是.

默认为 false.

属性

.array : TypedArray

保存属性数据的数组。它应该有 itemSize * numVertices 元素，其中 numVertices 是关联几何体中的顶点数。

.count : number (readonly)

表示此缓冲区属性存储的项目数。这是内部计算的 将 array 长度除以 itemSize。

.gpuType : FloatType | IntType

配置着色器中使用的绑定 GPU 类型。

注意：这仅对整数数组有效，对于浮点数组不可配置。 对于较低精度的浮点类型，请使用Float16BufferAttribute.

默认为FloatType.

.id : number (readonly)

缓冲区属性的ID。

.isBufferAttribute : boolean (readonly)

该标志可用于类型测试。

默认为true.

.itemSize : number

应关联的数组的值的数量一个特定的顶点。 例如，如果此属性存储一个 3 分量向量（例如位置、 正常，或颜色），则该值应为 3.

.name : string

缓冲区属性的名称。

.needsUpdate : number

Flag 来指示该属性已更改，应重新发送到 GPU。修改数组值时，将其设置为 true。

默认为 false.

.normalized : boolean

仅适用于整数数据。指示缓冲区中的基础数据如何映射到 GLSL 代码中的值。例如，如果 array 是 UInt16Array 的实例， 并且normalized是true，数组数据中的值0 - +65535将被映射到 GLSL 属性中的 0.0f - +1.0f。如果 normalized 是 false，则值将被转换 到未修改的浮点数，即 65535 变为 65535.0f.

.updateRanges : Array.<Object>

这可用于仅更新存储向量的某些组件（例如，仅更新 与颜色相关的组件）。使用 addUpdateRange() 函数向此数组添加范围。

.usage : StaticDrawUsage | DynamicDrawUsage | StreamDrawUsage | StaticReadUsage | DynamicReadUsage | StreamReadUsage | StaticCopyUsage | DynamicCopyUsage | StreamCopyUsage

定义数据存储的预期使用模式以进行优化。

注意：初次使用缓冲区后，其使用情况无法更改。相反， 实例化一个新版本并在下一次渲染之前设置所需的用法。

默认为 StaticDrawUsage.

.version : number

A 版本号，每次将 needsUpdate 设置为true.

方法

在数据数组中添加要在 GPU 上更新的数据范围。

start

开始更新的位置。
count

要更新的组件数量update.
