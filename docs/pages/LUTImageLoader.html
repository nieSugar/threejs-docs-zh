LUTImageLoader

用于加载 LUT 图像的加载器。

代码示例

const loader = new LUTImageLoader();
const map = loader.loadAsync( 'luts/NeutralLUT.png' );

导入

LUTImageLoader 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { LUTImageLoader } from 'three/addons/loaders/LUTImageLoader.js';

构造函数

new LUTImageLoader( manager : LoadingManager )

构造新的LUT loader.

manager

加载管理器。

Classes

LUTImageLoader

属性

.flip : boolean

是否垂直翻转LUT。

根据LUT的原点，纹理底部为绿色（例如对于Unreal） 或顶部为绿色（例如，用于 Unity URP 颜色查找）。如果您使用 lut 图像条 来自 Unity 管道，然后将此属性设置为 true.

默认为 false.

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定 URL 加载并传递加载的 LUT 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( dataArray : Uint8ClampedArray, size : number ) : Object

解析给定的 LUT 数据并返回生成的 3D 数据纹理。

dataArray

原始 LUT 数据。
size

LUT大小。
覆盖： Loader#parse
返回： 表示解析的 LUT 的对象.
