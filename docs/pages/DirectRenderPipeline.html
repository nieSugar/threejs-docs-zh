DirectRenderPipeline

直接应用输出处理的替代渲染管道 材质着色器。这避免了中间帧缓冲区和输出通道 由 Renderer 使用，但会更改混合并且与 对帧缓冲区进行采样的材质，例如透射材质。

注意：此模块只能与 WebGPURenderer 一起使用。

代码示例

const renderPipeline = new DirectRenderPipeline( renderer );
renderPipeline.render( scene, camera );

构造函数

new DirectRenderPipeline( renderer : Renderer, outputNode : Node.<vec4> )

构造直接渲染管道。

renderer

对渲染器.
outputNode

可选输出节点.

属性

.isDirectRenderPipeline : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.render( scene : Object3D, camera : Camera )

使用直接在材质着色器中应用的输出处理来渲染场景。

scene

要渲染的场景或对象.
camera

相机.
