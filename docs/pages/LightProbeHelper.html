LightProbeHelper

渲染球体以可视化场景中的光探针。

此助手只能与 WebGLRenderer 一起使用。 使用WebGPURenderer时，从LightProbeHelperGPU.js.

代码示例

const helper = new LightProbeHelper( lightProbe );
scene.add( helper );

导入

LightProbeHelper导入是一个插件，必须显式导入，请参见安装#Addons.

import { LightProbeHelper } from 'three/addons/helpers/LightProbeHelper.js';

构造函数

new LightProbeHelper( lightProbe : LightProbe, size : number )

构造一个新的光照探针助手。

lightProbe

可视化光探头.
size

助手的大小.

默认为1.

属性

.lightProbe : LightProbe

可视化光探头.

.size : number

助手的大小.

默认为1.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Mesh#dispose
