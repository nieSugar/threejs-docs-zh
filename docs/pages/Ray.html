Ray

从原点向特定方向发射的光线。该类由以下人员使用 Raycaster 协助光线投射。光线投射用于 鼠标拾取（确定鼠标位于 3D 空间中的哪些对象上方） 除此之外.

构造函数

new Ray( origin : Vector3, direction : Vector3 )

构造一条新射线.

origin

射线的原点.

默认为(0,0,0).
direction

射线的（标准化）方向.

默认为(0,0,-1).

属性

.direction : Vector3

射线的（标准化）方向.

.origin : Vector3

射线的原点.

方法

.applyMatrix4( matrix4 : Matrix4 ) : Ray

使用给定的 4x4 变换矩阵变换此射线。

matrix4

变换矩阵。
返回：对此射线的引用。

.at( t : number, target : Vector3 ) : Vector3

返回位于沿此给定距离处的向量射线.

t

沿着射线检索位置的距离.
target

用于存储方法结果的目标向量.
返回：射线上的位置.

.clone() : Ray

返回一条带有从此实例复制的值的新射线。

返回：此克隆instance.

.closestPointToPoint( point : Vector3, target : Vector3 ) : Vector3

返回沿着这条射线最接近给定点的点。

point

3D 空间中的一个点，用于获取射线上最近位置的点。
target

用于存储方法结果的目标向量.
返回：这条射线上最近的点。

.copy( ray : Ray ) : Ray

将给定射线的值复制到此实例.

ray

要复制的射线.
返回：对此射线的引用。

.distanceSqToPoint( point : Vector3 ) : number

返回该射线与给定点之间最近距离的平方距离。

point

3D 空间中用于计算距离的点to.
返回： 距离的平方。

.distanceSqToSegment( v0 : Vector3, v1 : Vector3, optionalPointOnRay : Vector3, optionalPointOnSegment : Vector3 ) : number

返回该射线与给定线段之间的平方距离。

v0

线段的起点。
v1

线的终点段.
optionalPointOnRay

提供时，它接收该射线上最接近该线段的点。
optionalPointOnSegment

提供时，它接收线段上最接近该射线的点。
返回： 距离的平方。

.distanceToPlane( plane : Plane ) : number

计算从射线原点到给定平面的距离。如果射线返回 null 不与平面相交。

plane

计算距离的平面。
返回：此射线是否与给定球体相交。

.distanceToPoint( point : Vector3 ) : number

返回此射线与给定球体之间最接近的距离点.

point

3D 空间中用于计算距离的点to.
返回： 距离.

.equals( ray : Ray ) : boolean

如果这条射线与给定的射线相等，则返回true.

ray

要测试的射线equal.
返回： 此射线是否与给定的射线相等。

.intersectBox( box : Box3, target : Vector3 ) : Vector3

将此射线与给定的边界框相交，返回交集 点或 null 如果没有交集。

box

要相交的框。
target

用于存储方法结果的目标向量.
返回： 交点。

.intersectPlane( plane : Plane, target : Vector3 ) : Vector3

将此射线与给定平面相交，返回交集 点或 null 如果没有相交。

plane

要相交的平面。
target

用于存储方法结果的目标向量.
返回： 交点。

.intersectSphere( sphere : Sphere, target : Vector3 ) : Vector3

将此射线与给定球体相交，返回交集 点或 null 如果没有交集。

sphere

要相交的球体。
target

用于存储方法结果的目标向量.
返回： 交点。

.intersectTriangle( a : Vector3, b : Vector3, c : Vector3, backfaceCulling : boolean, target : Vector3 ) : Vector3

将此射线与给定三角形相交，返回交集 点或 null（如果没有交点）。

a

三角形的第一个顶点。
b

三角形的第二个顶点。
c

三角形的第三个顶点三角形.
backfaceCulling

是否使用背面剔除。
target

用于存储方法结果的目标向量.
返回： 交点。

.intersectsBox( box : Box3 ) : boolean

如果该光线与给定的盒子相交，则返回true。

box

要相交的框。
返回：该光线是否与给定的盒子相交是否给定盒子。

.intersectsPlane( plane : Plane ) : boolean

如果此射线与给定平面相交，则返回 true。

plane

要相交的平面。
返回：此射线是否与给定平面相交。

.intersectsSphere( sphere : Sphere ) : boolean

返回true 如果此光线与给定球体相交。

sphere

要相交的球体。
返回：此射线是否与给定球体相交。

.lookAt( v : Vector3 ) : Ray

调整光线方向以指向世界空间中的给定向量。

v

目标位置。
返回：对此射线的引用。

.recast( t : number ) : Ray

沿给定方向移动此光线的原点距离.

t

沿光线进行插值的距离.
返回：对此射线的引用。

.set( origin : Vector3, direction : Vector3 ) : Ray

通过复制给定值设置光线的分量.

origin

原点.
direction

The方向.
返回：对此射线的引用。
