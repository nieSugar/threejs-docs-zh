MorphAnimMesh

具有简单界面的特殊类型的动画网格 用于动画播放。它允许只播放一个动画 动画更改之间没有任何过渡或淡入淡出。

导入

MorphAnimMesh 是一个插件，必须显式导入，请参阅 安装#Addons.

import { MorphAnimMesh } from 'three/addons/misc/MorphAnimMesh.js';

构造函数

new MorphAnimMesh( geometry : BufferGeometry, material : Material | Array.<Material> )

构造一个新的变形动画网格。

geometry

网格体几何形状。
material

网格材质。

属性

.activeAction : AnimationAction

当前活动的动画动作。

默认为null.

.mixer : AnimationMixer

内部动画混合器。

方法

.playAnimation( label : string, fps : number )

播放定义的动画剪辑。实现假设动画 剪辑存储在 Object3D#animations 或几何体中。

label

动画剪辑的名称。
fps

动画剪辑的 FPS。

.setDirectionBackward()

将动画播放方向设置为“向后”。

.setDirectionForward()

将动画播放方向设置为“前进”.

.updateAnimation( delta : number )

更新网格体的动画。必须在动画循环内调用。

delta

以秒为单位的增量时间。
