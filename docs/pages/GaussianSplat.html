GaussianSplat

3D 高斯splat 几何图形的最小渲染器。

请注意，此类只能与WebGPURenderer 一起使用。的 支持 forceWebGL 后备 WebGPURenderer，但是 WebGLRenderer 不是。导入地图或包导出必须解决 three/webgpu 和 three/tsl.

代码示例

const splats = new GaussianSplat( geometry );
scene.add( splats );

导入

GaussianSplat 都是插件，必须显式导入，请参阅 Installation#Addons.

import { GaussianSplat } from 'three/addons/objects/GaussianSplat.js';

构造函数

new GaussianSplat( splatGeometry : BufferGeometry, options : Object )

构造一个新的高斯splat网格。

splatGeometry

要渲染的splat几何体。高阶球面谐波属性必须使用 createGaussianSplatGeometry 中的打包 Uint32Array 字（每个 splat SH_BAND_WORDS[ degree ] 字，每个 4 个钳位字节系数） word).
options

Options.

autoSort

是否在onBeforeRender中自动排序.

默认为true.

属性

.autoSort : boolean

是否在onBeforeRender中自动排序.

.boundingBox : Box3

splats的边界框。可以通过GaussianSplat#computeBoundingBox.

默认为null.

.boundingSphere : Sphere

计算板的边界球体。可以通过 GaussianSplat#computeBoundingSphere.

默认为null.

.isGaussianSplat : boolean (readonly)

该标志可用于类型测试。

默认为true.

.splatGeometry : BufferGeometry

源 splat 几何图形进行计算。

方法

.computeBoundingBox()

计算 splats 的边界框，更新 GaussianSplat#boundingBox.

Each splat 按其自身范围扩展，而不是视为一个点，因此边界覆盖 绘制的内容.

.computeBoundingSphere()

计算splats的边界球体，更新GaussianSplat#boundingSphere.

Each splat 按其自身范围扩展，而不是视为一个点，因此边界覆盖 绘制的内容.

.raycast( raycaster : Raycaster, intersects : Array.<Object> )

计算投射光线和splats之间的交点.

raycaster

The raycaster.
intersects

保存交点的目标数组。
覆盖： Mesh#raycast

.updateSort( renderer : Renderer, camera : Camera ) : boolean

如果相机或网格方向发生足够的变化，则更新绘制顺序 需要一个新的排序。

renderer

渲染器.
camera

用于渲染的相机。
返回：此调用是否调度了排序。

.updateSphericalHarmonics( renderer : Renderer, camera : Camera ) : boolean

如果相机或 网格变换已更改。

renderer

渲染器.
camera

用于渲染的相机。
返回： 此调用是否调度计算通道。
