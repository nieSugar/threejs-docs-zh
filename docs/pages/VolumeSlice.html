VolumeSlice

这个类用于保存卷数据的切片。

导入

VolumeSlice 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { VolumeSlice } from 'three/addons/misc/VolumeSlice.js';

构造函数

new VolumeSlice( volume : Volume, index : number, axis : 'x' | 'y' | 'z' )

构造一个新的卷片。

volume

关联的卷。
index

切片的索引。

默认为0.
axis

目前只有 'x'、'y' 或'z' 但稍后它将更改为法线向量。

默认为 'z'.
参见：
  • Volume

属性

.axis : 'x' | 'y' | 'z'

法线轴.

.canvas : HTMLCanvasElement

用于纹理的最终画布.

.canvasBuffer : HTMLCanvasElement

The用于绘制数据的中间画布。

.ctx : CanvasRenderingContext2D

画布的渲染上下文。

.ctxBuffer : CanvasRenderingContext2D

画布缓冲区的渲染上下文，

.geometryNeedsUpdate : boolean

如果设置为true，则将在以下位置触发updateGeometry()

默认为true.

.iLength : number

原始坐标系中切片的宽度，对应缓冲区画布的宽度。

默认为0.

.index : number

切片的索引，如果更改，下次重绘时会自动调用updateGeometry。

默认为0.

.jLength : number

原始坐标系中切片的高度，对应缓冲区的高度canvas.

默认为0.

.mesh : Mesh

准备在场景中使用的网格体。

.sliceAccess : function

允许切片访问正确数据的功能。

参见：
  • Volume#extractPerpendicularPlane

.volume : Volume

关联的卷。

方法

.repaint()

如果geometryNeedsUpdate设置为，则刷新纹理和几何体true.

.updateGeometry()

根据轴和索引刷新几何.

参见：
  • Volume#extractPerpendicularPlane
