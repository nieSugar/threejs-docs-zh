PassNode

表示后期处理上下文中的渲染通道（有时称为美感通道）。 此通道为给定场景和摄像机生成渲染，并可以提供多个输出 通过MRT进行进一步处理。

代码示例

const postProcessing = new RenderPipeline( renderer );
const scenePass = pass( scene, camera );
postProcessing.outputNode = scenePass;

构造函数

new PassNode( scope : 'color' | 'depth', scene : Scene, camera : Camera, options : Object )

构造一个新的pass节点。

scope

pass的范围。范围决定节点是否输出颜色或深度。
scene

对场景的引用.
camera

对相机的引用。
options

内部渲染目标的选项。

属性

.autoClear : boolean

渲染器是否应在渲染通道之前自动清除。

默认为true.

.autoClearColor : boolean

是否应清除颜色缓冲区。

默认为true.

.autoClearDepth : boolean

是否应清除深度缓冲区已清除.

默认为true.

.autoClearStencil : boolean

是否应清除模板缓冲区。

默认为true.

.camera : Camera

对相机的引用。

.contextNode : ContextNode | null

通道的可选全局上下文.

.global : boolean

使用此标志用于全局缓存。

默认为true.

覆盖： TempNode#global

.isPassNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.opaque : boolean

通道是否不透明。

默认为true.

.options : Object

内部渲染目标的选项。

.overrideMaterial : Material | null

通道的可选覆盖材质。

.renderTarget : RenderTarget

通道的渲染目标。

.scene : Scene

对场景的引用.

.scope : 'color' | 'depth'

pass的范围。范围决定节点是否输出颜色或深度。

.transparent : boolean

通道是否不透明透明.

默认为 false.

.updateBeforeType : string

updateBeforeType 被设置为 NodeUpdateType.FRAME，因为节点在其 PassNode#updateBefore 方法中每帧渲染场景一次。

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.COLOR : 'color'

.DEPTH : 'depth'

方法

.compileAsync( renderer : Renderer ) : Promise (async)

预编译通道。

注意，必须在通道配置完成后调用此方法。 因此像setMRT()和getTextureNode()这样的调用必须进行预编译。

renderer

渲染器.
参见：
  • Renderer#compileAsync
返回：编译完成后解析的Promise。

.dispose()

释放内部资源。应该在节点不再使用时调用。

覆盖： TempNode#dispose

.getLayers() : Layers

获取该通道的当前层配置。

返回： .

.getLinearDepthNode( name : string ) : Node

返回该通道的线性深度节点。

name

输出名称获取线性深度节点。在大多数情况下，可以使用默认的 'depth'，但自定义深度输出存在该参数。

默认为 'depth'.
返回： 线性深度节点.

.getMRT() : MRTNode

返回当前MRT节点。

返回： 当前 MRT 节点。

.getPreviousTexture( name : string ) : Texture

返回保存给定输出名称的前一帧数据的纹理。

name

获取纹理的输出名称.
返回：纹理保存前一帧的数据。

.getPreviousTextureNode( name : string ) : TextureNode

返回给定输出名称的前一个纹理节点。

name

获取前一个纹理节点的输出名称。

默认为'output'.
返回：前一个纹理节点。

.getResolution() : number

获取通道的当前分辨率。

已弃用：自 r181 起。请使用 `getResolutionScale()` 代替。
返回： 当前分辨率。 1 值表示全分辨率。

.getResolutionScale() : number

获取通道的当前分辨率比例。

返回：当前分辨率比例。 1 值表示全分辨率。

.getTexture( name : string ) : Texture

返回给定输出名称的纹理。

name

获取纹理的输出名称.
返回： 纹理.

.getTextureNode( name : string ) : TextureNode

返回给定输出的纹理节点name.

name

获取纹理节点的输出名称.

默认为'output'.
返回：纹理节点.

.getViewZNode( name : string ) : Node

返回此通道的viewZ节点。

name

获取viewZ节点的输出名称。在大多数情况下，可以使用默认的 'depth'，但自定义深度输出存在该参数。

默认为 'depth'.
返回： viewZ 节点。

.setLayers( layers : Layers ) : PassNode

设置渲染通道时应使用的图层配置。

layers

要设置的图层对象。
返回： 引用到此通道。

.setMRT( mrt : MRTNode ) : PassNode

设置给定的 MRT 节点以为此通道设置 MRT。

mrt

MRT 对象。
返回： 引用到此通道。

.setResolution( resolution : number ) : PassNode

设置此通道的分辨率。 分辨率是与渲染器的宽度和高度相乘的系数。

resolution

要设置的分辨率。 1 值表示全分辨率。
已弃用：自 r181 起。请使用 `setResolutionScale()` 代替。
返回： 引用到此通道。

.setResolutionScale( resolutionScale : number ) : PassNode

设置通道的分辨率比例。 分辨率比例是与渲染器的宽度和高度相乘的系数。

resolutionScale

要设置的分辨率比例。值为 1 表示全分辨率。
返回： 引用到此通道。

.setScissor( x : number | Vector4, y : number, width : number, height : number )

此方法允许定义通道的剪刀矩形。默认情况下，保留剪刀矩形 与通行证的尺寸同步。要反转该过程并再次使用自动调整大小，请调用该方法 以 null 作为单个参数。

x

以逻辑像素为单位的框左下角的水平坐标。 该方法不传递四个参数，而是使用单个四维向量。
y

以逻辑像素为单位的框左下角的垂直坐标。
width

以逻辑像素为单位的剪刀框的宽度。
height

以逻辑像素为单位的剪刀框的高度单位.

.setSize( width : number, height : number )

设置通道渲染目标的大小。遵循像素比。

width

要设置的宽度。
height

要设置的高度。

.setViewport( x : number | Vector4, y : number, width : number, height : number )

此方法允许定义通道的视口。默认情况下，视口保持同步 与通行证的尺寸。要反转该过程并再次使用自动调整大小，请调用该方法 以 null 作为单个参数。

x

水平坐标以逻辑像素为单位的视口原点左下角。
y

以逻辑像素为单位的视口原点左下角的垂直坐标。
width

以逻辑像素为单位的视口宽度。
height

以逻辑像素为单位的视口高度单位.

.toggleTexture( name : string )

切换给定输出名称的当前和先前纹理。

name

输出名称.
