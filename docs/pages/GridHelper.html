GridHelper

帮助器是一个定义网格的对象。网格是二维的 线数组。

代码示例

const size = 10;
const divisions = 10;
const gridHelper = new THREE.GridHelper( size, divisions );
scene.add( gridHelper );

构造函数

new GridHelper( size : number, divisions : number, color1 : number | Color | string, color2 : number | Color | string )

构造一个新的网格助手。

size

网格的大小。

默认为10.
divisions

网格上的划分数。

默认为10.
color1

中心的颜色line.

默认为 0x444444.
color2

网格线的颜色.

默认为0x888888.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose
