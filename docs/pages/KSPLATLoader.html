KSPLATLoader

GaussianSplats3D 的加载程序.ksplat files.

此加载器将该格式解码为 BufferGeometry 以便与 GaussianSplat 一起使用。高阶球谐函数以可选的 sphericalHarmonics1 的形式通过 sphericalHarmonics3 打包的 uint32 几何属性 (SH_BAND_WORDS[ degree ] 每个 splat 的字) 进行暴露。系数使用限制字节编码 ( value - 128 ) / 128，每个字四个字节。

代码示例

const loader = new KSPLATLoader();
const data = await loader.loadAsync( './models/gsplat/example.ksplat' );
scene.add( new GaussianSplat( data ) );

导入

KSPLATLoader 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { KSPLATLoader } from 'three/addons/loaders/KSPLATLoader.js';

构造函数

new KSPLATLoader( manager : LoadingManager )

构造一个新的高斯splat KSPLAT加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的URL加载并将加载的splat数据传递给 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( buffer : ArrayBuffer ) : BufferGeometry

解析给定的 .ksplat 数据。

buffer

作为数组缓冲区的原始 KSPLAT 文件。
覆盖： Loader#parse
返回：解析的 splat 几何图形.
