GLBufferAttribute

对 VBO 有更多控制的缓冲区属性的替代版本。

渲染器不会为此类属性构造 VBO。相反，它使用 无论 VBO 在构造函数中传递，稍后都可以通过 buffer 属性进行更改。

此类最常见的用例是当某种 GPGPU 计算干扰时 甚至生成有问题的 VBO。

注意，此类只能与 WebGLRenderer 一起使用。

构造函数

new GLBufferAttribute( buffer : WebGLBuffer, type : number, itemSize : number, elementSize : number, count : number, normalized : boolean )

构造一个新的 GL 缓冲区属性。

buffer

本机 WebGL buffer.
type

本机数据类型（例如 gl.FLOAT）.
itemSize

项目大小。
elementSize

给定 type 参数的相应大小（以字节为单位）。
count

预期顶点数在VBO中.
normalized

数据是否标准化或不是.

默认为 false.

属性

.buffer : WebGLBuffer

本机 WebGL buffer.

.count : number

预期顶点数在VBO中.

.elementSize : number

给定 type 参数的相应大小（以字节为单位）。

.isGLBufferAttribute : boolean (readonly)

该标志可用于类型测试。

默认为true.

.itemSize : number

项目大小，请参见BufferAttribute#itemSize.

.name : string

缓冲区属性的名称。

.needsUpdate : number

Flag 来指示该属性已更改，应重新发送到 GPU。修改数组值时，将其设置为 true。

默认为 false.

.normalized : boolean

仅适用于整数数据。指示缓冲区中的基础数据如何映射到 GLSL 代码中的值。例如，如果buffer包含gl.UNSIGNED_SHORT的数据， 并且normalized是true，缓冲区数据中的值0 - +65535将被映射到 GLSL 属性中的 0.0f - +1.0f。如果 normalized 是 false，则值将被转换 为未修改的浮点数，即 65535 变为 65535.0f.

.type : number

本机数据类型。

.version : number

A 版本号，每次将 needsUpdate 设置为true.

方法

buffer

缓冲区为set.
返回：对此实例的引用。

.setCount( count : number ) : BufferAttribute

设置计数（VBO 中的预期顶点数）。

count

计数。
返回：对此实例的引用。

.setItemSize( itemSize : number ) : BufferAttribute

设置项目大小。

itemSize

项目大小。
返回：对此实例的引用。

.setType( type : number, elementSize : number ) : BufferAttribute

设置给定的本机数据类型和元素尺寸.

type

本机数据类型（例如 gl.FLOAT）.
elementSize

给定 type 参数的相应大小（以字节为单位）。
返回：对此实例的引用。
