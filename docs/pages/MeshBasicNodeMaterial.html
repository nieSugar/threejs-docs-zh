MeshBasicNodeMaterial

MeshBasicMaterial的节点材质版本__.

构造函数

new MeshBasicNodeMaterial( parameters : Object )

构造一个新的网格基本节点材质.

parameters

配置参数.

属性

.isMeshBasicNodeMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.lights : boolean

虽然基本材质根据定义是不发光的，但我们设置 由于我们使用光照模型来计算，因此将此属性设置为 true 片段着色器的出射光。

默认为true.

覆盖： NodeMaterial#lights

方法

.setupEnvironment( builder : NodeBuilder ) : BasicEnvironmentNode.<vec3>

覆盖，因为此类材质使用 BasicEnvironmentNode 实现默认环境映射。

builder

当前节点构建器.
覆盖： NodeMaterial#setupEnvironment
返回： 环境节点。

.setupLightMap( builder : NodeBuilder ) : BasicLightMapNode.<vec3>

由于评估光照贴图，因此必须覆盖此方法 使用基本材质的特殊比例因子。

builder

当前节点构建器.
覆盖： NodeMaterial#setupLightMap
返回： 光照贴图节点。

.setupLightingModel() : BasicLightingModel

设置光照model.

覆盖： NodeMaterial#setupLightingModel
返回： 光照模型.

.setupNormal() : Node.<vec3>

基本材质不受法线贴图和凹凸贴图影响，因此我们 默认返回 normalViewGeometry.

覆盖： NodeMaterial#setupNormal
返回： 普通节点.

.setupOutgoingLight() : Node.<vec3>

材质覆盖此方法，因为 lights 设置为 true 但 我们仍然想返回漫反射颜色作为出射光。

覆盖： NodeMaterial#setupOutgoingLight
返回：出射光节点。
