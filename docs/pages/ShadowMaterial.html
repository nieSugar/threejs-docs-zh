ShadowMaterial

此材质可以接收阴影，但在其他方面是完全透明的。

代码示例

const geometry = new THREE.PlaneGeometry( 2000, 2000 );
geometry.rotateX( - Math.PI / 2 );
const material = new THREE.ShadowMaterial();
material.opacity = 0.2;
const plane = new THREE.Mesh( geometry, material );
plane.position.y = -200;
plane.receiveShadow = true;
scene.add( plane );

构造函数

new ShadowMaterial( parameters : Object )

构造一个新的阴影材质。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.color : Color

材质的颜色。

默认为(0,0,0).

.fog : boolean

材质是否受雾影响。

默认为true.

.isShadowMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.transparent : boolean

由于阴影材质是透明的而被覆盖 默认情况下.

默认为true.

覆盖： Material#transparent
