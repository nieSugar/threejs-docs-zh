MeshStandardMaterial

基于物理的标准材质，使用金属粗糙度工作流程。

基于物理的渲染 (PBR) 最近已成为许多领域的标准 3D 应用程序，例如 Unity， 虚幻 和 3D Studio Max.

此方法与旧方法的不同之处在于，它不使用 光与表面相互作用方式的近似值 使用物理上正确的模型。这个想法是，而不是调整 为了使材质在特定照明下看起来不错，可以创建材质 在所有照明场景下都会“正确”地做出反应。

实际上，这给出了比 MeshLambertMaterial 或 MeshPhongMaterial，代价是 计算成本更高。 MeshStandardMaterial 使用每个片段 阴影.

请注意，为了获得最佳结果，在使用此材质时应始终指定环境贴图。

有关 PBR 概念以及如何设置环境贴图的非技术介绍 PBR 材料，请查看 marmoset 上的人们的这些文章：

  • 基于物理的渲染基本理论
  • 基于物理的渲染，你也可以做到

Three.js（以及大多数其他 PBR 系统）中使用的方法的技术细节可以在这里找到 来自迪士尼的论文 (pdf)，作者：Brent Burley。

构造函数

new MeshStandardMaterial( parameters : Object )

构造新的网格标准材质。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.alphaMap : Texture

Alpha 贴图是一个灰度纹理，用于控制整个网格的不透明度 表面（黑色：完全透明；白色：完全不透明）.

仅使用纹理的颜色，如果有则忽略 alpha 通道 存在。对于 RGB 和 RGBA 纹理，渲染器将使用绿色通道 当采样该纹理时，由于提供了额外的精度 DXT 压缩和未压缩 RGB 565 格式中为绿色。仅亮度和 亮度/alpha 纹理也仍将按预期工作。

alphaMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.aoMap : Texture

此纹理的红色通道用作环境光遮挡贴图。 需要第二组 UV。

aoMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.aoMapIntensity : number

环境光遮挡效果的强度。范围为 [0,1]，其中 0 禁用环境光遮挡。其中强度为 1 且 AO 贴图的 红色通道也是1，环境光在表面上被完全遮挡。

默认为1.

.bumpMap : Texture

创建凹凸贴图的纹理。黑色和白色值映射到 与灯光相关的感知深度。碰撞实际上并没有影响 物体的几何形状，只有照明。如果定义了法线贴图 这将被忽略。

bumpMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.bumpScale : number

凹凸贴图对材质的影响程度。典型范围为[0,1].

默认为1.

.color : Color

材质的颜色。

默认为(1,1,1).

.displacementBias : number

的偏移量网格顶点上的置换贴图值。 偏差被添加到位移图的缩放样本中。 如果没有设置置换贴图，则不应用该值。

默认为0.

.displacementMap : Texture

位移贴图影响网格顶点的位置。不像 其他贴图仅影响材质的明暗 位移的顶点可以投射阴影、阻挡其他对象等等 充当真实的几何体。位移纹理是一个图像，其中的值 每个像素（白色是最高的）被映射，并且 重新定位，网格的顶点。为了获得最佳效果，请配对 具有匹配法线贴图的置换贴图，因为渲染器可以 不从移位的顶点重新计算表面法线。

displacementMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.displacementScale : number

位移贴图对网格的影响程度（其中黑色不存在） 位移，白色为最大位移）。无位移 地图集，不应用此值。

默认为0.

.emissive : Color

材质的发射（光）颜色，本质上是纯色 不受其他照明的影响。

默认为(0,0,0).

.emissiveIntensity : number

发射光的强度。调制发射颜色。

默认为1.

.emissiveMap : Texture

设置发射（发光）贴图。发射贴图颜色由 发射颜色和发射强度。如果您有自发光贴图， 请务必将发光颜色设置为黑色以外的颜色。

emissiveMap 表示颜色数据，并且纹理必须分配一个 Texture#colorSpace。大多数 emissiveMap 纹理设置 texture.colorSpace = SRGBColorSpace。

默认为null.

.envMap : Texture

环境贴图。为了确保物理上正确的渲染，环境贴图 内部经过PMREMGenerator.

envMap表示亮度数据，必须分配纹理 Texture#colorSpace。大多数 envMap 纹理集 texture.colorSpace = LinearSRGBColorSpace 并使用浮点型格式 例如.exr或.hdr.

默认为null.

.envMapIntensity : number

通过乘以环境贴图的颜色来缩放环境贴图的效果。

默认为1.

.envMapRotation : Euler

环境贴图的旋转弧度。

默认为(0,0,0).

.flatShading : boolean

是否使用平面着色渲染材质。

默认为 false.

.fog : boolean

材质是否受雾影响。

默认为true.

.isMeshStandardMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.lightMap : Texture

光照贴图。需要第二组UV。

lightMap表示预烘焙的照度数据，必须指定纹理 Texture#colorSpace。大多数 lightMap 纹理集 texture.colorSpace = LinearSRGBColorSpace 并使用浮点类型格式 例如 .exr 或 .hdr.

默认为null.

.lightMapIntensity : number

烘焙光强度。

默认为1.

.map : Texture

颜色图。可以选择包含 alpha 通道，通常是组合的 与 Material#transparent 或 Material#alphaTest。纹理贴图 颜色由漫反射color.

map 表示颜色数据，并且必须为纹理分配一个 Texture#colorSpace。大多数 map 纹理设置 texture.colorSpace = SRGBColorSpace。

默认为null.

.metalness : number

材料与金属的相似程度进行了预处理。木材等非金属材料 或石头使用0.0，金属使用1.0，中间没有任何东西（通常）。 0.0 和 1.0 之间的值可用于呈现生锈的金属外观。 如果还提供了metalnessMap，则两个值都会相乘。

默认为0.

.metalnessMap : Texture

此纹理的蓝色通道用于更改纹理的金属度 material.

metalnessMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）。

默认为null.

.normalMap : Texture

用于创建法线贴图的纹理。 RGB 值影响表面 每个像素片段的法线并更改颜色的点亮方式。正常 贴图不会改变表面的实际形状，只会改变照明。在 如果材质具有使用左手创作的法线贴图 约定，normalScale 的 y 组件应被否定以补偿 对于不同的惯用手。

normalMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.normalMapType : TangentSpaceNormalMap | ObjectSpaceNormalMap

法线贴图的类型。

默认为TangentSpaceNormalMap.

.normalScale : Vector2

法线贴图对材质的影响程度。典型值范围为 [0,1].

默认为 (1,1).

.roughness : number

材料看起来有多粗糙。 0.0表示平滑镜面反射，1.0 意思是完全扩散。如果还提供了roughnessMap， 两个值都相乘。

默认为1.

.roughnessMap : Texture

此纹理的绿色通道用于改变纹理的粗糙度 material.

roughnessMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.wireframe : boolean

将几何体渲染为线框。

默认为 false.

.wireframeLinecap : 'round' | 'bevel' | 'miter'

定义线框末端的外观。

只能与SVGRenderer.

默认为 'round'.

.wireframeLinejoin : 'round' | 'bevel' | 'miter'

定义线框接头的外观。

只能与SVGRenderer.

默认为 'round'.

.wireframeLinewidth : number

控制厚度线框的.

只能与SVGRenderer.

默认为1.
