VertexNormalsHelper

可视化对象的顶点法线。

要求已在几何体中将法线指定为缓冲区属性或 已使用 BufferGeometry#computeVertexNormals 计算。

代码示例

const geometry = new THREE.BoxGeometry( 10, 10, 10, 2, 2, 2 );
const material = new THREE.MeshStandardMaterial();
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );
const helper = new VertexNormalsHelper( mesh, 1, 0xff0000 );
scene.add( helper );

导入

VertexNormalsHelper 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { VertexNormalsHelper } from 'three/addons/helpers/VertexNormalsHelper.js';

构造函数

new VertexNormalsHelper( object : Object3D, size : number, color : number | Color | string )

构造一个新的顶点法线助手。

object

可视化顶点法线的对象。
size

助手的大小。

默认为1.
color

助手的color.

默认为0xff0000.

属性

.isVertexNormalsHelper : boolean (readonly)

该标志可用于类型测试。

默认为true.

.matrixAutoUpdate : boolean

覆盖并设置自对象世界变换以来到 false 在助手的几何数据中进行编码。

默认为 false.

覆盖： LineSegments#matrixAutoUpdate

.object : Object3D

可视化顶点法线的对象。

.size : number

助手的大小。

默认为1.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose

.update()

根据对象的世界变换更新顶点法线预览。
