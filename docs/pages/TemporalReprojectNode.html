TemporalReprojectNode

用于去噪屏幕空间效果（SSGI、SSR 等）的时间重投影通道。

两种模式共享几何加权 4 抽头双线性历史采样和 YCoCg 方差裁剪。 始终首先对表面速度重投影进行采样。然后混合镜面反射模式 该表面结果之上的击中点视差历史记录。 漫反射模式应用速度场发散来检测表面拉伸。

与基于抖动的 TAA/TAAU 不同，此节点不应用相机子像素抖动 - 它仅 使用运动向量重新投影和累积历史记录。

导入

TemporalReprojectNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { temporalReproject } from 'three/addons/tsl/display/TemporalReprojectNode.js';

属性

.accumulate : boolean

当true时，解析输出每帧都会复制到内部历史缓冲区中。 当 false 时，历史记录通过 TemporalReprojectNode#setHistoryTexture 从外部提供。

.mode : TemporalReprojectMode

方法

.setHistoryTexture( source : Object | Texture )

提供外部历史记录源（例如 RecurrentDenoiseNode 或其 纹理）。仅当 TemporalReprojectNode#accumulate 为 false.
