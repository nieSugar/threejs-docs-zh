StereoEffect

创建立体效果的类。

注意，此类只能与WebGLRenderer一起使用。 使用 WebGPURenderer 时，请使用 StereoPassNode.

导入

StereoEffect 是一个插件，必须显式导入，请参阅 安装#Addons.

import { StereoEffect } from 'three/addons/effects/StereoEffect.js';

构造函数

new StereoEffect( renderer : WebGLRenderer )

构造新的立体效果。

renderer

渲染器.

方法

.render( scene : Object3D, camera : Camera )

当使用此效果时，应调用此方法而不是 默认 WebGLRenderer#render.

scene

要渲染的场景.
camera

相机.

.setEyeSeparation( eyeSep : number )

设置给定的眼睛间距。

eyeSep

要设置的眼睛间距。

.setSize( width : number, height : number )

调整效果大小.

width

逻辑中效果的宽度像素.
height

逻辑像素中效果的高度.
