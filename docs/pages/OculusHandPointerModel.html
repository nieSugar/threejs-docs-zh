OculusHandPointerModel

表示 Oculus 手指针模型。

导入

OculusHandPointerModel 是一个插件，必须显式导入，请参阅 安装#Addons.

import { OculusHandPointerModel } from 'three/addons/webxr/OculusHandPointerModel.js';

构造函数

new OculusHandPointerModel( hand : Group, controller : Group )

构建新的 Oculus 手部模型。

hand

手部控制器。
controller

目标光线空间中的WebXR控制器.

属性

.attached : boolean

模型是否已附加.

默认为 false.

.controller : Group

目标光线空间中的WebXR控制器.

.cursorObject : Mesh

光标对象.

默认为null.

.hand : Group

手部控制器。

.pinched : boolean

模型是否被挤压.

默认为 false.

.pointerGeometry : BufferGeometry

指针几何体.

默认为null.

.pointerMesh : Mesh

指针网格.

默认为null.

.pointerObject : Object3D

容纳指针网格的指针对象.

默认为null.

.raycaster : Raycaster

内部用于检测的光线投射器 交集.

默认为null.

方法

.checkIntersections( objects : Array.<Object3D>, recursive : boolean )

检查模型的光线投射器和给定对象之间的交集。方法 将光标对象更新到交点。

objects

要检查与射线是否相交的 3D 对象。
recursive

如果设置为 true，它还会检查所有后代。 否则，它仅检查与对象的相交。

默认为 false.

.createPointer()

创建指针网格并将其添加到此模型。

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Object3D#dispose

.intersectObject( object : Object3D, recursive : boolean ) : Array.<Raycaster~Intersection>

执行模型的光线投射器和给定对象的相交测试。

object

要检查与ray.
recursive

如果设置为 true，它还会检查所有后代。 否则，它仅检查与对象的相交。

默认为true.
返回： 保存交点的数组。

.intersectObjects( objects : Array.<Object3D>, recursive : boolean ) : Array.<Raycaster~Intersection>

与模型的光线投射器和给定对象执行相交测试。

objects

要检查与射线是否相交的 3D 对象。
recursive

如果设置为 true，它还会检查所有后代。 否则，它仅检查与对象的相交。

默认为true.
返回： 保存交点的数组。

.isAttached() : boolean

返回 true 是模型Attached.

返回： 模型是否已附加。

.isPinched() : boolean

Returns true 是否模型被捏住。

返回： 模型是否被捏住not.

.setAttached( attached : boolean )

设置附加状态。

attached

模型是否已附加.

.setCursor( distance : number )

将光标设置到给定距离。

distance

将光标设置到的距离。

.updateMatrixWorld( force : boolean )

用自定义实现覆盖。确保内部指针和光线投射器已更新。

force

当设置为true时，甚至会强制重新计算世界矩阵 当 Object3D#matrixWorldAutoUpdate 设置为 false.

默认为 false.
覆盖： Object3D#updateMatrixWorld
