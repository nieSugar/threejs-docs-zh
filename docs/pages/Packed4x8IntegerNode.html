Packed4x8IntegerNode

表示 WGSL 的内置函数之一 packed_4x8_integer_dot_product 语言扩展。如果扩展不可用，节点将回退到 使用普通整数位操作进行仿真。

构造函数

new Packed4x8IntegerNode( method : string, aNode : Node, bNode : Node )

构造一个压缩的 4x8 整数函数节点。

method

WGSL 内置函数名称。
aNode

第一个参数。
bNode

可选的第二个参数参数.

默认为null.

属性

.aNode : Node

第一个参数。

.bNode : Node

可选的第二个参数参数.

.isPacked4x8IntegerNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.method : string

WGSL 内置函数名称。
