ViewportDepthNode

此节点提供片段着色器中深度逻辑上下文中的功能集合。 根据ViewportDepthNode#scope，它可用于定义当前的深度值 片段或用于深度评估目的。

构造函数

new ViewportDepthNode( scope : 'depth' | 'depthBase' | 'linearDepth', valueNode : Node )

构造一个新的视口深度节点。

scope

节点的范围。
valueNode

值节点。

默认为null.

属性

.isViewportDepthNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.scope : 'depth' | 'depthBase' | 'linearDepth'

根据选择的范围，该节点的行为有所不同。

  • ViewportDepthNode.DEPTH_BASE: 允许为当前片段的深度定义一个值。
  • ViewportDepthNode.DEPTH：表示当前片段的深度值（valueNode 被忽略）。
  • ViewportDepthNode.LINEAR_DEPTH: 表示当前片段的线性（正射）深度值。 如果设置了 valueNode，则可以使用该范围将透视深度数据转换为线性数据。

.valueNode : Node

可用于定义自定义深度值。 该属性在 ViewportDepthNode.DEPTH 范围内被忽略。

默认为null.
