CSS2DObject

CSS2DRenderer.

导入

CSS2DObject 支持的唯一 3D 对象类型是一个插件，并且必须是显式导入，请参阅 Installation#Addons.

import { CSS2DObject } from 'three/addons/renderers/CSS2DRenderer.js';

构造函数

new CSS2DObject( element : HTMLElement )

构造一个新的 CSS2D 对象。

element

DOM 元素。

属性

.center : Vector2

对象的锚点，以及对象旋转的点。 值 (0.5, 0.5) 对应于对象的中点。一个值 (0, 0) 对应于对象的左上角。

默认为 (0.5,0.5).

.element : HTMLElement (readonly)

定义此 3D 对象外观的 DOM 元素。

默认为true.

.isCSS2DObject : boolean (readonly)

该标志可用于类型测试。

默认为true.

.rotation2D : number

The物体的旋转角度，逆时针，以弧度为单位。

默认为0.
