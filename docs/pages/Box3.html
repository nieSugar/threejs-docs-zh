Box3

表示 3D 空间中的轴对齐边界框 (AABB)。

构造函数

new Box3( min : Vector3, max : Vector3 )

构造一个新的边界框。

min

表示边界框下边界的向量box.

默认为(Infinity,Infinity,Infinity).
max

表示框上边界的向量.

默认为 (-Infinity,-Infinity,-Infinity).

属性

.isBox3 : boolean (readonly)

该标志可用于类型测试。

默认为true.

.max : Vector3

盒子的上边界。

.min : Vector3

盒子的下边界。

.expandByObject( object : Object3D, precise : boolean ) : Box3

扩展此框的边界以包含给定的 3D 对象，并且 它的孩子，解释对象的世界和孩子的世界 转变。该函数可能会产生比严格意义上更大的框 必要（除非精确参数设置为 true）。

object

应扩展边界框的 3D 对象。
precise

如果设置为 true，该方法将扩展边界框 以更多计算为代价尽可能少。

默认为 false.
返回：对此边界框的引用。

.expandByScalar( scalar : number ) : Box3

.expandByVector( vector : Vector3 ) : Box3

按给定向量等边扩展此框。这个的宽度 box 将被两个向量的 x 分量扩展 方向。该框的高度将按 y 分量扩展 两个方向上的向量。这个盒子的深度是 在两个方向上按向量的 z 分量展开。

vector

应扩展边界框的向量。
返回：对此边界框的引用。

.setFromObject( object : Object3D, precise : boolean ) : Box3

计算给定 3D 对象的世界轴对齐边界框 （包括其子对象），考虑对象的和子对象的， 世界发生转变。该函数可能会产生比严格必要的更大的框。

注意：要计算正确的边界框，请确保给定的 3D 对象 有一个最新的世界矩阵，反映了其当前的转变 祖先节点。如果存在以下情况，请提前调用 object.updateWorldMatrix( true, false ) 你不确定.

object

计算边界框的3D对象.
precise

如果设置为true，该方法计算最小的 世界轴对齐的边界框，但代价是更多的计算。

默认为 false.
返回：对此边界框的引用。
