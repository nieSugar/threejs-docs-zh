ParametricGeometry

此类可用于生成基于参数化曲面的几何图形。

参考： Mesh Generation with Python

代码示例

const geometry = new ParametricGeometry( klein, 25, 25 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const klein = new THREE.Mesh( geometry, material );
scene.add( klein );

导入

ParametricGeometry 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ParametricGeometry } from 'three/addons/geometries/ParametricGeometry.js';

构造函数

new ParametricGeometry( func : ParametricGeometry~Func, slices : number, stacks : number )

构造一个新的参数化几何体。

func

参数化函数。默认是生成曲面的函数。
slices

参数函数使用的切片数。

默认为 8.
stacks

用于参数函数的切片堆栈。

默认为 8.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

类型定义

.Func( u : number, v : number, target : Vector3 )

ParametricGeometry 的参数函数定义.

u

范围内的曲面上的 u 坐标[0,1].
v

[0,1] 范围内的曲面上的 v 坐标。
target

用于存储方法结果的目标向量.
