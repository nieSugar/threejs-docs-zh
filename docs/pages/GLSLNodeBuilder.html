GLSLNodeBuilder

针对 GLSL 的节点生成器.

此模块生成 GLSL 着色器来自节点材料的代码以及 生成相应的绑定和顶点缓冲区定义。这些 渲染器稍后使用数据来创建渲染和计算管道 用于渲染对象。

构造函数

new GLSLNodeBuilder( object : Object3D, renderer : Renderer )

构造一个新的 GLSL 节点生成器渲染器。

object

3D对象.
renderer

渲染器.

属性

.builtins : Object.<string, Array.<string>>

为每个着色器阶段保存一个已用内置函数数组的字典。

.extensions : Object.<string, Map.<string, Object>>

为每个着色器阶段保存一个已用映射的字典扩展.

.transforms : Array.<Object.<string, (AttributeNode|string)>>

一个数组，用于保存定义变量和属性数据的对象 变换反馈的上下文.

.uniformGroups : Object.<string, Object.<string, NodeUniformsGroup>>

每个着色器阶段都有一个字典（'顶点'，'片段'，'计算'） 另一个管理每组 UBO（“渲染”、“帧”、“对象”）的字典。
