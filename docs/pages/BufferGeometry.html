BufferGeometry

网格、线或点几何图形的表示。包括顶点 位置、面索引、法线、颜色、UV 和自定义属性 在缓冲区内，减少将所有这些数据传递到 GPU 的成本。

代码示例

const geometry = new THREE.BufferGeometry();
// create a simple square shape. We duplicate the top left and bottom right
// vertices because each vertex needs to appear once per triangle.
const vertices = new Float32Array( [
	-1.0, -1.0,  1.0, // v0
	 1.0, -1.0,  1.0, // v1
	 1.0,  1.0,  1.0, // v2
	 1.0,  1.0,  1.0, // v3
	-1.0,  1.0,  1.0, // v4
	-1.0, -1.0,  1.0  // v5
] );
// itemSize = 3 because there are 3 values (components) per vertex
geometry.setAttribute( 'position', new THREE.BufferAttribute( vertices, 3 ) );
const material = new THREE.MeshBasicMaterial( { color: 0xff0000 } );
const mesh = new THREE.Mesh( geometry, material );

构造函数

new BufferGeometry()

构造一个新的几何图形。

属性

.attributes : Object.<string, (BufferAttribute|InterleavedBufferAttribute)>

此字典具有要设置的属性名称作为 id 和值 要设置的缓冲区属性。而不是直接访问此属性， 使用 setAttribute() 和 getAttribute() 访问该几何体的属性。

.boundingBox : Box3

可以使用 computeBoundingBox() 计算的几何体的边界框。

默认为null.

.boundingSphere : Sphere

几何体的包围球可以通过 computeBoundingSphere() 计算。

默认为null.

.drawRange : Object

确定要渲染的几何体部分。这不应该直接设置， 而是使用 setDrawRange().

.groups : Array.<Object>

将几何体分成几组，每个组都将渲染在 单独的绘制调用。这允许将一组材质与几何体一起使用。

使用 addGroup() 和 clearGroups() 来编辑组，而不是直接修改此数组。

每个顶点和索引必须完全属于一个组 — 组不得共享顶点或 索引，并且不得保留未使用的顶点或索引。

.id : number (readonly)

几何图形的 ID。

.index : BufferAttribute

允许在多个三角形中重复使用顶点；这是 称为使用“索引三角形”。每个三角形都与 三个顶点的索引。因此，该属性存储的索引 每个三角形面的每个顶点。如果未设置该属性，则 渲染器假定每三个连续位置代表一个三角形。

默认为null.

.indirect : BufferAttribute

A（存储）缓冲区属性，由计算着色器生成，并且 现在定义间接绘制调用。

只能与WebGPURenderer和WebGPU后端一起使用。

默认为null.

.indirectOffset : number | Array.<number>

值数据开始的间接绘制缓冲区的偏移量（以字节为单位）。如果提供了数组，将为每个偏移量进行多次间接绘制调用。

只能与WebGPURenderer和WebGPU后端一起使用。

默认为0.

.isBufferGeometry : boolean (readonly)

该标志可用于类型测试。

默认为true.

.morphAttributes : Object

此字典保存几何体的变形目标。

注意：一旦渲染了几何体，变形属性数据就无法使用 被改变。您必须调用dispose()，并创建一个新的几何实例。

.morphTargetsRelative : boolean

用于控制变形目标行为；当设置为 true 时，变形 目标数据被视为相对偏移，而不是绝对偏移 位置/法线.

默认为 false.

.name : string

几何体的名称.

.userData : Object

可用于存储有关几何体的自定义数据的对象。 它不应包含对函数的引用，因为这些函数不会被克隆。

.uuid : string (readonly)

几何图形的 UUID。

.computeBoundingBox()

计算几何图形的边界框，并更新 boundingBox 成员。 边界框不是由引擎计算的；它必须由您的应用程序计算。 如果几何体顶点被修改，您可能需要重新计算边界框。

.computeBoundingSphere()

计算几何体的边界球体，并更新boundingSphere成员。 引擎会在需要时自动计算边界球体，例如用于光线投射或视锥体剔除。 如果几何体顶点被修改，您可能需要重新计算边界球体。

.computeTangents()

计算并向该几何体添加切线属性。

仅支持索引几何体以及位置、法线和 uv 属性的计算 被定义。当使用切线空间法线贴图时，更喜欢由 MikkTSpace 提供的算法 BufferGeometryUtils#computeMikkTSpaceTangents 改为 .

.computeVertexNormals()

计算给定顶点数据的顶点法线。对于索引几何图形，该方法设置 每个顶点法线是共享该顶点的面的面法线的平均值。 对于非索引几何体，顶点不共享，该方法设置每个顶点法线 与面法线相同。
