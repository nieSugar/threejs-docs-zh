RenderTransitionPass

用于实现过渡效果的特殊类型的渲染通道。 激活后，通道将从场景 A 过渡到场景 B。

代码示例

const renderTransitionPass = new RenderTransitionPass( fxSceneA.scene, fxSceneA.camera, fxSceneB.scene, fxSceneB.camera );
renderTransitionPass.setTexture( textures[ 0 ] );
composer.addPass( renderTransitionPass );

导入

RenderTransitionPass 是一个插件，必须显式导入，请参阅 安装#Addons.

import { RenderTransitionPass } from 'three/addons/postprocessing/RenderTransitionPass.js';

构造函数

new RenderTransitionPass( sceneA : Scene, cameraA : Camera, sceneB : Scene, cameraB : Camera )

构造渲染过渡通道。

sceneA

第一个场景.
cameraA

第一个场景的相机.
sceneB

第二个场景.
cameraB

第二个场景的摄像机.

属性

.cameraA : Camera

第一个场景的相机.

.cameraB : Camera

第二个场景的摄像机.

.material : ShaderMaterial

通道材质.

.sceneA : Scene

第一个场景.

.sceneB : Scene

第二个场景.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行过渡通道.

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize

.setTexture( value : Texture )

设置效果纹理.

value

效果纹理.

.setTextureThreshold( value : boolean | number )

设置纹理阈值。该值定义纹理效果的强度 过渡。必须在[0,1]范围内（0表示完全影响，1表示无影响）。

value

阈值。

.setTransition( value : boolean | number )

设置过渡因子。必须在 [0,1] 范围内。 该值决定两个场景混合的程度。

value

过渡因子。

.useTexture( value : boolean )

切换效果纹理的使用。

value

是否使用纹理过渡效果。
