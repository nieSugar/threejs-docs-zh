ModelNode

这种类型的节点是 Object3DNode 的专门版本 具有更大的模型相关指标集。与 Object3DNode 不同， ModelNode 从 中提取对 3D 对象的引用 当前节点框架状态。

构造函数

new ModelNode( scope : 'position' | 'viewPosition' | 'direction' | 'scale' | 'worldMatrix' )

构造一个新的对象模型节点。

scope

该节点根据范围表示不同类型的转换。

方法

.update( frame : NodeFrame )

从框架状态中提取模型引用，然后 根据范围更新统一值。

frame

当前节点框架.
覆盖： Object3DNode#update
