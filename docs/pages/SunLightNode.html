SunLightNode

用于将太阳光表示为节点的模块。注册它与 渲染器的节点库使用 SunLight 和 WebGPURenderer:

代码示例

renderer.library.addLight( SunLightNode, SunLight );

导入

SunLightNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { SunLightNode } from 'three/addons/lights/SunLightNode.js';

构造函数

new SunLightNode( light : SunLight )

构造一个新的太阳光节点.

light

太阳光源.

默认为null.

方法

.setupShadowNode() : SunShadowNode

覆盖以设置太阳光的级联阴影.

覆盖： AnalyticLightNode#setupShadowNode
返回：创建的阴影节点。
