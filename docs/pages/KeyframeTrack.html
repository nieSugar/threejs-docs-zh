KeyframeTrack

表示关键帧的定时序列，由以下列表组成 时间和相关值，用于为特定属性设置动画 对象的.

构造函数

new KeyframeTrack( name : string, times : Array.<number>, values : Array.<(number|string|boolean)>, interpolation : InterpolateLinear | InterpolateDiscrete | InterpolateSmooth | InterpolateBezier )

构造一个新的关键帧轨道.

name

关键帧轨道的名称。
times

关键帧时间列表。
values

关键帧值列表。
interpolation

插值类型.

属性

.DefaultInterpolation : InterpolateLinear | InterpolateDiscrete | InterpolateSmooth | InterpolateBezier

此关键帧的默认插值类型track.

默认为InterpolateLinear.

.TimeBufferType : TypedArray | Array

该关键帧轨道的时间缓冲区类型.

默认为Float32Array.constructor.

.ValueBufferType : TypedArray | Array

此关键帧的值缓冲区类型track.

默认为Float32Array.constructor.

.ValueTypeName : string

值类型名称.

默认为 ''.

.name : string

轨道的名称可以引用变形目标或骨骼或 动画对象中可能有其他值。请参阅 PropertyBinding#parseTrackName 可解析属性绑定的字符串形式。

.times : Float32Array

关键帧时间。

.values : Float32Array

关键帧值。

方法

.InterpolantFactoryMethodBezier( result : TypedArray ) : BezierInterpolant

用于创建新贝塞尔插值的工厂方法。

贝塞尔插值需要切线通过 settings 属性设置的数据 在创建插值之前在轨道上。设置应包含：

  • inTangents: 每个组件每个关键帧带有 [时间, 数值] 对的 Float32Array
  • outTangents：每个组件每个关键帧的 [时间, 值] 对组成的 Float32Array
result

结果缓冲区.
返回： 新插值。

.InterpolantFactoryMethodDiscrete( result : TypedArray ) : DiscreteInterpolant

用于创建新离散插值的工厂方法。

result

结果缓冲区.
返回： 新插值。

.InterpolantFactoryMethodLinear( result : TypedArray ) : LinearInterpolant

用于创建新线性插值的工厂方法interpolant.

result

结果缓冲区.
返回： 新插值。

.InterpolantFactoryMethodSmooth( result : TypedArray ) : CubicInterpolant

用于创建新的平滑插值的工厂方法。

result

结果缓冲区.
返回： 新插值。

.clone() : KeyframeTrack

返回一个新的关键帧轨道，其中包含从此实例复制的值。

返回：此克隆instance.

.getInterpolation() : InterpolateLinear | InterpolateDiscrete | InterpolateSmooth | InterpolateBezier

返回当前插值类型。

返回： 插值类型。

.getValueSize() : number

返回值大小。

返回：值大小。

.optimize() : KeyframeTrack

优化此通过删除等效的顺序键（即 常见于变形目标序列中）。

返回：对此关键帧轨道的引用。

.scale( timeScale : number ) : KeyframeTrack

按一个因子缩放所有关键帧时间（对于帧 - 秒转换有用）。

timeScale

时间比例.
返回：对此关键帧轨道的引用。

.setInterpolation( interpolation : InterpolateLinear | InterpolateDiscrete | InterpolateSmooth | InterpolateBezier ) : KeyframeTrack

定义此关键帧轨道的插值因子方法。

interpolation

插值类型.
返回：对此关键帧轨道的引用。

.shift( timeOffset : number ) : KeyframeTrack

在时间上向前或向后移动所有关键帧。

timeOffset

移动时间值的偏移量。
返回：对此关键帧轨道的引用。

.trim( startTime : number, endTime : number ) : KeyframeTrack

删除动画前后的关键帧，不带更改定义时间范围内的任何值。

注意：该方法不会将关键点移动到轨道时间的开头，因为对于插值 键这将更改其值

startTime

开始时间.
endTime

结束时间.
返回：对此关键帧轨道的引用。

.validate() : boolean

在关键帧轨道上执行最小验证。如果值返回 true 有效。

返回： 关键帧是否有效。

静态方法

.toJSON( track : KeyframeTrack ) : Object

将关键帧轨迹转换为 JSON。

track

将关键帧轨迹转换为 JSON。序列化.
返回： JSON 形式的序列化关键帧轨道.
