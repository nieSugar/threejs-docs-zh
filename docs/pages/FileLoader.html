FileLoader

A low用于使用 Fetch API 加载资源的级别类，由内部使用 大多数装载机。它还可以直接用于加载任何文件类型 没有加载器。

此加载器支持缓存。如果要使用，请添加THREE.Cache.enabled = true; 一次到您的应用程序。

代码示例

const loader = new THREE.FileLoader();
const data = await loader.loadAsync( 'example.txt' );

构造函数

new FileLoader( manager : LoadingManager )

构造一个新的文件加载器。

manager

加载管理器。

属性

.mimeType : string

预期的 mime 类型。可以找到有效值 此处

.responseType : 'arraybuffer' | 'blob' | 'document' | 'json' | ''

预期的响应类型。

默认为 ''.

方法

.abort() : FileLoader

中止正在进行的提取requests.

覆盖： Loader#abort
返回：对此实例的引用。

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定 URL 加载并将加载的响应传递给 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.setMimeType( value : string ) : FileLoader

设置预期已加载文件的 mime 类型。

value

mime 类型。
返回： 对此文件加载器的引用。

.setResponseType( value : 'arraybuffer' | 'blob' | 'document' | 'json' | '' ) : FileLoader

设置预期响应类型。

value

响应类型.
返回： 对此文件加载器的引用。
