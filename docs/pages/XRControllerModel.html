XRControllerModel

表示 XR 控制器模型。

构造函数

new XRControllerModel()

构造新的 XR 控制器模型。

属性

.envMap : Texture

控制器的环境map.

默认为null.

.motionController : MotionController

运动控制器.

默认为null.

方法

.setEnvironmentMap( envMap : Texture ) : XRControllerModel

设置应用于控制器模型的环境映射。

envMap

要应用的环境映射。
返回：对此实例的引用。

.updateMatrixWorld( force : boolean )

用自定义实现覆盖。从 XRInputSource 轮询数据并更新 模型的组件与现实世界数据相匹配。

force

当设置为true时，甚至会强制重新计算世界矩阵 当 Object3D#matrixWorldAutoUpdate 设置为 false.

默认为 false.
覆盖： Object3D#updateMatrixWorld
