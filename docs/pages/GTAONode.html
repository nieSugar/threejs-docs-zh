GTAONode

用于将地面实况环境光遮挡 (GTAO) 应用于场景的后处理节点。

参考：准确间接的实用实时策略遮挡.

代码示例

const renderPipeline = new THREE.RenderPipeline( renderer );
// pre-pass for normals and depth
const prePass = pass( scene, camera );
prePass.setMRT( mrt( {
	output: normalView
} ) );
const prePassNormal = prePass.getTextureNode();
const prePassDepth = prePass.getTextureNode( 'depth' );
// scene pass
const scenePass = pass( scene, camera );
// ao
const aoPass = ao( prePassDepth, prePassNormal, camera );
const aoPassOutput = aoPass.getTextureNode();
// apply the ambient occlusion to the scene
scenePass.contextNode = builtinAOContext( aoPassOutput.sample( screenUV ).r );
renderPipeline.outputNode = scenePass;

导入

GTAONode是一个插件，必须显式导入，请参阅Installation#Addons.

import { ao } from 'three/addons/tsl/display/GTAONode.js';

构造函数

new GTAONode( depthNode : Node.<float>, normalNode : Node.<vec3>, camera : Camera )

构造一个新的GTAO 节点.

depthNode

表示场景深度的节点。
normalNode

表示场景法线的节点。
camera

渲染场景的相机。

属性

.depthNode : Node.<float>

表示场景深度的节点。

.distanceExponent : UniformNode.<float>

已弃用：自 r186 起。新的距离模型“二次射线步进” 不再需要它了。

.distanceFallOff : UniformNode.<float>

已弃用：自 r186 起。新的距离模型“二次射线步进” 不再需要它了。

.normalNode : Node.<vec3>

表示场景法线的节点。如果没有法线传递给 构造函数（因为MRT不可用），法线可以自动 根据着色器中的深度值重建。

.radius : UniformNode.<float>

环境光遮挡的半径。

.resolutionScale : number

分辨率比例。默认情况下，效果以全分辨率渲染 为了获得最佳质量，但 0.5 的值对于大多数场景来说应该足够了。

默认为1.

.samples : UniformNode.<float>

使用多少个样本来计算 AO。 更高的价值会带来更好的质量，但同时 在更昂贵的运行时行为中。

注意：更改此成员会触发着色器重新编译。

.scale : UniformNode.<float>

环境光遮挡的比例。

.thickness : UniformNode.<float>

环境光遮挡的厚度。

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.useTemporalFiltering : boolean

是否使用时间过滤。将此属性设置为 true 需要使用 TRAANode。这将有助于减少噪音 尽管它引入了典型的 TAA 伪影，例如重影和时间 不稳定性.

如果将此属性设置为 false，则通过 DenoiseNode 进行手动降噪 可能需要.

默认为 false.

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
