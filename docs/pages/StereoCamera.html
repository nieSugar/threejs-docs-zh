StereoCamera

使用两个透视相机的特殊类型相机 立体投影。可用于渲染立体效果 例如 3D Anaglyph 或 视差屏障.

构造函数

new StereoCamera()

构造一个新的立体相机。

属性

.aspect : number

方面.

默认为1.

.cameraL : PerspectiveCamera

代表左眼的相机。这被添加到图层 1 中，以便对象 左相机渲染的也必须添加到该层。

.cameraR : PerspectiveCamera

代表右眼的相机。这被添加到图层 2 中，以便对象 右侧相机渲染的也必须添加到该图层中。

.eyeSep : number

代表距离的眼睛间距 左右相机之间。

默认值为 0.064.

.type : string (readonly)

type属性用于检测对象类型 在序列化/反序列化的上下文中。

方法

.update( camera : PerspectiveCamera )

根据给定的透视相机更新立体相机。

camera

透视相机.
