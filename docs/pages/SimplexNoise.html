SimplexNoise

提供噪声函数的实用程序类。

代码基于 单纯形噪声揭秘 作者：Stefan Gustavson，2005.

导入

SimplexNoise 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { SimplexNoise } from 'three/addons/math/SimplexNoise.js';

构造函数

new SimplexNoise( r : Object )

构造一个新的单纯形噪声对象。

r

包含 random() 方法的数学实用程序类。这使得 可以传入自定义随机数生成器。

默认为 Math.

方法

.noise( xin : number, yin : number ) : number

A 2D 单纯形噪声方法。

xin

x 坐标。
yin

y 坐标。
返回：噪声值.

.noise3d( xin : number, yin : number, zin : number ) : number

A 3D 单纯形噪声方法.

xin

x 坐标。
yin

y 坐标。
zin

z坐标.
返回：噪声值.

.noise4d( x : number, y : number, z : number, w : number ) : number

A 4D单纯形噪声方法.

x

x 坐标。
y

y 坐标。
z

z坐标.
w

w坐标.
返回：噪声值.
