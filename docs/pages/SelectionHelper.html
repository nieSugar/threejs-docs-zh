SelectionHelper

A helper for SelectionBox.

它使用 div 容器可视化当前选择框element.

导入

SelectionHelper 是一个插件，必须显式导入，请参阅Installation#Addons.

import { SelectionHelper } from 'three/addons/interactive/SelectionHelper.js';

构造函数

new SelectionHelper( renderer : WebGPURenderer | WebGLRenderer, cssClassName : string )

构造一个新选择helper.

renderer

渲染器.
cssClassName

div的CSS类名.

属性

.element : HTMLDivElement

选择框的可视化.

.enabled : boolean

是否启用helper.

默认为true.

.isDown : boolean

是否鼠标或指针按下.

默认为 false.

.renderer : WebGPURenderer | WebGLRenderer

对渲染器.

方法

.dispose()

如果不再需要使用控件，请调用此方法。它释放了所有内部 资源并删除所有事件侦听器。
