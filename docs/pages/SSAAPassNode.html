SSAAPassNode

一个特殊的渲染通道节点，使用 SSAA（超级采样抗锯齿）渲染场景。 这种手动 SSAA 方法会通过相机抖动重新渲染每个样本的场景并累积结果。

该节点产生高质量的抗锯齿输出，但也非常昂贵，因为 它多次重新渲染整个场景的强力方法。

参考：https://en.wikipedia.org/wiki/Supersampling

导入

SSAAPassNode 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { ssaaPass } from 'three/addons/tsl/display/SSAAPassNode.js';

构造函数

new SSAAPassNode( scene : Scene, camera : Camera )

构造新的SSAA通关节点。

scene

要渲染的场景.
camera

用于渲染场景的相机。

属性

.isSSAAPassNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.sampleLevel : number

指定样本级别为n，其中样本数量为2^n， 所以sampleLevel = 4，是2^4个样本，16.

默认为4.

.sampleWeight : UniformNode.<float>

代表样本权重的统一节点。

默认为1.

.unbiased : boolean

是否应减少舍入误差。

默认为true.

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要该通道时。

覆盖： PassNode#dispose

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的 MRT 配置和四边形网格。

builder

当前节点构建器.
覆盖： PassNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每次渲染一次 SSAA 效果框架.

frame

当前节点框架.
覆盖： PassNode#updateBefore
