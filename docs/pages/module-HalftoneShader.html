HalftoneShader

导入

HalftoneShader 是一个插件，必须显式导入，请参阅 安装#Addons.

import { HalftoneShader } from 'three/addons/shaders/HalftoneShader.js';

属性

.HalftoneShader : ShaderMaterial~Shader (inner, constant)

RGB半色调着色器.

由HalftonePass使用.

形状（1 = 点，2 = 椭圆，3 = 线，4 =方形，5 = 菱形） 混合模式（1 = 线性、2 = 相乘、3 = 加法、4 = 较亮、5 = 较暗）
