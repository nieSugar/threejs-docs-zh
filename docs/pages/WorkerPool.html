WorkerPool

用于管理 Web Workers 的简单池。

导入

WorkerPool 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { WorkerPool } from 'three/addons/utils/WorkerPool.js';

构造函数

new WorkerPool( pool : number )

构造一个新的Worker池。

pool

的大小pool.

默认为4.

Classes

WorkerPool

属性

.pool : number

的大小pool.

默认为4.

.queue : Array.<Object>

消息队列.

.workerCreator : function

用于创建worker的工厂函数.

.workerStatus : number

当前worker status.

.workers : Array.<Worker>

Workers 数组.

.workersResolve : Array.<function()>

带有消息解析函数的数组.

方法

.dispose()

终止此池中的所有 Worker。每当这个时候调用这个方法 您的应用程序中不再使用工作线程池。

.postMessage( msg : Object, transfer : Array.<ArrayBuffer> ) : Promise

向空闲的工作线程发送消息。如果没有可用的工人， 消息被推入消息队列以供稍后处理。

msg

消息。
transfer

带有用于数据传输的数组缓冲区的数组。
返回：当消息被处理时解析的 Promise已处理.

.setWorkerCreator( workerCreator : function )

设置负责创建Worker的函数.

workerCreator

worker创建者函数.

.setWorkerLimit( pool : number )

设置Worker限制

pool

的大小pool.
