Matrix2

表示一个 2x2 矩阵。

A 关于行主和列主排序的注释：

构造函数和Matrix2#set 方法接受参数 行优先 顺序，而在内部它们以列优先顺序存储在 Matrix2#elements 数组中。 这意味着调用：

const m = new THREE.Matrix2();
m.set( 11, 12,
       21, 22 );

将导致元素数组包含：

m.elements = [ 11, 21,
               12, 22 ];

并且在内部所有计算都使用列优先顺序执行。 然而，由于实际的排序在数学上没有区别， 大多数人习惯于按行优先顺序思考矩阵， Three.js 文档以行优先顺序显示矩阵。只要忍耐 请注意，如果您正在阅读源代码，则必须采取 转置此处概述的任何矩阵以理解计算。

构造函数

new Matrix2( n11 : number, n12 : number, n21 : number, n22 : number )

构造一个新的 2x2 矩阵。参数应该是 按行主顺序。如果没有提供参数，则构造函数 将矩阵初始化为单位矩阵。

n11

1-1 矩阵元素.
n12

1-2 矩阵元素.
n21

2-1 矩阵元素.
n22

2-2 矩阵element.
