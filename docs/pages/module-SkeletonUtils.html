SkeletonUtils

导入

SkeletonUtils 是一个插件，必须显式导入，请参阅 Installation#Addons.

import * as SkeletonUtils from 'three/addons/utils/SkeletonUtils.js';

方法

.clone( source : Object3D ) : Object3D (inner)

克隆给定的 3D 对象及其后代，确保任何 SkinnedMesh 实例都是 与他们的骨骼正确关联。骨头也是克隆的，而且一定是 对象传递给此方法。其他数据（例如几何图形和材质）通过引用重用。

source

要克隆的 3D 对象。
返回： 克隆的 3D 对象。

.retarget( target : Object3D | Skeleton, source : Object3D | Skeleton, options : module:SkeletonUtils~RetargetOptions ) (inner)

将骨架从给定源重新定位到target.

target 和 source 都可以是具有骨架属性的 3D 对象（例如蒙皮网格） 或直接 Skeleton.

target

目标对象.
source

源对象.
options

选项.

.retargetClip( target : Object3D, source : Object3D | Skeleton, clip : AnimationClip, options : module:SkeletonUtils~RetargetOptions ) : AnimationClip (inner)

将源的动画剪辑重新定位到目标 3D object.

source 可以是具有骨架属性的 3D 对象（例如蒙皮网格） 或直接 Skeleton。

target

目标 3D 对象。必须具有 skeleton 属性。
source

源对象.
clip

动画剪辑。
options

选项.
返回： 重新定位的动画剪辑。

类型定义

.RetargetOptions

重新定位选项SkeletonUtils.

useFirstFramePosition
boolean

是否使用第一帧的位置。

默认为 false.
fps
number

剪辑的FPS。
names
Object.<string, string>

用于将目标骨骼名称映射到源骨骼名称的字典。
getBoneName
function

A函数用于映射骨骼名称。 names.
trim
Array.<number>

的替代方案__是否修剪剪辑。如果设置，数组应保存开始和结束的两个值。
preserveBoneMatrix
boolean

是否保留骨骼矩阵。

默认为true.
preserveBonePositions
boolean

是否保留骨骼位置。

默认为true.
useTargetMatrix
boolean

是否使用目标矩阵。

默认为 false.
hip
string

骨骼的名称源的髋骨.

hipInfluence
Vector3

髋部影响.

默认为(1,1,1).
scale
number

比例.

默认为1.

每骨骼局部偏移矩阵，由骨骼键入名称.

Vector3
