SpotLightShadow

表示定向光源的阴影配置。

构造函数

new SpotLightShadow()

构造一个新的聚光灯阴影。

属性

.aspect : number

纹理纵横比。

默认为1.

.focus : number

用于聚焦阴影相机。相机的视野设置为 聚光灯视野的百分比。范围为 [0, 1].

默认为1.

.isSpotLightShadow : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.toJSON() : Object

将灯光阴影序列化为 JSON。

覆盖： LightShadow#toJSON
参见：
  • ObjectLoader#parse
返回： 表示序列化灯光的 JSON 对象阴影.
