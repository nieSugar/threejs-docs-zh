ClippingGroup

在早期的 Three.js 版本中，裁剪是全局定义的 在渲染器或材质级别上。这个特殊版本的 THREE.Group 允许将剪辑状态编码到场景中 图表。这意味着如果您创建该组的实例，所有 后代 3D 对象将受到各自剪裁的影响 planes.

注意：ClippingGroup只能与WebGPURenderer一起使用。

构造函数

new ClippingGroup()

构造一个新的裁剪组。

属性

.clipIntersection : boolean

是否使用裁剪平面的交集剪切对象，而不是它们的联合。

默认为 false.

.clipShadows : boolean

是否应剪切阴影。

默认为 false.

.clippingPlanes : Array.<Plane>

带有剪切平面的数组。

.enabled : boolean

是否应启用剪切.

默认为true.

.isClippingGroup : boolean (readonly)

该标志可用于类型测试。

默认为true.
