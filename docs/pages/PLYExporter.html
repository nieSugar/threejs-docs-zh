PLYExporter

PLY 的导出器。

PLY（多边形或斯坦福三角形格式）是一种用于高效交付和导出的文件格式。 以密集格式加载简单、静态的 3D 内容。二进制和ascii格式都是 支持。 PLY可以存储顶点位置、颜色、法线和uv坐标。无纹理 或保存纹理引用。

代码示例

const exporter = new PLYExporter();
const data = exporter.parse( scene, options );

导入

PLYExporter 是一个插件，必须显式导入，请参阅Installation#Addons.

import { PLYExporter } from 'three/addons/exporters/PLYExporter.js';

构造函数

new PLYExporter()

方法

.parse( object : Object3D, onDone : PLYExporter~OnDone, options : PLYExporter~Options ) : string | ArrayBuffer

解析给定的3D 对象并生成 PLY 输出。

如果 3D 对象由多个子对象和几何体组成，它们将合并到文件中的单个网格中。

object

要导出的 3D 对象。
onDone

导出完成时执行的回调函数。
options

导出选项.
返回： 导出的 PLY.

类型定义

.OnDone( result : string | ArrayBuffer )

onDone 回调 PLYExporter.

result

生成的 PLY ascii 或二进制.

.Options

PLYExporter的导出选项.

binary
boolean

是否以二进制格式或ASCII格式导出.

默认为 false.
excludeAttributes
Array.<string>

要显式排除哪些属性 导出的 PLY 文件。有效值为 'color'、'normal'、'uv' 和 'index'。如果三角形 排除索引，然后导出点云。
littleEndian
boolean

二进制导出是否使用小端或大端。

默认为 false.
customPropertyMapping
Object.<string, Array.<string>>

允许的映射 将自定义缓冲区属性导出为 PLY 顶点属性。每个条目映射一个缓冲区属性 name 为 PLY 属性名称数组。属性名称的数量必须与项目大小匹配 缓冲区属性。这是 PLYLoader.setCustomPropertyNameMapping().
