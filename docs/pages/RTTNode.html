RTTNode

RTTNode 采用另一个节点并将其与 QuadMesh 一起使用以渲染为纹理 (RTT)。 该模块在某些节点需要的后处理上下文中特别相关 其效果的纹理输入。使用基于辅助函数 convertToTexture() 在此模块上，如果需要，节点系统可以自动确保纹理输入。

构造函数

new RTTNode( node : Node, width : number, height : number, options : Object )

构造一个新的RTT节点。

node

用于渲染纹理的节点。
width

内部渲染目标的宽度。如果未应用宽度，则自动调整渲染目标的大小。

默认为null.
height

内部渲染目标的高度。

默认为null.
options

内部渲染目标的选项。

默认为 {}.

type

纹理类型.

默认为HalfFloatType.
autoUpdate

纹理是否应自动更新。

默认为true.
resolutionScale

分辨率比例。

默认为1.

属性

.autoResize : boolean (readonly)

内部渲染目标是否应自动更新是否调整大小。

默认为true.

.autoUpdate : boolean

纹理是否应自动更新。

默认为true.

.height : number

内部渲染目标的高度。

默认为null.

.isRTTNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.node : Node

用于渲染纹理的节点。

.renderTarget : RenderTarget

渲染目标

.textureNeedsUpdate : boolean

纹理是否需要更新。

默认为true.

.updateBeforeType : string

由于节点更新，updateBeforeType 设置为 NodeUpdateType.FRAME 在其 RTTNode#updateBefore 方法中每帧一次纹理。

中每帧效果一次，默认为 'frame'.

覆盖： TextureNode#updateBeforeType

.value

由于该值是由内部渲染定义的，因此被覆盖target.

覆盖： TextureNode#value

.value : Texture

内部渲染目标的纹理。

覆盖： TextureNode#value

.width : number

内部渲染目标的宽度。 如果未应用宽度，则自动调整渲染目标的大小。

默认为null.

方法

.dispose()

释放内部资源。应该在节点不再使用时调用。

覆盖： TextureNode#dispose

.getResolutionScale() : number

获取分辨率比例。

返回：分辨率比例。

.setResolutionScale( resolutionScale : number ) : RTTNode

设置分辨率比例。 分辨率比例是与渲染器的宽度和高度相乘的因子。

resolutionScale

要设置的分辨率比例。值为 1 表示全分辨率。
返回：对此节点的引用.

.setSize( width : number, height : number )

设置内部渲染目标的大小。

width

要设置的宽度。
height

要设置的高度。

.updateBefore( frame : NodeFrame )

在主渲染通道之前将节点的输出渲染到内部渲染目标中。 当启用 autoResize 时，处理渲染目标的自动调整大小， 如果 textureNeedsUpdate 和 autoUpdate 都不为 true，则跳过渲染。

frame

当前节点帧，提供对渲染器和其他帧数据的访问。
覆盖： TextureNode#updateBefore
