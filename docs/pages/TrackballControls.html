TrackballControls

此类类似于OrbitControls。然而，它并没有保持恒定的相机 up 向量。这意味着如果相机在“北极”和“南极”上空运行，它不会翻转 保持“正面朝上”。

导入

TrackballControls 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { TrackballControls } from 'three/addons/controls/TrackballControls.js';

构造函数

new TrackballControls( object : Object3D, domElement : HTMLElement )

构造一个新的控件实例。

object

控件管理的对象。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.dynamicDampingFactor : number

Defines阻尼强度。仅当 staticMoving 设置为 false 时才考虑。

默认为0.2.

.keys : Array.<string>

此数组保存用于控制交互的键码。

  • 当按下第一个定义的键时，所有鼠标操作（左键、中键、右键）都会执行环绕操作。
  • 当按下第二个定义的键时，所有鼠标操作（左键、中键、右键）都会执行缩放操作。
  • 当按下第三个定义的键时，所有鼠标操作（左键、中键、右键）都会执行平移操作。

默认为 KeyA、KeyS、KeyD 表示 A、S、 D.

覆盖： Controls#keys

.maxDistance : number

可以推出多远（透视相机）仅).

默认为 Infinity.

.maxZoom : number

您可以缩小多远（仅限正交相机）。

默认为 Infinity.

.minDistance : number

您可以移动多远（仅限透视相机）.

默认为0.

.minZoom : number

您可以放大多远（正交相机）仅).

默认为0.

.mouseButtons : Object

此对象包含对控件使用的鼠标操作的引用。

controls.mouseButtons = {
	LEFT: THREE.MOUSE.ROTATE,
	MIDDLE: THREE.MOUSE.DOLLY,
	RIGHT: THREE.MOUSE.PAN
}
覆盖： Controls#mouseButtons

.multiTouchRoll : boolean

两指扭动手势是否滚动

默认为 false.

.noPan : boolean

是否禁用平移.

默认为 false.

.noRotate : boolean

是否禁用旋转.

默认为 false.

.noZoom : boolean

是否禁用缩放.

默认为 false.

.panSpeed : number

平移speed.

默认为0.3.

.rollSpeed : number

多点触摸滚动时使用的滚动速度。

默认为1.

.rotateSpeed : number

旋转速度.

默认为1.

.screen : Object (readonly)

表示屏幕的属性。调用handleResize()时自动设置。

.staticMoving : boolean

是否禁用阻尼。

默认为 false.

.target : Vector3

控件焦点。

.zoomSpeed : number

变焦速度。

默认为1.2.

方法

.handleResize()

如果调整应用程序窗口大小，则必须调用。

.reset()

将控件重置为其初始状态。

Events

  • Object

Type:
