DragControls

此类可用于提供拖放交互。

代码示例

const controls = new DragControls( objects, camera, renderer.domElement );
// add event listener to highlight dragged objects
controls.addEventListener( 'dragstart', function ( event ) {
	event.object.material.emissive.set( 0xaaaaaa );
} );
controls.addEventListener( 'dragend', function ( event ) {
	event.object.material.emissive.set( 0x000000 );
} );

导入

DragControls 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { DragControls } from 'three/addons/controls/DragControls.js';

构造函数

new DragControls( objects : Array.<Object3D>, camera : Camera, domElement : HTMLElement )

构造一个新的控件实例。

objects

可拖动的 3D 对象数组。
camera

渲染场景的相机。
domElement

用于的 HTML DOM 元素事件侦听器。

默认为null.

属性

.objects : Array.<Object3D>

可拖动的 3D 对象数组。

.raycaster : Raycaster

用于检测 3D 对象的光线投射器。

.recursive : boolean

可拖动对象的子对象是否可以独立于其父对象进行拖动。

默认为true.

.rotateSpeed : number

在 rotate 模式下拖动时对象旋转的速度。 数字越大，旋转速度越快。

默认为1.

.transformGroup : boolean

仅当 objects 数组包含单个可拖动组对象时，此选项才有效。 如果设置为 true，控件不会变换单个对象，而是变换整个组。

默认为 false.

Events

.drag

当用户拖动 3D 对象时触发。

Type:
  • Object

.dragend

当用户完成拖动 3D 对象时触发。

Type:
  • Object

.hoveroff

当指针移动时触发移出 3D 对象。

Type:
  • Object

.hoveron

当指针移到 3D 对象或其子对象之一上时触发。

Type:
  • Object
