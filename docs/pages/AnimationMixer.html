AnimationMixer

AnimationMixer 是一个在特定对象上播放动画的播放器 现场。当场景中的多个对象独立进行动画处理时， 每个对象可以使用一个 AnimationMixer。

构造函数

new AnimationMixer( root : Object3D )

构造一个新的动画混合器。

root

该混合器应播放其动画的对象。

属性

.time : number

全局混合器时间（以秒为单位；从0 关于混频器的创建）。

默认为0.

.timeScale : number

全局时间的缩放因子。

注意：将此成员设置为 0，然后返回到 1 是 可以暂停/取消暂停由此控制的所有操作 mixer.

默认为1.

方法

.clipAction( clip : AnimationClip | string, optionalRoot : Object3D, blendMode : NormalAnimationBlendMode | AdditiveAnimationBlendMode ) : AnimationAction

为传递的剪辑返回 AnimationAction 的实例。

如果适合剪辑和根参数的动作尚不存在，则它 将通过此方法创建。多次调用此方法 相同的剪辑和根参数始终返回相同的动作。

clip

动画剪辑或动画剪辑的名称。
optionalRoot

替代根对象。
blendMode

混合模式。
返回：动画动作。

.existingAction( clip : AnimationClip | string, optionalRoot : Object3D ) : AnimationAction

返回现有动画传递的剪辑的动作。

clip

动画剪辑或动画剪辑的名称。
optionalRoot

替代根对象。
返回：动画动作。如果未找到任何操作，则返回 null。

.getRoot() : Object3D

返回此混合器的根对象。

返回： 混合器的根对象。

.setTime( time : number ) : AnimationMixer

将全局混合器设置为特定时间并更新动画因此.

当您需要跳转到动画中的准确时间时，这非常有用。的 输入参数将按 AnimationMixer#timeScale

time

以秒为单位设置的时间进行缩放。
返回： 对此动画混合器的引用。

.stopAllAction() : AnimationMixer

停用在此上的所有先前计划的操作mixer.

返回： 对此动画混合器的引用。

.uncacheAction( clip : AnimationClip | string, optionalRoot : Object3D )

为某个操作取消分配所有内存资源。该操作由以下项标识 给定的剪辑和可选的根对象。使用此方法之前先进行 请务必调用 AnimationAction#stop 来停用该操作。

clip

动画剪辑或动画剪辑的名称。
optionalRoot

替代根对象。

.uncacheClip( clip : AnimationClip )

取消分配剪辑的所有内存资源。使用此方法之前先进行 确保为所有相关操作调用 AnimationAction#stop。

clip

要取消缓存的剪辑。

.uncacheRoot( root : Object3D )

为根对象取消分配所有内存资源。使用此之前 方法确保为所有相关调用 AnimationAction#stop 动作或 AnimationMixer#stopAllAction 当 混合器在单个根上运行。

root

要取消缓存的根对象。

.update( deltaTime : number ) : AnimationMixer

提前全局混合器时间并更新动画。

这通常在渲染循环中通过传递增量来完成 从 Clock 或 Timer.

deltaTime

以秒为单位的增量时间。
返回： 对此动画混合器的引用。
