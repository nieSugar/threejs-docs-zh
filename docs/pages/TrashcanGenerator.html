TrashcanGenerator

纽约市绿色金属丝网垃圾篮：顶部较重的略微锥形的鼓 边缘，一个脚环，里面有一袋黑色的垃圾。构建一次并跨实例化 展示位置列表；一根便宜的材料树枝放在烤好的partId上，绘图 网格编织按程序从鼓自身的 UV 开始，因此没有 alpha 或额外的几何体 是需要的。规范模型位于 y = 0 上，以 X / Z 为中心.

代码示例

const cans = new TrashcanGenerator();
scene.add( cans.build( placements ) ); // placements: Matrix4[]

构造函数

new TrashcanGenerator()
