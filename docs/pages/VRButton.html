VRButton

用于创建允许启动的按钮的实用程序类 基于 WebXR 的沉浸式 VR 会话。可以创建按钮 使用工厂方法，然后附加到网站的 DOM。

代码示例

document.body.appendChild( VRButton.createButton( renderer ) );

导入

VRButton 是一个插件，必须显式导入，请参阅 安装#Addons.

import { VRButton } from 'three/addons/webxr/VRButton.js';

属性

.xrSessionIsGranted : boolean

是否已授予XR会话。

默认为 false.

静态方法

.createButton( renderer : WebGLRenderer | WebGPURenderer, sessionInit : XRSessionInit ) : HTMLElement

构造一个新的VR按钮。

renderer

渲染器.
sessionInit

AR 会话的配置对象。
返回： 按钮或错误消息，如果 immersive-ar不支持.

.registerSessionGrantedListener()

注册一个sessiongranted事件监听器。当授予会话时，VRButton#xrSessionIsGranted 标志将评估为 true。该方法由模块本身自动调用，因此有 应该不需要在应用程序级别使用它。
