Line2NodeMaterial

此节点材质可用于渲染尺寸大于 1 的线条 通过将它们表示为实例化网格。

构造函数

new Line2NodeMaterial( parameters : Object )

构造用于宽线渲染的新节点材质。

parameters

配置参数.

默认为 {}.

属性

.alphaToCoverage : boolean

是否应使用覆盖范围的 Alpha。

默认为true.

覆盖： NodeMaterial#alphaToCoverage

.blending : number

由于透明度而将混合设置为 NoBlending 尚不支持。

默认为0.

覆盖： NodeMaterial#blending

.dashOffset : number

短划线偏移量。

默认为0.

.dashScaleNode : Node.<float>

定义短划线比例。

默认为null.

.dashSizeNode : Node.<float>

定义短划线size.

默认为null.

.dashed : boolean

线条是否应为虚线。

默认为 false.

.gapSizeNode : Node.<float>

定义间隙大小。

默认为null.

.isLine2NodeMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.lineColorNode : Node.<vec3>

定义线条颜色。

已弃用：自 r185 起。请使用 NodeMaterial#colorNode 代替。

.offsetNode : Node.<float>

定义偏移量。

默认为null.

.vertexColors : boolean

是否应使用顶点颜色。

默认为 false.

覆盖： NodeMaterial#vertexColors

.worldUnits : boolean

线条大小是否应采用世界单位。 当设置为false时，单位为像素。

默认为 false.

方法

.setupDiffuseColor( builder : NodeBuilder )

设置片段阶段中线条材质的漫反射颜色。 覆盖基本设置以合并线条/虚线渲染和混合。

builder

当前节点构建器.
覆盖： NodeMaterial#setupDiffuseColor

.setupPosition( builder : NodeBuilder ) : Node.<vec3>

在本地设置扩展粗线顶点的位置space.

builder

当前节点构建器.
覆盖： NodeMaterial#setupPosition
返回： 粗线顶点在局部空间中的位置.
