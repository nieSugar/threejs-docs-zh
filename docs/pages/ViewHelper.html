ViewHelper

一种特殊类型的帮助器，可可视化相机的变换 在小视口区域中作为轴助手。经常需要这样的帮手 在 3D 建模工具或场景编辑器中，例如 Three.js 编辑器.

帮助器允许单击 X、Y 和 Z 轴来为相机设置动画 所以它看起来沿着选定的轴。

导入

ViewHelper 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { ViewHelper } from 'three/addons/helpers/ViewHelper.js';

构造函数

new ViewHelper( camera : Camera, domElement : HTMLElement )

构造一个新的视图助手。

camera

应可视化变换的相机。
domElement

用于渲染视图的 DOM 元素。

属性

.animating : boolean (readonly)

助手当前是否处于动画状态。

默认为 false.

.camera : Camera

可视化变换的相机。可以在以下位置重新分配 随时将助手重新绑定到不同的摄像机。

.center : Vector3

助手的中心点。

.isViewHelper : boolean (readonly)

该标志可用于类型测试。

默认为true.

.location : Object

控制助手在视口中的位置。 使用 top/bottom 进行垂直定位，使用 left/right 进行水平定位。 如果 left 是 null，则使用 right。如果top为null，则使用bottom。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Object3D#dispose

.handleClick( event : PointerEvent ) : boolean

当点击或指针事件时应调用此方法 应用程序中已发生。

event

要处理的事件。
返回：是否已检测到与帮助器的交叉点。

.render( renderer : WebGLRenderer | WebGPURenderer )

在视口中的单独视图中渲染帮助器。 位置由 location 属性控制。

renderer

渲染器.

.setLabelStyle( font : string, color : string, radius : number )

设置标签样式。当轴未标记时无效。

font

标签字体.

默认为'24px Arial'.
color

标签颜色.

默认为'#000000'.
radius

标签半径.

默认为14.

.setLabels( labelX : string | undefined, labelY : string | undefined, labelZ : string | undefined )

为每个轴设置标签。默认情况下，它们是未标记的。

labelX

x 轴的标签。
labelY

y 轴的标签。
labelZ

z 轴的标签。

.update( delta : number )

更新帮助器。应在应用程序的动画中调用此方法 循环.

delta

以秒为单位的增量时间。
