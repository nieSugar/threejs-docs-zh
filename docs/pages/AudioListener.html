AudioListener

该类代表所有位置和非位置音频效果的虚拟监听器 场景中。 Three.js 应用程序通常会创建一个侦听器。这是强制性的 音频实体的构造函数参数，如 Audio 和 PositionalAudio.

在大多数情况下，侦听器对象是相机的子对象。所以 3D 变换 相机代表听者的 3D 变换。

构造函数

new AudioListener()

构造一个新的音频听者。

属性

.context : AudioContext (readonly)

本机音频上下文。

.filter : AudioNode (readonly)

可选过滤器。

通过定义AudioListener#setFilter.

默认为null.

.gain : GainNode (readonly)

用于音量控制的增益节点。

.timeDelta : number (readonly)

linearRampToValueAtTime() 使用所需的时间增量值。

默认为0.

方法

.getFilter() : AudioNode

返回当前设置的过滤器。

返回： filter.

.getInput() : GainNode

返回侦听器的输入节点。

其他音频节点使用此方法连接到此侦听器。

返回： 输入节点。

.getMasterVolume() : number

返回应用程序主节点音量.

返回： 主音量。

.removeFilter() : AudioListener

从此侦听器中删除当前过滤器。

返回： 对此侦听器的引用。

.setFilter( value : AudioNode ) : AudioListener

将给定过滤器设置为此Listener.

value

要设置的过滤器。
返回： 对此侦听器的引用。

.setMasterVolume( value : number ) : AudioListener

设置应用程序主音量。该音量设置影响 场景中的所有音频节点.

value

要设置的主音量.
返回： 对此侦听器的引用。
