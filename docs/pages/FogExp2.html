FogExp2

此类可用于定义指数平方雾， 它可以在相机附近提供清晰的视野，并且速度比指数更快 距离摄像机较远的浓雾。

代码示例

const scene = new THREE.Scene();
scene.fog = new THREE.FogExp2( 0xcccccc, 0.002 );

构造函数

new FogExp2( color : number | Color, density : number )

构造一个新的雾。

color

雾的颜色.
density

定义雾变得浓密的速度。

默认为 0.00025.

属性

.color : Color

雾的颜色.

.density : number

定义雾变得浓密的速度。

默认为 0.00025.

.isFogExp2 : boolean (readonly)

该标志可用于类型测试。

默认为true.

.name : string

雾的名称。

方法

.clone() : FogExp2

返回包含此实例中复制值的新雾。

返回：此克隆instance.

.toJSON( meta : Object | string ) : Object

将雾序列化为 JSON。

meta

保存有关雾的元信息的可选值序列化.
返回： 表示序列化雾的 JSON 对象
