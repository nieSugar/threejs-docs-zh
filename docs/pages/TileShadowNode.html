TileShadowNode

扩展 ShadowBaseNode 以实现平铺阴影映射的类。 这允许将阴影贴图分割成多个图块，每个图块都有自己的灯光和相机， 提高大场景的阴影质量和性能。

注意： 该类目前不支持 VSMShadowMap。

导入

TileShadowNode 是一个插件，必须显式导入，请参阅Installation#Addons.

import { TileShadowNode } from 'three/addons/tsl/shadows/TileShadowNode.js';

构造函数

new TileShadowNode( light : Light, options : Object )

创建TileShadowNode.

light

用于阴影的原始光源的实例映射.
options

平铺阴影节点的配置选项.

默认为 {}.

tilesX

沿X轴的平铺数量.

默认为2.
tilesY

沿Y轴的平铺数量.

默认为2.
resolution

阴影的分辨率map.
debug

是否启用调试模式.

默认为 false.

方法

.disposeLightsAndNodes()

移除灯光和关联节点/目标的帮助方法。 在处置和潜在重新初始化期间内部使用。

.generateTiles( tilesX : number, tilesY : number ) : Array.<Object>

根据沿 X 轴和 Y 轴指定的图块数量生成阴影贴图的图块。

tilesX

沿X轴的平铺数量.
tilesY

沿Y轴的平铺数量.
返回：图块对象的数组，每个对象包含图块的边界和索引.

.init( builder : Builder )

通过为每个图块创建灯光、摄像机和阴影贴图来初始化图块阴影节点。

builder

用于创建渲染目标和其他资源的构建器。

.setup( builder : Builder ) : Node

设置用于渲染的阴影节点。

builder

用于创建渲染目标的构建器。设置阴影节点。
覆盖： ShadowBaseNode#setup
返回： 表示阴影值的节点。

.syncLightTransformation( lwLight : LwLight, sourceLight : Light )

将平铺光源的变换与源光源同步。

lwLight

要同步的平铺光源。
sourceLight

要复制的源光源来自.

.update()

更新每个图块的灯光变换和阴影摄像机。

覆盖： ShadowBaseNode#update

.updateBefore( frame : NodeFrame )

实现在必要时执行阴影贴图的更新。

frame

对当前节点框架的引用。
覆盖： ShadowBaseNode#updateBefore

.updateLightDirection()

根据灯光的目标更新初始灯光方向位置.

.updateShadow( frame : NodeFrame )

更新阴影贴图渲染.

frame

对当前节点框架的引用。
