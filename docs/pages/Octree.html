Octree

八叉树是一种分层树数据结构，用于划分三维空间 通过递归地将空间细分为八个八分圆。

此特定实现最多可以有十六个级别并存储最多八个三角形 在叶节点中。

Octree 可在游戏中用于计算游戏世界与碰撞器之间的碰撞 播放器或其他动态 3D 对象。

代码示例

const octree = new Octree().fromGraphNode( scene );
const result = octree.capsuleIntersect( playerCollider ); // collision detection

导入

Octree 是一个插件，必须显式导入，请参阅 安装#Addons.

import { Octree } from 'three/addons/math/Octree.js';

构造函数

new Octree( box : Box3 )

构造一个新的八叉树。

box

包围整个八叉树的基本框。

属性

.bounds : Box3

八叉树的边界。与 Octree#box 相比，没有 应用边距。

.box : Box3

包围整个八叉树的基本框。

.layers : Layers

可用于层配置以进行细化测试。

.maxLevel : number

八叉树的最大级别。它定义了最大 数据结构的层次深度。

默认为16.

.trianglesPerLeaf : number

叶子在分割之前可以存储的三角形数量。

默认为 8.

方法

.addTriangle( triangle : Triangle ) : Octree

将给定的三角形添加到八叉树。如果三角形顶点超过 八叉树的边界.

triangle

要添加的三角形.
返回：对此八叉树的引用.

.boxIntersect( box : Box3 ) : Object | boolean

对此执行边界框相交测试八叉树.

box

要测试的边界框。
返回： 交集对象。如果没有交集 检测到时，该方法返回 false。

.build() : Octree

构建八叉树.

返回：对此八叉树的引用.

.calcBox() : Octree

为构建准备Octree#box.

返回：对此八叉树的引用.

.capsuleIntersect( capsule : Capsule ) : Object | boolean

与此八叉树执行胶囊相交测试.

capsule

胶囊test.
返回： 交集对象。如果没有交集 检测到时，该方法返回 false。

.clear() : Octree

通过将其清空来清除八叉树。

返回：对此八叉树的引用.

.fromGraphNode( group : Object3D ) : Octree

从给定的 3D 对象构造八叉树。

group

场景图节点。
返回：对此八叉树的引用.

.getBoxTriangles( box : Box3, triangles : Array.<Triangle> )

计算可能与给定边界相交的三角形box.

box

边界框.
triangles

保存三角形的目标数组.

.getCapsuleTriangles( capsule : Capsule, triangles : Array.<Triangle> )

计算可能与给定胶囊相交的三角形。

capsule

胶囊test.
triangles

保存三角形的目标数组.

.getRayTriangles( ray : Ray, triangles : Array.<Triangle> )

计算可能与给定胶囊相交的三角形射线.

ray

要测试的光线。
triangles

保存三角形的目标数组.

.getSphereTriangles( sphere : Sphere, triangles : Array.<Triangle> )

计算可能与给定边界球体相交的三角形。

sphere

要测试的球体.
triangles

保存三角形的目标数组.

.rayIntersect( ray : Ray ) : Object | boolean

用此执行射线相交测试八叉树.

ray

要测试的光线。
返回：最近的交叉点对象。如果没有交集 检测到时，该方法返回 false.

.sphereIntersect( sphere : Sphere ) : Object | boolean

与此八叉树执行边界球相交测试。

sphere

返回： 交集对象。如果没有交集 检测到时，该方法返回 false。

.split( level : number ) : Octree

分割八叉树。当以下情况时，递归地使用该方法： 构建八叉树.

level

返回：对此八叉树的引用.
