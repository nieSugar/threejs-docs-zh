USDComposer

USDComposer 根据解析的美元数据处理场景合成。 这包括参考解析、变体选择、变换处理、 并构建 Three.js 场景图。

使用 USDCParser 中的 specsByPath 格式。

构造函数

new USDComposer()

方法

._applyMaterialBinding()

将材质绑定从 prim 路径应用到网格。 将引用的几何体合并到具有材质绑定的 prim 时使用。

._applyTextureOrValue()

用于应用着色器属性中的纹理或值的共享助手。 减少 _applyPreviewSurface 和 _applyOpenPBRSurface 之间的重复。

._buildCamera()

根据相机规格构建相机。

._buildGeomPrimitive()

从 USD 几何图元（立方体、球体、圆柱体、圆锥体、胶囊）构建网格。

._buildHierarchy()

构建场景层次结构递归地。 使用childrenByPath索引进行O(1)子查找而不是O(n)迭代。

._buildIndexes()

构建索引以进行高效查找。 在 compose() 期间调用一次，以避免每次查找 O(n) 次扫描。

._buildLight()

根据 UsdLux 灯光规格构建灯光。

._buildMesh()

根据网格规格构建网格。

._colorTemperature()

将开尔文色温转换为 RGB 颜色。 基于 Tanner Helland 的算法。

._computeVertexNormals()

从索引三角形数据计算每个顶点法线。 在每个共享顶点处累积面积加权面法线并标准化。

._findSingleMesh()

在组的浅层次结构中查找单个网格。 仅返回深度为 0 或 1 且未深度嵌套的网格。 这保留了复杂层次结构中的转换，例如厨房套件 同时支持 USDZExporter 往返（Xform > Xform > 网格图案）。

._getAttributes()

从属性规格中获取路径的属性。

._getBasePath()

从文件路径中获取基本路径（目录）。

._getLocalVariantSelections()

从规格中提取变体选择fields.

._getMaterialBindingSpec()

获取 prim 的材料绑定关系，包括来自的覆盖 活动变体.

._getMaterialBindingTarget()

获取 prim 的解析材料结合目标。材料绑定是 继承，并且标记为 StrongThanDescendants 的祖先优先 在其后代上创作的绑定。

._getMaterialPath()

获取网格体的材质路径，检查各种绑定源。

._getReferences() : Array.<string>

从原始规范中获取所有参考值。

返回：参考字符串数组，例如“@path@”或"@path@<prim>"

._getVariantPaths()

根据变体选择获取父路径的变体路径。

._hasNonIdentityTransform()

检查对象是否具有非同一局部变换。

._isDirectChild()

检查路径是否是parentPath的直接子级。

._resolveAttributeValue()

解析属性的创作值，使用前遵循连接 本地后备值。

._resolveFilePath()

解析相对于basePath的文件路径。

._resolveReference( refValue : string, localVariants : Object ) : Group | null

解析美元引用并返回组成的内容。

refValue

引用值，例如"@./path/to/file.usdc@"
localVariants

要应用的变体选择
返回： 组合内容或 null

.applyTransform()

将 USD 转换应用于 Three.js 对象。 使用适当的矩阵组合处理 xformOpOrder。 USD 使用行向量约定，Three.js 使用列向量。

.compose( parsedData : Object, assets : Object, variantSelections : Object, basePath : string ) : Group

根据解析的 USD 数据构建 Three.js 场景。

parsedData

来自 USDCParser 或 USDAParser 的数据
assets

引用资产的字典（specsByPath 或 blob） URL)
variantSelections

外部变量选择
basePath

解析相对引用的基本路径
返回： Three.js场景图
