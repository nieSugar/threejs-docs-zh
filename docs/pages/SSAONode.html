SSAONode

用于快速屏幕空间环境光遮挡 (SSAO) 的后处理节点。

它对每像素旋转的 Vogel 盘进行点采样，并通过单个深度抽头估计遮光度 每个样本，以 GTAONode 的地平线光线行进的真实精度为代价 成本更低。内置的可分离、深度感知的模糊对结果进行降噪，因此无需任何操作即可使用 时间累积。

代码示例

const scenePass = pass( scene, camera );
scenePass.setMRT( mrt( { output, normal: normalView } ) );
const scenePassColor = scenePass.getTextureNode( 'output' );
const scenePassDepth = scenePass.getTextureNode( 'depth' );
const scenePassNormal = scenePass.getTextureNode( 'normal' );
const aoPass = ssao( scenePassDepth, scenePassNormal, camera );
renderPipeline.outputNode = scenePassColor.mul( aoPass.r );

导入

SSAONode 是一个插件，必须显式导入，请参见Installation#Addons.

import { ssao } from 'three/addons/tsl/display/SSAONode.js';

构造函数

new SSAONode( depthNode : Node.<float>, normalNode : Node.<vec3>, camera : Camera )

构造一个新的SSAO节点.

depthNode

表示场景深度的节点。
normalNode

表示场景法线的节点。
camera

渲染场景的相机。

属性

.bias : UniformNode.<float>

抑制近平坦表面上的自遮挡的角度偏差。

.blurEnabled : boolean

是否应用对原始AO进行降噪的深度感知模糊。

默认为true.

.blurSharpness : UniformNode.<float>

模糊在深度不连续性上拒绝样本的强度， 相对于 AO 半径。较高的值使边缘更清晰。

.depthNode : Node.<float>

表示场景深度的节点。

.intensity : UniformNode.<float>

遮挡的强度。

.normalNode : Node.<vec3>

表示场景法线的节点。

.radius : UniformNode.<float>

遮挡聚集的世界空间半径。

.resolution : Vector2

效果的分辨率。设置从绘图缓冲区大小和resolutionScale.

.resolutionScale : number

分辨率比例。效果仅占绘图缓冲区的一小部分进行渲染 为了额外的速度； 0.5 对于像 AO 这样的低频信号来说是一个很好的默认值。

默认为0.5.

.samples : UniformNode.<float>

使用多少个样本来估计遮挡。更高的价值 以更高的运行时间成本获得更平滑的结果。

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
