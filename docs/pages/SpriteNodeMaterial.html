SpriteNodeMaterial

节点材质版本SpriteMaterial.

构造函数

new SpriteNodeMaterial( parameters : Object )

构造一个新的精灵节点材质。

parameters

配置参数.

属性

.isSpriteNodeMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.positionNode : Node.<vec2>

此属性使得可以使用 节点。当材质与实例渲染一起使用时，这会很有用 并且节点数据使用实例化属性节点定义：

const positionAttribute = new InstancedBufferAttribute( new Float32Array( positions ), 3 );
material.positionNode = instancedBufferAttribute( positionAttribute );

另一种可能性是使用计算着色器计算实例化数据：

const positionBuffer = instancedArray( particleCount, 'vec3' );
particleMaterial.positionNode = positionBuffer.toAttribute();

默认为null.

覆盖： NodeMaterial#positionNode

.rotationNode : Node.<float>

默认情况下精灵材质的旋转从 rotation 推断， 财产。该节点属性允许覆盖默认值并定义 用节点代替旋转。

如果您不想覆盖旋转但修改现有的 值，请使用 materialRotation.

默认为null.

.scaleNode : Node.<vec2>

该节点属性提供了一种在Object3D.scale旁边缩放精灵的额外方式。基于Object3D.scale的缩放变换将在顶点着色器中与此节点的缩放值相乘。

默认为null.

.sizeAttenuation : boolean

是否使用尺寸衰减。

默认为true.

.transparent : boolean

在 Sprites 中，默认启用透明属性。

默认为true.

覆盖： NodeMaterial#transparent

方法

.setupPositionView( builder : NodeBuilder ) : Node.<vec3>

设置视图空间中的位置节点。该方法实现了 精灵特定的顶点着色器。

builder

当前节点构建器.
覆盖： NodeMaterial#setupPositionView
返回：视图中的位置space.
