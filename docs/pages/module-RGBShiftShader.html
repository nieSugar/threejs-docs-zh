RGBShiftShader

导入

RGBShiftShader 是一个插件，必须显式导入，请参阅 安装#Addons.

import { RGBShiftShader } from 'three/addons/shaders/RGBShiftShader.js';

属性

.RGBShiftShader : ShaderMaterial~Shader (inner, constant)

RGB 移位着色器 将红色和蓝色通道从中心向相反方向移动 移植自 https://web.archive.org/web/20090820185047/http://kriss.cx/tom/2009/05/rgb-shift/ 作者：Tom Butterworth / https://web.archive.org/web/20090810054752/http://kriss.cx/tom/

amount：移位距离（1 是输入宽度） 角度：以弧度为单位的平移角度
