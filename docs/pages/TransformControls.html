TransformControls

此类可用于通过采用类似的交互模型来变换 3D 空间中的对象 Blender 等 DCC 工具。与其他控件不同，它并不是为了转换场景的相机。

TransformControls 期望其附加的 3D 对象是场景图的一部分。

导入

TransformControls 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { TransformControls } from 'three/addons/controls/TransformControls.js';

构造函数

new TransformControls( camera : Camera, domElement : HTMLElement )

构造一个新的控件实例。

camera

渲染场景的相机。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.axis : string

当前变换轴.

.camera : Camera

渲染场景的相机。

.dragging : boolean (readonly)

当前是否进行拖动.

默认为 false.

.maxX : number

在执行过程中允许的最大X位置平移过程中.

默认为 Infinity.

.maxY : number

平移过程中允许的最大Y位置.

默认为 Infinity.

.maxZ : number

平移过程中允许的最大Z位置.

默认为 Infinity.

.minX : number

平移过程中允许的最小X位置.

默认为 -Infinity.

.minY : number

平移过程中允许的最小y位置平移.

默认为 -Infinity.

.minZ : number

平移过程中允许的最小z位置.

默认为 -Infinity.

.mode : 'translate' | 'rotate' | 'scale'

当前变换轴.

默认为'translate'.

.rotationSnap : number

默认情况下，3D对象连续旋转。如果将此属性设置为数字 值（弧度），您可以定义 3D 对象应旋转的步骤。

默认为null.

.scaleSnap : number

默认情况下，3D 对象会连续缩放。如果将此属性设置为数字 值，您可以定义 3D 对象应按哪个步骤进行缩放。

默认为null.

.showE : boolean

e 旋转辅助对象是否应可见。

默认为true.

.showX : boolean

x 轴辅助对象是否应可见。

默认为true.

.showXY : boolean

xy 平面辅助对象是否应可见或不.

默认为true.

.showXYZE : boolean

xyze 旋转辅助器是否可见。

默认为true.

.showXZ : boolean

xz 轴辅助器是否可见。

默认为true.

.showY : boolean

y 轴辅助器是否可见。

默认为true.

.showYZ : boolean

是否yz 平面辅助程序应可见或不可见。

默认为true.

.showZ : boolean

z 轴辅助程序是否可见。

默认为true.

.size : number

辅助程序 UI 的大小（轴/平面）。

默认为1.

.space : 'world' | 'local'

定义应在其中进行坐标空间变换执行.

默认为'world'.

.translationSnap : number

默认情况下，3D对象连续平移。如果将此属性设置为数字 值（世界单位），您可以定义 3D 对象应平移的步骤。

默认为null.

.viewport : Vector4

视口矩形，以逻辑 (CSS) 像素为单位，原点位于左下角 画布的。当渲染器使用子画布视口时设置此项，以便指针 坐标映射到正确的区域。如果 null，则使用整个画布。

默认为null.

方法

.attach( object : Object3D ) : TransformControls

设置应转换的 3D 对象并确保控件 UI 可见。

object

应转换的 3D 对象。
返回：对此控件的引用.

.detach() : TransformControls

从控件中删除当前 3D 对象并使帮助程序 UI 不可见。

返回：对此控件的引用.

.getHelper() : TransformControlsRoot

返回控件的可视表示形式。将助手添加到您的场景中 直观地变换附加的 3D 对象。

返回： 帮助程序。

.getMode() : 'translate' | 'rotate' | 'scale'

返回变换模式。

返回： 变换模式。

.getRaycaster() : Raycaster

返回用于用户交互的光线投射器。该对象在所有对象之间共享 TransformControls 的实例。

返回： 内部光线投射器的实例。

.reset()

将对象的位置、旋转和缩放重置为当前变换开始时的位置。

.setColors( xAxis : number | Color | string, yAxis : number | Color | string, zAxis : number | Color | string, active : number | Color | string )

设置控件小控件的颜色。

xAxis

x 轴颜色.
yAxis

y 轴颜色.
zAxis

z 轴颜色.
active

活动元素的颜色.

.setMode( mode : 'translate' | 'rotate' | 'scale' )

设置给定的变换模式.

mode

变换模式为set.

.setRotationSnap( rotationSnap : number )

设置旋转捕捉。

rotationSnap

要设置的旋转捕捉。

.setScaleSnap( scaleSnap : number )

设置缩放捕捉。

scaleSnap

要设置的缩放捕捉。

.setSize( size : number )

设置缩放捕捉的大小辅助 UI.

size

要设置的大小。

.setSpace( space : 'world' | 'local' )

设置应用变换的坐标空间。

space

要设置的空间。

.setTranslationSnap( translationSnap : number )

设置平移捕捉。

translationSnap

The转换捕捉设置。

Events

.change

如果执行任何类型的更改（对象或属性更改），则触发。属性变化 是您可以添加事件侦听器的单独事件。事件类型为“propertyname-changed”。

Type:
  • Object

.mouseDown

如果指针（鼠标/触摸）变为活动状态，则触发。

Type:
  • Object

.mouseUp

如果指针（鼠标/触摸）不再活动，则触发。

Type:
  • Object

.objectChange

如果受控 3D 对象处于活动状态，则触发已更改.

Type:
  • Object
