LightProbeGrid

L2 球谐波辐照度探头的 3D 网格，提供 位置相关的漫反射全局照明。

这是 WebGPURenderer 的 LightProbeGrid 版本。网格是一个 Light，因此将其添加到场景中会将其烘焙辐照度应用于每个 自动点亮节点材质。使用WebGLRenderer时，导入 来自 LightProbeGridWebGL.js 的网格改为

烘焙数据存储在打包的单个 RGBA RenderTarget3D 图集中 将九个 L2 SH 系数放入沿 Z 堆叠的七个子体积中。烘焙是 完全驻留在 GPU 上：立方体贴图渲染、SH 投影和纹理打包全部 发生在 GPU 上，CPU 读回为零。

导入

LightProbeGrid 是一个插件，必须显式导入，请参阅 安装#Addons.

import { LightProbeGrid } from 'three/addons/lighting/LightProbeGrid.js';

构造函数

new LightProbeGrid( width : number, height : number, depth : number, widthProbes : number, heightProbes : number, depthProbes : number )

构造一个新的辐照度探头网格。

体积以对象位置为中心。

width

体积沿X的全宽度.

默认为1.
height

全高度沿 Y 的体积的深度.

默认为1.
depth

沿 Z 的体积的全深度.

默认为1.
widthProbes

沿 X 的探头数量。默认为 Math.max( 2, Math.round( width ) + 1 ).
heightProbes

沿 Y 方向的探针数量。默认值为 Math.max( 2, Math.round( height ) + 1 )。
depthProbes

沿 Z 轴的探针数量。默认为 Math.max( 2, Math.round( depth ) + 1 ).

属性

.boundingBox : Box3

网格的世界空间边界框。自动更新 by LightProbeGrid#bake.

.depth : number

沿 Z 方向的体积的完整深度.

.falloff : number

网格贡献淡出的世界单位距离 超过体积边界。 0 在任何地方应用贡献 （夹紧），与单卷设置匹配。使用小正值 混合多个重叠网格的值。

默认为0.

.height : number

沿 Y 的体积的完整高度。

.isLightProbeGrid : boolean (readonly)

该标志可用于类型测试。

默认为true.

.resolution : Vector3

沿每个轴的探针数量。

.texture : Data3DTexture

存储所有七个打包 SH 的单个 RGBA 图集 3D 纹理 沿 Z.

默认为null.

.width : number

沿 X.

方法

.bake( renderer : WebGPURenderer, scene : Scene, options : Object )

体积的整个宽度堆叠的子体积__通过在每个探针位置渲染立方体贴图来烘焙探针 投影到 L2 SH。可选择迭代额外的过程来捕获 间接反弹：每个额外的通道对前一个通道的数据进行采样，如下所示 间接光，每次额外通过累积一次反射。

使用 start 和 count 烘焙范围并立即发布其单元格。 索引沿 X、Z、Y 前进，从底部填充水平层 到顶部。对于增量间接反弹，完成 pass: 0 的整个网格， 然后重复 pass: 1 等。在索引 0 处开始每次传递以快照 更新其单元格之前的上一步。

SunLight 的阴影投射实例暂时替换为 等效定向光，因为它们的视图适合阴影级联 无法跨探针渲染冻结。

renderer

渲染器.
scene

要渲染的场景.
options

烘焙选项。

cubemapSize

每个立方体贴图面的分辨率。

默认为 8.
near

立方体相机的近平面。

默认为0.1.
far

立方体的远平面相机.

默认为100.
bounces

额外的反弹通道。仅在烘焙整个网格时可用。

默认为0.
sampleCount

将每个立方体贴图投影到 SH 时集成的方向。

默认为512.
start

要烘焙的第一个探针的索引。

默认为0.
count

要烘焙的探针数量。默认为剩余探针。
pass

起始通道。零捕获直射光；后面的通道对前一个通道进行采样。远程调用需要 bounces: 0.

默认为0.

.dispose()

释放 GPU 资源。

覆盖： Light#dispose

.getProbePosition( ix : number, iy : number, iz : number, target : Vector3 ) : Vector3

返回探头的世界空间位置网格索引 (ix, iy, iz).

ix

X 索引.
iy

Y 索引.
iz

Z 索引.
target

目标矢量.

.updateBoundingBox()

从当前位置和大小更新世界空间边界框。
