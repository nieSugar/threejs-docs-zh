UniformArrayNode

与 BufferNode 类似，该模块将类似数组的数据表示为 统一的缓冲区。与BufferNode不同，它可以处理更常见的 数组中的数据类型（例如 three.js 原语）并自动 管理缓冲区填充。它应该是合作时的首选 制服缓冲区。

代码示例

const tintColors = uniformArray( [
	new Color( 1, 0, 0 ),
	new Color( 0, 1, 0 ),
	new Color( 0, 0, 1 )
], 'color' );
const redColor = tintColors.element( 0 );

构造函数

new UniformArrayNode( value : Array.<any>, elementType : string )

构造一个新的统一数组节点。

value

保存缓冲区数据的数组。
elementType

缓冲区元素的数据类型。

默认为null.

属性

.array : Array.<any>

保存缓冲区数据的数组。与 BufferNode 不同，该数组可以 保存数字基元以及 Three.js 对象，例如向量、矩阵 或颜色。

.elementType : string

数组元素的数据类型。

.isArrayBufferNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.paddedType : string

填充类型。统一缓冲区必须符合特定的缓冲区布局 因此会计算一个单独的类型以确保正确的缓冲区大小。

.updateType : string

覆盖，因为每次渲染都会更新统一数组节点。

默认为'render'.

覆盖： BufferNode#updateType

方法

.element( indexNode : IndexNode ) : UniformArrayElementNode

覆盖默认值element() 提供元素访问的方法 基于UniformArrayNode.

indexNode

索引节点。

.generateNodeType( builder : NodeBuilder ) : string

由于节点类型是从 UniformArrayNode#paddedType.

builder

当前节点构建器.
覆盖： BufferNode#generateNodeType
返回： 节点类型。

.getElementType( builder : NodeBuilder ) : string

数组元素的数据类型。

builder

当前节点构建器.
覆盖： BufferNode#getElementType
返回：元素类型。

.getPaddedType() : string

返回基于元素的填充类型类型.

返回： 填充类型.

.onUpdate( callback : function, updateType : string ) : UniformArrayNode

通过缓冲区传输组成用户定义的更新。

callback

更新函数.
updateType

更新类型.
覆盖： BufferNode#onUpdate
返回：对此节点的引用.

.setup( builder : NodeBuilder ) : null

根据数组数据实现值缓冲区创建。

builder

对当前节点构建器的引用。
覆盖： BufferNode#setup

.updateBuffer()

该方法确保正确传输来自（复杂）对象 在数组中到内部，正确填充的值缓冲区。
