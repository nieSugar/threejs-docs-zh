CodeNode

此类表示本机代码部分。它是基础 FunctionNode 等模块的类允许实现 使用本机着色器语言的函数。

构造函数

new CodeNode( code : string, includes : Array.<Node>, language : 'js' | 'wgsl' | 'glsl' )

构造一个新的代码节点。

code

本机代码。

默认为 ''.
includes

包含数组。

默认为[].
language

使用的语言。

默认为 ''.

属性

.code : string

本机代码。

默认为 ''.

.global : boolean

使用此标志用于全局缓存。

默认为true.

覆盖： Node#global

.includes : Array.<Node>

包含数组

默认为[].

.isCodeNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.language : 'js' | 'wgsl' | 'glsl'

使用的语言。

默认为 ''.

方法

.getIncludes( builder : NodeBuilder ) : Array.<Node>

返回此代码节点的包含。

builder

当前节点构建器.
返回：包含.

.setIncludes( includes : Array.<Node> ) : CodeNode

设置此代码的包含节点.

includes

要设置的内容.
返回：对此节点的引用.
