AxesHelper

一个轴对象，用于以简单的方式可视化 3 个轴。 X 轴为红色。 Y 轴为绿色。 Z 轴是蓝色的。

代码示例

const axesHelper = new THREE.AxesHelper( 5 );
scene.add( axesHelper );

构造函数

new AxesHelper( size : number )

构造一个新的轴助手。

size

表示轴的线的大小。

默认为1.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose

.setColors( xAxisColor : number | Color | string, yAxisColor : number | Color | string, zAxisColor : number | Color | string ) : AxesHelper

定义坐标轴助手的颜色。

xAxisColor

x 轴的颜色。
yAxisColor

y 轴的颜色。
zAxisColor

z 轴的颜色axis.
返回： 对此轴助手的引用.
