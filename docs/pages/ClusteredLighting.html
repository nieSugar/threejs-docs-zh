ClusteredLighting

基于前向+集群着色的自定义照明实现 覆盖 WebGPURenderer 中的默认照明系统。适合 对于具有许多点光源和真实深度复杂性的 3D 场景 - 视图 视锥体被划分为 3D 簇网格，因此实际上只有灯光 评估到达每个片段。

代码示例

const lighting = new ClusteredLighting();
renderer.lighting = lighting; // set lighting system

导入

ClusteredLighting 是一个插件，必须显式导入，请参阅Installation#Addons.

import { ClusteredLighting } from 'three/addons/lighting/ClusteredLighting.js';

构造函数

new ClusteredLighting( maxLights : number, tileSize : number, zSlices : number, maxLightsPerCluster : number )

构造一个新的集群照明系统.

maxLights

最大点光源数量.

默认为1024.
tileSize

屏幕图块大小（以像素为单位）（集群XY大小）.

默认为32.
zSlices

数量指数深度切片。

默认为 24.
maxLightsPerCluster

每集群灯列表容量。

默认为64.
