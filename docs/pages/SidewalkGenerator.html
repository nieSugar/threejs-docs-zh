SidewalkGenerator

为城市街区生成凸起的人行道：每个街区有一个圆角混凝土 板的边缘是独特的花岗岩路缘石，突出了步行表面， 掉落到路上。在展示位置列表中进行实例化，并以自己的方式进行装饰 程序材料（浇注混凝土标志、刻痕伸缩缝、花岗岩路缘石）。 返回两个实例化网格体的 THREE.Group - 行走板和路缘石。

与建筑生成器不同，它拥有自己的材质：板和路缘石 几何体和遮蔽它们的 TSL 一起生活在这里。

代码示例

const sidewalk = new SidewalkGenerator( { width: 90, depth: 60, height: 0.5 } );
scene.add( sidewalk.build( placements ) ); // placements: Matrix4[]

构造函数

new SidewalkGenerator()
