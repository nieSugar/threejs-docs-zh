OrthographicCamera

使用正交投影的相机.

在此投影中模式下，渲染图像中对象的大小保持不变 无论距相机的距离如何，都是恒定的。这可能很有用 用于渲染 2D 场景和 UI 元素等。

代码示例

const camera = new THREE.OrthographicCamera( width / - 2, width / 2, height / 2, height / - 2, 1, 1000 );
scene.add( camera );

构造函数

new OrthographicCamera( left : number, right : number, top : number, bottom : number, near : number, far : number )

构造一个新的正交相机。

left

相机平截头体的左平面。

默认为 -1.
right

相机平截头体的右平面.

默认为1.
top

The相机视锥体的顶部平面。

默认为1.
bottom

相机视锥体的底部平面。

默认为 -1.
near

相机的近平面。

默认为0.1.
far

相机的远平面。

默认为2000.

属性

.bottom : number

相机视锥体的底部平面。

默认为 -1.

.far : number

相机的远平面。必须大于 OrthographicCamera#near.

默认为2000.

.isOrthographicCamera : boolean (readonly)

该标志可用于类型测试。

默认为true.

.left : number

相机平截头体的左平面。

默认为 -1.

.near : number

相机近平面的当前值。有效范围大于0 并且小于 OrthographicCamera#far 的当前值。

请注意，与 PerspectiveCamera 不同，0 是 正交相机近平面的有效值。

默认为0.1.

.right : number

相机平截头体的右平面.

默认为1.

.top : number

The相机视锥体的顶部平面。

默认为1.

.view : Object

表示视锥体窗口规范。不应编辑此属性 直接但通过 PerspectiveCamera#setViewOffset 和 PerspectiveCamera#clearViewOffset.

默认为null.

.zoom : number

相机的变焦系数。

默认为1.

方法

.clearViewOffset()

从投影矩阵中删除视图偏移。

.setViewOffset( fullWidth : number, fullHeight : number, x : number, y : number, width : number, height : number )

设置较大的偏移截锥体。这对于多窗口或 多屏/多机设置.

fullWidth

多视图设置的全宽.
fullHeight

多视图设置的全高.
x

子摄像头的水平偏移.
y

子摄像头的垂直偏移子摄像头.
width

子摄像头的宽度.
height

子摄像头的高度.
参见：
  • PerspectiveCamera#setViewOffset

.updateProjectionMatrix()

更新相机的投影矩阵。必须在任何更改后调用 相机属性.
