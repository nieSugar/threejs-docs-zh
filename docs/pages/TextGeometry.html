TextGeometry

用于将文本生成为单个几何图形的类。它是通过提供一串文本和一组 由加载的字体和挤出设置组成的参数。

有关其他详细信息，请参阅 FontLoader 页面。

TextGeometry 使用 typeface.json 生成的字体。 一些现有字体可以在 /examples/fonts 中找到。

代码示例

const loader = new FontLoader();
const font = await loader.loadAsync( 'fonts/helvetiker_regular.typeface.json' );
const geometry = new TextGeometry( 'Hello three.js!', {
	font: font,
	size: 80,
	depth: 5,
	curveSegments: 12
} );

导入

TextGeometry 是一个插件，必须显式导入，请参阅 安装#Addons.

import { TextGeometry } from 'three/addons/geometries/TextGeometry.js';

构造函数

new TextGeometry( text : string, parameters : TextGeometry~Options )

构造一个新的文本几何图形.

text

应转换为几何图形的文本.
parameters

文本设置.

类型定义

.Options

表示几何构造函数的options类型。

font
Font

The字体.
size
number

文本大小.

默认为100.
depth
number

挤出样条线的深度形状.

默认为50.
curveSegments
number

几何图形上的点数曲线.

默认为 12.
steps
number

用于沿挤出样条线深度细分线段的点数。

默认为1.
bevelEnabled
boolean

是否对形状进行斜切.

默认为 false.
bevelThickness
number

斜角进入原始形状的深度。

默认为10.
bevelSize
number

距离斜角延伸的形状轮廓。

默认为 8.
bevelOffset
number

距斜角开始的形状轮廓的距离。

默认为0.
bevelSegments
number

斜角层数。

默认为3.
direction
string

字符方向：ltr（从左到右），rtl（从右到左）和tb（顶部底部）.

默认为 'ltr'.
extrudePath
Curve

A形状应沿其挤出的 3D 样条路径。路径挤出不支持斜角。

默认为null.
UVGenerator
Object

为自定义 UV 生成提供 UV 生成器功能的对象。
