ShaderMaterial

使用自定义着色器渲染的材质。着色器是用 GLSL 编写的小程序。 在 GPU 上运行。如果您需要实现一个，您可能需要使用自定义着色器 任何内置材质都不包含该效果。

使用 ShaderMaterial 时要记住以下注意事项：

  • ShaderMaterial只能与WebGLRenderer一起使用。
  • 内置属性和统一变量会随着您的代码一起传递给着色器。如果您不想要这样，请改用 RawShaderMaterial。
  • 可以使用 #pragma unroll_loop_start 和 #pragma unroll_loop_end 指令， 让着色器预处理器展开 GLSL 中的 for 循环。指令必须紧挨着放在循环上方， 并且循环格式必须符合以下规范。
    • 循环必须是规范化循环。
    • 循环变量必须是 i。
    • 在给定的迭代中，值 UNROLLED_LOOP_INDEX 将被显式地替换为 i 的值，并且可以在预处理器语句中使用。

代码示例

const material = new THREE.ShaderMaterial( {
	uniforms: {
		time: { value: 1.0 },
		resolution: { value: new THREE.Vector2() }
	},
	vertexShader: document.getElementById( 'vertexShader' ).textContent,
	fragmentShader: document.getElementById( 'fragmentShader' ).textContent
} );

构造函数

new ShaderMaterial( parameters : Object )

构造新的着色器材质。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.clipping : boolean

定义此材质是否支持裁剪； true 让渲染器 传递clippingPlanesuniform.

默认为 false.

.defaultAttributeValues : Object

当渲染的几何体不包含这些属性但包含 材质执行此操作后，这些默认值将传递给着色器。这个 避免缓冲区数据丢失时出现错误。

  • 颜色: [ 1, 1, 1 ]
  • uv: [ 0, 0 ]
  • uv1: [ 0, 0 ]

.defines : Object

在 GLSL 代码中使用 #define 指令定义自定义常量 对于顶点着色器和片段着色器；每个键/值对 产生另一个指令。

defines: {
	FOO: 15,
	BAR: true
}

产生以下行：

#define FOO 15
#define BAR true

.extensions : Object

此对象允许启用某些 WebGL 2 扩展。

  • clipCullDistance：设置为 true 以使用顶点着色器裁剪
  • multiDraw：设置为 true 以使用顶点着色器 multi_draw / 启用 gl_DrawID

.fog : boolean

定义材质颜色是否受全局雾设置影响；true以将雾的 uniform 参数传递给着色器。

将此属性设置为 true 需要定义雾制服。它是 建议使用 UniformsUtils.merge() 来组合自定义着色器制服 具有预定义的雾制服。

const material = new ShaderMaterial( {
    uniforms: UniformsUtils.merge( [ UniformsLib[ 'fog' ], shaderUniforms ] );
    vertexShader: vertexShader,
    fragmentShader: fragmentShader,
    fog: true
} );

默认为 false.

.forceSinglePass : boolean

默认覆盖并设置为 true。

默认为true.

覆盖： Material#forceSinglePass

.fragmentShader : string

片段着色器 GLSL代码。这是着色器的实际代码。

.glslVersion : GLSL1 | GLSL3

定义自定义着色器代码的 GLSL 版本。

默认为null.

.index0AttributeName : string | undefined

如果设置，则调用 gl.bindAttribLocation 将通用顶点索引绑定到属性变量。

默认为undefined.

.isShaderMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.lights : boolean

定义此材质是否使用照明； true 传递统一数据 与此着色器的光照相关。

默认为 false.

.linewidth : number

控制线条粗细或行.

WebGL 和 WebGPU 忽略此设置并始终使用 一个像素的宽度。

默认为1.

.uniforms : Object

以下形式的对象：

{
	"uniform1": { value: 1.0 },
	"uniform2": { value: 2 }
}

指定要传递给着色器代码的制服；按键是统一的 名称、值的定义形式为

{
	value: 1.0
}

，其中value 是制服的值。姓名必须与姓名相符 GLSL 代码中定义的统一。请注意，制服已刷新 在每一帧上，因此更新制服的值将立即 更新 GLSL 代码可用的值。

.uniformsGroups : Array.<UniformsGroup>

保存用于配置 UBO 的制服组的数组。

.uniformsNeedUpdate : boolean

可用于在更改制服时强制进行统一更新 Object3D#onBeforeRender.

默认为 false.

.vertexShader : string

顶点着色器GLSL代码。这是着色器的实际代码。

.wireframe : boolean

将几何体渲染为线框。

默认为 false.

.wireframeLinewidth : number

控制厚度线框的.

WebGL 和 WebGPU 忽略此属性并始终渲染 1 像素宽线.

默认为1.

方法

.fromJSON( json : Object, textures : Object.<string, Texture> ) : ShaderMaterial

从以下位置反序列化材质给定的 JSON.

json

保存序列化材质的 JSON。
textures

保存材质引用的纹理的字典。
覆盖： Material#fromJSON
返回： 对此材质的引用。
