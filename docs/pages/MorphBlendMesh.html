MorphBlendMesh

具有更高级界面的特殊类型的动画网格 用于动画播放。与 MorphAnimMesh 不同。它允许 同时播放多个变形动画但不 淡入淡出选项。

导入

MorphBlendMesh 是一个插件，必须显式导入，请参阅Installation#Addons.

import { MorphBlendMesh } from 'three/addons/misc/MorphBlendMesh.js';

构造函数

new MorphBlendMesh( geometry : BufferGeometry, material : Material | Array.<Material> )

构造一个新的变形混合网格。

geometry

网格体几何形状。
material

网格材质。

属性

.animationsList : Array.<Object>

动画列表。

.animationsMap : Object.<string, Object>

动画字典。

方法

.autoCreateAnimations( fps : number )

根据中的值自动创建动画 Mesh#morphTargetDictionary.

fps

所有动画的FPS。

.createAnimation( name : string, start : number, end : number, fps : number )

创建一个新动画。

name

动画名称。
start

开始时间.
end

结束时间.
fps

The FPS.

.getAnimationDuration( name : string ) : number

返回定义的持续时间动画.

name

动画名称。
返回： 持续时间。

.getAnimationTime( name : string ) : number

返回定义的动画的时间。

name

动画名称。
返回： 时间。

.playAnimation( name : string )

播放定义的动画animation.

name

动画名称。

.setAnimationDirectionBackward( name : string )

将动画播放方向设置为“向后” 定义的动画.

name

动画名称。

.setAnimationDirectionForward( name : string )

将动画播放方向设置为“向前” 定义的动画。

name

动画名称。

.setAnimationDuration( name : string, duration : number )

将定义的动画的持续时间设置为给定值。

name

动画名称。
duration

要设置的持续时间。

.setAnimationFPS( name : string, fps : number )

将定义的动画的 FPS 设置为给定值。

name

动画名称。
fps

要设置的 FPS。

.setAnimationTime( name : string, time : number )

将定义的动画的时间设置为给定值动画.

name

动画名称。
time

设置的时间。

.setAnimationWeight( name : string, weight : number )

将定义的动画的权重设置为给定值。

name

动画名称。
weight

要设置的权重。

.stopAnimation( name : string )

停止定义的动画。

name

动画名称。

.update( delta : number )

更新动画的动画网格.

delta

以秒为单位的增量时间。
