WebGPU

具有基本 WebGPU 功能测试的实用程序模块。

导入

WebGPU 是一个插件，必须显式导入，请参阅 Installation#Addons.

import WebGPU from 'three/addons/capabilities/WebGPU.js';

静态方法

.getErrorMessage() : HTMLDivElement

返回一个 div 元素，表示可以附加到的格式化错误消息 如果不支持 WebGPU，则为网站。

返回： div 元素，表示不支持 WebGPU 的格式化错误消息。

.isAvailable() : boolean

如果支持 WebGPU，则返回 true available.

返回： WebGPU是否可用.
