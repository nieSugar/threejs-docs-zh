BufferAttributeNode

在早期的three.js版本中只能定义属性数据 在几何层面上。使用BufferAttributeNode，也可以这样做 在节点级别上。

const geometry = new THREE.PlaneGeometry();
const positionAttribute = geometry.getAttribute( 'position' );
const colors = [];
for ( let i = 0; i < position.count; i ++ ) {
	colors.push( 1, 0, 0 );
}
material.colorNode = bufferAttribute( new THREE.Float32BufferAttribute( colors, 3 ) );

当几何数据通过以下方式生成时，这种新方法特别有趣 计算着色器。下面这行将存储缓冲区转换为属性节点。

material.positionNode = positionBuffer.toAttribute();

构造函数

new BufferAttributeNode( value : BufferAttribute | InterleavedBuffer | TypedArray, bufferType : string, bufferStride : number, bufferOffset : number )

构造一个新的缓冲区属性节点。

value

属性数据。
bufferType

缓冲区类型（例如'vec3').

默认为null.
bufferStride

缓冲区步幅.

默认为0.
bufferOffset

缓冲区偏移量.

默认为0.

属性

.attribute : BufferAttribute

对缓冲区的引用attribute.

默认为null.

.bufferOffset : number

缓冲区偏移量.

默认为0.

.bufferStride : number

缓冲区步幅.

默认为0.

.bufferType : string

缓冲区类型（例如'vec3').

默认为null.

.global : boolean

BufferAttributeNode 默认情况下将此属性设置为 true。

默认为true.

覆盖： InputNode#global

.instanced : boolean

属性是否实例化。

默认为 false.

.isBufferNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.usage : number

用法属性。通过 .setUsage() 将其设置为 THREE.DynamicDrawUsage， 如果您计划更新每帧的属性数据。

默认为 StaticDrawUsage.

方法

.generate( builder : NodeBuilder ) : string

生成缓冲区属性节点的代码片段。

builder

当前节点构建器.
覆盖： InputNode#generate
返回：生成的代码snippet.

.generateNodeType( builder : NodeBuilder ) : string

该方法被覆盖，因为节点类型是从 缓冲区属性。

builder

当前节点构建器.
覆盖： InputNode#generateNodeType
返回： 节点类型。

.getHash( builder : NodeBuilder ) : string

由于属性数据可能共享，因此该方法被覆盖 因此哈希值也应该共享。

builder

当前节点构建器.
覆盖： InputNode#getHash
返回： 哈希值.

.getInputType( builder : NodeBuilder ) : string

覆盖默认实现以返回固定值'bufferAttribute'.

builder

当前节点构建器.
覆盖： InputNode#getInputType
返回： 输入类型.

.setInstanced( value : boolean ) : BufferAttributeNode

将 instanced 属性设置为给定值value.

value

要设置的值。
返回：对此节点的引用.

.setUsage( value : number ) : BufferAttributeNode

将 usage 属性设置为给定值。

value

设置的用法.
返回：对此节点的引用.

.setup( builder : NodeBuilder )

根据传递给节点的值，setup() 的行为 不同。如果没有传递 BufferAttribute 的实例，则该方法 创建一个内部属性并分别配置它。

builder

当前节点构建器.
覆盖： InputNode#setup
