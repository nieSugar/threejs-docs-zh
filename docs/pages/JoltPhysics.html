JoltPhysics

可用于将 Jolt 作为物理引擎包含到 three.js 应用程序。 API 可以通过以下方式初始化：

该组件会自动从 CDN 导入 Jolt，因此请确保 要使用具有活动互联网连接的组件。

代码示例

const physics = await JoltPhysics();

导入

JoltPhysics 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { JoltPhysics } from 'three/addons/physics/JoltPhysics.js';

方法

.addMesh( mesh : Mesh, mass : number, restitution : number )

将给定的网格添加到此物理模拟中。

mesh

要添加的网格。
mass

网格的质量（以千克为单位）。

默认为0.
restitution

网格体的恢复，通常从 0 到 1。表示对象相互碰撞时的“弹性”程度。

默认为0.

.addScene( scene : Object3D )

将给定场景添加到此物理模拟中。仅与具有 Object3D#userData 字段中的 physics 对象将受到尊重。 该对象可用于存储网格的质量和恢复。例如：

box.userData.physics = { mass: 1, restitution: 0 };
scene

要添加的场景或任何类型的 3D 对象。

.setMeshPosition( mesh : Mesh, position : Vector3, index : number )

设置作为物理模拟一部分的给定网格的位置。调用这个 方法将重置网格体的当前模拟速度。

mesh

要更新位置的网格体.
position

新位置.
index

如果网格体已实例化，则索引表示实例化的ID。

默认为0.
