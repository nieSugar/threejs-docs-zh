WebGPUTimestampQueryPool

管理用于性能测量的 WebGPU 时间戳查询池。 扩展基本 TimestampQueryPool 以提供特定于 WebGPU 的实现。

构造函数

new WebGPUTimestampQueryPool( device : GPUDevice, type : string, maxQueries : number )

创建新的 WebGPU 时间戳查询池。

device

要在其上创建查询的 WebGPU 设备.
type

此查询池的类型标识符。
maxQueries

此池可以的最大查询数保持.

默认为 2048.

方法

.allocateQueriesForContext( uid : string ) : number

为一个查询分配一对查询给定渲染上下文。

uid

渲染上下文的唯一标识符.
覆盖： TimestampQueryPool#allocateQueriesForContext
返回： 已分配查询的基本偏移量，如果分配失败则为 null。

.dispose() : Promise (async)

处理查询池。

覆盖： TimestampQueryPool#dispose
返回： 在处置完成后解析的 Promise 已执行.

.resolveQueriesAsync() : Promise.<number> (async)

异步解析所有挂起的查询并返回总持续时间。 如果已经有待处理的解析操作，则返回该承诺。

覆盖： TimestampQueryPool#resolveQueriesAsync
返回： 总持续时间（以毫秒为单位），或解析失败时的最后一个有效值。
