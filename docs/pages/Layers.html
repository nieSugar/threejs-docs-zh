Layers

图层对象将 3D 对象分配给 32 个中的 1 个或多个 编号为 0 到 31 的层 - 在内部，这些层存储为 位掩码]，默认情况下所有 3D 对象都是图层 0.

的成员，这可用于控制可见性 - 对象必须与 当相机的视图处于可见状态时，该相机可见 render.

从 Object3D 继承的所有类都有一个 layers 属性，该属性 是此类的一个实例。

构造函数

new Layers()

构造一个新的图层实例，具有成员资格 最初设置为图层 0.

属性

.mask : number

A 位掩码，存储该图层对象当前是 32 个图层中的哪一个 的成员.

方法

.disable( layer : number )

删除给定层的成员资格.

layer

要启用的层.

.disableAll()

从所有层中删除成员资格.

.enable( layer : number )

添加给定层的成员资格层.

layer

要启用的层.

.enableAll()

向所有层添加成员资格。

.isEnabled( layer : number ) : boolean

如果启用给定层，则返回true。

layer

要添加的层test.
返回： 给定层是否启用。

.set( layer : number )

设置给定层的成员资格，并删除所有其他层的成员资格。

layer

要设置的层。

.test( layers : Layers ) : boolean

返回true 如果此对象和给定的图层对象至少有一个 共同层.

layers

要测试的层.
返回：此对象与给定层对象是否至少有一个共同层。

.toggle( layer : number )

切换给定层的成员资格。

layer

要测试的层切换.
