TexturePass

此通道可用于在整个屏幕上渲染纹理。

代码示例

const texture = new THREE.TextureLoader().load( 'textures/2294472375_24a3b8ef46_o.jpg' );
texture.colorSpace = THREE.SRGBColorSpace;
const texturePass = new TexturePass( texture );
composer.addPass( texturePass );

导入

TexturePass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { TexturePass } from 'three/addons/postprocessing/TexturePass.js';

构造函数

new TexturePass( map : Texture, opacity : number )

构造一个新的纹理通道。

map

要渲染的纹理。
opacity

The不透明度.

默认为1.

属性

.map : Texture

要渲染的纹理。

.material : ShaderMaterial

通道材质.

.needsSwap : boolean

覆盖以禁用交换.

默认为 false.

覆盖： Pass#needsSwap

.opacity : number

The不透明度.

默认为1.

.uniforms : Object

通道制服.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行纹理通过.

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
