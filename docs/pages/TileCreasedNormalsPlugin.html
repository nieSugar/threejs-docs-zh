TileCreasedNormalsPlugin

3d-tiles-renderer 的插件，用于计算折痕顶点法线 每个加载的图块的几何形状：除了面相交的地方之外，所有地方都平滑法线 角度大于折痕角度。对于摄影测量图块集很有用 就像 Google Photorealistic 3D Tiles 一样，它没有顶点法线。

法线是在 Web Worker 中计算的，因此图块处理不会阻止 主线程。一旦法线准备就绪，图块就会显示。

代码示例

tiles.registerPlugin( new TileCreasedNormalsPlugin( { creaseAngle: Math.PI / 6 } ) );

导入

TileCreasedNormalsPlugin 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { TileCreasedNormalsPlugin } from 'three/addons/misc/TileCreasedNormalsPlugin.js';

构造函数

new TileCreasedNormalsPlugin( options : Object )

构造一个新插件。

options

配置选项.

creaseAngle

以弧度表示的折痕角度。

默认为Math.PI/3.

属性

.creaseAngle : number

以弧度表示的折痕角度。

方法

.dispose()

当插件未注册或插件未注册时由图块渲染器调用 处理了tiles渲染器。

.processTileModel( scene : Object3D ) : Promise

由tiles渲染器为每个加载的tile模型调用。瓷砖是 返回的 Promise 解析后显示。

scene

图块模型。
返回： 当所有几何图形都折痕法线时解析的 Promise.
