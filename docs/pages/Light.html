Light

灯光的抽象基类 - 所有其他灯光类型都继承 这里描述的属性和方法.

构造函数

new Light( color : number | Color | string, intensity : number ) (abstract)

构造一个新的灯光.

color

灯光的颜色.

默认为0xffffff.
intensity

灯光的强度/强度.

默认为1.

属性

.color : Color

灯光的颜色.

.intensity : number

灯光的强度.

默认为1.

.isLight : boolean (readonly)

该标志可用于类型测试。

默认为true.
