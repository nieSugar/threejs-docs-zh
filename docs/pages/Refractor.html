Refractor

可用于创建平坦的折射表面，如特殊的 窗户或水效果。

注意，此类只能与WebGLRenderer一起使用。 使用 WebGPURenderer 时，请使用 viewportSharedTexture.

代码示例

const geometry = new THREE.PlaneGeometry( 100, 100 );
const refractor = new Refractor( refractorGeometry, {
	color: 0xcbcbcb,
	textureWidth: 1024,
	textureHeight: 1024
} );
scene.add( refractor );

导入

Refractor 是一个插件，必须显式导入，请参阅 安装#Addons.

import { Refractor } from 'three/addons/objects/Refractor.js';

构造函数

new Refractor( geometry : BufferGeometry, options : Refractor~Options )

构造一个新的折射器.

geometry

折射器的几何形状.
options

配置选项.

属性

.camera : PerspectiveCamera

反射器的虚拟相机.

.isRefractor : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Mesh#dispose

.getRenderTarget() : WebGLRenderTarget

返回反射器的内部渲染目标。

返回： 内部渲染target

类型定义

.Options

构造函数选项Refractor.

color
number | Color | string

折射器的颜色.

默认为0x7F7F7F.
textureWidth
number

纹理宽度。值越高，折射越清晰，但成本也越高。

默认为512.
textureHeight
number

纹理高度。值越高，折射越清晰，但成本也越高。

默认为512.
clipBias
number

剪辑偏差。

默认为0.
shader
Object

可用于传入定义折射视图如何投影到反射器几何体上的自定义着色器。
multisample
number

用于 MSAA 的样本数。 0 禁用 MSAA。

默认为4.
