TreeGenerator

生长一个程序树骨架 - 树干、树枝和细枝，每个都扫成锥形 管 - 并将其烘焙到一个索引的 BufferGeometry （位置和正常 仅），准备实例化到森林中。它仅产生分支；添加树叶作为 单独的层.

对于给定的seed，分支是确定性的：递归扫描轻轻地放下 具有平行传输框架的弯曲管（因此它们不会扭曲），由 管道模型（每个孩子比其父母细得多），沿着管道传播孩子 每个树枝的上部进行黄金角滚动，然后将它们拉回到 光。角色中的喇叭形根部、非线性锥度和重力下垂填充。

参数使用流畅的构建器设置：每个默认值都存在 set<Param>() ( setSeed, setLevels, setChildren, … ), 每个返回 this 用于链接.

Each build() 返回调用者拥有的一个新的、独立的网格，因此 生成器可以重新参数化并重复构建以生长不同的支架：

代码示例

const generator = new TreeGenerator( material );
const oak = generator.setSeed( 1 ).setLevels( 4 ).build();
const pine = generator.setSeed( 2 ).setLevels( 5 ).build();

构造函数

new TreeGenerator()
