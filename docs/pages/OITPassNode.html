OITPassNode

使用顺序无关透明度渲染场景的渲染通道节点 基于 McGuire 和 Bavoil 的加权混合 OIT 技术。

透明对象在单独的通道中渲染为两个累积 目标（加权颜色和和像素的显示）是 然后合成场景的其余部分。因为结果不依赖于 在绘制顺序上，来自基于排序的透明度的伪像，例如弹出或 避免错误解析相交几何体。

仅使用 NormalBlending 的透明材质且不符合传输条件 对于 OIT。所有其他对象均照常渲染。

MSAA 仅支持 WebGPU 后端。

通过 setMRT() 分配的 MRT 配置仅适用于默认通道。 OIT 合格的对象有助于颜色输出，但不利于自定义 MRT 输出，因为一个像素可能会累积多个透明表面。

参考：

  • https://jcgt.org/published/0002/02/09/
  • https://casual-effects.blogspot.com/2014/03/weighted-blended-order-independent.html

代码示例

const renderPipeline = new THREE.RenderPipeline( renderer );
renderPipeline.outputNode = oitPass( scene, camera );

导入

OITPassNode 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { oitPass } from 'three/addons/tsl/display/OITPassNode.js';

构造函数

new OITPassNode( scene : Scene, camera : Camera, options : Object )

构造一个新的OIT pass节点。

scene

要渲染的场景.
camera

用于渲染场景的相机。
options

内部渲染目标的选项。

默认为 {}.

属性

.isOITPassNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.weightNode : Node.<float>

透明片段基于深度的权重，参见等式(7)至(9) 在报纸上。当null时，使用等式(9)。必须先分配 第一次渲染.

默认为null.
