AnimationClip

表示动画的可重用关键帧轨迹集。

构造函数

new AnimationClip( name : string, duration : number, tracks : Array.<KeyframeTrack>, blendMode : NormalAnimationBlendMode | AdditiveAnimationBlendMode )

构造一个新的动画剪辑。

注意：不要直接使用构造函数，你可以 使用此类的静态接口来创建剪辑。但在大多数情况下，动画剪辑 导入动画 3D 资源时，加载程序将自动创建。

name

剪辑的名称。

默认为 ''.
duration

剪辑的持续时间（以秒为单位）。如果传递负值， 持续时间将从传递的关键帧计算。

默认为 -1.
tracks

关键帧轨迹数组。
blendMode

定义动画的方式 当两个或多个动画同时播放时混合/组合。

默认为 NormalAnimationBlendMode.

属性

.blendMode : NormalAnimationBlendMode | AdditiveAnimationBlendMode

定义当两个或多个动画时动画如何混合/组合 同时播放。

.duration : number

剪辑的持续时间（以秒为单位）。

.name : string

剪辑的名称。

.tracks : Array.<KeyframeTrack>

关键帧轨迹数组。

.userData : Object

可用于存储有关动画剪辑的自定义数据的对象。 它不应包含对函数的引用，因为这些函数不会被克隆。

.uuid : string (readonly)

动画剪辑的 UUID。

方法

.clone() : AnimationClip

返回一个新的动画剪辑，其中包含从此实例复制的值。

返回：此克隆instance.

.optimize() : AnimationClip

通过删除等效的顺序键（即 常见于变形目标序列中）。

返回：对此动画剪辑的引用。

.resetDuration() : AnimationClip

将此剪辑的持续时间设置为其最长关键帧轨道的持续时间。

返回：对此动画剪辑的引用。

.toJSON() : Object

将此动画剪辑序列化为JSON.

返回： JSON 对象。

.trim() : AnimationClip

将所有轨道修剪为剪辑的持续时间。

返回：对此动画剪辑的引用。

.validate() : boolean

对剪辑中的每个轨道执行最少的验证。如果全部返回 true 轨道有效。

返回：剪辑的关键帧是否有效。

静态方法

.CreateClipsFromMorphTargetSequences( morphTargets : Array.<Object>, fps : number, noLoop : boolean ) : Array.<AnimationClip>

返回从变形目标创建的新动画剪辑数组 几何体的序列，尝试将变形目标名称排序为 基于动画组的模式，例如“Walk_001、Walk_002、Run_001、Run_002...”。

请参阅MD2Loader#parse作为如何使用该方法的示例。

morphTargets

变形序列目标.
fps

每秒帧数值.
noLoop

剪辑是否不应循环.
返回：新动画剪辑的数组。

.CreateFromMorphTargetSequence( name : string, morphTargetSequence : Array.<Object>, fps : number, noLoop : boolean ) : AnimationClip

返回新动画剪辑传递的变形目标数组 几何体，取一个名称和每秒的帧数。

注意：fps参数是必需的，但动画速度可以是 通过 AnimationAction#setDuration 覆盖。

name

动画剪辑的名称。
morphTargetSequence

变形序列目标.
fps

每秒帧数值.
noLoop

剪辑是否不应循环.
返回： 新的动画剪辑。

.findByName( objectOrClipArray : Array.<AnimationClip> | Object3D, name : string ) : AnimationClip

按名称搜索动画剪辑，并将其作为其第一个参数 剪辑数组，或者包含 名为“animations”属性的数组。

objectOrClipArray

要搜索的数组或对象。
name

要搜索的名称。
返回：找到的动画剪辑。如果未找到剪辑，则返回 null。

.parse( json : Object ) : AnimationClip

用于从给定 JSON 创建动画剪辑的工厂方法。

json

序列化动画剪辑。
返回： 新的动画剪辑。

.toJSON( clip : AnimationClip ) : Object

将给定动画剪辑序列化为JSON.

clip

要序列化的动画剪辑.
返回： JSON 对象。
