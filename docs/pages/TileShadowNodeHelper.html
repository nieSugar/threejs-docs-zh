TileShadowNodeHelper

Helper 类用于管理和显示 TileShadowNode 的调试视觉效果。

导入

TileShadowNodeHelper 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { TileShadowNodeHelper } from 'three/addons/tsl/shadows/TileShadowNodeHelper.js';

构造函数

new TileShadowNodeHelper( tileShadowNode : TileShadowNode )

tileShadowNode

要调试的 TileShadowNode 实例。

方法

.dispose()

从scene.

覆盖： Group#dispose

.init()

初始化调试显示（平面和相机助手）。 应在 TileShadowNode 初始化其灯光和阴影节点后调用。

.update()

更新调试视觉效果（特别是相机助手）。 应该在 TileShadowNode 的更新方法中调用。
