SpotLightHelper

这显示 SpotLight.

当聚光灯或其目标发生变换或灯光属性发生变化时显示锥形辅助对象 更改后，需要调用相应助手的 update() 方法。

代码示例

const spotLight = new THREE.SpotLight( 0xffffff );
spotLight.position.set( 10, 10, 10 );
scene.add( spotLight );
const spotLightHelper = new THREE.SpotLightHelper( spotLight );
scene.add( spotLightHelper );

构造函数

new SpotLightHelper( light : HemisphereLight, color : number | Color | string )

构造一个新的聚光灯助手。

light

要可视化的光源。
color

助手的颜色。如果没有设置，助手将采取 灯光的颜色。

属性

.color : number | Color | string

构造函数中传递的颜色参数。 如果未设置，助手将采用灯光的颜色。

.light : SpotLight

正在可视化的灯光。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Object3D#dispose

.update()

更新帮助者匹配的位置和方向 光被可视化.
