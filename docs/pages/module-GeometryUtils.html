GeometryUtils

导入

GeometryUtils 是一个插件，必须显式导入，请参阅 安装#Addons.

import * as GeometryUtils from 'three/addons/utils/GeometryUtils.js';

方法

.gosper( size : number ) : Array.<number> (inner)

生成Gosper曲线（位于XY平面）.

参考：https://gist.github.com/nitaku/6521802

size

单个戈斯珀岛的大小.

默认为1.
返回：戈斯珀岛点.

.hilbert2D( center : Vector3, size : number, iterations : number, v0 : number, v1 : number, v2 : number, v3 : number ) : Array.<Vector3> (inner)

沿线生成二维坐标希尔伯特曲线.

基于以下人员的工作：http://www.openprocessing.org/sketch/15493

center

希尔伯特中心曲线.
size

希尔伯特曲线总宽度.

默认为10.
iterations

细分数.

默认为10.
v0

角点索引-X，-Z.

默认为0.
v1

角点索引-X， +Z.

默认为1.
v2

角点索引 +X, +Z.

默认为2.
v3

角点索引 +X, -Z.

默认为3.
返回： 希尔伯特曲线点.

.hilbert3D( center : Vector3, size : number, iterations : number, v0 : number, v1 : number, v2 : number, v3 : number, v4 : number, v5 : number, v6 : number, v7 : number ) : Array.<Vector3> (inner)

沿 a 生成 3D 坐标希尔伯特曲线.

基于以下工作：https://openprocessing.org/user/5654

center

希尔伯特中心曲线.
size

希尔伯特曲线总宽度.

默认为10.
iterations

细分数.

默认为1.
v0

角点索引-X、+Y、 -Z.

默认为0.
v1

角点索引-X、+Y、+Z.

默认为1.
v2

角点索引-X、-Y、+Z.

默认为2.
v3

角点索引-X、-Y、-Z.

默认为3.
v4

角点索引+X、-Y、 -Z.

默认为4.
v5

角点索引 +X、-Y、+Z.

默认为5.
v6

角点索引 +X、+Y、+Z.

默认为6.
v7

角点索引 +X、+Y、-Z.

默认为7.
返回：
  • 希尔伯特曲线点。
