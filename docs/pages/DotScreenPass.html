DotScreenPass

用于创建点屏效果的Pass。

代码示例

const pass = new DotScreenPass( new THREE.Vector2( 0, 0 ), 0.5, 0.8 );
composer.addPass( pass );

导入

DotScreenPass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { DotScreenPass } from 'three/addons/postprocessing/DotScreenPass.js';

构造函数

new DotScreenPass( center : Vector2, angle : number, scale : number )

构造新的点屏通道.

center

中心点.
angle

以弧度为单位的效果旋转。
scale

效果的规模。值越高意味着点越小。

属性

.material : ShaderMaterial

通道材质.

.uniforms : Object

合格制服。如果您想更新，请使用此对象 center、angle 或 scale 运行时的值。

pass.uniforms.center.value.copy( center );
pass.uniforms.angle.value = 0;
pass.uniforms.scale.value = 0.5;

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行点屏幕传递。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
