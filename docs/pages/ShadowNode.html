ShadowNode

表示照明节点的默认阴影实现。

构造函数

new ShadowNode( light : Light, shadow : LightShadow )

构造一个新的阴影节点。

light

阴影投射光。
shadow

可选灯光Shadow.

默认为null.

属性

.depthLayer : number (readonly)

当使用 RenderTarget 数组覆盖 setupRenderTarget 时可以使用此索引来指定深度层。

默认为true.

.isShadowNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.shadow : LightShadow

定义灯光属性的灯光阴影 阴影.

默认为null.

.shadowMap : RenderTarget

对作为渲染目标的阴影贴图的引用。

默认为null.

.vsmMaterialHorizontal : NodeMaterial

仅与VSM阴影相关。节点材质其中 用于渲染第二个 VSM 通道。

默认为null.

.vsmMaterialVertical : NodeMaterial

仅与 VSM 阴影相关。节点材质其中 用于渲染第一个 VSM 通道。

默认为null.

.vsmShadowMapHorizontal : RenderTarget

仅与 VSM 阴影相关。渲染目标为 第二个 VSM 渲染通道。

默认为null.

.vsmShadowMapVertical : RenderTarget

仅与 VSM 阴影相关。渲染目标为 第一个 VSM 渲染通道。

默认为null.

方法

.dispose()

释放此阴影节点的内部资源。

覆盖： ShadowBaseNode#dispose

.getShadowFilterFn( type : number ) : function

返回给定阴影类型的阴影过滤函数。

type

影子类型.
返回：过滤function.

.renderShadow( frame : NodeFrame )

渲染阴影。可以包含该函数的逻辑 进入 ShadowNode#updateShadow 但更专业的阴影 节点可能需要自定义阴影贴图渲染。通过拥有 专用方法，更容易覆盖默认行为。

frame

对当前节点框架的引用。

.setup( builder : NodeBuilder ) : ShaderCallNodeInternal

该实现执行输出节点的设置。输出仅 如果在渲染器中全局启用阴影贴图，则生成。

builder

对当前节点构建器的引用。
覆盖： ShadowBaseNode#setup
返回： 输出节点。

.setupShadow( builder : NodeBuilder ) : Node.<vec3>

设置阴影输出节点。

builder

对当前节点构建器的引用。
返回： 阴影输出节点.

.setupShadowCoord( builder : NodeBuilder, shadowPosition : Node.<vec3> ) : Node.<vec3>

设置阴影坐标。

builder

对当前节点构建器的引用。
shadowPosition

表示阴影的节点位置.
返回： 阴影坐标。

.setupShadowFilter( builder : NodeBuilder, inputs : Object ) : Node.<float>

设置阴影过滤。

builder

对当前节点构建器的引用。
inputs

定义阴影过滤的配置对象。

filterFn

此函数定义阴影贴图的过滤类型，例如PCF.
depthTexture

对阴影贴图纹理数据的引用。
shadowCoord

用于从阴影贴图采样的阴影坐标。
shadow

光阴影。
返回：阴影过滤的结果节点.

.updateBefore( frame : NodeFrame )

实现在必要时执行阴影贴图的更新。

frame

对当前节点框架的引用。
覆盖： ShadowBaseNode#updateBefore

.updateShadow( frame : NodeFrame )

更新阴影。

frame

对当前节点框架的引用。

.vsmPass( renderer : Renderer )

对于 VSM，需要额外的渲染通道。

renderer

对当前材质的引用渲染器.
