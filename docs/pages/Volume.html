Volume

编写此类是为了处理 NRRDLoader 的输出。 它包含大量数据和相关信息。目前它仅处理 3 维数据。

导入

Volume 是一个插件，必须显式导入，请参阅 安装#Addons.

import { Volume } from 'three/addons/misc/Volume.js';

构造函数

new Volume( xLength : number, yLength : number, zLength : number, type : string, arrayBuffer : ArrayBuffer )

构造一个新卷.

xLength

卷的宽度.
yLength

卷的长度.
zLength

卷的深度卷.
type

数据类型 (uint8, uint16, ...).
arrayBuffer

包含卷数据的缓冲区.

属性

.RASDimensions : Array.<number>

该数组保存 RAS 空间中卷的维度

.axisOrder : Array.<string>

由NRRD header

.data : TypedArray

体积的数据.

.inverseMatrix : Martrix3

RAS到IJK矩阵.

.lowerThreshold : number

值低于此阈值的体素不会出现在切片中。 如果更改，则与该卷关联的所有切片上的geometryNeedsUpdate会自动设置为true。

.matrix : Martrix3

IJK到RAS矩阵。

.offset : Array.<number>

卷在RAS坐标系中的偏移

.segmentation : boolean

是否使用分段模式。 它可以正确加载 16 位 nrrd。

默认为 false.

.sliceList : Array.<VolumeSlice>

与此卷关联的所有切片的列表

.spacing : Array.<number>

应用于从 IJK 到 RAS 坐标系的卷的间距

.upperThreshold : number

值超过此阈值的体素不会出现在切片中。 如果更改，则与该体积关联的所有切片上的geometryNeedsUpdate会自动设置为true

.xLength : number

IJK坐标系中体积的宽度。

默认为1.

.yLength : number

IJK坐标系中体积的高度。

默认为1.

.zLength : number

IJK坐标系中体积的深度system.

默认为1.

方法

.access( i : number, j : number, k : number ) : number

计算IJK系统中给定坐标对应的数据数组中的索引。

i

第一个坐标.
j

第二个坐标.
k

第三个坐标坐标.
返回： 索引.

.computeMinMax() : Array.<number>

计算卷中数据的最小值和最大值。

返回： 最小/最大数据为[min,max].

.extractPerpendicularPlane( axis : 'x' | 'y' | 'z', RASIndex : number ) : Object

计算切片的方向并返回与几何相关的所有信息，例如sliceAccess、 平面矩阵（RAS 坐标中的方向和位置）以及两个坐标系中平面的尺寸。

axis

切片的法线轴。
RASIndex

切片的索引。
返回： 包含有关切片几何形状的所有有用信息的对象slice.

.extractSlice( axis : 'x' | 'y' | 'z', index : number ) : VolumeSlice

返回与给定轴和索引对应的切片。 坐标以右前上坐标格式给出。

axis

切片的法线轴。
index

切片的索引。
返回： 提取的切片。

.getData( i : number, j : number, k : number ) : number

数据[access(i,j,k)]的快捷方式。

i

第一个坐标.
j

第二个坐标.
k

第三个坐标坐标.
返回：数据中的值array.

.map( functionToMap : function, context : Object ) : Volume

对所有体素应用一个函数，小心，该值将被替换。

functionToMap

对每个体素应用一个函数，将使用以下参数调用： 体素的值、体素的索引、数据（TypedArray）。
context

您可以指定调用该函数的上下文，默认情况下是此卷。
返回：对此实例的引用。

.repaintAllSlices() : Volume

对从此卷中提取的所有切片调用重绘。

参见：
  • VolumeSlice#repaint
返回：对此卷的引用。

.reverseAccess( index : number ) : Array.<number>

检索中给定索引对应的体素的 IJK 坐标data.

index

体素索引.
返回： IJK坐标为[x,y,z].
