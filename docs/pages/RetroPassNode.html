RetroPassNode

将复古 PS1 风格效果应用于场景的后处理通道。

此节点使用经典 PlayStation 1 视觉特征渲染场景：

  • 顶点捕捉：顶点被捕捉到屏幕像素，创建标志性的 "晃动" 几何形状
  • 仿射纹理映射：纹理采样不进行透视校正，导致变形效果
  • 低分辨率：默认 0.25 缩放（典型的 320x240 等效）
  • 最近邻过滤: 清晰的像素化纹理，无平滑

构造函数

new RetroPassNode( scene : Scene, camera : Camera, options : Object )

创建新的RetroPassNode 实例.

scene

要渲染的场景.
camera

要渲染的相机.
options

复古通道的其他选项.

默认为 {}.

affineDistortion

将仿射失真应用于UV的可选节点.

默认为null.
