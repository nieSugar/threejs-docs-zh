CSMHelper

用于可视化 CSM 实例级联的帮助器。

导入

CSMHelper 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { CSMHelper } from 'three/addons/csm/CSMHelper.js';

构造函数

new CSMHelper( csm : CSM | CSMShadowNode )

构造新的 CSM 帮助程序。

csm

要可视化的 CSM 实例。

属性

.csm : CSM | CSMShadowNode

要可视化的 CSM 实例。

.displayFrustum : boolean

是否显示 CSM是否截锥体.

默认为true.

.displayPlanes : boolean

是否显示级联平面.

默认为true.

.displayShadowBounds : boolean

是否显示阴影边界.

默认为true.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Group#dispose

.update()

更新帮助程序。应在应用程序的动画循环中调用此方法。

.updateVisibility()

如果在运行时更改 display* 属性之一，则必须调用此方法。
