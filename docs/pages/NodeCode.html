NodeCode

NodeBuilder 将在构建过程中创建此类的实例 节点数。它们代表用户定义的本机着色器代码部分，这些部分将被 由构建器注入。节点代码字典保存在NodeBuilder#codes中 为此目的.

构造函数

new NodeCode( name : string, type : string, code : string )

构造一个新的代码节点。

name

代码名称.
type

节点类型。
code

本机着色器代码.

默认为 ''.

属性

.code : string

本机着色器代码.

默认为 ''.

.name : string

代码名称.

.type : string

节点类型。
