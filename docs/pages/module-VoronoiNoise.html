VoronoiNoise

导入

VoronoiNoise 是一个插件，必须显式导入，请参阅 安装#Addons.

import { voronoi2d, voronoi3d } from 'three/addons/tsl/math/voronoiNoise.js';

静态方法

.hash2d( p : Node.<vec2> ) : Node.<vec2>

从给定坐标生成伪随机vec2。

参考：https://www.shadertoy.com/view/MslGD8.

p

输入坐标.
返回：范围内的伪随机值[0, 1].

.hash3d( p : Node.<vec3> ) : Node.<vec3>

从给定坐标生成伪随机 vec3。

p

输入坐标.
返回：范围内的伪随机值[0, 1].

.voronoi2d( p : Node.<vec2>, time : Node.<float> ) : Node.<float>

动画 2D Voronoi 噪声。特征点在其细胞内绕轨道运行，因此 生成的图案随时间变化。

参考：https://www.shadertoy.com/view/MslGD8.

p

输入坐标.
time

动画时间。
返回：到最近特征点的平方距离，大致在[0, 1]范围内。

.voronoi3d( p : Node.<vec3>, time : Node.<float> ) : Node.<float>

动画3D Voronoi噪声。与 voronoi2d 类似，但具有体积输入 坐标，因此该图案可以应用于任意表面，而无需 投影伪影。评估 27 个单元格而不是 9 个单元格，因此 比 2D 版本贵得多。

p

输入坐标.
time

动画时间。
返回：到最近特征点的平方距离，大致在[0, 1]范围内。
