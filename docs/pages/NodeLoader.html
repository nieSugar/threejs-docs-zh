NodeLoader

用于加载 Three.js JSON 对象/场景格式的节点对象的加载器。

构造函数

new NodeLoader( manager : LoadingManager )

构造一个新的节点加载器。

manager

对加载的引用manager.

属性

.nodes : Object.<string, Node.constructor>

表示节点类型的字典。

.textures : Object.<string, Texture>

表示纹理的字典。

方法

.createNodeFromType( type : string ) : Node

从给定类型创建节点对象。

type

节点类型。
返回：创建的节点实例.

.load( url : string, onLoad : function, onProgress : function, onError : function )

从给定的URL加载节点定义.

url

要加载的文件的路径/URL。
onLoad

将在加载完成时调用.
onProgress

将在加载进行时调用.
onError

将在加载期间抛出错误时调用进程.
覆盖： Loader#load

.parse( json : Object ) : Node

从给定的JSON解析节点.

json

JSON定义

type

节点类型。
uuid

节点UUID.
nodes

节点依赖关系.
meta

元data.
覆盖： Loader#parse
返回： 解析后的节点。

.parseNodes( json : Array.<Object> ) : Object.<string, Node>

解析加载节点的节点依赖关系。

json

JSON定义
返回： 包含节点依赖关系的字典。

.setNodes( value : Object.<string, Node.constructor> ) : NodeLoader

定义节点的字典类型.

value

节点库定义为<classname,class>.
返回：对此加载程序的引用。

.setTextures( value : Object.<string, Texture> ) : NodeLoader

定义纹理字典.

value

纹理库定义为<uuid,texture>.
返回：对此加载程序的引用。
