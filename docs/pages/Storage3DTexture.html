Storage3DTexture

这种特殊类型的纹理适用于计算着色器。 它可用于通过计算着色器计算纹理的数据。

注意：此类纹理只能与 WebGPURenderer 一起使用 和一个WebGPU后端.

构造函数

new Storage3DTexture( width : number, height : number, depth : number )

构造一个新的存储纹理.

width

存储纹理的宽度.

默认为1.
height

存储纹理的高度.

默认为1.
depth

存储纹理的深度.

默认为1.

属性

.image : Object

仅代表纹理尺寸的图像对象。

覆盖： Texture#image

.is3DTexture : boolean

指示该纹理是否为3D纹理。

.isStorageTexture : boolean (readonly)

该标志可用于类型测试。

默认为true.

.magFilter : number

存储纹理的默认magFilter为THREE.LinearFilter.

覆盖： Texture#magFilter

.minFilter : number

存储纹理的默认minFilter为THREE.LinearFilter.

覆盖： Texture#minFilter

.wrapR : number

这定义了纹理在深度方向上的包裹方式，对应于 UVW 贴图中的 W。

方法

.copy( source : Storage3DTexture ) : Storage3DTexture

将给定纹理的值复制到此实例.

source

纹理复制.
覆盖： Texture#copy
返回：对此实例的引用。

.setSize( width : number, height : number, depth : number )

设置存储 3d 纹理的大小。

width

存储纹理的新宽度。
height

存储纹理的新高度。
depth

存储纹理的新深度纹理.
