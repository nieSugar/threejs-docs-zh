BoxHelper

Helper 对象以图形方式显示世界轴对齐的边界框 围绕一个物体。实际的边界框是用 Box3 处理的， 这只是一个用于调试的可视化助手。它可以自动 创建对象时使用 BoxHelper#update 调整大小 被改造了。请注意，该对象必须具有几何形状才能起作用， 所以它不适用于精灵。

代码示例

const sphere = new THREE.SphereGeometry();
const object = new THREE.Mesh( sphere, new THREE.MeshBasicMaterial( 0xff0000 ) );
const box = new THREE.BoxHelper( object, 0xffff00 );
scene.add( box );

构造函数

new BoxHelper( object : Object3D, color : number | Color | string )

构造一个新的盒子助手。

object

显示世界轴对齐边界框的3D对象。
color

框的颜色.

默认为0xffff00.

属性

.object : Object3D

正在可视化的3D对象。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose

.setFromObject( object : Object3D ) : BoxHelper

更新传递对象的线框。

object

要为其创建助手的 3D 对象。
返回：对此实例的引用。

.update()

更新助手的几何形状以匹配对象的尺寸， 包括任何儿童.
