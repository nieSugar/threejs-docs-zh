TAARenderPass

临时抗锯齿渲染通道.

当场景中没有运动时，TAA 渲染通道会累积相机抖动 跨帧采样以创建高质量的抗锯齿结果。

注意：此效果不使用重投影，因此它不是 TRAA 实现。

代码示例

const taaRenderPass = new TAARenderPass( scene, camera );
taaRenderPass.unbiased = false;
composer.addPass( taaRenderPass );

导入

TAARenderPass 是一个插件，必须显式导入，请参阅 安装#Addons.

import { TAARenderPass } from 'three/addons/postprocessing/TAARenderPass.js';

构造函数

new TAARenderPass( scene : Scene, camera : Camera, clearColor : number | Color | string, clearAlpha : number )

构造新的TAA渲染通道。

scene

要渲染的场景.
camera

相机.
clearColor

渲染通道的清除颜色。

默认为0x000000.
clearAlpha

渲染通道的清除alpha。

默认为0.

属性

.accumulate : boolean

是否累积帧。这使得 TAA.

默认为 false.

.accumulateIndex : number

累积索引.

默认为 -1.

.sampleLevel : number

覆盖并默认设置为 0。

默认为0.

覆盖： SSAARenderPass#sampleLevel

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： SSAARenderPass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行 TAA 渲染通道。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： SSAARenderPass#render
