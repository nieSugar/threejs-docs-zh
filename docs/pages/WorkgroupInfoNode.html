WorkgroupInfoNode

A 节点允许用户在 计算着色器的上下文。通常，工作组范围的缓冲区是 创建用于保存从全局存储范围传输到的数据 本地工作组范围。对于工作组内的调用，数据 “工作组”范围缓冲区的访问速度可以显着加快 与全局可访问存储缓冲区上的类似访问操作相比。

此节点只能与 WebGPU 后端一起使用。

构造函数

new WorkgroupInfoNode( scope : string, bufferType : string, bufferCount : number )

构造一个新的工作组信息节点。

scope

缓冲区作用域的地址空间。目前仅使用'Workgroup'。
bufferType

“工作组”作用域缓冲区元素的数据类型。
bufferCount

缓冲区中的元素数量。

默认为0.
