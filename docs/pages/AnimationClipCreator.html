AnimationClipCreator

具有用于创建基本动画剪辑的工厂方法的实用程序类。

导入

AnimationClipCreator 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { AnimationClipCreator } from 'three/addons/animation/AnimationClipCreator.js';

静态方法

.CreateMaterialColorAnimation( duration : number, colors : Array.<Color> ) : AnimationClip

创建一个动画剪辑，对 3D 对象的 color 属性进行动画处理 材质.

duration

动画的持续时间。
colors

应按顺序进行动画处理的颜色数组。
返回：创建的动画剪辑。

.CreatePulsationAnimation( duration : number, pulseScale : number ) : AnimationClip

创建一个以缩放方式缩放 3D 对象的动画剪辑脉冲模式 在给定的时间段内.

duration

动画的持续时间。
pulseScale

脉冲的比例.
返回：创建的动画剪辑。

.CreateRotationAnimation( period : number, axis : 'x' | 'y' | 'z' ) : AnimationClip

创建将3D对象旋转360度的动画剪辑 在给定时间内围绕给定轴。

period

动画的持续时间。
axis

旋转轴。

默认为 'x'.
返回：创建的动画剪辑。

.CreateScaleAxisAnimation( period : number, axis : 'x' | 'y' | 'z' ) : AnimationClip

创建一个缩放 3D 对象的动画剪辑0 至 1 在给定时间段内沿着给定轴。

period

动画的持续时间。
axis

沿轴缩放 3D 对象。

默认为 'x'.
返回：创建的动画剪辑。

.CreateShakeAnimation( duration : number, shakeScale : Vector3 ) : AnimationClip

创建一个以抖动模式平移 3D 对象的动画剪辑 在给定的时间段内.

duration

动画的持续时间。
shakeScale

震动的规模.
返回：创建的动画剪辑。

.CreateVisibilityAnimation( duration : number ) : AnimationClip

创建一个切换3D对象可见性的动画剪辑.

duration

动画的持续时间。
返回：创建的动画剪辑。
