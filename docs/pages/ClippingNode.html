ClippingNode

此节点在 NodeMaterial 中用于设置剪辑 这可以发生硬件加速（如果支持）并且可选 使用 alpha-to-coverage 进行抗锯齿剪切边缘。

构造函数

new ClippingNode( scope : 'default' | 'hardware' | 'alphaToCoverage' )

构造一个新的剪切节点。

scope

节点的范围。与其他节点类似， 所选范围会影响节点的行为以及生成的代码类型。

默认为 'default'.

属性

.scope : 'default' | 'hardware' | 'alphaToCoverage'
