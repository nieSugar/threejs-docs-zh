CubeTextureLoader

用于加载立方体纹理的类。图像通过 ImageLoader.

内部加载。加载程序返回 CubeTexture 的实例，并期望立方体贴图 被定义为代表立方体侧面的六个独立图像。其他立方体贴图定义 像垂直和水平交叉一样，不支持列和行布局。

请注意，按照惯例，立方体贴图是在坐标系中指定的 其中，当查找正 z 轴时，正 x 位于右侧 -- 换句话说，使用左手坐标系。由于 Three.js 使用 右手坐标系，在 Three.js 中使用的环境贴图将 pos-x 和 neg-x 交换了。

加载的立方体纹理位于 sRGB 颜色空间中。含义 Texture#colorSpace 默认设置为 SRGBColorSpace。

代码示例

const loader = new THREE.CubeTextureLoader().setPath( 'textures/cubeMaps/' );
const cubeTexture = await loader.loadAsync( [
	'px.png', 'nx.png', 'py.png', 'ny.png', 'pz.png', 'nz.png'
] );
scene.background = cubeTexture;

构造函数

new CubeTextureLoader( manager : LoadingManager )

构造一个新的立方体纹理加载器。

manager

加载管理器。

方法

.load( urls : Array.<string>, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback ) : CubeTexture

开始从给定的 URL 加载并传递完全加载的立方体纹理 到 onLoad() 回调。该方法还返回一个新的立方体纹理对象，该对象可以 直接用于材质创作。如果你这样做，立方体纹理 相应的加载过程完成后，可能会在场景中弹出。

urls

6 个图像 URL 的数组，每侧一个 立方体纹理。 url 应按以下顺序指定：pos-x， 负 x、正 y、负 y、正 z、负 z。也允许使用数据 URI 数组。
onLoad

加载过程完成时执行。
onProgress

此加载程序不支持。
onError

发生错误时执行。
覆盖： Loader#load
返回： 立方体纹理。
