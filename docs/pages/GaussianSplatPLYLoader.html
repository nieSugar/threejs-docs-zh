GaussianSplatPLYLoader

Gaussian splat PLY 文件的加载器，例如与原件导出的一样 GraphDECO/INRIA 3D Gaussian Splatting 实现.

PLY 本身是一种通用格式，因此调用者通常必须知道 文件的球谐（SH）度提前配置 PLYLoader 在解析之前具有正确的自定义属性映射。这个 加载器通过扫描纯文本 PLY 标头中的 f_rest_N 来避免这种情况 首先是属性，因为 SH 度映射到一个固定的、封闭的表 f_rest 计数（0/9/24/45 -> 度 0/1/2/3），并配置 在将结果转换为之前相应地内部 PLYLoader 高斯splat几何.

代码示例

const loader = new GaussianSplatPLYLoader();
const geometry = await loader.loadAsync( './models/gsplat/point_cloud.ply' );
scene.add( new GaussianSplat( geometry ) );

导入

GaussianSplatPLYLoader是一个插件，必须显式导入，请参阅安装#Addons.

import { GaussianSplatPLYLoader } from 'three/addons/loaders/GaussianSplatPLYLoader.js';

构造函数

new GaussianSplatPLYLoader( manager : LoadingManager )

构造一个新的高斯splat PLY加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的URL加载并传递加载的高斯splat 几何到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( data : ArrayBuffer | string ) : BufferGeometry

解析给定的高斯 splat PLY 数据并返回结果 高斯splat几何.

这会扫描PLY标头以获取文件的球谐度， 因此，与普通的 PLYLoader 不同，不需要事先设置。

data

原始 PLY 数据，作为数组缓冲区或字符串。
覆盖： Loader#parse
返回： 解析的高斯分布几何图形。
