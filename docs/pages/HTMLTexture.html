HTMLTexture

从 HTML 元素创建纹理。

这与基本纹理类几乎相同，除了它设置 Texture#needsUpdate 立即到 true 并侦听父画布的绘制事件以触发更新。

构造函数

new HTMLTexture( element : HTMLElement, mapping : number, wrapS : number, wrapT : number, magFilter : number, minFilter : number, format : number, type : number, anisotropy : number )

构造一个新的纹理。

element

HTML 元素.
mapping

纹理映射.

默认为 Texture.DEFAULT_MAPPING.
wrapS

wrapS 值.

默认为ClampToEdgeWrapping.
wrapT

wrapT 值.

默认为ClampToEdgeWrapping.
magFilter

mag 滤镜值.

默认为LinearFilter.
minFilter

最小滤镜值.

默认为LinearMipmapLinearFilter.
format

纹理格式.

默认为RGBAFormat.
type

纹理类型.

默认为UnsignedByteType.
anisotropy

各向异性值.

默认为Texture.DEFAULT_ANISOTROPY.

属性

.isHTMLTexture : boolean (readonly)

该标志可用于类型测试。

默认为true.
