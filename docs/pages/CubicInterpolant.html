CubicInterpolant

快速而简单的三次样条插值。

它源自设置一阶导数的埃尔米特构造 在每个样本位置到相邻位置之间的线性斜率 在其参数间隔上。

构造函数

new CubicInterpolant( parameterPositions : TypedArray, sampleValues : TypedArray, sampleSize : number, resultBuffer : TypedArray )

构造一个新的三次插值。

parameterPositions

参数位置保存插值因子。
sampleValues

样本值。
sampleSize

样本size
resultBuffer

结果缓冲区.
