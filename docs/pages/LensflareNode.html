LensflareNode

用于添加基于光晕的镜头眩光效果的后处理节点。这个效果 要求您首先通过绽放通道提取场景的绽放。

参考：

  • https://john-chapman-graphics.blogspot.com/2013/02/pseudo-lens-flare.html.
  • https://john-chapman.github.io/2017/11/05/pseudo-lens-flare.html.

导入

LensflareNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { lensflare } from 'three/addons/tsl/display/LensflareNode.js';

构造函数

new LensflareNode( textureNode : TextureNode, params : Object )

构造一个新的镜头光晕节点。

textureNode

表示场景光晕的纹理节点。
params

用于配置效果的参数对象。

ghostTint

定义色调耀斑/重影的.

默认为vec3(1, 1, 1).
threshold

控制效果的大小和强度。阈值越高，耀斑越小。

默认为 float(0.5).
ghostSamples

表示围绕中心旋转的每个亮点的耀斑/重影数量。

默认为float(4).
ghostSpacing

定义耀斑/重影的间距。

默认为float(0.25).
ghostAttenuationFactor

定义衰减系数耀斑/重影.

默认为 float(25).
downSampleRatio

定义如何下采样，因为效果通常不会以全分辨率渲染。

默认为4.

属性

.downSampleRatio : number

定义如何下采样，因为效果通常不会以全分辨率渲染。

.ghostAttenuationFactorNode : Node.<float>

定义衰减系数耀斑/重影.

.ghostSamplesNode : Node.<float>

表示围绕中心旋转的每个亮点的耀斑/重影数量。

.ghostSpacingNode : Node.<float>

定义耀斑/重影的间距。

.ghostTintNode : Node.<vec3>

定义色调耀斑/重影的.

.textureNode : TextureNode

表示场景光晕的纹理节点。

.thresholdNode : Node.<float>

控制效果的大小和强度。阈值越高，耀斑越小。

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
