MRTNode

此节点可用于设置 MRT 上下文以进行渲染。典型的 MRT 设置 后处理如下所示：

MRT输出被定义为字典。

代码示例

const mrtNode = mrt( {
  output: output,
  normal: normalView
} ) ;

构造函数

new MRTNode( outputNodes : Object.<string, Node> )

构造一个新的输出结构节点。

outputNodes

MRT输出。

属性

.blendModes : Object.<string, BlendMode>

存储每个混合模式的字典输出.

.clearColors : Object.<string, Color4>

存储每个输出的清晰颜色的字典。

.isMRTNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.outputNodes : Object.<string, Node>

代表MRT输出的字典。关键 是输出的名称，节点产生的值 输出结果。

方法

.get( name : string ) : Node

返回给定名称的输出节点。

name

输出的名称。
返回： 输出节点。

.getBlendMode( name : string ) : BlendMode

返回给定输出名称的混合模式。

name

输出的名称。
返回：混合模式。

.getClearColor( name : string ) : Color4

返回给定输出名称的透明颜色。

name

输出的名称。
返回： 透明颜色。如果未定义清晰颜色，则返回 null 这意味着应用了渲染器的默认清除策略。

.has( name : string ) : NodeBuilder

如果 MRT 节点有给定名称的输出，则返回 true。

name

输出的名称。
返回： MRT 节点是否有给定名称的输出not.

.merge( mrtNode : MRTNode ) : MRTNode

将给定 MRT 节点的输出与此节点的输出合并。

mrtNode

要合并的 MRT.
返回： 具有合并输出的新 MRT 节点..

.setBlendMode( name : string, blend : BlendMode ) : MRTNode

设置给定输出名称的混合模式。

name

输出的名称。
blend

混合模式。
返回： 当前 MRT 节点。

.setClearColor( name : string, color : number | string | Color, alpha : number ) : MRTNode

设置给定输出名称的透明颜色。

name

输出的名称。
color

透明颜色.
alpha

清除alpha.

默认为1.
返回： 当前 MRT 节点。
