ShadowBaseNode

所有阴影节点的基类。

阴影节点封装阴影相关逻辑，并且始终耦合到照明节点。 照明节点可能共享相同的阴影节点类型或使用特定的阴影节点类型，具体取决于 他们的要求。

构造函数

new ShadowBaseNode( light : Light )

构造一个新的阴影基础节点。

light

阴影投射光。

属性

.isShadowBaseNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.light : Light

阴影投射光。

.updateBeforeType : string

覆盖，因为默认情况下每次渲染都会更新阴影。

默认为'render'.

覆盖： Node#updateBeforeType

方法

.disposeShadowMaterial()

处理阴影投射光的阴影材质source.

.getShadowMaterial() : NodeMaterial

检索或创建阴影投射光源的阴影材质。

此方法检查内部库中是否已存在提供的光源的阴影材质。 如果没有，它会创建一个新的NodeMaterial，配置用于阴影渲染并存储它以供将来使用。

返回：与给定灯光关联的阴影材质。

.getShadowRenderObjectFunction( renderer : Renderer, shadow : LightShadow ) : function

返回一个函数，用于为给定灯光阴影渲染场景中的阴影对象，并renderer.

renderer

渲染器.
shadow

包含阴影属性的光阴影对象.

默认为this.light.shadow.
返回：渲染阴影的函数对象.

.setupShadowPosition( object : NodeBuilder )

设置阴影位置节点，默认情况下是预定义的TSL节点对象shadowPositionWorld.

object

必须至少保存材质引用的配置对象。
