StreetlightGenerator

A NYC 眼镜蛇头路灯：站在路边的高锥形桅杆，带有 弯曲的手臂伸过道路，伸向吊灯。建造一次并且 展示位置列表中的实例，采用一种廉价材料 烘烤的partId上的树枝（深色金属杆，浅色灯透镜）。

规范模型站在y = 0上，以X / Z为中心，手臂伸向 朝向 +Z，因此本地 +Z 面向道路的放置会抛出灯 上面.

代码示例

const lights = new StreetlightGenerator();
scene.add( lights.build( placements ) ); // placements: Matrix4[]

构造函数

new StreetlightGenerator()
