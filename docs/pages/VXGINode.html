VXGINode

基于体素的全局照明的后处理节点。场景被体素化为 VXGIVolume 和间接漫射光和环境光遮挡按每个收集 具有近似体素锥体追踪的像素。

该节点是SSGI和Light Probe Grids之间的中间路径：

  • 与 SSGINode 相比，它没有屏幕空间伪影，并且提供了明显更一致的光照，因为屏幕外的表面和薄的遮挡物也会产生贡献。 但是，它的动态性较低：对象应保持静止，因为几何体的变化需要重新体素化 (needsUpdate = true)，这对于每帧动画来说代价过高。
  • 与 LightProbeGrid 相比，它支持动态照明而无需新的烘焙过程，并且产生更好的整体照明质量，同时光泄漏更少。然而，它成本更高，因此对于性能受限的使用场景不太适合。

效果的质量/性能主要取决于体素分辨率、锥体数量 跟踪每个像素以及锥体的孔径。

灯光及其阴影贴图会自动拾取。仅注入直射光。

参考：

  • https://research.nvidia.com/publication/2011-09_interactive-indirect-illumination-using-voxel-cone-tracing：Crassin 等人，使用体素锥追踪的交互式间接光照，Pacific Graphics 2011。

注意：此节点只能与 WebGPURenderer 和 WebGPU 后端一起使用。

导入

VXGINode 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { vxgi } from 'three/addons/lighting/vxgi/VXGINode.js';

构造函数

new VXGINode( depthNode : TextureNode, normalNode : TextureNode, scene : Scene, camera : Camera, resolution : number )

构造一个新的体素GI节点。

depthNode

代表场景深度的纹理节点。
normalNode

表示场景视图空间的纹理节点法线.
scene

要体素化的场景.
camera

渲染场景的相机。
resolution

沿体积最长轴的体素数。不应超过 256，较高的值超过体素分析器的最大存储缓冲区大小。

默认为128.

属性

.aoDistance : UniformNode.<float>

遮挡由AO的1 / ( 1 + distance / aoDistance )加权，所以遮挡物在此 世界空间距离占一半。 0 禁用衰减。

默认为1.

.aoIntensity : UniformNode.<float>

应用于 AO 的幂函数，使其显得更暗/更亮。

默认为1.

.aoMinVisibility : UniformNode.<float>

环境光遮挡可以达到的最暗值。消除折痕和接触区域 纯黑色，体素追踪遮挡往往会高估其分辨率 一个体素。 0 保持完整的遮挡范围。

默认为0.

.bounces : number

缓存的间接反弹数量。请参阅VXGIVolume#bounces.

.camera : Camera

渲染场景的相机。

.coneAngle : UniformNode.<float>

漫反射锥体的孔径（以度为单位）。较宽的锥体速度更快（步数更少），但会泄漏 过度遮挡越多，窄锥体越精确，但噪音更大，并且需要更多步骤。 与 VXGINode#coneCount 一起选择。应在 [10, 90].

默认为40.

.coneCount : UniformNode.<uint>

每个像素跟踪的锥体数量范围内。应在[2, 8]范围内。

主要定义体素锥追踪的质量和精度。值为 2 - 4 是推荐设置。将 2 用于性能受限的用例。

默认为3.

.debug : UniformNode.<int>

调试体积可视化：0 = 关闭，1 = 辐射体素，2 = 每轴不透明度体素。 可视化替换了 GI 输出。

默认为0.

.debugLevel : UniformNode.<float>

调试可视化显示的 mip 级别。

默认为0.

.depthNode : TextureNode

表示场景深度的节点。

.directionalRadiance : boolean

是否定向过滤较粗糙的辐射级别以减少光溢出 穿过薄薄的墙壁和地板。默认情况下关闭，因为它会消耗内存和性能。 请参见VXGIVolume#directionalRadiance.

.giIntensity : UniformNode.<float>

间接漫射辐照度的强度。

默认为1.

.lightingNeedsUpdate : boolean

设置为true以在下一帧中重新注入照明。

.needsUpdate : boolean

设置为true 在下一帧中重新体素化场景。

覆盖： TempNode#needsUpdate

.normalNode : TextureNode

表示场景法线的节点。如果 null，则从深度重建法线。

.normalOffset : UniformNode.<float>

锥体原点沿体素中表面法线的偏移。表面自己的体素 可以延伸至表面上方半个体素和样品的三线性足迹 跨越另一半体素，因此 1.5 体素在每种情况下都避免自遮挡。

默认为1.5.

.scene : Scene

要体素化的场景.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.useTemporalFiltering : boolean

是否使用时间过滤。将此属性设置为 true 需要 TRAANode 的用法。然后每帧旋转锥体方向以收敛噪声。

默认为true.

.volume : VXGIVolume

体素体积。用它来配置边界、图层和反弹。

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getAONode() : PassTextureNode

以纹理节点的形式返回效果的 AO 结果。

返回： 表示效果的 AO 结果的纹理节点。

.getGINode() : PassTextureNode

以纹理节点的形式返回效果的GI结果。纹理持有间接 漫射辐照度，准备通过 builtinGIContext().

返回：表示效果的GI结果的纹理节点.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
