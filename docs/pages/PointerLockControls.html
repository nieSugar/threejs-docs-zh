PointerLockControls

此类的实现基于指针锁定API。 PointerLockControls 是第一人称 3D 游戏的完美选择。

代码示例

const controls = new PointerLockControls( camera, document.body );
// add event listener to show/hide a UI (e.g. the game's menu)
controls.addEventListener( 'lock', function () {
	menu.style.display = 'none';
} );
controls.addEventListener( 'unlock', function () {
	menu.style.display = 'block';
} );

导入

PointerLockControls 是一个插件，必须显式导入，请参阅 安装#Addons.

import { PointerLockControls } from 'three/addons/controls/PointerLockControls.js';

构造函数

new PointerLockControls( camera : Camera, domElement : HTMLElement )

构造一个新的控件实例。

camera

控件管理的摄像机。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.isLocked : boolean (readonly)

控件是否锁定。

默认为 false.

.maxPolarAngle : number

摄像机间距，上限。范围为“[0, Math.PI]”（以弧度为单位）。

默认为 Math.PI.

.minPolarAngle : number

相机间距，下限。范围为“[0, Math.PI]”（以弧度为单位）。

默认为0.

.pointerSpeed : number

指针移动对相机旋转影响程度的乘数。

默认为1.

方法

.getDirection( v : Vector3 ) : Vector3

返回相机的视线方向。

v

用于存储方法结果的目标向量.
返回：标准化方向矢量.

.lock( unadjustedMovement : boolean )

激活指针锁定。

unadjustedMovement

禁用操作系统级别的鼠标加速调整，并访问原始鼠标输入。 将其设置为 true 将禁用鼠标加速。

默认为 false.

.moveForward( distance : number )

将相机平行于 xz 平面向前移动。假设camera.up为y向上。

distance

有符号距离。

.moveRight( distance : number )

平行于xz平面向侧移动相机。

distance

有符号距离。

.unlock()

退出指针锁定。

Events

.change

当用户移动相机时触发mouse.

Type:
  • Object

.lock

当指针锁定状态为“锁定”（即：鼠标被捕获）时触发。

Type:
  • Object

.unlock

当指针锁定状态为“解锁”（即：鼠标不再被捕获）时触发。

Type:
  • Object
