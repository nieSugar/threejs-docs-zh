RenderPass

此类表示渲染通道。它需要一台相机和一个场景并产生 用于后续后期处理效果的美容通道。

代码示例

const renderPass = new RenderPass( scene, camera );
composer.addPass( renderPass );

导入

RenderPass 是一个插件，必须显式导入，请参阅 安装#Addons.

import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';

构造函数

new RenderPass( scene : Scene, camera : Camera, overrideMaterial : Material, clearColor : number | Color | string, clearAlpha : number )

构造一个新的渲染通道。

scene

要渲染的场景.
camera

相机.
overrideMaterial

覆盖材质。如果设置，则使用此材质 对于场景中的所有对象。

默认为null.
clearColor

渲染通道的清除颜色。

默认为null.
clearAlpha

渲染通道的清除alpha。

默认为null.

属性

.camera : Camera

相机.

.clear : boolean

默认覆盖以执行清除操作。

默认为true.

覆盖： Pass#clear

.clearAlpha : number

渲染通道的清除alpha。

默认为null.

.clearColor : number | Color | string

渲染通道的清除颜色。

默认为null.

.clearDepth : boolean

如果设置为true，则仅清除深度时clear 对应 false.

默认为 false.

.isRenderPass : boolean (readonly)

此标志表示此通道渲染场景本身。

默认为true.

.needsSwap : boolean

覆盖以禁用交换.

默认为 false.

覆盖： Pass#needsSwap

.overrideMaterial : Material

覆盖材质。如果设置，则使用此材质 对于场景中的所有对象。

默认为null.

.scene : Scene

要渲染的场景.

方法

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

使用配置的场景和相机执行美容通道。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
