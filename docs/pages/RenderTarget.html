RenderTarget

A 渲染目标是视频卡为场景绘制像素的缓冲区 这是在后台渲染的。它被用于不同的效果， 例如在显示渲染图像之前对其进行后处理 在屏幕上.

构造函数

new RenderTarget( width : number, height : number, options : RenderTarget~Options )

构造一个新的渲染目标.

width

渲染目标的宽度。

默认为1.
height

渲染目标的高度。

默认为1.
options

配置object.

属性

.depth : number

渲染目标的深度.

默认为1.

.depthBuffer : boolean

是否分配深度缓冲区.

默认为true.

.depthTexture : DepthTexture

不是将深度保存在渲染缓冲区中，而是使用纹理 可以用来代替，这对于进一步处理很有用 例如在后处理的上下文中。

默认为null.

.height : number

渲染目标的高度。

默认为1.

.isRenderTarget : boolean (readonly)

该标志可用于类型测试。

默认为true.

.multiview : boolean

此目标是否用于多视图渲染。

默认为 false.

.resolveColorBuffer : boolean

是否解析颜色缓冲区。当设置为 false 时，颜色 附件不接收渲染的解析（单采样）输出 通过并且渲染目标的纹理保持不变。渲染出来的 那么内容只能在渲染通道本身内访问。

仅与多重采样渲染目标相关。

默认为true.

.resolveDepthBuffer : boolean

是否解析深度缓冲区。当设置为 false 时，深度 纹理不接收渲染通道的解析深度输出 节省内存带宽。当渲染的深度数据 之后不需要 pass。

仅与 WebGL 中的多重采样渲染目标相关。 WebGPU 没有 支持深度解析；对多重采样渲染的深度纹理进行采样 目标直接访问多重采样数据，请参阅 RenderTarget#storeMultisampledDepthBuffer.

默认为true.

.resolveStencilBuffer : boolean

是否解析模板缓冲区。类似于 RenderTarget#resolveDepthBuffer 但对于模板方面。

默认为true.

.samples : number

MSAA 样本数。

0 的值禁用 MSAA。

默认为0.

.scissor : Vector4

渲染内的矩形区域目标的视口。片段是

默认为(0,0,width,height).

.scissorTest : boolean

表示渲染到时是否启用剪刀测试 是否为该渲染目标。

默认为 false.

.stencilBuffer : boolean

是否分配模板缓冲区。

默认为 false.

.storeMultisampledColorBuffer : boolean

是否存储多重采样颜色缓冲区。当设置为false时， 多重采样数据在渲染过程结束时被丢弃，紧接着 他们已经解决了。这可以节省内存带宽，尤其是基于图块的 GPU，是完全重绘的渲染目标的推荐设置 每个帧及其输出只能通过解析的纹理访问（例如 后处理链中的场景传递）。

当渲染后需要多重采样数据时必须保留true 通行证结束，例如当渲染到目标而不清除时或者当 场景包含需要中通帧缓冲区副本的透射对象。

默认为true.

.storeMultisampledDepthBuffer : boolean

是否存储多重采样深度缓冲区。当设置为false时， 多重采样深度数据在渲染通道结束时被丢弃 节省内存带宽。

当多重采样渲染的深度纹理时，必须在 WebGPU 中保留 true 目标被采样（例如通过基于深度的后处理效果），因为深度 直接从多重采样数据中读取。

默认为true.

.storeMultisampledStencilBuffer : boolean

是否存储多重采样模板缓冲区。类似于 RenderTarget#storeMultisampledDepthBuffer 但用于模板方面。

默认为true.

.texture : Texture

表示默认颜色附件的纹理。

.textures : Array.<Texture>

纹理数组。每个颜色附件都表示为单独的纹理。 至少有一个默认颜色附件条目。

.useArrayDepthTexture : boolean

是否将深度纹理创建为数组纹理以进行每层深度测试。 这与多视图是分开的，因此分层渲染目标可以使用数组深度，而无需 多视图扩展。

默认为 false.

.viewport : Vector4

表示渲染目标视口的矩形区域。

默认为(0,0,width,height).

.width : number

渲染目标的宽度。

默认为1.

方法

.clone() : RenderTarget

返回具有从此实例复制的值的新渲染目标。

返回：此克隆instance.

.copy( source : RenderTarget ) : RenderTarget

复制给定渲染目标的设置。这是一个结构副本，所以 复制后，渲染目标之间不会共享任何资源。这包括 所有 MRT 纹理和深度纹理。

source

要复制的渲染目标。
返回：对此实例的引用。

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

Fires:
  • RenderTarget#event:dispose

.setSize( width : number, height : number, depth : number )

设置此渲染目标的大小。

width

宽度。
height

高度。
depth

The深度.

默认为1.
