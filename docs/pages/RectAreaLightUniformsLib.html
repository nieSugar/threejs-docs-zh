RectAreaLightUniformsLib

仅当使用 RectAreaLight 和 WebGLRenderer.

在矩形区域灯可以之前，该类才相关要使用渲染器的内部统一库必须是 使用以下代码增强。

代码示例

RectAreaLightUniformsLib.init();

导入

RectAreaLightUniformsLib 是一个插件，必须显式导入，请参阅Installation#Addons.

import { RectAreaLightUniformsLib } from 'three/addons/lights/RectAreaLightUniformsLib.js';

静态方法

.init()

Inits theUniform Library使用矩形区域灯时需要。
