GroundedSkybox

导入

GroundedSkybox 是一个插件，必须显式导入，请参阅 安装#Addons.

import { getGroundProjectedNormal } from 'three/addons/tsl/utils/GroundedSkybox.js';

静态方法

.getGroundProjectedNormal( radiusNode : Node.<float>, heightNode : Node.<float> ) : Node.<vec3>

将世界位置投影到底部被地面圆盘夹住的球体上， 然后返回一个可用于对环境立方体贴图进行采样的向量。

radiusNode

投影球体的半径。必须足够大，以确保场景的相机保持在内部。
heightNode

高度是拍摄照片的相机距地面的距离。较大的值将放大图像的向下部分。
返回：用于采样环境立方体贴图的方向向量。
