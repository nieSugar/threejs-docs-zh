ViewportSharedTextureNode

ViewportTextureNode 为每个节点实例创建一个内部纹理。该模块 在 ViewportSharedTextureNode 的所有实例之间共享纹理。应该 出于性能原因，成为使用默认/屏幕帧缓冲区数据时的首选。

构造函数

new ViewportSharedTextureNode( uvNode : Node, levelNode : Node )

构造一个新的视口共享纹理节点。

uvNode

uv节点.

默认为screenUV.
levelNode

级别节点.

默认为null.

方法

.getTextureForReference() : FramebufferTexture

覆盖，因此该方法始终返回唯一的共享纹理 帧缓冲区纹理.

覆盖： ViewportTextureNode#getTextureForReference
返回： 共享帧缓冲区纹理.
