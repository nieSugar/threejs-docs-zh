EllipseCurve

表示椭圆的曲线。

代码示例

const curve = new THREE.EllipseCurve(
	0, 0,
	10, 10,
	0, 2 * Math.PI,
	false,
	0
);
const points = curve.getPoints( 50 );
const geometry = new THREE.BufferGeometry().setFromPoints( points );
const material = new THREE.LineBasicMaterial( { color: 0xff0000 } );
// Create the final object to add to the scene
const ellipse = new THREE.Line( geometry, material );

构造函数

new EllipseCurve( aX : number, aY : number, xRadius : number, yRadius : number, aStartAngle : number, aEndAngle : number, aClockwise : boolean, aRotation : number )

构造一条新的椭圆曲线。

aX

X 中心椭圆.

默认为0.
aY

椭圆的Y中心。

默认为0.
xRadius

椭圆在x方向的半径。

默认为1.
yRadius

椭圆在 y 轴上的半径方向.

默认为1.
aStartAngle

从正X轴开始的曲线的起始角度（以弧度为单位）。

默认为0.
aEndAngle

椭圆的结束角度从正 X 轴开始的弧度曲线。

默认为 Math.PI*2.
aClockwise

是否顺时针绘制椭圆。

默认为 false.
aRotation

椭圆的旋转角度（以弧度为单位），从正X轴逆时针旋转。

默认为0.

属性

.aClockwise : boolean

是否顺时针绘制椭圆。

默认为 false.

.aEndAngle : number

椭圆的结束角度从正 X 轴开始的弧度曲线。

默认为 Math.PI*2.

.aRotation : number

椭圆的旋转角度（以弧度为单位），从正X轴逆时针旋转。

默认为0.

.aStartAngle : number

从正X轴开始的曲线的起始角度（以弧度为单位）。

默认为0.

.aX : number

X 中心椭圆.

默认为0.

.aY : number

椭圆的Y中心。

默认为0.

.isEllipseCurve : boolean (readonly)

该标志可用于类型测试。

默认为true.

.xRadius : number

椭圆在x方向的半径。 将此值设置为等于 EllipseCurve#yRadius 将生成一个圆。

默认为1.

.yRadius : number

y 方向上椭圆的半径。 将此值设置为等于 EllipseCurve#xRadius 将产生一个圆。

默认为1.

方法

.getPoint( t : number, optionalTarget : Vector2 ) : Vector2

返回曲线上的点。

t

表示曲线上位置的插值因子。必须在 [0,1] 范围内。
optionalTarget

结果写入的可选目标向量。
覆盖： Curve#getPoint
返回：曲线上的位置.
