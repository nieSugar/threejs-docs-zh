AsciiEffect

创建 ASCII 效果的类。

ASCII 生成基于 jsascii.

导入

AsciiEffect 是一个插件，必须显式导入，请参阅 安装#Addons.

import { AsciiEffect } from 'three/addons/effects/AsciiEffect.js';

构造函数

new AsciiEffect( renderer : WebGLRenderer, charSet : string, options : AsciiEffect~Options )

构造新的ASCII效果.

renderer

渲染器.
charSet

字符集.

默认为' .:-=+*#%@'.
options

配置参数.

属性

.domElement : HTMLDivElement

效果的DOM元素。必须使用该元素来代替 默认 WebGLRenderer#domElement.

方法

.render( scene : Object3D, camera : Camera )

当使用此效果时，应调用此方法而不是 默认 WebGLRenderer#render.

scene

要渲染的场景.
camera

相机.

.setSize( w : number, h : number )

调整效果大小.

w

逻辑中效果的宽度像素.
h

逻辑像素中效果的高度.

类型定义

.Options

该类型表示 AsciiEffect.

resolution
number

的配置设置，值越高，越多详细信息.

默认为0.15.
scale
number

效果的比例。

默认为1.
color
boolean

是否应启用颜色。质量更好，但渲染速度变慢。

默认为 false.
alpha
boolean

是否应启用透明度。

默认为 false.
block
boolean

是否应启用阻塞字符。

默认为 false.
invert
boolean

是否应反转颜色。

默认为 false.
strResolution
'low' | 'medium' | 'high'

字符串分辨率.

默认为'low'.
