FSR1Node

用于应用 AMD FidelityFX 超级分辨率 1 (FSR 1) 的后处理节点。

组合两个通道：

  • EASU（边缘自适应空间上采样）：使用十字分布的 12 个纹理样本来检测局部边缘方向，然后将近似的 Lanczos2 核形状调整为与检测到的边缘对齐的椭圆。
  • RCAS（鲁棒对比度自适应锐化）：使用5抽头交叉模式应用对比度感知锐化，并且每个像素自动限制以避免伪影。

注意：仅在以下情况下使用 FSR 1：应用程序受片段着色器限制，无法渲染 以全分辨率。 FSR 1 增加了自己的开销，因此简单的着色场景渲染速度会更快 在没有它的情况下以原始分辨率。此外，FSR 1 应始终与抗锯齿一起使用 源图像.

参考： https://gpuopen.com/fidelityfx-superresolution/.

导入

FSR1Node 是插件，并且必须显式导入，请参阅 Installation#Addons。

import { fsr1 } from 'three/addons/tsl/display/fsr1/FSR1Node.js';

构造函数

new FSR1Node( textureNode : TextureNode, sharpness : Node.<float>, denoise : Node.<bool> )

构造新的 FSR 1 节点。

textureNode

代表输入的纹理节点效果.
sharpness

RCAS 锐化强度。 0 = 最大锐化，2 = 无锐化.

默认为0.2.
denoise

是否在噪声区域衰减RCAS锐化。

默认为 false.

属性

.denoise : Node.<bool>

是否在噪声区域衰减RCAS锐化。

.sharpness : Node.<float>

RCAS锐化强度。 0 = 最大值，2 = 无。

.textureNode : TextureNode

代表输入的纹理节点效果.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的输出大小。

width

以像素为单位的宽度。
height

以像素为单位的高度。

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
