CountingSort

可重用的 GPU 计数排序。

这会计算整数的稳定排列 [0, count)，按 任意，用户在 [0, binCount) 范围内提供 uint 密钥（“bin”）。它非常适合 大元素计数（数十万到数百万）的近似排序，其中精确的 比较排序，例如双调排序（参见 BitonicSort）会太慢：计数 排序只需要固定次数的遍历（重置、直方图、前缀总和、分散），无论 count，代价是仅精确到 binCount 的分辨率 - 着陆的元素 在同一个垃圾箱中最终以未指定的相对顺序排列。

此类本身不计算排序键。相反，TSL 函数是通过提供的 CountingSort#setBinNode 将当前 instanceIndex 映射到一个 bin，以及一个等效的 对于没有以下功能的平台，可以将纯 JavaScript 函数提供给 CountingSort#computeCPU 计算着色器支持（例如 WebGPURenderer 的 WebGL 后端）。

代码示例

const sort = new CountingSort( count, { binCount: 4096 } );
sort.setBinNode( () => {
	// return a `Node<uint>` bin index for `instanceIndex`, e.g. derived from a depth value.
} );
sort.compute( renderer );
// `sort.orderRead` now holds a storage buffer of `count` indices, ordered by bin.

导入

CountingSort 是一个插件，必须显式导入，请参阅 安装#Addons.

import { CountingSort } from 'three/addons/gpgpu/CountingSort.js';

构造函数

new CountingSort( count : number, options : Object )

构造新的计数排序。

count

要排序的元素数量。
options

修改计数排序的选项。

默认为 {}.

binCount

排序的 bin/bucket 数量键被量化为。较大的值会提高排序精度，但代价是较长（但仍是单遍）前缀和。

默认为 4096.
workgroupSize

排序期间执行的计算着色器的工作组大小。

默认为256.

属性

.binCount : number

排序键量化到的 bin/bucket 数量。

.binRead : StorageBufferNode

保存每个元素 bin 的只读存储节点，在直方图传递期间计算。

.binWrite : StorageBufferNode

保存每个元素的可写存储节点元素的 bin.

.count : number

要排序的元素数量。

.histogramAtomic : StorageBufferNode

用于累积每个 bin 直方图的原子存储节点。

.offsetAtomic : StorageBufferNode

用于直方图的独占前缀和的原子存储节点， 分散传递，作为每个 bin 写入游标。

.orderAttribute : StorageBufferAttribute

保存排序顺序的缓冲区属性（[0, count) 的排列）。这是 还有由 CountingSort#computeCPU 保持最新的属性。

.orderRead : StorageBufferNode

排序顺序缓冲区的只读存储节点。

.orderWrite : StorageBufferNode

排序顺序缓冲区的可写存储节点。

.workgroupSize : number

排序期间执行的计算着色器的工作组大小。

方法

.compute( renderer : Renderer )

在 GPU 上执行完整的计数排序，更新CountingSort#orderRead.

renderer

当前场景的渲染器。

.computeCPU( binFn : function )

在 CPU 上执行完整计数排序，更新 CountingSort#orderAttribute。 旨在作为不支持计算着色器的后端的后备。

binFn

获取元素索引并返回其 bin 的函数（[0, binCount) 中的普通数字）。

.enableWebGLBuffers()

为订单缓冲区启用特定于 WebGL 的存储缓冲区路径（PBO + 动态绘制使用）。 仅当 CountingSort#computeCPU 与 WebGPURenderer 的 WebGL 后端一起使用时才需要。

.setBinNode( binNode : function )

设置用于计算当前引用的元素的 bin 的 TSL 函数 instanceIndex，并（重新）构建 CountingSort#compute 使用的计算节点。

binNode

A 无参数函数返回 Node<uint> [0, binCount).
