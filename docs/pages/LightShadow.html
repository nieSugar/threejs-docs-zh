LightShadow

光阴影类的抽象基类。这些课程 表示不同灯光类型的阴影配置。

构造函数

new LightShadow( camera : Camera ) (abstract)

构造新的灯光阴影。

camera

灯光的世界视图。

属性

.autoUpdate : boolean

启用灯光阴影的自动更新。如果不需要动态 照明/阴影，您可以将其设置为 false.

默认为true.

.bias : number

阴影贴图偏差，从标准化深度中添加或减去多少 当确定表面是否处于阴影中时。

默认为0。这里的调整非常小（按照 0.0001 的顺序） 可能有助于减少阴影中的伪像。

默认为0.

.biasNode : Node.<float>

bias 的节点版本。仅支持 WebGPURenderer。

如果定义了偏置节点，则 bias 无效。

默认为null.

.blurSamples : number

模糊 VSM 阴影贴图时使用的样本量。

默认为 8.

.camera : Camera

灯光的世界视图。

.intensity : number

强度的影子。默认值为 1。 有效值范围为[0, 1].

默认为1.

.map : RenderTarget

使用内部摄像头生成的深度图；超出某个位置 像素的深度位于阴影中。渲染时内部计算的

默认为null.

.mapPass : RenderTarget

使用内部相机生成的分布图；遮挡是 根据深度分布计算。期间内部计算 render.

默认为null.

.mapSize : Vector2

定义阴影贴图的宽度和高度。值越高，质量越好 以计算时间为代价的阴影。值必须是 2 的幂。

默认为 (512,512).

.mapType : number

阴影纹理的类型。默认为 UnsignedByteType.

默认为UnsignedByteType.

.matrix : Matrix4

阴影相机空间的模型，用于计算阴影贴图中的位置和深度。 这是在渲染期间内部计算的。

.needsUpdate : boolean

当设置为 true 时，阴影贴图将在下一个 render 调用中更新。 如果您已将 LightShadow#autoUpdate 设置为 false，则需要 将此属性设置为 true，然后进行渲染调用以更新灯光的阴影。

默认为 false.

.normalBias : number

定义用于查询阴影贴图的位置沿偏移量 物体正常。默认值为 0。增加该值可用于 减少阴影痤疮，尤其是在光线照射的大场景中 浅角几何。代价是阴影可能会出现扭曲。

默认为0.

.radius : number

将此值设置为大于 1 将使阴影边缘模糊。 高值会在阴影中产生不必要的条带效应 - 更大 在这些效果之前，地图大小将允许在此处使用更高的值 变为可见。

当阴影贴图类型为 BasicShadowMap 时，该属性无效。

默认为1.

方法

.clone() : LightShadow

返回一个新的光阴影实例，其中包含从此实例复制的值。

返回：此克隆instance.

.copy( source : LightShadow ) : LightShadow

将给定光阴影实例的值复制到此实例实例.

source

要复制的灯光阴影.
返回：对此灯光阴影实例的引用。

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

.getCamera( viewportIndex : number ) : Camera

由渲染器内部使用以获取渲染给定视口的相机。

viewportIndex

视口index.

默认为0.
返回： 阴影相机。

.getFrameExtents() : Vector2

返回框架延伸。

返回： 框架延伸。

.getFrustum() : Frustum

获取阴影相机平截头体。由渲染器在内部用于剔除对象。

返回： 阴影摄像机视锥体。

.getViewport( viewportIndex : number ) : Vector4

返回给定视口索引的视口定义。

viewportIndex

视口index.
返回： viewport.

.getViewportCount() : number

由渲染器内部使用以获取需要的视口数量 要为此阴影渲染。

返回： 视口计数。

.toJSON() : Object

将灯光阴影序列化为 JSON。

参见：
  • ObjectLoader#parse
返回： 表示序列化灯光的 JSON 对象阴影.

.updateMatrices( light : Light )

更新渲染器内部使用的相机和阴影的矩阵。

light

正在渲染阴影的灯光.
