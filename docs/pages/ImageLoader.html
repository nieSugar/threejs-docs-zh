ImageLoader

用于加载图像的加载器。该类使用 HTML Image API 加载图像。

请注意，ImageLoader 已放弃对进度的支持 r84 中的事件。对于支持进度事件的 ImageLoader，请参阅 此线程.

代码示例

const loader = new THREE.ImageLoader();
const image = await loader.loadAsync( 'image.png' );

构造函数

new ImageLoader( manager : LoadingManager )

构造一个新的图像加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback ) : Image

开始从给定的 URL 加载并传递加载的图像 到 onLoad() 回调。该方法还返回一个新的 Image 对象，该对象可以 直接用于纹理创建。如果你这样做的话，纹理 相应的加载过程完成后，可能会在场景中弹出。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

此加载程序不支持。
onError

发生错误时执行。
覆盖： Loader#load
返回：图像.
