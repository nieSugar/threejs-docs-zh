ClearMaskPass

此通道可用于清除先前使用 MaskPass 定义的掩码。

代码示例

const clearPass = new ClearMaskPass();
composer.addPass( clearPass );

构造函数

new ClearMaskPass()

构造一个新的清除掩码pass.

属性

.needsSwap : boolean

覆盖以禁用交换.

默认为 false.

覆盖： Pass#needsSwap

方法

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行当前定义掩码的清除.

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
