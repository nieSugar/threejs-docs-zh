PackFloatNode

该节点表示将向量的浮点值打包为无符号32位整数的操作

构造函数

new PackFloatNode( encoding : 'snorm' | 'unorm' | 'float16', vectorNode : Node )

encoding

描述浮点值如何映射到整数范围的数字编码。
vectorNode

要打包的向量节点

属性

.encoding : string

数值编码.

.isPackFloatNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.layout : '2x16' | '4x8'

打包整数的组件布局。

默认为'2x16'.

.vectorNode : Node

要打包的向量.
