Euler

表示欧拉角的类。

Euler 角通过旋转对象来描述旋转变换 每个轴指定数量的各个轴，以及指定的轴 order.

迭代实例将产生其组件 (x, y, z, order) 按照相应的顺序。

代码示例

const a = new THREE.Euler( 0, 1, 1.57, 'XYZ' );
const b = new THREE.Vector3( 1, 0, 1 );
b.applyEuler(a);

构造函数

new Euler( x : number, y : number, z : number, order : string )

构造一个新的欧拉实例。

x

以弧度为单位的 x 轴角度。

默认为0.
y

以弧度为单位的 y 轴角度。

默认为0.
z

以弧度为单位的 z 轴角度弧度.

默认为0.
order

表示旋转应用顺序的字符串。

默认为 Euler.DEFAULT_ORDER.

属性

.isEuler : boolean (readonly)

该标志可用于类型测试。

默认为true.

.order : string

表示旋转应用顺序的字符串。

默认为'XYZ'.

.x : number

以弧度为单位的 x 轴角度。

默认为0.

.y : number

以弧度为单位的 y 轴角度。

默认为0.

.z : number

以弧度为单位的 z 轴角度弧度.

默认为0.

.DEFAULT_ORDER : string

默认欧拉角顺序。

默认为'XYZ'.

方法

.clone() : Euler

返回一个新的欧拉实例，其中包含从此实例复制的值。

返回：此克隆instance.

.copy( euler : Euler ) : Euler

将给定 Euler 实例的值复制到此实例。

euler

要复制的 Euler 实例。
返回： 对此 Euler 实例的引用。

.equals( euler : Euler ) : boolean

如果此 Euler 实例相等，则返回 true与给定的一个.

euler

要测试相等性的Euler实例。
返回：此Euler实例是否与给定的一个相等。

.fromArray( array : Array.<number, number, number, ?string> ) : Euler

将此Euler实例的组件设置为给定数组中的值。前三名 数组的条目分配给 x、y 和 z 分量。可选的第四个条目 定义欧拉阶。

array

保存欧拉分量值的数组。
返回： 对此 Euler 实例的引用。

.reorder( newOrder : string ) : Euler

通过从此创建四元数，用新阶重置欧拉角 欧拉角，然后用四元数和设置该欧拉角 新顺序.

警告：这会丢弃旋转信息。

newOrder

表示应用旋转的新顺序的字符串。
返回： 对此 Euler 实例的引用。

.set( x : number, y : number, z : number, order : string ) : Euler

设置欧拉分量。

x

以弧度为单位的 x 轴角度。
y

以弧度为单位的 y 轴角度。
z

以弧度为单位的 z 轴角度弧度.
order

表示旋转应用顺序的字符串。
返回： 对此 Euler 实例的引用。

.setFromQuaternion( q : Quaternion, order : string, update : boolean ) : Euler

根据标准化设置此欧拉实例的角度四元数.

q

标准化四元数.
order

表示旋转应用顺序的字符串。
update

是否应执行内部onChange回调。

默认为true.
返回： 对此 Euler 实例的引用。

.setFromRotationMatrix( m : Matrix4, order : string, update : boolean ) : Euler

从纯旋转设置此欧拉实例的角度矩阵.

m

A 4x4 矩阵，其中矩阵的上部 3x3 是纯旋转矩阵（即未缩放）。
order

表示旋转应用顺序的字符串。
update

是否应执行内部onChange回调。

默认为true.
返回： 对此 Euler 实例的引用。

.setFromVector3( v : Vector3, order : string ) : Euler

设置此欧拉实例与给定向量的角度。

v

The vector.
order

表示旋转应用顺序的字符串。
返回： 对此 Euler 实例的引用。

.toArray( array : Array.<number, number, number, string>, offset : number ) : Array.<number, number, number, string>

将此 Euler 实例的组件写入给定数组。如果没有提供数组， 该方法返回一个新实例。

array

保存 Euler 组件的目标数组。

默认为[].
offset

数组中第一个元素的索引。

默认为0.
返回： Euler 组件.
