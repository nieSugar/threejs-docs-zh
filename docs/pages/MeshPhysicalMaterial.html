MeshPhysicalMaterial

MeshStandardMaterial 的扩展，提供更高级的功能 基于物理的渲染属性：

  • 各向异性：表示材料各向异性属性的能力，可在拉丝金属中观察到。
  • 清漆层：某些材料——如汽车漆、碳纤维和潮湿表面——需要在另一层可能不规则或粗糙的表面上覆盖一层清晰的反射层。清漆层近似这种效果，而不需要单独的透明表面。
  • 彩虹色：允许渲染颜色随视角和光照角度变化的效果。这可以在肥皂泡、油膜或许多昆虫的翅膀上看到。
  • 基于物理的透明度：Material#opacity 的一个限制是高度透明的材料反射性较低。基于物理的透射为玻璃等薄透明表面提供了更逼真的选项。
  • 高级反射率：为非金属材料提供更灵活的反射率。
  • 回反射：将镜面光重新导向光源，用于道路标线和反光胶带等安全材料。
  • 光泽：可用于表示布料和织物材料。

由于这些复杂的着色功能，MeshPhysicalMaterial 具有 与其他 Three.js 材料相比，每像素的性能成本更高。大多数 默认情况下，效果处于禁用状态，并且在启用时会增加成本。对于 最佳结果，使用此材质时始终指定环境贴图。

构造函数

new MeshPhysicalMaterial( parameters : Object )

构造新的网格物理材质。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.anisotropy : number

各向异性强度，从 0.0 到1.0.

默认为0.

.anisotropyMap : Texture

红色和绿色通道代表[-1, 1]切线的各向异性方向， 双切空间，旋转 anisotropyRotation。蓝色通道 包含强度为 [0, 1] 乘以 anisotropy.

anisotropyMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.anisotropyRotation : number

切线、双切线空间中各向异性的旋转，以弧度为单位 从切线逆时针方向。当存在 anisotropyMap 时，此 属性为纹理中的向量提供额外的旋转。

默认为1.

.attenuationColor : Color

白光到达时由于吸收而变成的颜色 衰减距离.

默认为(1,1,1).

.attenuationDistance : number

以光传播的平均距离给出的介质密度 与粒子相互作用之前的介质。该值是世界上给定的 空间单位，并且必须大于零。

默认为 Infinity.

.clearcoat : number

表示透明涂层的强度，从0.0到1.0。使用 透明涂层相关特性使多层材料具有 基础层上的薄半透明层。

默认为0.

.clearcoatMap : Texture

此纹理的红色通道与clearcoat相乘， 用于按像素控制涂层强度。

clearcoatMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）。

默认为null.

.clearcoatNormalMap : Texture

可用于启用透明涂层的独立法线。

clearcoatNormalMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.clearcoatNormalScale : Vector2

clearcoatNormalMap 对透明涂层的影响有多大，从 (0,0) 至 (1,1).

默认为 (1,1).

.clearcoatRoughness : number

透明涂层的粗糙度，从 0.0 至 1.0.

默认为0.

.clearcoatRoughnessMap : Texture

The该纹理的绿色通道乘以 clearcoatRoughness，用于按像素控制涂层的粗糙度。

clearcoatRoughnessMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.dispersion : number

定义颜色（色差）透射角分离的强度 通过比较清晰的音量。任何零或更大的值都是有效的，典型范围 实际值为 [0, 1]。此属性只能用于透射对象。

默认为0.

.ior : number

非金属材料的折射率，从 1.0 到 2.333.

默认为1.5.

.iridescence : number

虹彩层的强度，根据之间的角度模拟 RGB 颜色偏移 表面和观察者，从 0.0 到 1.0.

默认为0.

.iridescenceIOR : number

虹彩 RGB 颜色偏移效果的强度，由折射率表示。 1.0 到 2.333.

之间，默认为 1.3.

.iridescenceMap : Texture

此纹理的红色通道相乘iridescence，针对每个像素 控制虹彩。

iridescenceMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.iridescenceThicknessMap : Texture

定义虹彩层厚度的纹理，存储在绿色通道中。 厚度的最小值和最大值由iridescenceThicknessRange数组定义：

  • 0.0 在绿色通道中将导致厚度等于数组的第一个元素。
  • 在绿色通道中的 1.0 将导致厚度等于数组的第二个元素。
  • 数组中的中间值将在线性插值于数组的元素之间。

iridescenceThicknessMap表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.iridescenceThicknessRange : Array.<number, number>

恰好包含 2 个元素的数组，指定虹彩层的最小和最大厚度。 虹彩层的厚度与 thickness 对 ior.

默认为 [100,400].

.isMeshPhysicalMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.reflectivity : number

反射率具有同等效果0.0 至 1.0。默认为 0.5，即 对应于折射率 1.5.

这模拟了非金属材料的反射率。没有效果 当metalness为1.0

默认为0.5.

.retroreflectivity : number

时，逆反射的强度，从0.0到1.0。值为 1.0 使用视图方向评估材料的微面反射 关于表面法线反射，将镜面波瓣重定向回来 朝向光源。

默认为0.

.sheen : number

光泽层的强度，从0.0到1.0.

默认为0.

.sheenColor : Color

光泽色调。

默认为(0,0,0).

.sheenColorMap : Texture

此纹理的RGB通道相乘针对 sheenColor，用于每像素控制 过光泽色调。

sheenColorMap 表示颜色数据，并且纹理必须分配一个 Texture#colorSpace。大多数 sheenColorMap 纹理设置 texture.colorSpace = SRGBColorSpace。

默认为null.

.sheenRoughness : number

光泽层的粗糙度，从 0.0 到 1.0.

默认为1.

.sheenRoughnessMap : Texture

此纹理的 Alpha 通道相乘sheenRoughness，用于逐像素控制 光泽粗糙度。

sheenRoughnessMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）。

默认为null.

.specularColor : Color

仅对非金属在垂直入射时对镜面反射进行着色。

默认为(1,1,1).

.specularColorMap : Texture

此纹理的 RGB 通道与 specularColor 相乘， 用于对镜面反射颜色进行逐像素控制。

specularColorMap 表示颜色数据，并且纹理必须分配一个 Texture#colorSpace。大多数 specularColorMap 纹理设置 texture.colorSpace = SRGBColorSpace。

默认为null.

.specularIntensity : number

仅缩放非金属镜面反射量的浮点数。 当设置为零时，模型实际上是朗伯模型。从 0.0 到 1.0.

默认为1.

.specularIntensityMap : Texture

该纹理的 Alpha 通道与 specularIntensity 相乘， 用于对镜面反射强度进行逐像素控制。

specularIntensityMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）。

默认为null.

.thickness : number

表面下方体积的厚度。该值在中给出 网格的坐标空间。如果值为 0，则材质为 薄壁。否则，材质是体积边界。

默认为0.

.thicknessMap : Texture

定义厚度的纹理，存储在绿色通道中。这将 乘以 thickness.

thicknessMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.transmission : number

透射度（或光学透明度），从0.0到1.0.

保留薄、透明或半透明的塑料或玻璃材料 即使它们是完全透射的，也很大程度上是反射的。传输 属性可用于对这些材质进行建模。

当透射率非零时，opacity 应设置为 1.

默认为0.

.transmissionMap : Texture

此纹理的红色通道相乘transmission，用于逐像素控制 光学透明度。

transmissionMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.
