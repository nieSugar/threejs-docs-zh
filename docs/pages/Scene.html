Scene

Scenes 允许您设置要渲染的内容以及 Three.js 的渲染位置。 您可以在此处放置网格、线条或灯光等 3D 对象。

构造函数

new Scene()

构造新场景。

属性

.background : Color | Texture

定义场景的背景。有效输入为：

  • 用于定义均匀颜色背景的颜色。
  • 用于定义（平面）纹理背景的纹理。
  • 立方体纹理或等矩形纹理，用于定义天空盒。

默认为null.

.backgroundBlurriness : number

设置背景的模糊度。仅影响环境贴图 分配给 Scene#background。有效输入是 0 之间的浮点数 和 1.

默认为0.

.backgroundIntensity : number

减弱背景颜色。仅适用于背景纹理。

默认为1.

.backgroundRotation : Euler

背景的旋转弧度。仅影响环境贴图 分配给 Scene#background.

默认为(0,0,0).

.environment : Texture

设置场景中所有物理材质的环境贴图。然而， 无法覆盖分配给 envMap 的现有纹理 材质属性.

默认为null.

.environmentIntensity : number

减弱环境的颜色。仅影响环境贴图 分配给Scene#environment.

默认为1.

.environmentRotation : Euler

环境贴图的旋转（以弧度为单位）。只影响物理材质 在使用 Scene#environment 时的场景中。

默认为(0,0,0).

.fog : Fog | FogExp2

定义影响所有内容的雾类型的雾实例 在场景中渲染。

默认为null.

.isScene : boolean (readonly)

该标志可用于类型测试。

默认为true.

.overrideMaterial : Material

强制使用定义的材质渲染场景中的所有内容。有可能 通过将 Material#allowOverride 设置为 false.

默认为null.
