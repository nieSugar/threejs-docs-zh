DirectionalLightHelper

Helper 对象，用于协助可视化 DirectionalLight 现场效果。它由一个平面和一条线组成，代表 光的位置和方向。

当方向光或其目标发生变换或光属性时 更改后，需要调用相应助手的 update() 方法。

代码示例

const light = new THREE.DirectionalLight( 0xFFFFFF );
scene.add( light );
const helper = new THREE.DirectionalLightHelper( light, 5 );
scene.add( helper );

构造函数

new DirectionalLightHelper( light : DirectionalLight, size : number, color : number | Color | string )

构造一个新的定向光源助手。

light

要可视化的光源。
size

光源的尺寸plane.

默认为1.
color

助手的颜色。如果没有设置，助手将采取 灯光的颜色。

属性

.color : number | Color | string

构造函数中传递的颜色参数。 如果未设置，助手将采用灯光的颜色。

.light : DirectionalLight

正在可视化的灯光。

.lightPlane : Line

包含显示定向光位置的线。

.targetLine : Line

表示定向光的目标线。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Object3D#dispose

.update()

更新帮助者匹配的位置和方向 光被可视化.
