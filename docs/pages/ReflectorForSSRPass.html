ReflectorForSSRPass

Reflector 的特殊版本，用于与SSRPass.

导入

ReflectorForSSRPass 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ReflectorForSSRPass } from 'three/addons/objects/ReflectorForSSRPass.js';

构造函数

new ReflectorForSSRPass( geometry : BufferGeometry, options : ReflectorForSSRPass~Options )

构造一个新的反射器.

geometry

反射器的几何形状.
options

配置选项.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Mesh#dispose

.getRenderTarget() : WebGLRenderTarget

返回反射器的内部渲染目标。

返回： 内部渲染target

类型定义

.Options

ReflectorForSSRPass的构造函数选项.

color
number | Color | string

反射器的颜色.

默认为0x7F7F7F.
textureWidth
number

纹理宽度。值越高，反射越清晰，但成本也越高。

默认为512.
textureHeight
number

纹理高度。值越高，反射越清晰，但成本也越高。

默认为512.
clipBias
number

剪辑偏差。

默认为0.
shader
Object

可用于传入定义反射视图如何投影到反射器几何体上的自定义着色器。
useDepthTexture
boolean

是否在纹理中存储深度值.

默认为true.
resolution
Vector2

反射器的分辨率通过.
