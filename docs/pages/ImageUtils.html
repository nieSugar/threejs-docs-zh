ImageUtils

包含图像实用函数的类。

静态方法

.getDataURL( image : HTMLImageElement | HTMLCanvasElement, type : string ) : string

返回包含给定图像表示形式的数据 URI。

image

图像object.
type

表示图像格式。

默认为'image/png'.
返回：数据URI.

.sRGBToLinear( image : HTMLImageElement | HTMLCanvasElement | ImageBitmap | Object ) : HTMLCanvasElement | Object

转换将 sRGB 图像数据提供给线性色彩空间。

image

图像object.
返回： 转换后的图像。
