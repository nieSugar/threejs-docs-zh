Audio

表示非位置（全局）音频对象。

此和相关音频模块使用 Web Audio API.

代码示例

// create an AudioListener and add it to the camera
const listener = new THREE.AudioListener();
camera.add( listener );
// create a global audio source
const sound = new THREE.Audio( listener );
// load a sound and set it as the Audio object's buffer
const audioLoader = new THREE.AudioLoader();
audioLoader.load( 'sounds/ambient.ogg', function( buffer ) {
	sound.setBuffer( buffer );
	sound.setLoop( true );
	sound.setVolume( 0.5 );
	sound.play();
});

构造函数

new Audio( listener : AudioListener )

构造新音频.

listener

全局音频监听器.

属性

.autoplay : boolean

是否自动开始播放.

默认为 false.

.buffer : AudioBuffer (readonly)

对音频的引用buffer.

通过Audio#setBuffer定义。

默认为null.

.context : AudioContext (readonly)

音频上下文.

.detune : number (readonly)

修改音调，以音分为单位。 +/- 100 是一个半音。 +/- 1200 是一个八度音程。

通过 Audio#setDetune 定义。

默认为0.

.duration : undefined | number

覆盖音频的默认持续时间。

默认为undefined.

.filters : Array.<AudioNode> (readonly)

可用于应用各种低阶滤波器来创建 更复杂的音效，例如via BiquadFilterNode.

该属性由Audio#setFilters自动设置。

.gain : GainNode (readonly)

用于音量控制的增益节点。

.hasPlaybackControl : boolean (readonly)

表示是否可以控制音频播放 使用类似 Audio#play 或 Audio#pause.

的方法，当音频源为 定义.

默认为true.

.isPlaying : boolean (readonly)

指示音频是否正在播放.

使用Audio#play时会自动设置该标志， Audio#pause, Audio#stop.

默认为 false.

.listener : AudioListener (readonly)

全局音频监听器.

.loop : boolean (readonly)

音频是否循环.

通过定义Audio#setLoop.

默认为 false.

.loopEnd : number

定义重播应在音频缓冲区中的位置 停止，以秒为单位。

默认为0.

.loopStart : number

定义重播应在音频缓冲区中的位置 开始，以秒为单位。

默认为0.

.offset : number

音频缓冲区内播放时间的偏移量 应该开始，以秒为单位。

默认为0.

.playbackRate : number (readonly)

播放速度。

通过Audio#setPlaybackRate定义。

默认为1.

.source : AudioNode (readonly)

保存对当前音频源的引用。

该属性自动加一set*() 方法的之一。

默认为null.

.sourceType : 'empty' | 'audioNode' | 'mediaNode' | 'mediaStreamNode' | 'buffer' (readonly)

定义源类型。

该属性由 set*() 方法之一自动设置。

默认为'empty'.

方法

.connect() : Audio

连接到音频源。这是内部使用的 初始化以及设置/删除过滤器时。

返回：对此实例的引用。

.disconnect() : Audio | undefined

断开与音频源的连接。这是内部使用的 初始化以及设置/删除滤波器时。

返回：对此实例的引用。

.getDetune() : number

返回以分为单位的振荡失谐。

返回：以分为单位的振荡失谐。

.getFilter() : AudioNode | undefined

返回列表中的第一个滤波器过滤器.

返回： 过滤器列表中的第一个过滤器。

.getFilters() : Array.<AudioNode>

返回当前设置的过滤器。

返回： 过滤器列表。

.getLoop() : boolean

返回循环flag.

只能与允许播放控制的兼容音频源一起使用。

返回：音频是否应该循环播放。

.getOutput() : GainNode

返回输出音频节点.

返回： 输出节点。

.getPlaybackRate() : number

返回当前播放速率。

返回：播放速率。

.getVolume() : number

返回音量.

返回： 音量.

.onEnded()

播放完成时自动调用。

.pause() : Audio | undefined

暂停音频播放。

只能与允许播放控制的兼容音频源一起使用。

返回：对此实例的引用。

.play( delay : number ) : Audio | undefined

开始播放音频音频.

只能与允许播放控制的兼容音频源一起使用。

delay

音频应开始播放的延迟（以秒为单位）。

默认为0.
返回：对此实例的引用。

.setBuffer( audioBuffer : AudioBuffer ) : Audio

将给定的音频缓冲区设置为此实例的源。

Audio#sourceType 设置为 buffer 并且Audio#hasPlaybackControl 到 true.

audioBuffer

音频缓冲区。
返回：对此实例的引用。

.setDetune( value : number ) : Audio

定义以分为单位的振荡失谐。

value

以分为单位的振荡失谐cents.
返回：对此实例的引用。

.setFilter( filter : AudioNode ) : Audio

对音频应用单个过滤器节点。

filter

要设置的过滤器。
返回：对此实例的引用。

.setFilters( value : Array.<AudioNode> ) : Audio

设置过滤器数组并将它们与音频源连接。

value

A 列表过滤器.
返回：对此实例的引用。

.setLoop( value : boolean ) : Audio | undefined

设置循环标志.

只能与允许播放控制的兼容音频源一起使用。

value

音频是否循环.
返回：对此实例的引用。

.setLoopEnd( value : number ) : Audio

设置循环结束值，该值定义重播应在音频缓冲区中的位置 停止，以秒为单位。

value

循环结束值。
返回：对此实例的引用。

.setLoopStart( value : number ) : Audio

设置循环起始值，该值定义重播应在音频缓冲区中的位置 开始，以秒为单位。

value

循环起始值。
返回：对此实例的引用。

.setMediaElementSource( mediaElement : HTMLMediaElement ) : Audio

将给定媒体元素设置为此实例的源。

Audio#sourceType 设置为 mediaNode 并且Audio#hasPlaybackControl 到 false.

mediaElement

媒体元素.
返回：对此实例的引用。

.setMediaStreamSource( mediaStream : MediaStream ) : Audio

将给定媒体流设置为此媒体流的源实例.

Audio#sourceType 设置为 mediaStreamNode 并将 Audio#hasPlaybackControl 设置为 false.

mediaStream

媒体Stream.
返回：对此实例的引用。

.setNodeSource( audioNode : AudioNode ) : Audio

将给定音频节点设置为此实例的源。

Audio#sourceType 设置为 audioNode 并将 Audio#hasPlaybackControl 设置为false.

audioNode

音频节点，如OscillatorNode.
返回：对此实例的引用。

.setPlaybackRate( value : number ) : Audio | undefined

设置播放速率。

只能与允许播放控制的兼容音频源一起使用。

value

播放速率为set.
返回：对此实例的引用。

.setVolume( value : number ) : Audio

设置音量。

value

要设置的音量。
返回：对此实例的引用。

.stop( delay : number ) : Audio | undefined

停止音频播放。

只能与允许播放控制的兼容音频源一起使用。

delay

音频应停止的延迟（以秒为单位）正在播放.

默认为0.
返回：对此实例的引用。
