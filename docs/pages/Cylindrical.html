Cylindrical

此类可用于将 3D 空间中的点表示为 圆柱坐标.

构造函数

new Cylindrical( radius : number, theta : number, y : number )

构造一个新的圆柱.

radius

从原点到x-z方向上一点的距离平面.

默认为1.
theta

从正 z 轴开始以弧度测量的 x-z 平面中的逆时针角度。

默认为0.
y

x-z 平面上方的高度。

默认为0.

属性

.radius : number

从原点到x-z方向上一点的距离平面.

默认为1.

.theta : number

从正 z 轴开始以弧度测量的 x-z 平面中的逆时针角度。

默认为0.

.y : number

x-z 平面上方的高度。

默认为0.

方法

.clone() : Cylindrical

返回包含此实例中复制值的新圆柱体。

返回：此克隆instance.

.copy( other : Cylindrical ) : Cylindrical

复制值给定圆柱体到此实例的值。

other

要复制的圆柱体。
返回：对此圆柱体的引用。

.set( radius : number, theta : number, y : number ) : Cylindrical

通过复制给定值来设置圆柱体分量。

radius

The半径.
theta

theta 角.
y

高度值.
返回：对此圆柱体的引用。

.setFromCartesianCoords( x : number, y : number, z : number ) : Cylindrical

设置给定笛卡尔坐标的圆柱分量.

x

x 值.
y

x 值.
z

x 值.
返回：对此圆柱体的引用。

.setFromVector3( v : Vector3 ) : Cylindrical

设置圆柱分量从假设持有的给定向量 笛卡尔坐标.

v

要设置的向量。
返回：对此圆柱体的引用。
