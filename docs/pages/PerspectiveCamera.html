PerspectiveCamera

使用透视投影的相机.

此投影模式旨在模仿人眼的观看方式。它 是用于渲染 3D 场景的最常见投影模式。

代码示例

const camera = new THREE.PerspectiveCamera( 45, width / height, 1, 1000 );
scene.add( camera );

构造函数

new PerspectiveCamera( fov : number, aspect : number, near : number, far : number )

构造新的透视相机。

fov

垂直视野。

默认为50.
aspect

纵横比。

默认为1.
near

相机的近平面。

默认为0.1.
far

相机的远平面。

默认为2000.

属性

.aspect : number

纵横比，通常是画布宽度/画布高度。

默认为1.

.far : number

相机的远平面。必须大于 PerspectiveCamera#near.

默认为2000.

.filmGauge : number

用于较大轴的胶片尺寸的当前值。默认值为 35（毫米）。这个 参数不会影响投影矩阵，除非 PerspectiveCamera#filmOffset 设置为非零值。

默认为 35.

.filmOffset : number

水平偏心偏移，单位与 PerspectiveCamera#filmGauge.

默认为0.

.focus : number

用于的物体距离立体视觉和景深效果。这个 参数不会影响投影矩阵，除非 StereoCamera 正在使用。

默认为10.

.fov : number

垂直视野，从下到上的视野， 以度为单位。

默认为50.

.isPerspectiveCamera : boolean (readonly)

该标志可用于类型测试。

默认为true.

.near : number

相机的近平面。有效范围大于0 并且小于PerspectiveCamera#far的当前值。

请注意，与OrthographicCamera不同，0不是 透视相机近平面的有效值。

默认为0.1.

.view : Object

表示视锥体窗口规范。不应编辑此属性 直接但通过 PerspectiveCamera#setViewOffset 和 PerspectiveCamera#clearViewOffset.

默认为null.

.zoom : number

相机的变焦系数。

默认为1.

方法

.clearViewOffset()

从投影矩阵中删除视图偏移。

.getEffectiveFOV() : number

考虑到 PerspectiveCamera#zoom.

返回： 有效视场。

.getFilmHeight() : number

返回图像的高度电影。如果 PerspectiveCamera#aspect 大于或 等于 1（横向格式），结果等于 PerspectiveCamera#filmGauge.

返回： 胶片宽度。

.getFilmWidth() : number

返回胶片上图像的宽度。如果 PerspectiveCamera#aspect 大于或 等于 1（横向格式），结果等于 PerspectiveCamera#filmGauge.

返回： 胶片宽度。

.getFocalLength() : number

返回当前 PerspectiveCamera#fov 的焦距，并且 PerspectiveCamera#filmGauge.

返回：计算出的焦距。

.getViewBounds( distance : number, minTarget : Vector2, maxTarget : Vector2 )

计算沿观察方向给定距离处相机可视矩形的2D边界。 将minTarget和maxTarget设置为视图矩形的左下角和右上角的坐标。

distance

观看距离。
minTarget

视图矩形的左下角写入此向量.
maxTarget

视图矩形的右上角写入此向量。

.getViewSize( distance : number, target : Vector2 ) : Vector2

计算沿观看方向给定距离处相机可视矩形的宽度和高度。

distance

观看距离。
target

用于存储结果的目标向量，其中x为宽度，y为高度.
返回： 视图尺寸.

.setFocalLength( focalLength : number )

根据焦距设置相对于当前PerspectiveCamera#filmGauge的FOV.

默认胶片规格为35，因此可以指定焦距 35 毫米（全画幅）相机。

focalLength

焦距和胶片规格的值必须具有相同的单位。

.setViewOffset( fullWidth : number, fullHeight : number, x : number, y : number, width : number, height : number )

设置较大的偏移截锥体。这对于多窗口或 多屏/多机设置.

例如，如果您有 3x2 显示器，并且每个显示器的分辨率为 1920x1080，并且 监视器位于这样的网格中

  +---+---+---+
  | A | B | C |
  +---+---+---+
  | D | E | F |
  +---+---+---+

然后对于每个监视器，您可以这样称呼它：

const w = 1920;
const h = 1080;
const fullWidth = w * 3;
const fullHeight = h * 2;
// --A--
camera.setViewOffset( fullWidth, fullHeight, w * 0, h * 0, w, h );
// --B--
camera.setViewOffset( fullWidth, fullHeight, w * 1, h * 0, w, h );
// --C--
camera.setViewOffset( fullWidth, fullHeight, w * 2, h * 0, w, h );
// --D--
camera.setViewOffset( fullWidth, fullHeight, w * 0, h * 1, w, h );
// --E--
camera.setViewOffset( fullWidth, fullHeight, w * 1, h * 1, w, h );
// --F--
camera.setViewOffset( fullWidth, fullHeight, w * 2, h * 1, w, h );

注意监视器没有理由必须具有相同的大小或位于网格中。

fullWidth

多视图设置的全宽.
fullHeight

多视图设置的全高.
x

子摄像头的水平偏移.
y

子摄像头的垂直偏移子摄像头.
width

子摄像头的宽度.
height

子摄像头的高度.

.updateProjectionMatrix()

更新相机的投影矩阵。必须在任何更改后调用 相机属性.
