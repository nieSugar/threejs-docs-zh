PropertyMixer

允许加权累加的缓冲场景图属性；内部使用.

构造函数

new PropertyMixer( binding : PropertyBinding, typeName : string, valueSize : number )

构造一个新的属性混合器.

binding

属性绑定.
typeName

关键帧轨道类型名称.
valueSize

关键帧轨道值大小.

属性

.binding : PropertyBinding

属性绑定.

.cumulativeWeight : number

累计属性绑定的权重。

默认为0.

.cumulativeWeightAdditive : number

属性绑定的累积附加权重。

默认为0.

.referenceCount : number

引用此属性绑定的关键帧轨道的数量。

默认为0.

.useCount : number

当前使用此属性绑定的活动关键帧轨道的数量。

默认为0.

.valueSize : number

关键帧轨道值大小.

方法

.accumulate( accuIndex : number, weight : number )

在incoming区域进入accu<i>.

accuIndex

累积索引.
weight

权重.

.accumulateAdditive( weight : number )

累积数据incoming 区域进入 add.

weight

权重.

.apply( accuIndex : number )

当 Accus 不同时，将 accu<i> 的状态应用于绑定。

accuIndex

累积索引.

.restoreOriginalState()

应用先前通过获取的状态PropertyMixer#saveOriginalState 到绑定。

.saveOriginalState()

记住绑定属性的状态并将其复制到两个累加器。
