RoundedBoxGeometry

具有圆角和边缘的特殊类型的盒子几何图形。

代码示例

const geometry = new RoundedBoxGeometry();
const material = new THREE.MeshStandardMaterial( { color: 0x00ff00 } );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

导入

RoundedBoxGeometry 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { RoundedBoxGeometry } from 'three/addons/geometries/RoundedBoxGeometry.js';

构造函数

new RoundedBoxGeometry( width : number, height : number, depth : number, segments : number, radius : number )

构造一个新的圆角盒几何形状。

width

宽度。即平行于X轴的边的长度

默认为1.
height

高度。即平行于Y轴的边的长度。

默认为1.
depth

深度。即，平行于 Z 轴的边的长度。

默认为1.
segments

形成圆角的段数。

默认为2.
radius

圆角的半径圆角.

默认为0.1.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

覆盖： BoxGeometry#parameters

静态方法

.fromJSON( data : Object ) : RoundedBoxGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
