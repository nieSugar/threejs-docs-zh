OBJExporter

OBJ 的导出器.

OBJExporter 无法将材质数据导出到 MTL 文件中，因此只有几何数据支持。

代码示例

const exporter = new OBJExporter();
const data = exporter.parse( scene );

导入

OBJExporter 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OBJExporter } from 'three/addons/exporters/OBJExporter.js';

构造函数

new OBJExporter()

方法

.parse( object : Object3D ) : string

解析给定的 3D 对象并生成OBJ 输出。

如果 3D 对象由多个子对象和几何体组成，它们将合并到文件中的单个网格中。

object

要导出的 3D 对象。
返回： 导出的OBJ.
