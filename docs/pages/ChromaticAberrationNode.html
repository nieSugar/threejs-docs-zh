ChromaticAberrationNode

用于应用半色调的后处理节点像差效应。 此效果模拟真实相机镜头中出现的色边 通过分离和偏移红色、绿色和蓝色通道。

导入

ChromaticAberrationNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { chromaticAberration } from 'three/addons/tsl/display/ChromaticAberrationNode.js';

构造函数

new ChromaticAberrationNode( textureNode : TextureNode, strengthNode : Node, centerNode : Node, scaleNode : Node )

构造新的色差节点。

textureNode

代表输入的纹理节点效果.
strengthNode

作为节点的色差效果的强度。
centerNode

作为节点的色差效果的中心点。节点.
scaleNode

以中心为节点进行步进缩放的比例因子。

属性

.centerNode : Node

保存效果中心点的节点。

.scaleNode : Node

保存步进缩放比例因子的节点。

.strengthNode : Node

保存效果强度的节点。效果.

.textureNode : texture

代表输入的纹理节点效果.

方法

.setup( builder : NodeBuilder ) : ShaderCallNodeInternal

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup
