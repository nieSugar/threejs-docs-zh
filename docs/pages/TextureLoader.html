TextureLoader

用于加载纹理的类。图片是内部的 通过ImageLoader.

加载请注意，TextureLoader已放弃对进度的支持 r84 中的事件。对于支持进度事件的 TextureLoader，请参阅 此线程.

代码示例

const loader = new THREE.TextureLoader();
const texture = await loader.loadAsync( 'textures/land_ocean_ice_cloud_2048.jpg' );
const material = new THREE.MeshBasicMaterial( { map:texture } );

构造函数

new TextureLoader( manager : LoadingManager )

构造一个新的纹理加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback ) : Texture

开始从给定的 URL 加载并传递完全加载的纹理加载器纹理 到 onLoad() 回调。该方法还返回一个新的纹理对象，该对象可以 直接用于材质创作。如果你这样做的话，纹理 相应的加载过程完成后，可能会在您的场景中弹出。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

此加载程序不支持。
onError

发生错误时执行。
覆盖： Loader#load
返回： 纹理.
