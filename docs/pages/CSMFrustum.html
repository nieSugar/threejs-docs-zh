CSMFrustum

表示 CSM 实例的平截头体。

导入

CSMFrustum 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { CSMFrustum } from 'three/addons/csm/CSMFrustum.js';

构造函数

new CSMFrustum( data : CSMFrustum~Data )

构造一个新的 CSM 平截头体。

data

CSM数据.

属性

.vertices : Object

表示近邻和近邻顶点的对象 视图空间中的远平面。

.zFar : number

zFar 值。

.zNear : number

zNear 值。该值取决于CSM是否 与 WebGL 或 WebGPU 一起使用。两个 API 使用不同的 投影矩阵的约定。

方法

.setFromProjectionMatrix( projectionMatrix : Matrix4, maxFar : number ) : Object

根据给定的投影矩阵和最大远值设置此 CSM 平截头体。

projectionMatrix

投影矩阵，通常是场景相机的投影矩阵。
maxFar

最大远值.
返回： 表示视图中近平面和远平面顶点的对象空间.

.split( breaks : Array.<number>, target : Array.<CSMFrustum> )

按给定数组分割 CSM 平截头体。新的 CSM 平截头体被推入给定的 目标数组.

breaks

范围内的数字数组 [0,1] 定义如何 CSM 平截头体应被拆分。
target

保存新 CSM 平截头体的目标数组。

.toSpace( cameraMatrix : Matrix4, target : CSMFrustum )

将给定的目标 CSM 平截头体转换为由 给定相机矩阵.

cameraMatrix

定义新坐标系的矩阵.
target

要转换的CSM.

类型定义

.Data

CSMFrustum的构造函数数据.

webGL
boolean

是否此CSM视锥体与 WebGL 或 WebGPU 一起使用。
reversedDepth
boolean

是否启用反向深度缓冲区。
projectionMatrix
Matrix4

通常是场景相机的投影矩阵。
maxFar
number

最大远值.
