Flow

用于使网格围绕曲线弯曲的修改器。

此模块只能与 WebGLRenderer 一起使用。当使用WebGPURenderer时， import the class from CurveModifierGPU.js.

导入

Flow 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { Flow } from 'three/addons/modifiers/CurveModifier.js';

构造函数

new Flow( mesh : Mesh, numberOfCurves : number )

构造一个新的 Flow 实例。

mesh

要克隆和修改以围绕曲线弯曲的网格。
numberOfCurves

应为额外的空间预先分配的空间量曲线.

默认为1.

Classes

Flow

方法

.moveAlongCurve( amount : number )

沿曲线移动网格。

amount

偏移量.

.updateCurve( index : number, curve : Curve )

更新给定曲线的曲线索引.

index

曲线索引.
curve
