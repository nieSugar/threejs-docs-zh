ComputeBuiltinNode

ComputeBuiltinNode 表示公开信息的计算范围内置值 关于当前正在运行的调度和/或其正在运行的设备。

此节点只能与 WebGPU 后端一起使用。

构造函数

new ComputeBuiltinNode( builtinName : string, nodeType : string )

构造一个新的计算内置节点。

builtinName

内置名称。
nodeType

节点类型。

方法

.generateNodeType( builder : NodeBuilder ) : string

此方法被覆盖，因为节点类型只是派生自nodeType..

builder

当前节点构建器.
覆盖： Node#generateNodeType
返回： 节点类型。

.getBuiltinName( builder : NodeBuilder ) : string

返回内置名称.

builder

当前节点构建器.
返回：内置名称.

.getHash( builder : NodeBuilder ) : string

由于哈希是从内置名称派生的，因此该方法被覆盖name.

builder

当前节点构建器.
覆盖： Node#getHash
返回： 哈希值.

.hasBuiltin( builder : NodeBuilder ) : boolean

当前节点构建器是否具有内置函数。

builder

当前节点构建器.
返回：构建器是否具有内置函数not.

.setBuiltinName( builtinName : string ) : ComputeBuiltinNode

设置内置名称.

builtinName

内置名称。
返回：对此节点的引用.
