StructTypeNode

表示基于节点的系统中的结构类型节点。 此类用于定义和管理结构成员的布局和类型。 它扩展了 Node 基类并提供了获取结构长度的方法， 检索成员类型，并生成构建器的结构类型。

构造函数

new StructTypeNode( membersLayout : Object, name : string )

创建 StructTypeNode 的实例。

membersLayout

结构的成员布局。
name

结构的可选名称。

默认为null.

属性

.isStructTypeNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.membersLayout : Array.<{name: string, type: string, atomic: boolean}>

成员的布局对于 struct

.name : string

引擎的名称struct.

默认为null.

覆盖： Node#name

方法

.getLength() : number

返回 4 字节元素（例如 float 或 int 组件）中的结构长度。 长度是通过对结构成员的长度求和来计算的，并考虑到内存对齐。 要获取以字节为单位的大小，请将返回值乘以 4.

返回： 4 字节元素中的结构长度.
