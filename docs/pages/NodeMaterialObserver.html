NodeMaterialObserver

WebGPURenderer 使用该类作为管理组件。 它的主要目的是确定渲染对象是否需要 在渲染或不渲染之前刷新。

构造函数

new NodeMaterialObserver( builder : NodeBuilder )

构造一个新的节点材质观察器。

builder

节点构建器。

属性

.hasAnimation : boolean

节点构建器的 3D 对象是否有动画。

.hasNode : boolean

材质是否使用节点对象。

.refreshUniforms : Array.<string>

A所有可能材质制服的列表

.renderId : number

保存节点框架中的当前渲染ID。

默认为0.

.renderObjects : WeakMap.<RenderObject, Object>

节点材质可以由多个渲染对象使用，因此 监视器必须维护渲染对象列表。

方法

.containsNode( builder : NodeBuilder ) : boolean

如果节点构建器的材质使用，则返回 true 节点属性。

builder

当前节点构建器.
返回： 节点构建器的材质是否使用节点属性。

.equals( renderObject : RenderObject, lightsData : Array.<Light>, renderId : number ) : boolean

如果给定渲染对象未更改其状态，则返回 true。

renderObject

渲染对象.
lightsData

当前材质灯.
renderId

当前渲染ID.
返回：给定渲染对象是否等于其缓存状态。

.firstInitialization( renderObject : RenderObject ) : boolean

如果给定渲染对象是第一次验证，则返回true观察者.

renderObject

渲染对象.
返回：给定的渲染对象是否第一次被该观察者验证。

.getAttributesData( attributes : Object ) : Object

返回一个属性数据结构，保存属性版本 监控.

attributes

几何属性.
返回： 用于监控属性版本的对象。

.getGeometryData( geometry : BufferGeometry ) : Object

返回保存几何属性值的几何数据结构 监控.

geometry

几何体.
返回： 用于监视几何属性的对象。

.getLights( lightsNode : LightsNode, renderId : number ) : Array.<Object>

返回给定灯光节点和渲染 ID 的灯光。

lightsNode

灯光节点.
renderId

渲染ID.
返回： 给定灯光节点和渲染的灯光ID.

.getLightsData( materialLights : Array.<Light> ) : Array.<Object>

返回给定材质灯光的灯光数据。

materialLights

材质灯光。
返回：给定材质灯光的灯光数据。

.getMaterialData( material : Material ) : Object

返回保存以下材质属性值的材质数据结构 监控.

material

材质.
返回： 用于监控材质属性的对象。

.getRenderObjectData( renderObject : RenderObject ) : Object

返回给定渲染对象的监控数据。

renderObject

渲染对象.
返回： 监控数据。

.getTextureData( texture : Texture ) : Object

返回纹理保存纹理状态的数据结构 监控.

texture

纹理.
返回： 用于监控纹理的对象。

.hasDynamicInstancing( object : Object3D ) : boolean

如果给定的 3D 对象使用具有动态绘制用途的实例缓冲区，则返回 true。 每次渲染必须上传一次此类缓冲区，以便渲染对象需要完全刷新。

object

3D对象.
返回：给定的 3D 对象是否使用具有动态绘制用途的实例缓冲区。

.needsRefresh( renderObject : RenderObject, nodeFrame : NodeFrame ) : number

检查给定的渲染对象是否需要refresh.

renderObject

渲染对象.
nodeFrame

当前节点框架.
返回：刷新类型，参见RenderObjectRefreshType.

.needsVelocity( renderer : Renderer ) : boolean

如果当前渲染产生运动，则返回true矢量.

renderer

渲染器.
返回：当前渲染是否产生运动矢量.
