GTAOPass

GTAO 效果的通道。

GTAOPass 提供比 SSAOPass 更好的质量，但也更多昂贵.

代码示例

const gtaoPass = new GTAOPass( scene, camera, width, height );
gtaoPass.output = GTAOPass.OUTPUT.Denoise;
composer.addPass( gtaoPass );

导入

GTAOPass 是一个插件，必须显式导入，请参阅Installation#Addons.

import { GTAOPass } from 'three/addons/postprocessing/GTAOPass.js';

构造函数

new GTAOPass( scene : Scene, camera : Camera, width : number, height : number, parameters : Object, aoParameters : Object, pdParameters : Object )

构造一个新的 GTAO pass.

scene

计算AO的场景.
camera

相机.
width

效果的宽度.

默认为512.
height

效果的高度.

默认为512.
parameters

传递参数.
aoParameters

AO参数.
pdParameters

降噪参数.

属性

.blendIntensity : number

AO混合强度.

默认为1.

.camera : Camera

相机.

.clear : boolean

默认覆盖以执行清除操作。

默认为true.

覆盖： Pass#clear

.gtaoMap : Texture (readonly)

保存计算的 AO 的纹理。

.height : number

效果的高度.

默认为512.

.output : number

输出配置.

默认为0.

.pdRadiusExponent : number

泊松降噪半径指数.

默认为2.

.pdRings : number

泊松降噪环数.

默认为2.

.pdSamples : number

泊松降噪样本计数.

默认为16.

.scene : Scene

渲染AO的场景for.

.width : number

效果的宽度.

默认为512.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行GTAO pass。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setGBuffer( depthTexture : DepthTexture, normalTexture : DepthTexture )

配置此pass的GBuffer。如果没有传递任何参数， 该通道创建一个内部渲染目标来保持深度 和法线数据.

depthTexture

深度纹理.
normalTexture

法线纹理.

.setSceneClipBox( box : Box3 )

使用给定的AABB配置GTAO着色器的剪辑框.

box

包围应接收AO的场景的AABB。经过时 null，使用剪辑框。

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize

.updateGtaoMaterial( parameters : Object )

从给定参数对象更新 GTAO 材质。

parameters

GTAO 材质参数。

.updatePdMaterial( parameters : Object )

从给定参数更新降噪材质对象.

parameters

降噪参数.
