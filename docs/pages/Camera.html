Camera

相机的抽象基类。这个类应该总是被继承 当您构建新相机时.

构造函数

new Camera() (abstract)

构建新相机.

属性

.coordinateSystem : WebGLCoordinateSystem | WebGPUCoordinateSystem

使用相机的坐标系.

.isCamera : boolean (readonly)

该标志可用于类型测试。

默认为true.

.matrixWorldInverse : Matrix4

相机世界矩阵的逆矩阵.

.projectionMatrix : Matrix4

相机的投影矩阵.

.projectionMatrixInverse : Matrix4

相机投影矩阵的逆。

.reversedDepth : boolean

指示相机是否使用反向深度缓冲区的标志。

默认为 false.

方法

.getWorldDirection( target : Vector3 ) : Vector3

返回表示世界中3D对象（“观看”）方向的向量space.

此方法被覆盖，因为与其他相机相比，相机具有不同的前向矢量 3D 对象。默认情况下，相机向下查看其本地负 z 轴。

target

结果存储到的目标向量。
覆盖： Object3D#getWorldDirection
返回： 3D物体在世界空间中的方向.
