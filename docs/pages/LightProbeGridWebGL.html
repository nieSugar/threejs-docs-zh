LightProbeGridWebGL

L2 球谐波辐照度探头的 3D 网格，提供 位置相关的漫反射全局照明。

注意，此类只能与 WebGLRenderer 一起使用。 对于WebGPURenderer，使用LightProbeGrid.

所有七个打包的SH子卷都存储在单个 RGBA中 WebGL3DRenderTarget 使用沿 Z 轴的纹理图集布局。 每个子卷占用 ( nz + 2 ) atlas 切片：一个填充切片位于 每个末端（最近边缘数据切片的副本）以防止颜色渗色 当硬件三线性过滤器跨子体积边界读取时.

图集布局（nz = resolution.z，PADDING = 1）：

总图集深度= 7 * ( nz + 2 ).

烘焙完全驻留在GPU上：立方体贴图渲染、SH 投影和 纹理打包全部发生在 GPU 上，CPU 读回为零。

代码示例

  slice   0              : padding  (copy of sub-volume 0, data slice 0)
  slices  1 … nz         : sub-volume 0 data
  slice   nz + 1         : padding  (copy of sub-volume 0, data slice nz-1)
  slice   nz + 2         : padding  (copy of sub-volume 1, data slice 0)
  slices  nz+3 … 2*nz+2  : sub-volume 1 data
  …

导入

LightProbeGridWebGL 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { LightProbeGridWebGL } from 'three/addons/lighting/LightProbeGridWebGL.js';

构造函数

new LightProbeGridWebGL( width : number, height : number, depth : number, widthProbes : number, heightProbes : number, depthProbes : number )

构造一个新的辐照度探头网格。

体积以对象位置为中心。

width

体积沿X的全宽度.

默认为1.
height

全高度沿 Y 的体积的深度.

默认为1.
depth

沿 Z 的体积的全深度.

默认为1.
widthProbes

沿 X 的探头数量。默认为 Math.max( 2, Math.round( width ) + 1 ).
heightProbes

沿 Y 方向的探针数量。默认值为 Math.max( 2, Math.round( height ) + 1 )。
depthProbes

沿 Z 轴的探针数量。默认为 Math.max( 2, Math.round( depth ) + 1 ).

属性

.boundingBox : Box3

网格的世界空间边界框。自动更新 通过 LightProbeGridWebGL#bake.

.depth : number

沿 Z 方向的体积的完整深度.

.height : number

沿 Y 的体积的完整高度。

.isLightProbeGrid : boolean (readonly)

该标志可用于类型测试。

默认为true.

.resolution : Vector3

沿每个轴的探针数量。

.texture : Data3DTexture

存储所有七个打包 SH 子卷的单个 RGBA 图集 3D 纹理。

默认为null.

.width : number

沿 X.

方法

.bake( renderer : WebGLRenderer, scene : Scene, options : Object )

通过在每个探针位置渲染立方体贴图来烘焙探针 投影到 L2 SH。可选择迭代额外的过程来捕获 间接反弹：每个额外的通道对前一个通道的数据进行采样，如下所示 间接光，因此在烘焙之前添加到场景的网格会累积 每额外通过一次弹跳。

使用 start 和 count 烘焙范围并立即发布其单元格。 索引沿 X、Z、Y 前进，从底部填充水平层 到顶部。对于增量间接反弹，完成 pass: 0 的整个网格， 然后重复 pass: 1 等。在索引 0 处开始每次传递以快照 更新其单元格之前的上一步。

SunLight 的阴影投射实例暂时替换为 等效定向光，因为它们的视图适合阴影级联 无法跨探针渲染冻结。

renderer

渲染器.
scene

要渲染的场景.
options

烘焙选项。

cubemapSize

每个立方体贴图面的分辨率。

默认为 8.
near

立方体相机的近平面。

默认为0.1.
far

立方体的远平面相机.

默认为100.
bounces

额外的反弹通道。仅在烘焙整个网格时可用。

默认为0.
start

要烘焙的第一个探针的索引。

默认为0.
count

要烘焙的探针数量。默认为剩余探针。
pass

起始通道。零捕获直射光；后面的通道对前一个通道进行采样。远程调用需要 bounces: 0.

默认为0.

.dispose()

释放 GPU 资源。

.getProbePosition( ix : number, iy : number, iz : number, target : Vector3 ) : Vector3

返回探头的世界空间位置网格索引 (ix, iy, iz).

ix

X 索引.
iy

Y 索引.
iz

Z 索引.
target

目标矢量.
返回： 世界空间位置。

.updateBoundingBox()

从当前位置和大小更新世界空间边界框。
