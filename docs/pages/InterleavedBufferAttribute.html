InterleavedBufferAttribute

具有交错数据的缓冲区属性的替代版本。交错 属性共享一个公共交错数据存储 (InterleavedBuffer) 并引用 缓冲区中的不同偏移量。

构造函数

new InterleavedBufferAttribute( interleavedBuffer : InterleavedBuffer, itemSize : number, offset : number, normalized : boolean )

构造一个新的交错缓冲区属性。

interleavedBuffer

保存交错数据的缓冲区。
itemSize

项目大小。
offset

缓冲区中的属性偏移量。
normalized

数据是否标准化或不是.

默认为 false.

属性

.array : TypedArray

保存交错缓冲区属性的数组data.

.count : number (readonly)

此缓冲区属性的项计数。

.data : InterleavedBuffer

保存交错数据的缓冲区。

.isInterleavedBufferAttribute : boolean (readonly)

该标志可用于类型测试。

默认为true.

.itemSize : number

项目大小，请参见BufferAttribute#itemSize.

.name : string

缓冲区属性的名称。

.needsUpdate : number

Flag 来指示该属性已更改，应重新发送到 GPU。修改数组值时，将其设置为 true。

默认为 false.

.normalized : InterleavedBuffer

数据是否标准化，请参见BufferAttribute#normalized

.offset : number

缓冲区中的属性偏移量。
