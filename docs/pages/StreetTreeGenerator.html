StreetTreeGenerator

路边坑中的一棵年轻的行道树：从树干中升起的喇叭形树干 铸铁坑栅，分支成顶点抖动的叶丛的树冠。的 簇法线向共享的冠球体混合，因此簇阴影为一个 不规则的表冠而不是单独的球，并且该材料增加了内部 自阴影和斑驳的颜色，因此叶子看起来像叶团。建造一次 并在一系列展示位置中进行实例化，并使用一种廉价材料进行装饰 烘烤的 partId.

上的树枝__树冠几乎是旋转对称的，因此规范模型站在 y = 0，以 X / Z 为中心，稍微倾斜于 +Z 与另一个匹配 街道设施.

代码示例

const trees = new StreetTreeGenerator();
scene.add( trees.build( placements ) ); // placements: Matrix4[]

构造函数

new StreetTreeGenerator()
