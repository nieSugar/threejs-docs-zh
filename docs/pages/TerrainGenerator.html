TerrainGenerator

将程序山脉烘焙为单个网格，以 THREE.Group 返回。 域扭曲、导数阻尼噪声塑造了脊线；热侵蚀松弛 陡峭的斜坡。 TSL 材质根据海拔和坡度遮蔽草地、岩石和雪。

烘焙网格可通过 TerrainGenerator#sampleHeight 获得 在地形上放置森林或其他物体。

代码示例

const terrain = new TerrainGenerator( { seed: 1 } );
scene.add( terrain.build() );

构造函数

new TerrainGenerator()
