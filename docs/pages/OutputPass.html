OutputPass

此通道负责包括色调映射和色彩空间转换 进入你的通证链。在大多数情况下，此通道应包含在末尾 每个传递链。如果某个通道需要 sRGB 输入（例如 FXAA），则该通道 通道链中必须遵循 OutputPass。

从渲染器中提取色调映射和色彩空间设置。

代码示例

const outputPass = new OutputPass();
composer.addPass( outputPass );

导入

OutputPass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';

构造函数

new OutputPass()

构造一个新的输出通道。

属性

.isOutputPass : boolean (readonly)

此标志表明这是一个输出通道。

默认为true.

.material : RawShaderMaterial

通道材质.

.uniforms : Object

通道制服.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行输出通过.

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
