ImageBitmapLoader

用于将图像加载为 ImageBitmap 的加载器。 ImageBitmap 提供了一种异步且资源高效的途径来准备 用于渲染的纹理。

注意，图像位图会忽略Texture#flipY和Texture#premultiplyAlpha。 这些选项需要在加载之前通过 ImageBitmapLoader#setOptions 配置， 与可以在纹理上配置以在 GPU 上传时设置这些选项的常规图像不同。

为了匹配 Texture 的默认行为，需要以下选项：

{ imageOrientation: 'flipY', premultiplyAlpha: 'none' }

另请注意，与 FileLoader 不同，此加载程序只会避免对如果启用 Cache，则为相同的 URL。

const loader = new THREE.ImageBitmapLoader();
loader.setOptions( { imageOrientation: 'flipY' } ); // set options if needed
const imageBitmap = await loader.loadAsync( 'image.png' );
const texture = new THREE.Texture( imageBitmap );
texture.needsUpdate = true;

构造函数

new ImageBitmapLoader( manager : LoadingManager )

构造新的图像位图加载器。

manager

加载管理器。

属性

.isImageBitmapLoader : boolean (readonly)

该标志可用于类型测试。

默认为true.

.options : Object

表示加载器选项。

默认为{premultiplyAlpha:'none'}.

方法

.abort() : ImageBitmapLoader

中止正在进行的提取requests.

覆盖： Loader#abort
返回：对此实例的引用。

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的 URL 加载并将加载的图像位图传递给 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

此加载程序不支持。
onError

发生错误时执行。
覆盖： Loader#load

.setOptions( options : Object ) : ImageBitmapLoader

设置给定的加载器选项。对象的结构必须与 options 参数匹配 createImageBitmap.

注意：启用缓存后，缓存键仅基于 URL。加载相同的 URL 不同的选项将返回第一个请求的缓存结果。

options

要设置的加载器选项。
返回：对此图像位图加载器的引用。
