OctahedronGeometry

用于表示八面体的几何类。

代码示例

const geometry = new THREE.OctahedronGeometry();
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const octahedron = new THREE.Mesh( geometry, material );
scene.add( octahedron );

构造函数

new OctahedronGeometry( radius : number, detail : number )

构造一个新的八面体几何。

radius

八面体的半径八面体.

默认为1.
detail

将其设置为大于0的值会添加顶点，使其不再是八面体.

默认为0.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

覆盖： PolyhedronGeometry#parameters

静态方法

.fromJSON( data : Object ) : OctahedronGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
