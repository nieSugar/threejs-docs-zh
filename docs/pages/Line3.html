Line3

3D 空间中由起点和终点表示的分析线段。

构造函数

new Line3( start : Vector3, end : Vector3 )

构造一个新线段。

start

线的起点段.

默认为(0,0,0).
end

线段结束.

默认为(0,0,0).

属性

.end : Vector3

线段结束.

.start : Vector3

线的起点段.

方法

.applyMatrix4( matrix : Matrix4 ) : Line3

对此线应用4x4变换矩阵段.

matrix

变换矩阵。
返回：对此线段的引用。

.at( t : number, target : Vector3 ) : Vector3

返回线段上某个位置处的向量。

t

[0,1] 之间的值，表示沿线的位置段.
target

用于存储方法结果的目标向量.
返回： 增量向量。

.clone() : Line3

返回包含此实例中复制值的新线段。

返回：此克隆instance.

.closestPointToPoint( point : Vector3, clampToLine : boolean, target : Vector3 ) : Vector3

返回给定点的线上最近的点。

point

要计算直线上最近的点
clampToLine

是否将结果限制在[0,1]范围内。
target

用于存储方法结果的目标向量.
返回：直线上的最近点。

.closestPointToPointParameter( point : Vector3, clampToLine : boolean ) : number

返回基于投影的最近点的点参数线段。

point

要为其返回点参数的点。
clampToLine

是否将结果限制在[0,1]范围内。
返回： 点参数。

.copy( line : Line3 ) : Line3

将给定线段的值复制到此实例。

line

要返回的线段copy.
返回：对此线段的引用。

.delta( target : Vector3 ) : Vector3

返回线段起点和终点的增量向量。

target

用于存储方法结果的目标向量.
返回： 增量向量。

.distance() : number

返回线段起点和终点之间的欧几里德距离。

返回：欧几里德距离距离.

.distanceSq() : number

返回线段起点和终点之间的欧氏距离平方。

返回：欧氏距离平方.

.distanceSqToLine3( line : Line3, c1 : Vector3, c2 : Vector3 ) : number

返回该线段与给定点之间最接近的平方距离一.

line

计算最近平方距离的线段.
c1

此线段上的最近点.
c2

给定线段上的最近点.
返回：此线段与给定的线段.

.equals( line : Line3 ) : boolean

如果该线段与给定的线段相等，则返回true.

line

要测试相等的线段.
返回：该线段是否与给定的线段相等一.

.getCenter( target : Vector3 ) : Vector3

返回线段的中心。

target

用于存储方法结果的目标向量.
返回：中心点。

.set( start : Vector3, end : Vector3 ) : Line3

通过复制给定向量设置起始值和结束值。

start

开始点.
end

终点.
返回：对此线段的引用。
