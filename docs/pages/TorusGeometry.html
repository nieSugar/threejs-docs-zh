TorusGeometry

用于表示圆环的几何类。

代码示例

const geometry = new THREE.TorusGeometry( 10, 3, 16, 100 );
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const torus = new THREE.Mesh( geometry, material );
scene.add( torus );

构造函数

new TorusGeometry( radius : number, tube : number, radialSegments : number, tubularSegments : number, arc : number, thetaStart : number, thetaLength : number )

构造一个新的圆环几何。

radius

圆环的半径，从圆环的中心到圆环的中心tube.

默认为1.
tube

管的半径。必须小于radius.

默认为0.4.
radialSegments

径向段数.

默认为 12.
tubularSegments

管状段数.

默认为48.
arc

中心角（以弧度为单位）.

默认为 Math.PI*2.
thetaStart

管状扫描的起点（以弧度为单位）。

默认为0.
thetaLength

管状扫描的长度（以弧度为单位）.

默认为 Math.PI*2.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : TorusGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
