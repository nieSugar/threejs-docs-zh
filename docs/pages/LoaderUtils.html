LoaderUtils

具有加载器实用函数的类。

构造函数

new LoaderUtils()

静态方法

.extractUrlBase( url : string ) : string

从给定 URL 中提取基本 URL。

url

要提取基本 URL 的 URL from.
返回： 提取的基本 URL。

.resolveURL( url : string, path : string ) : string

根据给定路径解析相对 URL。绝对路径、数据 URL、 并且 blob URL 将按原样返回。无效的 URL 将返回空 string.

url

要解析的 URL.
path

要解析的相对 URL 的基本路径.
返回： 解析的 URL.
