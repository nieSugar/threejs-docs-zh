BufferNode

一种特殊类型的统一节点，表示类似数组的数据 作为统一缓冲区。访问通常通过 element() 进行 它返回 ArrayElementNode 的实例。例如：

一般情况下，建议使用更托管的UniformArrayNode 因为它处理更多的输入类型并自动关心缓冲区填充。

代码示例

const bufferNode = buffer( array, 'mat4', count );
const matrixNode = bufferNode.element( index ); // access a matrix from the buffer

构造函数

new BufferNode( value : Array.<number>, bufferType : string, bufferCount : number )

构造一个新的缓冲区节点。

value

类数组缓冲区数据。
bufferType

缓冲区的数据类型。
bufferCount

缓冲区的计数elements.

默认为0.

属性

.bufferCount : number

保存引用节点值的统一节点。

默认为0.

.bufferType : string

缓冲区的数据类型。

.isBufferNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.updateRanges : Array.<{start: number, count: number}>

更新范围数组。

方法

.addUpdateRange( start : number, count : number )

在数据数组中添加要在 GPU 上更新的数据范围。

start

开始更新的位置。
count

要更新的组件数量update.

.clearUpdateRanges()

清除更新范围。

.getElementType( builder : NodeBuilder ) : string

缓冲区元素的数据类型。

builder

当前节点构建器.
覆盖： UniformNode#getElementType
返回：元素类型。

.getInputType( builder : NodeBuilder ) : string

覆盖默认实现以返回固定值'buffer'.

builder

当前节点构建器.
覆盖： UniformNode#getInputType
返回： 输入类型.
