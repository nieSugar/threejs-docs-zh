EventDispatcher → Controls →

FirstPersonControls

此类是 FlyControls.

导入

FirstPersonControls 的替代实现，是一个插件，必须显式导入，请参阅Installation#Addons.

import { FirstPersonControls } from 'three/addons/controls/FirstPersonControls.js';

构造函数

new FirstPersonControls( object : Object3D, domElement : HTMLElement )

构造一个新的控件实例。

object

控件管理的对象。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.autoForward : boolean

相机是否自动向前移动

默认为 false.

.constrainVertical : boolean

是否环顾四周受到垂直方向的约束verticalMin 和 verticalMax.

默认为 false.

.dampingFactor : number

运动和观看速度赶上输入的速度有多快。较低 值感觉更重（惯性更大），1 禁用阻尼。

默认为0.1.

.heightCoef : number

确定当 y 分量接近 heightMax 时相机移动的速度有多快__.

默认为1.

.heightMax : number

用于移动速度的相机高度上限

默认为1.

.heightMin : number

用于移动速度调整的相机高度下限。

默认为0.

.heightSpeed : boolean

相机高度是否影响向前移动速度。 使用属性 heightCoef、heightMin 和 heightMax 进行配置。

默认为 false.

.lookSpeed : number

环视速度。

默认为0.005.

.lookVertical : boolean

是否可以垂直环视.

默认为true.

.mouseDragOn : boolean (readonly)

鼠标是否按下.

默认为 false.

.movementSpeed : number

移动速度.

默认为1.

.verticalMax : number

垂直可以多远环顾四周，上限。范围为 0 到 Math.PI（以弧度为单位）。

默认为0.

.verticalMin : number

您可以垂直环顾四周的距离，下限。范围为 0 到 Math.PI（以弧度为单位）。

默认为0.

方法

.handleResize()

.lookAt( x : number | Vector3, y : number, z : number ) : FirstPersonControls

向定义的目标位置旋转相机。

x

目标位置的 x 坐标或表示目标的向量位置.
y

目标位置的y坐标.
z

目标位置的z坐标.
返回：对此控件的引用.
