SkyscraperGenerator

生成复杂的三方“美术风格/新哥特式”赤土陶器 来自一小组参数的摩天大楼。

质量被读取为足迹多边形（带有一个倒角的矩形） 角）分为垂直面，每个面分为三层——一个高 拱形底座、重复轴和华丽的皇冠——然后进入地板和 海湾。一些创作作品（码头、窗户、檐口轮廓、 哥特式拱门）在整个塔上实例化，然后与 定制的基础拱廊 - 进入单个非索引 BufferGeometry 标记 每个顶点 partId (PartId)，因此一种材质可以对每个区域进行着色。

生成器与材质无关 - 它只生成几何体。通过单 材质（例如在 partId 上分支的 TSL 节点材质）来装饰它。

代码示例

const generator = new SkyscraperGenerator( { seed: 35, totalHeight: 140 }, material );
scene.add( generator.build() ); // a single Mesh

构造函数

new SkyscraperGenerator()
