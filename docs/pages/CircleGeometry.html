CircleGeometry

欧几里德几何的简单形状。它是由一个 围绕中心点定向的三角形线段的数量和 延伸至给定半径。它是从逆时针方向建造的 起始角和给定的圆心角。它也可以用来创建 正多边形，其中线段的数量决定了 边.

代码示例

const geometry = new THREE.CircleGeometry( 5, 32 );
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const circle = new THREE.Mesh( geometry, material );
scene.add( circle )

构造函数

new CircleGeometry( radius : number, segments : number, thetaStart : number, thetaLength : number )

构造一个新的圆形几何图形。

radius

圆的半径.

默认为1.
segments

线段数（三角形），最小值 = 3.

默认为32.
thetaStart

第一段的起始角度（以弧度为单位）。

默认为0.
thetaLength

圆心角，通常称为 theta， 以弧度表示的圆形扇区。默认值会形成一个完整的圆。

默认为 Math.PI*2.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : CircleGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
