Info

这个渲染器模块提供了一系列统计信息 关于 GPU 内存和渲染过程。对于调试很有用 和监控。

构造函数

new Info()

构造一个新的信息组件。

属性

.autoReset : boolean

框架相关指标是否应该自动 是否重置。该属性应设置为 false 通过管理自己的动画循环的应用程序。他们必须 然后每帧手动调用一次renderer.info.reset()。

默认为true.

.calls : number (readonly)

自 应用已启动.

默认为0.

.compute : Object (readonly)

计算相关指标.

calls
number

自应用启动以来的计算调用次数.
frameCalls
number

当前帧的计算调用次数.
timestamp
number

使用时帧的时间戳renderer.computeAsync().

.frame : number (readonly)

当前帧ID。该ID已被管理 by NodeFrame.

默认为0.

.memory : Object (readonly)

内存相关指标.

attributes
number

活动属性的数量.
attributesSize
number

活动属性的内存大小（以字节为单位）.
geometries
number

活动属性的数量geometries.
indexAttributes
number

活动索引属性的数量。
indexAttributesSize
number

活动索引属性的内存大小（以字节为单位）。
indirectStorageAttributes
number

活动间接存储属性的数量。
indirectStorageAttributesSize
number

活动间接存储属性的内存大小（以字节为单位）。字节.
programs
number

活动程序的数量.
programsSize
number

活动程序的内存大小（以字节为单位）.
readbackBuffers
number

活动读回缓冲区的数量.
readbackBuffersSize
number

活动读回缓冲区的内存大小（以字节为单位） bytes.
renderTargets
number

活动渲染目标的数量.
storageAttributes
number

活动存储属性的数量.
storageAttributesSize
number

活动存储属性的内存大小（以字节为单位）.
textures
number

活动存储属性的数量纹理.
texturesSize
number

活动纹理的内存大小（以字节为单位）。
uniformBuffers
number

活动统一缓冲区的数量。
uniformBuffersSize
number

活动统一缓冲区的内存大小（以字节为单位）。
total
number

总内存大小（以字节为单位）。 bytes.

.render : Object (readonly)

渲染相关指标。

calls
number

自应用程序启动以来的渲染调用次数。
frameCalls
number

当前帧的渲染调用次数。
drawCalls
number

当前帧的绘制调用次数帧.
triangles
number

当前帧渲染的三角形图元数量.
points
number

当前帧渲染的点图元数量.
lines
number

当前帧渲染的线图元数量.
timestamp
number

当前帧的时间戳帧.

方法

.createAttribute( attribute : BufferAttribute )

显式跟踪常规属性内存.

attribute

要跟踪的属性.

.createIndexAttribute( attribute : BufferAttribute )

显式跟踪索引属性内存.

attribute

要跟踪的索引属性track.

.createIndirectStorageAttribute( attribute : BufferAttribute )

显式跟踪间接存储属性内存。

attribute

要跟踪的间接存储属性。

.createProgram( program : ProgrammableStage )

显式跟踪程序内存，更新计数和字节跟踪。

program

要跟踪的程序track.

显式跟踪读回缓冲区内存。

readbackBuffer

.createStorageAttribute( attribute : BufferAttribute )

texture

uniformBuffer

.destroyAttribute( attribute : BufferAttribute )

attribute

.destroyProgram( program : Object )

显式跟踪程序内存，更新计数和字节跟踪。

program

.destroyReadbackBuffer( readbackBuffer : ReadbackBuffer )

显式跟踪读回缓冲区内存。

readbackBuffer

.destroyTexture( texture : Texture )

显式跟踪纹理内存，更新计数和字节跟踪。

texture

.destroyUniformBuffer( uniformBuffer : UniformBuffer )

显式跟踪统一缓冲区内存。

uniformBuffer

要跟踪的统一缓冲区。

.dispose()

执行对象的完全重置。

.reset()

重置与帧相关的指标。

.update( object : Object3D, count : number, instanceCount : number )

应在每次绘制调用时执行此方法并更新相应的指标。

object

将要跟踪的 3D 对象渲染.
count

顶点或索引计数.
instanceCount

实例计数。
