XRHandMeshModel

表示 XRHandModelFactory 可能产生的手部模型类型之一 取决于所选的配置文件。 XRHandMeshModel 代表一只手 自定义资源。

导入

XRHandMeshModel 是一个插件，必须显式导入，请参阅Installation#Addons.

import { XRHandMeshModel } from 'three/addons/webxr/XRHandMeshModel.js';

构造函数

new XRHandMeshModel( handModel : XRHandModel, controller : Group, path : string, handedness : XRHandedness, loader : Loader, onLoad : function, customCache : Object )

构造一个新的 XR 手网格模型.

handModel

手部模型.
controller

WebXR控制器.
path

模型路径.
handedness

XR输入源的惯用手。
loader

加载器。如果未提供，则将使用 GLTFLoader 的实例来加载模型。

默认为null.
onLoad

加载控制器模型时执行的回调。

默认为null.
customCache

一个可选的共享缓存对象，用于跨实例存储和重用加载的资源。

默认为null.

属性

.bones : Array.<Bone>

代表骨骼的骨骼数组 手部骨骼的轮廓。

.controller : Group

WebXR控制器.

.handModel : XRHandModel

手部模型.

方法

.updateMesh()

根据跟踪的 XR 关节数据更新网格。
