OutlinePass

用于渲染选定对象周围轮廓的通道。

代码示例

const resolution = new THREE.Vector2( window.innerWidth, window.innerHeight );
const outlinePass = new OutlinePass( resolution, scene, camera );
composer.addPass( outlinePass );

导入

OutlinePass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OutlinePass } from 'three/addons/postprocessing/OutlinePass.js';

构造函数

new OutlinePass( resolution : Vector2, scene : Scene, camera : Camera, selectedObjects : Array.<Object3D> )

构造一个新的轮廓通道。

resolution

效果的分辨率。
scene

要渲染的场景.
camera

相机.
selectedObjects

应接收轮廓的选定 3D 对象。

属性

.downSampleRatio : number

下采样率。效果可以在很多 分辨率低于美颜通道。

默认为2.

.edgeGlow : number

可用于动画发光/脉冲效果。

默认为0.

.edgeStrength : number

边缘强度。

默认为3.

.edgeThickness : number

边缘厚度。

默认为1.

.hiddenEdgeColor : Color

隐藏边缘颜色。

默认为(0.1,0.04,0.02).

.patternTexture : Texture

可用于突出显示选定的 3D 对象。需要设置 OutlinePass#usePatternTexture至true.

默认为null.

.pulsePeriod : number

脉冲周期.

默认为0.

.renderCamera : Object

相机.

.renderScene : Object

要渲染的场景.

.resolution : Vector2

效果的分辨率。

默认为(256,256).

.selectedObjects : Array.<Object3D>

应接收轮廓的选定 3D 对象。

.usePatternTexture : boolean

是否使用用于突出显示所选内容的图案纹理 是否为 3D 对象。

默认为 false.

.visibleEdgeColor : Color

可见边缘颜色。

默认为(1,1,1).

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行轮廓通道。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize
