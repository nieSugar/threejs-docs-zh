Vector2

表示 2D 矢量的类。二维向量是一对有序的数字 （标记为x和y），可以用来表示很多东西，比如：

  • 二维空间中的一个点（即平面上的一个位置）。
  • 在平面上的一个方向和长度。在 three.js 中，长度将始终是从 (0, 0) 到 (x, y) 的欧几里得距离（直线距离），方向也从 (0, 0) 指向 (x, y) 测量。
  • 任意有序数对。

2D向量还可以用来表示其他东西，比如 动量向量、复数等等，但这些是最常见的 Three.js 中的常见用途.

迭代向量实例将产生其组件 (x, y) 相应的顺序.

代码示例

const a = new THREE.Vector2( 0, 1 );
//no arguments; will be initialised to (0, 0)
const b = new THREE.Vector2( );
const d = a.distanceTo( b );
