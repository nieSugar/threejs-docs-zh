XREstimatedLight

该类可以用来表示环境光 XR 会话。它依赖于 WebXR 光照估计 API。

导入

XREstimatedLight 是一个插件，必须显式导入，请参阅 安装#Addons.

import { XREstimatedLight } from 'three/addons/webxr/XREstimatedLight.js';

构造函数

new XREstimatedLight( renderer : WebGLRenderer, environmentEstimation : boolean )

构造一个新的灯光.

renderer

渲染器.
environmentEstimation

是否使用环境估计.

默认为true.

Classes

XREstimatedLight

属性

.directionalLight : DirectionalLight

代表来自XR的主光环境.

.environment : Texture

如果环境估计为，则将设置为 SessionLightProbe 中的立方体贴图 可用且已请求。

默认为null.

.lightProbe : LightProbe

表示估计光的光探头。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Group#dispose
