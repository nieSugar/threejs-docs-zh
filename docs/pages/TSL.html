.instanceIndex : IndexNode (constant)

TSL 对象，根据着色器阶段上下文表示特定索引数据。

在顶点和片段阶段内，instanceIndex 将表示着色器正在评估的当前网格实例的索引。 在这些阶段中，使用 instanceIndex 根据实例修改网格或选择每个实例的数据。

// instanceIndex will equal the current mesh's instance index between 0-500
const material = new THREE.BasicNodeMaterial();
material.positionNode = vec3( instanceIndex.mod( 10 ), instanceIndex.div( 10 ), 0 );
const mesh = new THREE.InstancedMesh( geometry, material, 500 );

在计算阶段中，instanceIndex 将表示 3 维计算工作组负载中计算调用的全局索引。 在此阶段，使用 instanceIndex 修改或选择缓冲区内给定索引处的数据，或从索引本身派生值。

// instanceIndex will equal value between 0 - 255
const computeFn = Fn() => {
	storageBuffer.element( instanceIndex ).assign( instanceIndex );
} )().compute( 255 )

.lobeNormalWeight (constant)

自适应波瓣正常边缘停止权重

完全在余弦空间中评估：使用 angle² ≈ 2(1 − cosθ)，原始值 exp( −SCALE·angle/halfAngle ) 变为高斯 exp( falloff·(cosθ − 1) )，因此 单个 exp 取代了每次点击 acos。与原件的半角匹配 窄波瓣，对于宽（扩散）波瓣稍微更宽松。

适用于任何重投影（表面速度或视差命中点），因为它区分了 最终历史 UV，因此相同的因子适用于漫反射和镜面反射路径。
