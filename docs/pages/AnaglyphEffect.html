AnaglyphEffect

使用物理正确创建浮雕效果的类 离轴立体投影.

此实现使用CameraUtils.frameCorners()来对齐立体 相机视锥体到虚拟屏幕平面，提供准确的深度 平面距离处零视差的感知。

注意，此类只能与 WebGLRenderer 一起使用。 使用 WebGPURenderer 时，请使用 AnaglyphPassNode.

导入

AnaglyphEffect 是一个插件，必须显式导入，请参阅 安装#Addons.

import { AnaglyphEffect } from 'three/addons/effects/AnaglyphEffect.js';

构造函数

new AnaglyphEffect( renderer : WebGLRenderer, width : number, height : number )

构造新的浮雕效果。

renderer

渲染器.
width

物理像素中效果的宽度。

默认为512.
height

以物理像素为单位的效果高度。

默认为512.

属性

.eyeSep : number

以世界单位表示的瞳距（眼睛间距）。 典型的人类 IPD 为 0.064 米（64 毫米）。

默认值为 0.064.

.planeDistance : number

从观看者到虚拟世界的距离（以世界单位表示） 出现零视差（屏幕深度）的屏幕平面。 此距离处的物体出现在屏幕表面。 较近的物体出现在屏幕前面（负视差）。 物体进一步出现在屏幕后面（正视差）。

屏幕尺寸源自相机的视场角和宽高比 在这个距离，确保立体视图与相机的视野相匹配。

默认为0.5.

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

.render( scene : Object3D, camera : Camera )

当使用此效果时，应调用此方法而不是 默认 WebGLRenderer#render.

scene

要渲染的场景.
camera

相机.

.setSize( width : number, height : number )

调整效果大小.

width

逻辑中效果的宽度像素.
height

逻辑像素中效果的高度.
