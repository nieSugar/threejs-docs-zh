Sculptor

使用自适应拓扑雕刻三角形网格。

用包含位置、法线的焊接几何体替换 mesh.geometry 和指数。源几何体未更改且未处理。

网格必须使用一种材质和非零统一世界比例，且不 剪切。不支持蒙皮、实例化和批处理网格。

Sculptor 管理边界、绘制范围和备用缓冲区容量。几何和 属性可能会随着容量的变化而被替换；不要缓存它们。使用 Sculptor#getGeometry 用于导出或几何处理的紧凑副本。

代码示例

const sculptor = new Sculptor( mesh, camera )
	.setTool( 'inflate' )
	.setSize( 75 )
	.setStrength( 0.3 );
sculptor.connect( renderer.domElement );

导入

Sculptor 是一个插件，必须显式导入，请参阅 安装#Addons.

import { Sculptor } from 'three/addons/misc/Sculptor.js';

构造函数

new Sculptor( mesh : Mesh, camera : Camera )

mesh

要雕刻的网格体.
camera

用于指针拾取的相机.

属性

.camera : Camera

用于指针拾取的相机.

.domElement : HTMLElement

接收指针事件的元素，或null已断开.

默认为null.

.enabled : boolean

是否启用指针输入。不影响编程笔划。

默认为true.

.mesh : Mesh (readonly)

正在雕刻的网格。

方法

.beginStroke() : Sculptor

开始笔划并触发start。中风发生时什么也不做。 通过指针输入或第一个成功的光线标记自动调用。

返回：对此雕刻家的引用。

.connect( element : HTMLElement )

将指针输入连接到 DOM 元素。

element

接收指针事件的元素。

.disconnect()

断开指针输入并完成活动笔画。

.dispose()

断开雕刻器。网格及其几何体未处理。

.endStroke() : Sculptor

释放指针捕获，平衡八叉树并更新精确边界， 然后触发 end。闲置时什么都不做。当出现以下情况时自动调用 指针行程结束或取消。

返回：对此雕刻家的引用。

.getDetail() : number

返回自适应拓扑详细信息。 0 冻结拓扑。

返回： 详细级别。

.getGeometry() : BufferGeometry

返回活动顶点和三角形的独立副本，不带 闲置产能。适用于导出或几何处理。调用者拥有它。

返回：包含活动顶点和三角形的新几何图形。

.getHitNormal( target : Vector3 ) : Vector3

将当前局部空间单位表面法线复制到目标向量中。 没有命中时返回零向量。

target

接收表面法线的向量。
返回：目标向量.

.getHitPoint( target : Vector3 ) : Vector3

将当前局部空间命中位置复制到目标向量中。 没有命中时返回零向量。

target

接收命中位置的向量。
返回：目标向量.

.getNegative() : boolean

返回活动工具是否应用其反向效果。

返回：工具方向是否为反转。

.getSize() : number

返回以 CSS 像素为单位的指针笔刷半径。

返回： 笔刷半径。

.getStrength() : number

返回活动工具的强度。

返回：工具强度。

.getTool() : 'clay' | 'brush' | 'inflate' | 'smooth' | 'flatten' | 'pinch' | 'crease' | 'drag' | 'scale'

返回活动雕刻工具。

返回： 工具名称。

.getWorldRadius() : number

返回以世界单位表示的笔刷半径，或 0 不带hit.

返回： 以世界单位表示的笔刷半径。

.hasHit() : boolean

返回最新的拾取或描边射线是否击中网格。

返回：最新的射线是否击中网格。网格.

.isSculpting() : boolean

返回指针或编程笔划是否处于活动状态。

返回：笔划是否处于活动状态。

.pickFromPointer( clientX : number, clientY : number ) : boolean

从客户端坐标更新当前点击而不进行雕刻。

clientX

水平客户端坐标以 CSS 像素为单位。
clientY

以 CSS 像素为单位的垂直客户端坐标。
返回： 指针射线是否击中网格。

.pickFromRay( ray : Ray, worldRadius : number ) : boolean

从世界空间射线更新当前击中而不进行雕刻。

ray

The世界空间射线，方向非零。
worldRadius

以世界单位表示的笔刷半径。
返回：射线是否击中网格。

.setDetail( value : number ) : Sculptor

设置自适应拓扑细节。值越高，边缘越短 相对于刷子半径； 0 冻结拓扑。重新划分长裂痕 边缘和塌陷短边，甚至可以在零强度下改变表面。

value

0 到 1 之间的值。
返回：对此雕刻家的引用。

.setNegative( value : boolean ) : Sculptor

设置活动工具是否应用其反向效果。

value

工具方向是否为反转。
返回：对此雕刻家的引用。

.setSize( value : number ) : Sculptor

以 CSS 像素为单位设置指针画笔半径。

value

5 到 500 之间的值。
返回：对此雕刻家的引用。

.setStrength( value : number ) : Sculptor

设置活动工具的强度。 0 的值会禁用变形，但不会禁用自适应重新网格化。 拖动和缩放使用指针移动而不是此设置。

value

0 到 1 之间的值。
返回：对此雕刻家的引用。

.setTool( value : 'clay' | 'brush' | 'inflate' | 'smooth' | 'flatten' | 'pinch' | 'crease' | 'drag' | 'scale' ) : Sculptor

选择工具并恢复其大小、强度和负设置。

value

工具名称。
返回：对此雕刻家的引用。

.strokeFromRay( ray : Ray, worldRadius : number ) : boolean

应用光线图章，在击中时开始描边。致电 Sculptor#endStroke 在最后一个标记之后。

返回 false，而不在指针敲击期间更新命中。 拖动和缩放需要指针输入。

ray

The世界空间射线，方向非零。
worldRadius

以世界单位表示的笔刷半径。
返回：射线是否击中网格。

Events

.change

在更新雕刻几何体后触发。

Type:
  • Object

.end

在活动笔划完成且精确边界更新后触发。

Type:
  • Object

.start

在指针或编程笔划开始时触发。

Type:
  • Object
