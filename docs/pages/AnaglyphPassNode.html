AnaglyphPassNode

使用物理正确创建浮雕效果的渲染通道节点 离轴立体投影。

此实现使用CameraUtils.frameCorners()来对齐立体 相机视锥体到虚拟屏幕平面，提供准确的深度 平面距离处零视差的感知。

导入

AnaglyphPassNode 是一个插件，必须显式导入，请参阅Installation#Addons.

import { anaglyphPass, AnaglyphAlgorithm, AnaglyphColorMode } from 'three/addons/tsl/display/AnaglyphPassNode.js';

构造函数

new AnaglyphPassNode( scene : Scene, camera : Camera )

构造一个新的浮雕传递节点。

scene

要渲染的场景.
camera

用于渲染场景的相机。

属性

.algorithm : string

获取当前浮雕算法。

.algorithm : string

设置浮雕算法。

.colorMode : string

获取当前颜色mode.

.colorMode : string

设置颜色模式。

.eyeSep : number

以世界单位表示的瞳距（眼睛间距）。 典型的人类 IPD 为 0.064 米（64 毫米）。

默认值为 0.064.

.isAnaglyphPassNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.planeDistance : number

从观看者到虚拟世界的距离（以世界单位表示） 出现零视差（屏幕深度）的屏幕平面。 此距离处的物体出现在屏幕表面。 较近的物体出现在屏幕前面（负视差）。 物体进一步出现在屏幕后面（正视差）。

屏幕尺寸源自相机的视场角和宽高比 在这个距离，确保立体视图与相机的视野相匹配。

默认为0.5.

方法

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： StereoCompositePassNode#setup

.updateStereoCamera( coordinateSystem : number )

使用frameCorners更新内部立体相机 物理正确的离轴投影。

coordinateSystem

当前坐标系。
覆盖： StereoCompositePassNode#updateStereoCamera
