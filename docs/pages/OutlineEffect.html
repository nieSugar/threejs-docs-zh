OutlineEffect

卡通着色器的轮廓效果。

请注意，此类只能与 WebGLRenderer 一起使用。 使用 WebGPURenderer 时，请使用 ToonOutlinePassNode.

代码示例

const effect = new OutlineEffect( renderer );
function render() {
	effect.render( scene, camera );
}

导入

OutlineEffect 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OutlineEffect } from 'three/addons/effects/OutlineEffect.js';

构造函数

new OutlineEffect( renderer : WebGLRenderer, parameters : OutlineEffect~Options )

构造新的轮廓效果。

renderer

渲染器.
parameters

配置参数.

方法

.render( scene : Object3D, camera : Camera )

当使用此效果时，应调用此方法而不是 默认 WebGLRenderer#render.

scene

要渲染的场景.
camera

相机.

.renderOutline( scene : Object3D, camera : Camera )

该方法可用于在VR中渲染轮廓。

const effect = new OutlineEffect( renderer );
let renderingOutline = false;
scene.onAfterRender = function () {
	if ( renderingOutline ) return;
	renderingOutline = true;
	effect.renderOutline( scene, camera );
	renderingOutline = false;
};
function render() {
	renderer.render( scene, camera );
}
scene

要渲染的场景.
camera

相机.

.setSize( width : number, height : number )

调整效果大小.

width

逻辑中效果的宽度像素.
height

逻辑像素中效果的高度.

类型定义

.Options

该类型代表配置设置OutlineEffect.

defaultThickness
number

轮廓粗细.

默认为0.003.
defaultColor
Array.<number>

轮廓颜色.

默认为[0,0,0].
defaultAlpha
number

轮廓alpha值.

默认为1.
defaultKeepAlive
boolean

是否保持缓存内部材质.

默认为 false.
