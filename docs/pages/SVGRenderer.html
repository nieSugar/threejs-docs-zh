SVGRenderer

此渲染器可用于使用 SVG 渲染几何数据。产生的向量 图形在以下用例中特别有用：

  • 动画徽标或图标。
  • 交互式二维/三维图表。
  • 交互式地图。
  • 复杂或动画用户界面。

SVGRenderer 具有各种优点。它产生晶莹剔透、锐利的输出， 与实际视口分辨率无关。SVG 元素可以通过 CSS 设置样式。 而且它们具有良好的可访问性，因为可以添加标题或描述等元数据 （对搜索引擎或屏幕阅读器有用）.

然而，有一些重要的限制：

  • 没有高级着色。
  • 不支持纹理。
  • 不支持阴影。

导入

SVGRenderer 是一个插件，必须显式导入，请参阅 安装#Addons.

import { SVGRenderer } from 'three/addons/renderers/SVGRenderer.js';

构造函数

new SVGRenderer()

构造一个新的SVG渲染器。

属性

.autoClear : boolean

是否在渲染调用之前自动执行清除。

默认为true.

.domElement : SVGSVGElement

渲染器附加其属性的 DOM child-elements.

.info : Object

提供有关数量的信息 渲染的顶点和面。

.outputColorSpace : SRGBColorSpace | LinearSRGBColorSpace

输出色彩空间。

默认为SRGBColorSpace.

.overdraw : number

放大多边形的分数像素数，以便 防止抗锯齿间隙。范围为[0,1].

默认为0.5.

.sortElements : boolean

是否对元素进行排序.

默认为true.

.sortObjects : boolean

是否对3D对象进行排序.

默认为true.

方法

.clear()

使用定义的清除执行手动清除颜色.

.getSize() : Object

返回包含渲染器宽度和高度的对象。

返回：渲染器的大小。

.render( scene : Object3D, camera : Camera )

渲染给定场景使用给定的相机。

scene

场景或任何其他类型的 3D 对象。
camera

相机.

.setClearColor( color : number | Color | string )

设置清除颜色.

color

要设置的清除颜色.

.setPrecision( precision : number )

设置用于创建路径的数据的精度.

precision

要设置的精度set.

.setQuality( quality : 'low' | 'high' )

设置渲染质量。设置为 high 可使浏览器提高 SVG 质量 渲染速度和几何精度.

quality

质量.

.setSize( width : number, height : number )

将渲染器的大小调整为给定的宽度和高度。

width

渲染器的宽度。
height

渲染器的高度renderer.
