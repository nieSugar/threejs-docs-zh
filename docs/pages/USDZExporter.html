USDZExporter

USDZ 的导出器。

代码示例

const exporter = new USDZExporter();
const arraybuffer = await exporter.parseAsync( scene );

导入

USDZExporter 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { USDZExporter } from 'three/addons/exporters/USDZExporter.js';

构造函数

new USDZExporter()

构造一个新的 USDZ 导出器。

属性

.textureUtils : WebGLTextureUtils | WebGPUTextureUtils

对纹理实用程序模块的引用。

默认为null.

方法

.parse( scene : Object3D, onDone : USDZExporter~OnDone, onError : USDZExporter~OnError, options : USDZExporter~Options )

解析给定的 3D 对象并生成 USDZ输出.

scene

要导出的 3D 对象。
onDone

导出完成时执行的回调函数。
onError

发生错误时执行的回调函数。
options

导出选项.

.parseAsync( scene : Object3D, options : USDZExporter~Options ) : Promise.<ArrayBuffer> (async)

异步版本USDZExporter#parse.

scene

要导出的 3D 对象。
options

导出选项.
返回：使用导出的USDZ数据解析的Promise.

.setTextureUtils( utils : WebGLTextureUtils | WebGPUTextureUtils )

为此导出器设置纹理实用程序。仅在必须导出压缩纹理时相关。

根据您是否使用 WebGLRenderer 或 WebGPURenderer，您必须注入 对应的纹理utils module:WebGLTextureUtils或module:WebGPUTextureUtils.

utils

纹理utils.

类型定义

.OnDone( result : ArrayBuffer )

onDone回调USDZExporter.

result

生成的USDZ.

.OnError( error : Error )

USDZExporter.

error

错误对象.

.Options

的导出选项的onError回调USDZExporter.

maxTextureSize
number

要导出的最大纹理大小。

默认为1024.
includeAnchoringProperties
boolean

是否包含锚定属性。

默认为true.
onlyVisible
boolean

仅导出可见的3D对象。

默认为true.
ar
Object

如果includeAnchoringProperties设置为true，锚定类型和对齐方式 可以通过ar.anchoring.type和ar.planeAnchoring.alignment配置.
quickLookCompatible
boolean

是否使导出的USDZ兼容QuickLook 这意味着资源已被修改以适应错误 FB10036297 和 FB11442287（Apple 反馈）。

默认为 false.
animations
Array.<AnimationClip>

动画剪辑将烘焙到 xformOp 时间样本中 目标对象。仅导出 position、quaternion 和 scale 轨道。

默认为[].
animationFrameRate
number

写入动画样本时每秒使用的时间代码。

默认为60.
