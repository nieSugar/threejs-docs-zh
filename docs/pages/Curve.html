Curve

用于创建包含方法的分析曲线对象的抽象基类 用于插值。

构造函数

new Curve() (abstract)

构造一条新曲线。

属性

.arcLengthDivisions : number

该值确定计算时的划分数量 通过 Curve#getLengths 计算曲线的累积线段长度。为确保 使用 Curve#getSpacedPoints 等方法时的精度，它是 如果曲线很大，建议增加该属性的值。

默认为200.

.needsUpdate : boolean

如果曲线参数发生变化，必须设置为true。

默认为 false.

.type : string (readonly)

type属性用于检测对象类型 在序列化/反序列化的上下文中。

方法

.clone() : Curve

返回一条带有从此实例复制的值的新曲线。

返回：此克隆instance.

.computeFrenetFrames( segments : number, closed : boolean ) : Object

生成 Frenet 帧。需要 3D 空间中的曲线定义。二手 在 TubeGeometry 或 ExtrudeGeometry 等几何图形中。

segments

段数。
closed

曲线是否闭合.

默认为 false.
返回： Frenet 框架。

.copy( source : Curve ) : Curve

复制值到此实例的给定曲线。

source

要复制的曲线。
返回：对此曲线的引用。

.fromJSON( json : Object ) : Curve

从给定的 JSON 反序列化曲线。

json

保存序列化的 JSON曲线.
返回：对此曲线的引用。

.getLength() : number

返回曲线的总弧长。

返回：曲线的长度。

.getLengths( divisions : number ) : Array.<number>

返回曲线累积线段长度的数组。

divisions

默认为 this.arcLengthDivisions.
返回： 保存累积段长度的数组。

.getPoint( t : number, optionalTarget : Vector2 | Vector3 ) : Vector2 | Vector3 (abstract)

此方法返回 2D 或 3D 空间中的向量（取决于曲线定义） 对于给定的插值因子。

t

表示曲线上位置的插值因子。必须在 [0,1] 范围内。
optionalTarget

结果写入的可选目标向量。
返回：曲线上的位置。它可以是 2D 或 3D 向量，具体取决于曲线定义。

.getPointAt( u : number, optionalTarget : Vector2 | Vector3 ) : Vector2 | Vector3

此方法返回 2D 或 3D 空间中的向量（取决于曲线定义） 对于给定的插值因子。与 Curve#getPoint 不同，此方法遵循长度 等距采样的曲线。

u

表示曲线上位置的插值因子。必须在 [0,1] 范围内。
optionalTarget

结果写入的可选目标向量。
返回：曲线上的位置。它可以是 2D 或 3D 向量，具体取决于曲线定义。

.getPoints( divisions : number ) : Array.<(Vector2|Vector3)>

此方法通过 Curve#getPoint 对曲线进行采样，并返回表示的点数组 曲线形状。

divisions

默认为5.
返回： 保存采样曲线值的数组。点数为 divisions + 1.

.getSpacedPoints( divisions : number ) : Array.<(Vector2|Vector3)>

此方法通过 Curve#getPointAt 对曲线进行采样，并返回表示 曲线形状。与 Curve#getPoints 不同，此方法返回整个区域的等距点 曲线。

divisions

默认为5.
返回： 保存采样曲线值的数组。点数为 divisions + 1.

.getTangent( t : number, optionalTarget : Vector2 | Vector3 ) : Vector2 | Vector3

返回给定插值因子的单位向量正切。 如果导出的曲线没有实现其切线求导， 相距小增量的两个点将用于找到其梯度 这似乎给出了一个合理的近似值。

t

插值因子。
optionalTarget

结果写入的可选目标向量。
返回：切线向量。

.getTangentAt( u : number, optionalTarget : Vector2 | Vector3 ) : Vector2 | Vector3

与Curve#getTangent相同，但等距Samples.

u

插值因子。
optionalTarget

结果写入的可选目标向量。
参见：
  • Curve#getPointAt
返回：切线向量。

.getUtoTmapping( u : number, distance : number ) : number

给定范围 [0,1] 内的插值因子，此方法返回更新后的值 相同范围内的插值因子，可用于等距点采样 来自曲线。

u

插值因子。
distance

曲线上的可选距离。

默认为null.
返回：更新的插值因子。

.toJSON() : Object

将曲线序列化为 JSON。

参见：
  • ObjectLoader#parse
返回： A JSON表示序列化曲线的对象。

.updateArcLengths()

更新累积段距离缓存。该方法必须被调用 每次更改曲线参数时。如果更新的曲线是 类似 CurvePath 的组合曲线，必须在 也是组合曲线.
