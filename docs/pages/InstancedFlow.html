InstancedFlow

Flow 的实例化版本，用于使网格围绕曲线弯曲，其中实例放置在曲线上。

此模块只能与WebGLRenderer一起使用。

导入

InstancedFlow是一个插件，必须显式导入，请参阅Installation#Addons。

import { InstancedFlow } from 'three/addons/modifiers/CurveModifier.js';

构造函数

new InstancedFlow( count : number, curveCount : number, geometry : Geometry, material : Material )

构造一个新的InstancedFlow实例。

count

实例的数量元素.
curveCount

要预分配的曲线数.
geometry

用于实例化网格的几何体.
material

用于实例化的材质网格.

Classes

InstancedFlow

方法

.moveIndividualAlongCurve( index : number, offset : number )

沿曲线将单个元素移动特定量。

index

要更新哪个元素。
offset

偏移量.

.setCurve( index : number, curveNo : number )

选择要用于网格划分的曲线元素.

index

要更新的实例化元素的索引.
curveNo

应使用的曲线的索引.

.writeChanges( index : number )

有关哪个曲线和曲线位置存储在实例化对象矩阵的平移分量中的额外信息 这会将信息写入矩阵并将其标记为需要更新。

index

要更新的 tge 实例化元素的索引。
