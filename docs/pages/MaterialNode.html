MaterialNode

此类应简化节点对材料属性的访问。 它内部使用参考节点来确保材质的更改 属性会自动反映到预定义的 TSL 对象 就像例如materialColor.

构造函数

new MaterialNode( scope : string )

构造一个新的材质节点。

scope

范围定义节点引用了什么样的材质属性。

属性

.scope : string

范围定义了节点引用了什么样的材质属性。 node.

方法

.getCache( property : string, type : string ) : MaterialReferenceNode

返回给定属性和类型的缓存引用节点。

property

材质属性的名称。
type

属性的统一类型。
返回：表示属性的材质引用节点access.

.getColor( property : string ) : MaterialReferenceNode.<color>

返回给定属性名称的颜色类型材质引用节点。

property

材质属性的名称。
返回：表示属性的材质引用节点access.

.getFloat( property : string ) : MaterialReferenceNode.<float>

返回给定属性名称的浮点类型材质引用节点。

property

材质属性的名称。
返回：表示属性的材质引用节点access.

.getTexture( property : string ) : MaterialReferenceNode

返回给定属性的纹理类型材质引用节点name.

property

材质属性的名称。
返回：表示属性的材质引用节点access.

.setup( builder : NodeBuilder ) : Node

根据所选范围完成节点设置。多种材料特性 如果它们在逻辑上属于在一起，则可能会被分组为单个节点组合。

builder

当前节点构建器.
覆盖： Node#setup
返回：表示所选范围的节点。
