Box2

表示 2D 空间中的轴对齐边界框 (AABB)。

构造函数

new Box2( min : Vector2, max : Vector2 )

构造一个新的边界框。

min

表示边界框下边界的向量box.

默认为 (Infinity,Infinity).
max

表示框上边界的向量.

默认为(-Infinity,-Infinity).

属性

.isBox2 : boolean (readonly)

该标志可用于类型测试。

默认为true.

.max : Vector2

盒子的上边界。

.min : Vector2

盒子的下边界。

方法

.clampPoint( point : Vector2, target : Vector2 ) : Vector2

将给定点限制在该盒子的边界内。

point

指向的点夹紧.
target

用于存储方法结果的目标向量.
返回：夹紧点.

box

返回从此框的任何边缘到指定点的欧氏距离。如果 给定点位于此框内，距离将为 0.

point

.expandByPoint( point : Vector2 ) : Box2

.expandByScalar( scalar : number ) : Box2

按给定标量扩展框的每个维度。如果为负数，则 框的尺寸将收缩。

scalar

.expandByVector( vector : Vector2 ) : Box2

按给定向量等边扩展此框。这个的宽度 box 将被两个向量的 x 分量扩展 方向。该框的高度将按 y 分量扩展 两个方向的向量。

vector

应扩展边界框的向量。

.intersect( box : Box2 ) : Box2

计算此边界框与给定边界框的交集，设置上边界框 该框的边界到两个框的上限和下界中较小的一个 该框的下界与两个框下界中较大者的差值。如果 没有重叠，使此框为空。

box

要与之相交的边界框.

.intersectsBox( box : Box2 ) : boolean

.isEmpty() : boolean

如果此框在其边界内包含零点，则返回 true。 请注意，下限和上限相等的框仍包含一个 点，两个边界共享。

返回：此框是否为空。

.makeEmpty() : Box2

使此框为空，这意味着在 2D 中包含零空间。

返回：对此边界框的引用。

.set( min : Vector2, max : Vector2 ) : Box2

设置此框的下边界和上边界。 请注意，此方法仅复制给定对象中的值。

盒子的下边界。
max

盒子的上边界。

.setFromCenterAndSize( center : Vector2, size : Vector2 ) : Box2

将此框置于给定的中心向量上并设置此框的宽度、高度和 给定大小值的深度。

center

盒子的中心。
size

盒子的 x 和 y 尺寸。
返回：对此边界框的引用。

.setFromPoints( points : Array.<Vector2> ) : Box2

设置此盒子的上限和下限，以便它包含位置数据 在给定的数组中。

将 2D 位置数据保存为 Vector2 的实例的数组。
返回：对此边界框的引用。

.translate( offset : Vector2 ) : Box2

将给定的偏移量添加到此边界框的上限和下限， 在 2D 空间中有效地移动它。

offset

应用于平移边界框的偏移量。
返回：对此边界框的引用。

.union( box : Box2 ) : Box2

计算此框与另一个框和给定框的并集，设置上边界框 该框的边界到两个框的上限和 该框的下界到两个框下界中较小的一个。

box

将与此实例合并的边界框。
返回：对此边界框的引用。
