Matrix4

表示 4x4 矩阵。

4x4 矩阵在 3D 计算机图形学中最常见的用途是作为变换矩阵。 有关 WebGL 中使用的变换矩阵的介绍，请查看本教程

这允许表示 3D 空间中的点的 3D 向量经历 变换，例如平移、旋转、剪切、缩放、反射、 正交或透视投影等，通过乘以 矩阵。这被称为 applying 向量矩阵。

A 关于行主和列主排序的注释：

构造函数和 Matrix3#set 方法接受参数 行优先 顺序，而在内部它们以列优先顺序存储在 Matrix3#elements 数组中。 这意味着调用：

const m = new THREE.Matrix4();
m.set( 11, 12, 13, 14,
       21, 22, 23, 24,
       31, 32, 33, 34,
       41, 42, 43, 44 );

将导致元素数组包含：

m.elements = [ 11, 21, 31, 41,
               12, 22, 32, 42,
               13, 23, 33, 43,
               14, 24, 34, 44 ];

并且在内部所有计算都使用列优先顺序执行。 然而，由于实际的排序在数学上没有区别， 大多数人习惯于按行优先顺序思考矩阵， Three.js 文档以行优先顺序显示矩阵。只要忍耐 请注意，如果您正在阅读源代码，则必须采取 转置此处概述的任何矩阵以理解计算。

.determinantAffine() : number

计算并返回 4x4 矩阵的行列式，但假设 矩阵是仿射矩阵，可以节省一些计算。

对于仿射矩阵（如对象的世界矩阵），该值等于 完整的 4x4 Matrix4#determinant 但计算起来更便宜。

假设底行是 [0, 0, 0, 1].
