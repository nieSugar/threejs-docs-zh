InstancedMesh

具有实例渲染支持的网格的特殊版本。使用 如果您必须使用相同的对象渲染大量对象，则使用此类 几何和材料，但具有不同的世界变换。用途 'InstancedMesh' 将帮助您减少绘制调用的数量，从而 提高应用程序的整体渲染性能。

构造函数

new InstancedMesh( geometry : BufferGeometry, material : Material | Array.<Material>, count : number )

构造新的实例化网格体。

geometry

网格体几何形状。
material

网格材质。
count

实例数。

属性

.boundingBox : Box3

实例化网格体的边界框。可以通过 InstancedMesh#computeBoundingBox.

默认为null.

.boundingSphere : Sphere

实例化网格体的边界球体进行计算。可以通过InstancedMesh#computeBoundingSphere计算。

默认为null.

.count : number

实例数。

覆盖： Mesh#count

.instanceColor : InstancedBufferAttribute

表示所有实例的颜色。你必须设置它的 如果修改实例数据，则 BufferAttribute#needsUpdate 标志为 true 通过 InstancedMesh#setColorAt.

默认为null.

.instanceMatrix : InstancedBufferAttribute

表示所有实例的局部变换。你必须设置它的 如果修改实例数据，则 BufferAttribute#needsUpdate 标志为 true 通过 InstancedMesh#setMatrixAt.

.isInstancedMesh : boolean (readonly)

该标志可用于类型测试。

默认为true.

.morphTexture : DataTexture

表示所有实例的变形目标权重。你必须设置它的 如果修改实例数据，则 Texture#needsUpdate 标志为 true 通过 InstancedMesh#setMorphAt.

默认为null.

方法

.computeBoundingBox()

计算实例化网格的边界框，并更新 InstancedMesh#boundingBox。 边界框不是由引擎自动计算的；此方法必须由您的应用程序调用。 如果通过 InstancedMesh#setMatrixAt 转换实例，您可能需要重新计算边界框。

.computeBoundingSphere()

计算实例化网格体的边界球体，并更新 InstancedMesh#boundingSphere 引擎会在需要时自动计算边界球体，例如用于光线投射或视锥体剔除。 如果通过InstancedMesh#setMatrixAt转换实例，您可能需要重新计算边界球。

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Mesh#dispose
