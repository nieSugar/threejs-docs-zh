OctreeHelper

用于可视化八叉树的帮助器。

代码示例

const helper = new OctreeHelper( octree );
scene.add( helper );

导入

OctreeHelper 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OctreeHelper } from 'three/addons/helpers/OctreeHelper.js';

构造函数

new OctreeHelper( octree : Octree, color : number | Color | string )

构造一个新的八叉树助手。

octree

要可视化的八叉树。
color

助手的color.

默认为0xffff00.

属性

.color : number | Color | string

助手的color.

.octree : Octree

要可视化的八叉树。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose

.update()

更新帮助程序。每当八叉树出现时都必须调用此方法 结构已更改。
