ForestGenerator

在单实例绘制调用中用树木覆盖 TerrainGenerator。 每棵树都是一个扭曲的生态球，具有烘烤的树冠梯度。海拔、坡度 和密度掩模控制放置；树之间的旋转和比例不同。

兼容的地形对象公开sampleHeight、sampleSlope、minY、maxY 和 parameters.size.

代码示例

const forest = new ForestGenerator( { count: 500000 } );
scene.add( forest.build( terrain ) );

构造函数

new ForestGenerator()
