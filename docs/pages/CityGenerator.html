CityGenerator

布置城市街区网格并用 SkyscraperGenerator 填充每个地块 有自己的种子、高度和占地面积的塔，可以选择在凸起的人行道上 板（路缘石）。返回一个 THREE.Group 准备添加到场景中。

传递建筑材料来装饰塔楼；人行道会自己打扮 通过SidewalkGenerator。布局公开为 CityGenerator#layout 所以周围的场景（道路标记等） 可以对齐到同一网格。

代码示例

const city = new CityGenerator( { seed: 1 } );
scene.add( city.build( materials ) );

构造函数

new CityGenerator()

属性

.seedNode : UniformNode.<uint>

建筑和代理材料共享的城市种子。将此传递给 createBuildingMaterial 在重建时更新调色板。

方法

.buildProxy() : InstancedMesh

为城市构建一个轻量级替身：每座塔一个实例化盒子， 在一次绘制调用中调整大小以匹配。用于廉价的全局照明 烘烤时，不需要详细的立面和街道设施， 盒子仍然投射相同的街道阴影并反射相同的温暖填充。

在 CityGenerator#build 之后调用，记录塔盒。

返回： 代理网格。
