TRAANode

应用TRAA（时间重投影抗锯齿）的特殊节点。

参考：

  • https://alextardif.com/TAA.html
  • https://www.elopezr.com/temporal-aa-and-the-quest-for-the-holy-trail/

注意：当TRAA处于启用状态时，必须禁用MSAA use.

导入

TRAANode 是一个插件，必须显式导入，请参阅Installation#Addons.

import { traa } from 'three/addons/tsl/display/TRAANode.js';

构造函数

new TRAANode( beautyNode : TextureNode, depthNode : TextureNode, velocityNode : TextureNode, camera : Camera )

构造一个新的TRAA node.

beautyNode

代表输入的纹理节点效果.
depthNode

表示场景深度的节点。
velocityNode

表示场景速度的节点。
camera

渲染场景的相机。

属性

.beautyNode : TextureNode

代表输入的纹理节点效果.

.camera : Camera

渲染场景的相机。

.depthNode : TextureNode

表示场景速度的节点。

.depthThreshold : number

当当前和先前深度之间的差异超过此阈值时， 历史记录被视为无效。

默认为 0.0005.

.edgeDepthDiff : number

将像素视为边缘的 3×3 邻域内的深度差。

默认为0.001.

.isTRAANode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.maxVelocityLength : number

当速度的像素长度接近此值时，历史记录将变得无效value.

默认为128.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.useSubpixelCorrection : boolean

当速度大于亚像素时是否减少当前帧的权重。 这可以减少运动下的模糊度，但会引入方形图案伪影。

默认为true.

.velocityNode : TextureNode

表示场景速度的节点。

方法

.clearViewOffset()

清除场景相机的视图偏移。

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setViewOffset( width : number, height : number )

将 TRAA 的当前抖动定义为视图偏移 到场景的摄像机.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的渲染目标和 TSL代码.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
