GLTFLoader

glTF 2.0 格式的加载器。

glTF (GL传输格式）尽可能是开放格式规范。请注意，图像位图不是 当它们不再被引用时会自动被 GC 收集，并且在期间需要特殊处理 处置过程。

GLTFLoader 支持以下 glTF 2.0 扩展：

  • KHR_draco_mesh_compression
  • KHR_lights_punctual
  • KHR_materials_anisotropy
  • KHR_materials_clearcoat
  • KHR_materials_dispersion
  • KHR_materials_emissive_strength
  • KHR_materials_ior
  • KHR_materials_specular
  • KHR_materials_transmission
  • KHR_materials_iridescence
  • KHR_materials_unlit
  • KHR_materials_volume
  • KHR_mesh_quantization
  • KHR_meshopt_compression
  • KHR_texture_basisu
  • KHR_texture_transform
  • EXT_materials_bump
  • EXT_meshopt_compression
  • EXT_mesh_gpu_instancing
  • EXT_texture_avif
  • EXT_texture_webp

以下 glTF 2.0 扩展由单独注册的插件支持：

  • KHR_gaussian_splatting
  • KHR_materials_variants
  • MSFT_texture_dds
  • KHR_animation_pointer
  • NEEDLE_progressive

代码示例

const loader = new GLTFLoader();
// Optional: Provide a DRACOLoader instance to decode compressed mesh data
const dracoLoader = new DRACOLoader();
dracoLoader.setDecoderPath( '/threejs-docs-zh/examples/jsm/libs/draco/' );
loader.setDRACOLoader( dracoLoader );
const gltf = await loader.loadAsync( 'models/gltf/duck/duck.gltf' );
scene.add( gltf.scene );

导入

GLTFLoader是一个插件，必须显式导入，请参阅Installation#Addons。

import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

构造函数

new GLTFLoader( manager : LoadingManager )

构造一个新的glTF加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的URL加载并传递加载的glTF资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( data : string | ArrayBuffer, path : string, onLoad : function, onError : onErrorCallback )

解析给定的 glTF 数据并返回结果组。

data

原始 glTF 数据。
path

URL 基础路径.
onLoad

加载过程完成时执行。
onError

发生错误时执行。
覆盖： Loader#parse

.parseAsync( data : string | ArrayBuffer, path : string ) : Promise.<GLTFLoader~LoadObject> (async)

Async 版本GLTFLoader#parse.

data

原始 glTF 数据。
path

URL 基础路径.
返回： 解析完成后使用加载的 glTF 解析的 Promise。

.register( callback : function ) : GLTFLoader

注册插件回调。该API在内部用于实现各种 glTF 扩展，但也可以由第三方代码使用来添加额外的逻辑 到加载程序。

callback

要注册的回调函数。
返回：对此加载程序的引用。

.setDRACOLoader( dracoLoader : DRACOLoader ) : GLTFLoader

将给定的 Draco 加载程序设置为此加载程序。解码资产所需 使用 KHR_draco_mesh_compression 扩展名进行压缩。

dracoLoader

要设置的 Draco 加载程序。
返回：对此加载程序的引用。

.setKTX2Loader( ktx2Loader : KTX2Loader ) : GLTFLoader

将给定的 KTX2 加载程序设置为此加载程序。加载 KTX2 所需 压缩纹理。

ktx2Loader

要设置的 KTX2 加载程序。
返回：对此加载程序的引用。

.setMeshoptDecoder( meshoptDecoder : Object ) : GLTFLoader

设置给定的 meshopt 解码器。解码资产所需 使用EXT_meshopt_compression扩展进行压缩。

meshoptDecoder

要设置的meshopt解码器。
返回：对此加载程序的引用。

.unregister( callback : function ) : GLTFLoader

取消注册插件回调.

callback

回调函数unregister.
返回：对此加载程序的引用。

类型定义

.LoadObject

GLTFLoader的加载器结果__.

animations
Array.<AnimationClip>

动画数组剪辑.
asset
Object

有关加载资源的元数据.
cameras
Array.<Camera>

相机数组.
parser
GLTFParser

对内部解析器的引用.
scene
Group

默认场景.
scenes
Array.<Group>

glTF资源可能定义多个场景.
userData
Object

附加数据.
