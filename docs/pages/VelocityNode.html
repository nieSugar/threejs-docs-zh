VelocityNode

用于表示运动或速度矢量的节点。基金会 用于运动模糊或 TRAA 等高级后处理效果。

节点跟踪模型、视图和投影矩阵 前一帧的数据并使用它们来计算 NDC 空间中的偏移量。 这些偏移量表示最终速度。

构造函数

new VelocityNode()

构造一个新的顶点颜色节点。

属性

.previousCameraViewMatrix : UniformNode.<mat4>

表示先前视图矩阵的统一节点。

默认为null.

.previousModelWorldMatrix : UniformNode.<mat4>

表示世界空间中先前模型矩阵的统一节点。

默认为null.

.previousProjectionMatrix : UniformNode.<mat4>

表示先前投影的统一节点矩阵.

默认为null.

.projectionMatrix : Matrix4

当前投影矩阵。

默认为null.

.updateAfterType : string

由于速度节点在更新后保存数据而被覆盖。

默认为 'object'.

覆盖： TempNode#updateAfterType

.updateType : string

由于速度节点而被覆盖每个对象都会更新。

默认为 'object'.

每帧一次其内部制服覆盖： TempNode#updateType

方法

.setProjectionMatrix( projectionMatrix : Matrix4 )

设置给定的投影矩阵。

projectionMatrix

要设置的投影矩阵。

.setup( builder : NodeBuilder ) : Node.<vec2>

基于先前和当前顶点数据实现速度计算。

builder

对当前节点构建器的引用。
覆盖： TempNode#setup
返回：运动矢量.

.update( frame : NodeFrame )

更新速度特定制服。

frame

对当前节点框架的引用。
覆盖： TempNode#update

.updateAfter( frame : NodeFrame )

覆盖为更新的速度特定制服.

frame

对当前节点框架的引用。
覆盖： TempNode#updateAfter
