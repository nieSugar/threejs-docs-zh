PointShadowNode

表示点光源节点的阴影实现。

构造函数

new PointShadowNode( light : PointLight, shadow : PointLightShadow )

构造一个新的点阴影节点。

light

阴影投射点light.
shadow

可选的点光源阴影.

默认为null.

方法

.getShadowFilterFn( type : number ) : function

覆盖默认实现以返回点光源阴影特定 过滤函数.

type

影子类型.
覆盖： ShadowNode#getShadowFilterFn
返回：过滤function.

.renderShadow( frame : NodeFrame )

用特定于点光源的默认实现覆盖 渲染代码。

frame

对当前节点框架的引用。
覆盖： ShadowNode#renderShadow

.setupRenderTarget( shadow : LightShadow, builder : NodeBuilder ) : Object

覆盖默认实现以使用 CubeDepthTexture 创建 CubeRenderTarget。

shadow

光阴影对象.
builder

对当前节点构建器的引用。
返回： 包含阴影贴图和深度纹理的对象。

.setupShadowCoord( builder : NodeBuilder, shadowPosition : Node.<vec3> ) : Node.<vec3>

覆盖默认实现，以便使用未更改的阴影位置。

builder

对当前节点构建器的引用。
shadowPosition

表示阴影的节点位置.
覆盖： ShadowNode#setupShadowCoord
返回： 阴影坐标。

.setupShadowFilter( builder : NodeBuilder, inputs : Object ) : Node.<float>

覆盖默认实现以仅使用特定于点光源 阴影过滤函数。

builder

对当前节点构建器的引用。
inputs

定义阴影过滤的配置对象。

filterFn

此函数定义阴影贴图的过滤类型，例如PCF.
depthTexture

对阴影贴图深度纹理的引用。
shadowCoord

用于从阴影贴图采样的阴影坐标。
shadow

光阴影。
覆盖： ShadowNode#setupShadowFilter
返回：阴影过滤的结果节点.
