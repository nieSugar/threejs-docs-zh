InstancedInterleavedBuffer

交错的实例化版本buffer.

构造函数

new InstancedInterleavedBuffer( array : TypedArray, stride : number, meshPerAttribute : number )

构造一个新的实例化交错缓冲区。

array

具有存储属性数据的共享缓冲区的类型化数组。
stride

每个顶点的类型化数组元素数。
meshPerAttribute

定义此交错的值的频率缓冲区应重复。

默认为1.

属性

.isInstancedInterleavedBuffer : boolean (readonly)

该标志可用于类型测试。

默认为true.

.meshPerAttribute : number

定义此缓冲区属性的值应重复的频率， 参见 InstancedBufferAttribute#meshPerAttribute.

默认为1.
