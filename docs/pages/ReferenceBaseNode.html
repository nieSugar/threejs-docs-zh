ReferenceBaseNode

建立对另一个对象的属性的引用的节点的基类。 这样，节点的值就自动链接到了 引用的对象。参考节点内部表示链接值 作为统一。

构造函数

new ReferenceBaseNode( property : string, uniformType : string, object : Object, count : number )

构造一个新的引用基节点。

property

节点引用的属性的名称。
uniformType

应用于表示属性值的统一类型。
object

属性所属的对象。

默认为null.
count

当链接属性是类数组时，该参数定义其长度。

默认为null.

属性

.count : number

当链接属性是数组时，该参数定义其长度。 length.

默认为null.

.group : UniformGroupNode

内部uniform的uniform组。

默认为null.

.node : UniformNode

保存引用节点值的统一节点。

默认为null.

.object : Object

属性所属的对象。

默认为null.

.properties : Array.<string>

属性名称可能有点，因此可以引用嵌套属性。 名称的层次结构存储在该数组中。

.property : string

节点引用的属性的名称。

.reference : Object

指向当前引用的对象。此属性位于 ReferenceNode#object 旁边 因为最终的引用可能会通过调用代码进行更新。

默认为null.

.uniformType : string

应用于表示属性值的统一类型。

.updateType : string

覆盖，因为每个对象都会更新引用节点。

默认为 'object'.

覆盖： Node#updateType

方法

.element( indexNode : IndexNode ) : ReferenceElementNode

当引用的属性类似于数组时，可以使用此方法 通过索引节点访问元素。

indexNode

indexNode.
返回： 对元素的引用。

.generateNodeType( builder : NodeBuilder ) : string

由于节点类型是从 引用节点的类型。

builder

当前节点构建器.
覆盖： Node#generateNodeType
返回： 节点类型。

.getValueFromReference( object : Object ) : any

从给定引用的对象返回属性值。

object

要从中检索属性值的对象。

默认为this.reference.
返回： 值.

.setGroup( group : UniformGroupNode ) : ReferenceBaseNode

设置此参考节点的统一组。

group

要设置的统一组。
返回：对此节点的引用.

.setNodeType( uniformType : string )

设置自动定义内部的节点类型 统一类型。

uniformType

类型为set.

.setup() : UniformNode

参考节点的输出是内部统一节点。

覆盖： Node#setup
返回： 输出节点。

.update( frame : NodeFrame )

覆盖以更新内部统一值。

frame

对当前节点框架的引用。
覆盖： Node#update

.updateReference( state : NodeFrame | NodeBuilder ) : Object

允许根据给定状态更新参考。国家只是 评估的 ReferenceBaseNode#object 未设置。

state

当前状态。
覆盖： Node#updateReference
返回： 更新的参考.

.updateValue()

从引用的对象属性中检索值并使用它 更新内部制服.
