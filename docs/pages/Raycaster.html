Raycaster

此类旨在协助光线投射。光线投射用于 鼠标拾取（计算出鼠标位于 3D 空间中的哪些对象） 除此之外.

构造函数

new Raycaster( origin : Vector3, direction : Vector3, near : number, far : number )

构造一个新的光线投射器.

origin

光线投射的原点向量.
direction

为光线提供方向的（归一化）方向向量.
near

返回的所有结果都比近处更远。近不能为负。

默认为0.
far

返回的所有结果都比远更近。远不能低于近。

默认为 Infinity.

属性

.camera : Camera

针对依赖于视图的对象进行光线投射时使用的相机，例如 广告牌上的对象，例如精灵。该字段可以手动设置或 在调用 setFromCamera() 时设置。

默认为null.

.far : number

返回的所有结果都比远更近。远不能低于近。

默认为 Infinity.

.layers : Layers

允许在执行相交测试时有选择地忽略 3D 对象。 以下代码示例确保只有 1 层上的 3D 对象才会被 由 raycaster 授予。

raycaster.layers.set( 1 );
object.layers.enable( 1 );

.near : number

返回的所有结果都比近处更远。近不能为负。

默认为0.

.params : Object

配置光线投射的参数对象。它具有以下结构：

{
	Mesh: {},
	Line: { threshold: 1 },
	LOD: {},
	Points: { threshold: 1 },
	Sprite: {}
}

其中threshold是光线投射器在与对象相交时的精度（以世界单位表示）。

.ray : Ray

用于光线投射的光线。

方法

.intersectObject( object : Object3D, recursive : boolean, intersects : Array.<Raycaster~Intersection> ) : Array.<Raycaster~Intersection>

检查光线与物体之间有或没有相交的所有相交的 后代。返回的交点按距离排序，最接近的在前。

Raycaster 委托给所传递的 3D 对象的 raycast() 方法，当 评估光线是否与物体相交。这允许网格响应 与射线投射与线或点不同。

注意，对于网格体，面必须按顺序指向射线原点 被检测到；穿过脸部背面的光线的交点不会 被检测到。要对对象的两个面进行光线投射，您需要设置 Material#side 到 THREE.DoubleSide.

请注意，精确地沿着两个面共享的边撞击三角形网格的光线可能是 由两个面报告，导致两个重合的交叉点（相同的点和 返回数组中的距离）。

object

要检查与ray.
recursive

如果设置为 true，它还会检查所有后代。 否则，它仅检查与对象的相交。

默认为true.
intersects

保存方法结果的目标数组。

默认为[].
返回： 保存交点的数组。

.intersectObjects( objects : Array.<Object3D>, recursive : boolean, intersects : Array.<Raycaster~Intersection> ) : Array.<Raycaster~Intersection>

检查光线与有或没有的物体之间的所有交集 后代。返回的交点按距离排序，最接近的在前。

objects

要检查与射线是否相交的 3D 对象。
recursive

如果设置为 true，它还会检查所有后代。 否则，它仅检查与对象的相交。

默认为true.
intersects

保存方法结果的目标数组。

默认为[].
返回： 保存交点的数组。

.set( origin : Vector3, direction : Vector3 )

通过复制参数中的值，用新的原点和方向更新射线。

origin

光线投射的原点向量.
direction

为光线提供方向的（归一化）方向向量.

.setFromCamera( coords : Vector2, camera : Camera )

使用给定的坐标和相机计算内部射线的新原点和方向。

coords

以标准化设备坐标表示的鼠标的 2D 坐标（国家数据中心）。 X 和 Y 分量应位于 -1 和 1 之间。
camera

光线应源自的相机。

.setFromXRController( controller : WebXRController ) : Raycaster

使用给定的 WebXR 控制器计算内部图像的新原点和方向射线.

controller

复制位置和方向的控制器.
返回：对此光线投射器的引用。

世界坐标中的交点。
face

已相交的面.
faceIndex
number

面索引.
object

交点处的 U,V 坐标。
uv1

交点处的第二组 U、V 坐标。
normal

交点处的插值法向量。

number
