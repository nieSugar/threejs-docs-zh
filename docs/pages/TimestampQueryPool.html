TimestampQueryPool

时间戳查询池的抽象基类。

构造函数

new TimestampQueryPool( maxQueries : number ) (abstract)

创建一个新的时间戳查询池。

maxQueries

此池可以的最大查询数保持.

默认为256.

属性

.currentQueryIndex : number

到目前为止分配了多少个查询.

默认为0.

.frames : Array.<number>

存储所有时间戳帧.

.isDisposed : boolean

池是否已被释放.

默认为 false.

.lastValue : number

直到下一个帧的总持续时间update.

默认为0.

.maxQueries : number

此池可以的最大查询数保持.

默认为256.

.pendingResolve : boolean | Promise.<number>

此属性用于避免多个并发解析操作。 WebGL 后端将其用作布尔标志。在 WebGPU 的上下文中，它成立 当前解析操作的承诺。

默认为 false.

.queryOffsets : Map.<string, number>

跟踪不同上下文的偏移量。

.timestamps : Map.<string, number>

存储每个渲染上下文的最新时间戳。

.trackTimestamp : boolean

是否跟踪时间戳。

默认为true.

方法

.allocateQueriesForContext( uid : string, frameId : number ) : number (abstract)

为特定的查询分配查询uid.

uid

渲染上下文的唯一标识符.
frameId

当前帧标识符。

.dispose() (abstract)

处理查询池。

.getTimestamp( uid : string ) : number

返回给定渲染上下文的时间戳。

uid

渲染上下文的唯一标识符.
返回：时间戳，如果没有，则未定义可用.

.getTimestampFrames() : Array.<number>

返回所有时间戳帧。

返回：时间戳帧。

.hasTimestampQuery( uid : string ) : boolean

返回时间戳是否可用于给定渲染上下文。

uid

渲染上下文的唯一标识符.
返回：如果时间戳可用，则返回 true，否则返回 false。

.resolveQueriesAsync() : Promise.<number> | number (async, abstract)

解析所有时间戳并返回数据（或处理它们）.

返回：解析的时间戳值.
