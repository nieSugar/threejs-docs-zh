ColorUtils

导入

ColorUtils 是一个插件，必须显式导入，请参阅 Installation#Addons.

import * as ColorUtils from 'three/addons/utils/ColorUtils.js';

方法

.setKelvin( color : Color, kelvin : number ) : Color (inner)

从开尔文色温设置给定颜色。

将相关色温 (CTT) 转换为近似 sRGB 颜色 使用 Tanner Helland 的算法。对于基于物理的照明很有用 设置——例如蜡烛火焰 (~1900K)、钨丝灯泡 (~3200K)、日光 （~6500K），或清澈的蓝天（~10000K）。 [1000, 40000] 之外的值是 夹紧.

参考：https://tannerhelland.com/2012/09/18/convert-temper-rgb-algorithm-code.html

color

要设置的颜色。
kelvin

开尔文色温。固定为 [1000, 40000].
返回： 更新后的颜色.
