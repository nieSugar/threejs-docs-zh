CCDIKSolver

此类通过 CCD 算法.

CCDIKSolver 设计用于处理 SkinnedMesh.

导入

CCDIKSolver 的实例插件，并且必须显式导入，请参阅 Installation#Addons.

import { CCDIKSolver } from 'three/addons/animation/CCDIKSolver.js';

构造函数

new CCDIKSolver( mesh : SkinnedMesh, iks : Array.<CCDIKSolver~IK> )

mesh

蒙皮网格物体.
iks

IK 对象.

默认为[].

属性

.iks : Array.<CCDIKSolver~IK>

IK 对象.

.mesh : SkinnedMesh

蒙皮网格物体.

方法

.createHelper( sphereSize : number ) : CCDIKHelper

创建用于可视化 CCDIK 的帮助程序。

sphereSize

球体尺寸.
返回： helper.

.update( globalBlendFactor : number ) : CCDIKSolver

通过求解 CCD 算法更新所有 IK 骨骼。

globalBlendFactor

如果 IK 链没有自己的 .blendFactor，则应用混合因子。

默认为1.0.
返回：对此实例的引用。

.updateOne( ik : CCDIKSolver~IK, overrideBlend : number ) : CCDIKSolver

更新一个 IK 骨骼求解 CCD 算法。

ik

要更新的 IK.
overrideBlend

如果 IK 对象未定义 blendFactor，则该值为使用.

默认为1.0.
返回：对此实例的引用。

类型定义

.BoneLink

此类型表示骨骼链接。

index
number

链接骨骼的索引，引用Skeleton.bones数组中的骨骼。
limitation
number

旋转轴。
rotationMin
number

旋转最小值limit.
rotationMax
number

旋转最大限制.
enabled
boolean

链接是否启用.

默认为true.

.IK

该类型代表IK配置对象.

target
number

目标骨骼索引，指的是骨骼中的骨骼Skeleton.bones 数组。
effector
number

效应器骨骼索引，引用 Skeleton.bones 数组中的骨骼。
links
Array.<CCDIKSolver~BoneLink>

骨骼链接数组。
iteration
number

计算的迭代次数。越小速度越快，但精度越低。

默认为1.
minAngle
number

以弧度为单位的最小旋转角度。
maxAngle
number

以弧度为单位的最小旋转角度。
blendFactor
number

混合因子。
