DebugEnvironment

此类表示具有非常基本的房间设置的场景，可用作 输入 PMREMGenerator#fromScene。生成的 PMREM 代表房间的 照明，可通过将其分配给 Scene#environment 来用于基于图像的照明 或直接作为 PBR 材质的环境贴图。

此类使用简单的房间设置，只能用于开发目的。 更适合生产的设置是 RoomEnvironment.

代码示例

const environment = new DebugEnvironment();
const pmremGenerator = new THREE.PMREMGenerator( renderer );
const envMap = pmremGenerator.fromScene( environment ).texture;
scene.environment = envMap;

导入

DebugEnvironment 是一个插件，必须显式导入，请参阅 安装#Addons.

import { DebugEnvironment } from 'three/addons/environments/DebugEnvironment.js';

构造函数

new DebugEnvironment()

构建新的调试环境.

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要环境时。

覆盖： Scene#dispose
