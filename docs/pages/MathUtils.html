.damp( x : number, y : number, lambda : number, dt : number ) : number

使用 delta 以类似弹簧的方式平滑地将数字从 x 插值到 y 保持帧速率独立运动的时间。详细信息请参见 使用 lerp 实现与帧速率无关的阻尼.

x

当前点.
y

目标点.
lambda

较高的 lambda 值将使运动更突然， 较低的值将使运动更加渐进。
dt

以秒为单位的增量时间。
返回：插值。

.setQuaternionFromProperEuler( q : Quaternion, a : number, b : number, c : number, order : 'XYX' | 'XZX' | 'YXY' | 'YZY' | 'ZXZ' | 'ZYZ' )

从内固有欧拉角 由给定的角度和顺序定义。

旋转按 order 指定的顺序应用于轴： 首先应用角度 a 旋转，然后应用角度 b，然后应用角度 c.

q

要设置的四元数。
a

应用于第一个轴的旋转，在弧度.
b

应用于第二个轴的旋转，以弧度为单位。
c

应用于第三个轴的旋转，以弧度为单位。
order

指定轴顺序的字符串。

.smootherstep( x : number, min : number, max : number ) : number

最小值。任何低于最小值的 x 值都将为 0.
max

最大值。任何高于最大值的 x 值都将为 1.

.smoothstep( x : number, min : number, max : number ) : number

返回 [0,1] 范围内的值，表示 x 所占的百分比 在 min 和 max 之间移动，但越接近 x 就越平滑或减慢 min 和 max.

有关更多信息，请参阅 Smoothstep详细信息.

x

根据其在最小值和最大值之间的位置评估的值。
min

最小值。任何低于最小值的 x 值都将为 0.
max

最大值。任何高于最大值的 x 值都将为 1.
返回： 替代值.
