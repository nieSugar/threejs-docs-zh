Transpiler

将着色器代码从一种语言转换为另一种语言的类。

Transpiler 目前只能用于将 GLSL 转换为 TSL。其目的是 当开发人员想要从 当前新的基于节点的材质系统。

导入

Transpiler 是一个插件，必须显式导入，请参阅 安装#Addons.

import Transpiler from 'three/addons/transpiler/Transpiler.js';

构造函数

new Transpiler( decoder : GLSLDecoder, encoder : TSLEncoder )

构造一个新的转译器。

decoder

GLSL 解码器。
encoder

TSL 编码器。

属性

.decoder : GLSLDecoder

GLSL 解码器。该组件解析 GLSL 并生成 用于进一步处理的独立于语言的 AST。

.encoder : TSLEncoder

TSL 编码器。它接受 AST 并发出 TSL 代码。

.linker : Linker

链接器。它处理 AST 并解析 变量和函数引用，确保所有 依赖项已正确链接。

方法

.parse( source : string ) : string

解析给定的 GLSL 源并返回 TSL 语法。

source

GLSL 源代码.
返回： TSL 代码。
