CSMShadowNode

级联阴影贴图 (CSM) 的实现。

此模块只能与 WebGPURenderer 一起使用。当使用WebGLRenderer时， 使用 CSM 代替。

导入

CSMShadowNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { CSMShadowNode } from 'three/addons/csm/CSMShadowNode.js';

构造函数

new CSMShadowNode( light : DirectionalLight, data : CSMShadowNode~Data )

构造一个新的CSM影子节点。

light

CSM灯光.
data

CSM数据.

默认为 {}.

属性

.breaks : Array.<number>

数字数组在 [0,1] 范围内定义如何 mainCSM视锥体需要分割.

.camera : Camera

场景相机.

默认为null.

.cascades : number

级联数量.

默认为3.

.customSplitsCallback : function

自定义分割时的回调使用mode='custom'.

.fade : boolean

是否在级联之间淡入淡出.

默认为 false.

.frustums : Array.<CSMFrustum>

表示级联的平截头体数组.

.lightMargin : number

光照余量.

默认为200.

.lights : Array.<DirectionalLight>

投射阴影的定向光数组 不同的级联。每个都有一个定向灯 级联.

.mainFrustum : CSMFrustum

主视锥体.

默认为null.

.maxFar : number

最大远值.

默认为100000.

.mode : 'practical' | 'uniform' | 'logarithmic' | 'custom'

视锥体分割模式.

默认为'practical'.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： ShadowBaseNode#dispose

.updateFrustums()

应用程序每次更改相机或 CSM 设置时都必须调用此方法。
