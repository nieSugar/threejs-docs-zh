Uniform

代表一个全局着色器变量的统一。它们被传递给着色器程序。

当声明 ShaderMaterial 的统一时，它是通过值或对象声明的。

由于此类只能在 ShaderMaterial 的上下文中使用，因此仅支持它 在WebGLRenderer.

代码示例

uniforms: {
	time: { value: 1.0 },
	resolution: new Uniform( new Vector2() )
};

构造函数

new Uniform( value : any )

构造一个新的uniform。

value

uniform值。

属性

.boundary : number

用于根据STD140布局构建uniform缓冲区。 派生的制服会将此属性设置为特定的数据类型 value.

.index : number

该属性由UniformsGroup设置并标记 统一数组中的索引位置。

.itemSize : number

项目大小。派生的制服会将此属性设置为数据 类型具体值.

.name : string

制服名称.

.offset : number

该属性由UniformsGroup和标记设置 制服缓冲区中的起始位置。

.value : any

uniform值。

.value : any

制服的值。

方法

.clone() : Uniform

返回一个新制服，其中包含从此实例复制的值。 如果该值具有 clone() 方法，则也会克隆该值。

返回：此克隆instance.

.getValue() : any

返回制服的值。

返回： 值.

.setValue( value : any )

设置制服的值。

value

要设置的值。
