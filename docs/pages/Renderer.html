Renderer

渲染器的基类.

构造函数

new Renderer( backend : Backend, parameters : Renderer~Options )

构造一个新的渲染器.

backend

渲染器所针对的后端（例如WebGPU或WebGL） 2).
parameters

配置参数.

属性

.alpha : boolean

默认的framebuffer是否应该是透明的还是不透明的.

默认为true.

.autoClear : boolean

渲染器是否应该自动清除当前渲染目标 在执行 render() 调用之前。目标可以是画布（默认帧缓冲区） 或当前绑定的渲染目标（自定义帧缓冲区）。

默认为true.

.autoClearColor : boolean

当autoClear设置为true时，此属性定义渲染器是否 应清除颜色缓冲区。

默认为true.

.autoClearDepth : boolean

当autoClear设置为true时，此属性定义渲染器是否 应清除深度缓冲区。

默认为true.

.autoClearStencil : boolean

当autoClear设置为true时，此属性定义渲染器是否 应清除模板缓冲区。

默认为true.

.backend : Backend

对当前后端的引用。

.contextNode : ContextNode

存储特定转换或计算的覆盖节点的全局上下文节点。 这些节点可用于替换渲染管道中的默认行为。

value
Object

上下文值对象。

.coordinateSystem : number (readonly)

渲染器的坐标系。该房产的价值 取决于所选的后端。 THREE.WebGLCoordinateSystem 或 THREE.WebGPUCoordinateSystem.

.currentColorSpace : string

渲染器的当前颜色空间。当不产生屏幕输出时， 颜色空间始终是工作颜色空间。

.currentSamples : number

当前用于多样本抗锯齿 (MSAA) 的样本数。

渲染到自定义渲染目标时，使用该渲染目标的样本数。 当渲染器需要内部帧缓冲区目标时，样本数设置为 0 色调映射或色彩空间转换，或者将全屏四边形渲染到屏幕时。

.currentToneMapping : number

渲染器的当前色调映射。当不产生屏幕输出时， 色调映射始终为 NoToneMapping.

.debug : DebugConfig

渲染器的调试配置。

.depth : boolean

默认帧缓冲区是否应具有深度缓冲区。

默认为true.

.domElement : HTMLCanvasElement | OffscreenCanvas

对渲染器正在绘制的画布元素的引用。 该属性的值将自动创建 渲染器.

.highPrecision : boolean

启用或禁用模型视图和普通视图矩阵的高精度。 启用后，将使用 CPU 64 位精度来获得更高的精度，而不是使用 GPU 32 位来获得更高的性能。

注意：64 位精度与 InstancedMesh 和 SkinnedMesh 不兼容。

.highPrecision : boolean

返回是否高精度是否启用。

.info : Info

保存一系列有关GPU内存的统计信息 以及渲染过程。对于调试和监视很有用。

.initialized (readonly)

返回渲染器是否已初始化。

.inspector : InspectorBase

检查器实例。检查器可以是从 InspectorBase 扩展的任何类。

.isOutputTarget

如果渲染设置设置为屏幕输出，则返回 true。

.isRenderer : boolean (readonly)

该标志可用于类型测试。

默认为true.

.library : NodeLibrary

节点库定义某些库对象（如材质、灯光）的方式 或色调映射函数被映射到节点类型。这是必需的，因为 尽管 MeshBasicMaterial 或 PointLight 等类的实例可以 作为场景图的一部分，它们在内部表示为节点 进一步处理。

.lighting : Lighting

用于管理灯光的类似地图的数据结构。

.logarithmicDepthBuffer : boolean (readonly)

是否启用对数深度缓冲区。

默认为 false.

.needsFrameBufferTarget : boolean

如果需要帧缓冲区目标来执行色调映射或颜色空间转换，则返回true。 如果是这种情况，渲染器会为此目的分配一个内部渲染目标。

.onDeviceLost : function

A 回调函数，定义发生设备/上下文丢失时应发生的情况。

.onError : function

A 回调函数，定义未捕获时应发生的情况 报告后端错误（例如 WebGPU 验证/内存不足/内部 在错误范围之外引发的错误）。应用程序可以覆盖它 在自己的 UI 中显示错误，而不让其升级到设备 损失。默认实现记录到控制台。

.opaque : boolean

渲染器是否应渲染不透明渲染对象。

默认为true.

.outputColorSpace : string

定义渲染器的输出颜色空间。

默认为SRGBColorSpace.

.reversedDepthBuffer : boolean (readonly)

是否启用反向深度缓冲区。

默认为 false.

.samples : number

用于多样本抗锯齿 (MSAA) 的样本。

默认为0.

.shadowMap : ShadowMapConfig

渲染器的阴影配置。

.sortObjects : boolean

渲染器是否应对其渲染列表进行排序。

注意：排序用于尝试正确渲染具有一定透明度的对象。 根据定义，对对象进行排序可能并非在所有情况下都有效。根据应用的需要， 可能需要关闭排序并使用其他方法来处理透明渲染 例如手动确定每个对象的渲染顺序。

默认为true.

.stencil : boolean

默认帧缓冲区是否应该有模板缓冲区。

默认为 false.

.toneMapping : number

定义渲染器的色调映射。

默认为NoToneMapping.

.toneMappingExposure : number

定义色调映射曝光。

默认为1.

.transparent : boolean

渲染器是否应渲染透明渲染对象。

默认为true.

.xr : XRManager

渲染器的XR manager.
