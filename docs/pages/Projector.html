Projector

此类可以将 3D 空间中的给定场景投影为 2D 表示 用于使用 2D API 进行渲染。 Projector 当前由 SVGRenderer 使用 之前由旧版本 CanvasRenderer.

导入

Projector 使用，是一个插件，必须显式导入，请参阅 安装#Addons.

import { Projector } from 'three/addons/renderers/Projector.js';

构造函数

new Projector()

构造一个新的投影仪。

方法

.projectScene( scene : Object3D, camera : Camera, sortObjects : boolean, sortElements : boolean ) : Object

将3D空间中的给定场景投影到2D表示中。结果 是一个具有可渲染项的对象。

scene

场景或任何其他类型的 3D 对象。
camera

相机.
sortObjects

是否对对象进行排序。
sortElements

是否对元素（面、线和精灵）进行排序。
返回：可渲染的投影场景对象.
