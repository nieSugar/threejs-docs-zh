Loader

加载器的抽象基类。

构造函数

new Loader( manager : LoadingManager ) (abstract)

构造一个新的加载器。

manager

加载管理器。

属性

.crossOrigin : string

实现 CORS 的 crossOrigin 字符串，用于从 a 加载 url 允许 CORS 的不同域。

默认为 'anonymous'.

.manager : LoadingManager

加载管理器。

默认为 DefaultLoadingManager.

.path : string

资产所在的基本路径已加载.

.requestHeader : Object.<string, any>

请求标头 在 HTTP 请求中使用。

.resourcePath : string

将从中加载附加资源（例如纹理）的基本路径。

.withCredentials : boolean

XMLHttpRequest 是否使用凭据。

默认为 false.

.DEFAULT_MATERIAL_NAME : string

加载程序使用的默认材质名称 为加载的 3D 对象创建材质时。

注意：并非所有加载器都可能遵循此设置。

默认为 '__DEFAULT'.

方法

.abort() : Loader (abstract)

此方法可以在加载器中实现，用于中止正在进行的进程requests.

返回：对此实例的引用。

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback ) (abstract)

该方法需要所有具体加载器实现。它持有 从后端加载资源的逻辑。

url

要加载的文件的路径/URL。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。

.loadAsync( url : string, onProgress : onProgressCallback ) : Promise

Loader#load的异步版本__.

url

要加载的文件的路径/URL。
onProgress

加载正在进行时执行。
返回：当资源被加载时解析的Promise loaded.

.parse( data : any ) (abstract)

该方法需要所有具体加载器实现。它持有 将资产解析为 Three.js 实体的逻辑。

data

要解析的数据。

.setCrossOrigin( crossOrigin : string ) : Loader

设置 crossOrigin 字符串以实现用于加载 URL 的 CORS 来自允许 CORS 的不同域。

crossOrigin

crossOrigin 值。
返回：对此实例的引用。

.setPath( path : string ) : Loader

设置资产的基本路径。

path

基本路径。
返回：对此实例的引用。

.setRequestHeader( requestHeader : Object ) : Loader

设置给定的请求header.

requestHeader

A 请求标头 用于配置 HTTP 请求。
返回：对此实例的引用。

.setResourcePath( resourcePath : string ) : Loader

设置依赖资源（如纹理）的基本路径。

resourcePath

资源路径。
返回：对此实例的引用。

.setWithCredentials( value : boolean ) : Loader

XMLHttpRequest 是否使用凭据（如 cookie、授权） 标头或 TLS 客户端证书，请参阅 XMLHttpRequest.withCredentials.

注意：如果您在本地或从同一服务器加载文件，则此设置无效域.

value

withCredentials 值.
返回：对此实例的引用。
