ShadowMapViewer

这是一个用于可视化给定灯光阴影贴图的帮助程序。 它适用于阴影投射光：DirectionalLight 和 SpotLight。 它渲染出阴影贴图并将其显示在 HUD 上。

此模块只能与 WebGLRenderer 一起使用。当使用WebGPURenderer时， import the class from ShadowMapViewerGPU.js.

代码示例

const lightShadowMapViewer = new ShadowMapViewer( light );
lightShadowMapViewer.position.x = 10;
lightShadowMapViewer.position.y = SCREEN_HEIGHT - ( SHADOW_MAP_HEIGHT / 4 ) - 10;
lightShadowMapViewer.size.width = SHADOW_MAP_WIDTH / 4;
lightShadowMapViewer.size.height = SHADOW_MAP_HEIGHT / 4;
lightShadowMapViewer.update();

导入

ShadowMapViewer 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ShadowMapViewer } from 'three/addons/utils/ShadowMapViewer.js';

构造函数

new ShadowMapViewer( light : Light )

构造新的阴影贴图查看器。

light

阴影投射光。

属性

.enabled : boolean

是否显示阴影贴图查看器。

默认为true.

.position : Object

查看器的位置。更改此属性时，请确保 调用ShadowMapViewer#update.

默认为true.

.size : Object

查看器的大小。更改此属性时，请确保 调用 ShadowMapViewer#update.

默认为true.

方法

.render( renderer : WebGLRenderer )

渲染查看器。必须在应用程序的动画循环中调用此方法。

renderer

渲染器.

.update()

更新查看器。

.updateForWindowResize()

调整查看器的大小。每当应用程序运行时都应该调用此方法 窗口大小已调整。
