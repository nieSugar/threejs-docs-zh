TempNode

该模块使用缓存管理来创建临时变量 如果多次使用节点以防止重复计算。

该类充当许多其他节点类型的基类。

构造函数

new TempNode( nodeType : string )

构造临时节点。

nodeType

节点类型。

默认为null.

属性

.isTempNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.hasDependencies( builder : NodeBuilder ) : boolean

是否在其他上下文中多次使用此节点节点.

builder

节点构建器。
返回： 一个标志，指示是否存在对其他节点的多个依赖关系。
