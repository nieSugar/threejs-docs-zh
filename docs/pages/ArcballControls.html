ArcballControls

Arcball 控件允许通过具有完全触摸支持和高级导航功能的虚拟轨迹球控制相机。 光标/手指位置和移动被映射到由小控件表示的虚拟轨迹球表面上，并以直观和直观的方式映射 一致的相机移动。拖动光标/手指将导致相机以保守的方式围绕轨迹球中心旋转 方式（返回起点将使相机返回到起始方向）。

除了支持平移、缩放和捏合手势外，双击/点击聚焦于一个点，直观地移动物体的位置 虚拟轨迹球中心的兴趣点。焦点可以在复杂的环境中更好地检查和导航。 此外，Arcball 控件允许 FOV 操作（以眩晕方式）和 z 轴旋转。保存和恢复相机状态 还可以通过剪贴板支持（使用 ctrl+c 和 ctrl+v 快捷键来复制和粘贴状态）。

与 OrbitControls 和 TrackballControls 不同，ArcballControls 不需要update() 在外部调用 动画开启时的动画循环。

导入

ArcballControls 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { ArcballControls } from 'three/addons/controls/ArcballControls.js';

构造函数

new ArcballControls( camera : Camera, domElement : HTMLElement, scene : Scene )

构造一个新的控件实例。

camera

要控制的相机。相机不能是另一个对象的子对象，除非该对象是场景本身。
domElement

用于事件侦听器的 HTML 元素。

默认为null.
scene

相机渲染的场景。如果没有给出，则无法显示小工具。

默认为null.

属性

.adjustNearFar : boolean

如果设置为true，则每次缩放时都会调整相机的近距和远距值 尝试保持初始近和远给出的相同可见部分 价值观。仅适用于透视相机。

此功能仅在相机初始状态（位置、近距值和远距值）时按预期工作 在创建控件之前已正确配置。否则 ArcballControls#setCamera 必须由应用程序调用。

默认为 false.

.cursorZoom : boolean

设置为 true 以使缩放变为光标居中。

默认为 false.

.dampingFactor : number

使用的阻尼惯性，如果'enableAnimationsis set totrue`.

默认为 25.

.enableAnimations : boolean

设置为 true 以启用旋转（阻尼）和聚焦动画操作.

默认为true.

.enableFocus : boolean

启用或禁用双击（或单击）操作时相机对焦。

默认为true.

.enableGizmos : boolean

启用或禁用小工具。

默认为true.

.enableGrid : boolean

如果设置为true，执行平移操作时会出现网格 （仅限桌面交互）.

默认为 false.

.enablePan : boolean

启用或禁用相机平移。

默认为true.

.enableRotate : boolean

启用或禁用相机旋转。

默认为true.

.enableZoom : boolean

启用或禁用相机变焦。

默认为true.

.focusAnimationTime : number

焦点动画的持续时间（以毫秒为单位）

默认为500.

.maxDistance : number

您可以走多远推车出来。仅适用于透视相机。

默认为 Infinity.

.maxFov : number

以度为单位的最大视场角。

默认为90.

.maxZoom : number

可以缩小多远。仅适用于正交相机。

默认为 Infinity.

.minDistance : number

您可以推入多远。仅适用于透视相机。

默认为0.

.minFov : number

以度为单位的最小 FOV。

默认为5.

.minZoom : number

您可以放大多远。仅适用于正交相机。

默认为0.

.mouseActions : Array.<Object>

保留该相机的鼠标操作控制。该属性由方法维护 setMouseAction() 和 unsetMouseAction().

.radiusFactor : number

小控件相对于屏幕宽度和高度的大小。

默认为0.67.

.rotateSpeed : number

旋转速度.

默认为1.

.scaleFactor : number

执行缩放操作时使用的缩放系数.

默认为1.1.

.scene : Scene

相机渲染的场景。如果没有给出，则无法显示小工具。

默认为null.

.target : Vector3

控件的焦点。

.wMax : number

旋转动画开始时允许的最大角速度。

默认为20.

方法

.activateGizmos( isActive : boolean )

使旋转小工具或多或少可见。

isActive

如果设置为true，小工具更加可见。

.copyState()

将当前状态复制到剪贴板（如可读的 JSON 文本）。

.disposeGrid()

从场景中删除网格。

.getRaycaster() : Raycaster

返回用于用户交互的光线投射器。该对象在所有对象之间共享 ArcballControls.

返回： 内部光线投射器的实例。

.pasteState()

从剪贴板设置控件状态，假设剪贴板存储 JSON 从copyState()保存的文本。

.reset()

重置控件。

.saveState()

保存控件的当前状态。稍后可以使用 reset() 恢复。

.setCamera( camera : Camera )

设置要控制的相机。 必须调用才能设置要控制的新相机。

camera

要控制的相机。

.setGizmosVisible( value : boolean )

设置小工具可见性。

value

小工具可见性值。

.setMouseAction( operation : 'PAN' | 'ROTATE' | 'ZOOM' | 'FOV', mouse : 0 | 1 | 2 | 'WHEEL', key : 'CTRL' | 'SHIFT' ) : boolean

通过指定要执行的操作和鼠标/按键组合。如有冲突，替换现有的。

operation

要执行的操作（'PAN'、'ROTATE'、'ZOOM'、'FOV'）.
mouse

鼠标按钮（0、1、2）或滚轮的“WHEEL”凹口.
key

键盘修饰符（'CTRL'、'SHIFT'）或 null（如果不需要键）。

默认为null.
返回： true 如果已成功添加鼠标操作，false否则.

.setTbRadius( value : number )

设置小控件半径因子并重绘小控件。

value

半径因子的值.

.unsetMouseAction( mouse : 0 | 1 | 2 | 'WHEEL', key : 'CTRL' | 'SHIFT' ) : boolean

通过指定鼠标/按键组合删除鼠标操作。

mouse

鼠标按钮（0、1、2）或滚轮的“WHEEL”凹口.
key

键盘修饰符（'CTRL'、'SHIFT'）或 null（如果不需要键）。

默认为null.
返回： true 如果操作已成功删除，则 false 否则。
