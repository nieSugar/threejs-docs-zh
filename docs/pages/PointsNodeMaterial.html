PointsNodeMaterial

PointsMaterial的节点材质版本__.

此材质可以通过两种方式使用：

  • 通过使用 Points 来渲染点基元。由于 WebGPU 仅支持像素大小为 1 的点基元，因此无法定义大小。
const pointCloud = new THREE.Points( geometry, new THREE.PointsNodeMaterial() );
  • 通过使用精灵渲染点原语。在这种情况下，会遵守大小设置，参见 PointsNodeMaterial#sizeNode.
const instancedPoints = new THREE.Sprite( new THREE.PointsNodeMaterial( { positionNode: instancedBufferAttribute( positionAttribute ) } ) );

构造函数

new PointsNodeMaterial( parameters : Object )

构造一个新的点节点材质。

parameters

配置参数.

属性

.alphaToCoverage : boolean

是否应使用覆盖范围的 Alpha。

默认为true.

覆盖： SpriteNodeMaterial#alphaToCoverage

.isPointsNodeMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.sizeNode : Node.<vec2>

此节点属性提供了另一种设置点大小的方法。

请注意，WebGPU 仅支持具有 1 像素大小的点基元。因此， 当材质与 Points 和 WebGPU 一起使用时，此节点无效 后端。如果应用程序想要渲染大小大于 1 像素的点， 该材质应与 Sprite 和实例一起使用。

默认为null.
