VXGIVolume

保存 VXGINode 场景的体素表示：各向异性不透明度 mip 链、直接辐射量和带有缓存反弹的辐射量。

该表示是 Crassin 等人的预过滤体素层次结构的密集变体。 2011年 （密集的 mip 链而不是稀疏的八叉树，它将锥体样本保留为两次纹理获取）： 不透明度存储每个主轴的可见性并进行定向过滤（体积积分 沿轴，在其上取平均值），辐射度被存储不透明度预乘和间接反弹 通过锥体追踪缓存在卷中。仅注入直射光。 体素化在计算着色器中沿主三角轴使用保守光栅化。

每个体素注入直接光，而不是像在 paper：渲染器渲染的阴影贴图是光视图贴图，每个占用的体素 从它们中获取可见性（用于定向光和聚光灯的 2D 贴图，用于点光源的立方体贴图 灯）并分析评估其辐照度。这会重用现有的影子通道，使得 注入的阴影与直接照明完全匹配，既不需要原子也不需要 通过光子密度归一化。没有阴影贴图的灯光会回落到可见锥体 通过体积进行追踪。权衡是与占用体素的数量成正比的成本 倍于光而不是光视图分辨率，并且仅输出漫射辐射率 存储（光泽锥体没有传入方向分布）。

参考：

  • https://research.nvidia.com/publication/2011-09_interactive-indirect-illumination-using-voxel-cone-tracing：Crassin 等人，使用体素锥追踪的交互式间接光照，Pacific Graphics 2011。
  • https://developer.nvidia.com/content/basics-gpu-voxelization：GPU 体素化基础。

注意：此类只能与 WebGPURenderer 和 WebGPU 后端一起使用。

导入

VXGIVolume 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { VXGIVolume } from 'three/addons/lighting/vxgi/VXGIVolume.js';

构造函数

new VXGIVolume( resolution : number )

构造一个新卷.

resolution

沿边界最长轴的体素数量。不应超过 256，较高的值超过体素分析器的最大存储缓冲区大小。

默认为128.

属性

.bounceConeAngle : UniformNode.<float>

用于缓存反弹的锥体孔径（以度为单位）。

默认为60.

.bounces : number

存储在卷中的缓存间接反弹数量。应在 [0, 2].

默认为1.

.bounds : Box3

请求的卷的世界空间范围内。如果为空（默认），则边界为 根据体素化场景计算。请参阅 VXGIVolume#worldBounds 了解 有效边界.

.boundsMinNode : UniformNode.<vec3>

体积的最小角点。

.directionalNode : Texture3DNode

VXGIVolume#directionalTexture 的纹理节点。在体积的重新分配中保持有效。

.directionalRadiance : boolean

是否对较粗的辐射级别进行定向过滤：沿着每个轴，越精细 体素使用其表面法线从前到后合成，因此圆锥体仅聚集 面向它的表面。这可以减少透过薄壁和地板的光线（例如， 阳光照射的地板照亮了下面房间的天花板），但需要额外的内存 以及更昂贵的辐射查找。更改它会触发重新体素化。

默认为 false.

.directionalTexture : Storage3DTexture

针对光线可以传播的六个方向定向过滤的较粗糙的辐射级别 (+x, -x, +y, -y, +z, -z)，仅使用 VXGIVolume#directionalRadiance 分配。每个 texel 保存面向该方向的表面的辐射亮度与其权重的预乘 (rgb) 和重量 (a);遮挡来自不透明度 MIP 链。六个方向 沿着 x 并排存储在一个半分辨率 mip 链中；卷的级别 n 是 其级别n - 1.

.directionalWidthNode : UniformNode.<float>

纹理像素中方向纹理的一个方向块的宽度（在其级别0）。

.layers : Layers

仅通过此层测试的网格体进行体素化。

.lightingNeedsUpdate : boolean

设置为true 在下次更新中重新注入照明。灯光和灯光的变化 注射参数会自动检测，因此很少需要。

默认为true.

.maxDistance : UniformNode.<float>

世界单位的最大锥体长度。 0 表示无界。

默认为0.

.maxLevelNode : UniformNode.<float>

体素纹理的最高有效 mip 级别。

.maxLights : number

注入体积的最大灯光数量。

默认为 8.

.minOpacity : number

不透明度较低的三角形不是体素化.

默认为0.1.

.needsUpdate : boolean

设置为true以在下次更新中重新体素化场景。

默认为true.

.opacityNode : Texture3DNode

VXGIVolume#opacityTexture的纹理节点。在体积的重新分配中保持有效。

.opacityTexture : Storage3DTexture

场景的每轴不透明度 (xyz) 和作为 mip 链的占用率 (w)。

.radianceNode : Texture3DNode

VXGIVolume#radianceTexture的纹理节点。在体积重新分配后仍然有效。

.radianceTexture : Storage3DTexture

场景的辐射度，包括缓存的反弹，预乘占用率，作为 mip 链。 使用 VXGIVolume#directionalRadiance 时，仅使用最精细的级别，而使用较粗糙的级别 级别位于 VXGIVolume#directionalTexture.

.resolution : number

沿边界最长轴的体素数量。不应超过 256，较高的值超过体素分析器的最大存储缓冲区大小。

默认为128.

.shadowConeAngle : UniformNode.<float>

向不提供 阴影贴图。较宽的锥体更便宜，但会软化注入的阴影。

默认为10.

.stepScale : UniformNode.<float>

相对于采样 mip 级别的纹素大小的步长。

默认为0.5.

.traceDistanceNode : Node.<float>

作为节点的有效最大锥体长度。

.volumeSizeNode : UniformNode.<vec3>

体积的大小。

.voxelSizeNode : UniformNode.<float>

a 的大小体素.

.worldBounds : Box3 (readonly)

体素网格的有效世界空间边界，在体素化时更新。

方法

.dispose()

释放内部resources.

.update( renderer : Renderer, scene : Scene )

如果需要，更新体积。设置 needsUpdate 时对场景进行体素化并重新注入 设置 lightingNeedsUpdate 或灯光发生变化时照明。

renderer

渲染器.
scene

场景.
