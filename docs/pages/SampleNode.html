EventDispatcher → Node →

SampleNode

表示使用提供的回调函数对值进行采样的节点的类。

构造函数

new SampleNode( callback : function, uvNode : Node.<vec2> )

创建 SampleNode 的实例。

callback

采样时调用的函数。应该接受一个 UV 节点并返回一个值。
uvNode

要在纹理采样中使用的 UV 节点。

默认为null.

属性

.isSampleNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.uvNode : Node.<(vec2|vec3)>

表示纹理坐标.

默认为null.

.type : string (readonly)

返回检查器节点的类型node.

方法

.sample( uv : Node.<vec2> ) : Node

使用提供的UV节点调用回调函数。

uv

要传递给回调的UV节点或值。
返回：回调函数的结果。

.setup() : Node

通过采样设置节点默认 UV 访问器。

覆盖： Node#setup
返回： 使用 UV 节点调用回调函数的结果。
