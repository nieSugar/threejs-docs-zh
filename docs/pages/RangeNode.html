RangeNode

RangeNode 在定义的范围内生成随机实例化属性数据。 该实用程序节点的一个示例性用例是生成随机的每个实例 color:

代码示例

const material = new MeshBasicNodeMaterial();
material.colorNode = range( new Color( 0x000000 ), new Color( 0xFFFFFF ) );
const mesh = new InstancedMesh( geometry, material, count );

构造函数

new RangeNode( minNode : Node.<any>, maxNode : Node.<any> )

构造一个新的范围节点。

minNode

定义范围下限的节点。

默认为float().
maxNode

定义范围上限的节点范围。

默认为float().

属性

.maxNode : Node.<any>

定义范围上限的节点范围。

默认为float().

.minNode : Node.<any>

定义范围下限的节点。

默认为float().

方法

.generateNodeType( builder : NodeBuilder ) : string

由于节点类型是从范围定义中推断出来的，因此该方法被覆盖。

builder

当前节点构建器.
覆盖： Node#generateNodeType
返回： 节点类型。

.getConstNode( node : Node ) : Node

通过遍历给定节点返回常量节点。

node

要返回的节点遍历.
返回：常量节点（如果找到）。

.getVectorLength( builder : NodeBuilder ) : number

返回根据范围定义计算的向量长度。

builder

当前节点构建器.
返回：向量长度.
