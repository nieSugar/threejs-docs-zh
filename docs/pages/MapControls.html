MapControls

此类旨在从鸟瞰角度在地图上转换相机。 该类与 OrbitControls 共享其实现，但使用特定的预设 用于鼠标/触摸交互并默认禁用屏幕空间平移。

  • 旋转：右键，或左键 + ctrl/meta/shift 键 / 触控：双指旋转。
  • 缩放：中键，或鼠标滚轮 / 触控：双指扩展或捏合。
  • 平移：左键，或方向键 / 触控：单指移动。

导入

MapControls 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { MapControls } from 'three/addons/controls/MapControls.js';

构造函数

new MapControls()

属性

.mouseButtons : Object

此对象包含对控件使用的鼠标操作的引用。

controls.mouseButtons = {
	LEFT: THREE.MOUSE.PAN,
	MIDDLE: THREE.MOUSE.DOLLY,
	RIGHT: THREE.MOUSE.ROTATE
}
覆盖： OrbitControls#mouseButtons

.screenSpacePanning : boolean

覆盖并设置为 false 以与世界空间方向正交平移 camera.up.

默认为 false.

覆盖： OrbitControls#screenSpacePanning

.touches : Object

此对象包含对控件使用的触摸操作。

controls.mouseButtons = {
	ONE: THREE.TOUCH.PAN,
	TWO: THREE.TOUCH.DOLLY_ROTATE
}
覆盖： OrbitControls#touches
