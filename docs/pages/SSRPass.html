SSRPass

基本 SSR 效果的通道。

代码示例

const ssrPass = new SSRPass( {
	renderer,
	scene,
	camera,
	width: innerWidth,
	height: innerHeight
} );
composer.addPass( ssrPass );

导入

SSRPass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { SSRPass } from 'three/addons/postprocessing/SSRPass.js';

构造函数

new SSRPass( options : SSRPass~Options )

构建新的SSR通道.

options

通道选项.

属性

.blur : boolean

是否模糊反射.

默认为true.

.bouncing : boolean

是否启用弹跳

默认为 false.

.camera : Camera

相机.

.clear : boolean

默认覆盖以执行清除操作。

默认为true.

覆盖： Pass#clear

.distanceAttenuation : boolean

是否使用距离衰减.

默认为true.

.fresnel : boolean

是否使用菲涅耳.

默认为true.

.groundReflector : ReflectorForSSRPass

地面反射镜.

默认为0.

.height : number

效果的高度.

默认为512.

.infiniteThick : boolean

是否使用无限厚度或不是.

默认为 false.

.maxDistance : number

控制片段可以反射多远.

默认为180.

.opacity : number

The不透明度.

默认为0.5.

.output : number

输出配置.

默认为0.

.renderer : WebGLRenderer

渲染器.

.resolutionScale : number

分辨率比例。有效值范围为 [0,1]。1 表示最佳质量，但也会导致更多的计算开销。设置为 0.5 表示效果以半分辨率计算。

默认为1.

.scene : Scene

要渲染的场景.

.selective : boolean

是否选择性通过.

默认为 false.

.selects : Array.<Object3D>

应该是哪些3D对象受SSR影响。如果未设置，整个场景都会受到影响。

默认为null.

.thickness : number

控制计数之间的截止 可能的反射命中，而什么则不然。

默认为 .018.

.width : number

效果的宽度.

默认为512.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行 SSR 传递。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize
