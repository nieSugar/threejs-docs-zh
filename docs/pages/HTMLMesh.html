HTMLMesh

此类可用于将 DOM 元素渲染到画布上并将其用作纹理 对于平面网格。

此类的典型用例是将 lil-gui 的 GUI 渲染为纹理，以便它 与 VR 兼容。

代码示例

const gui = new GUI( { width: 300 } ); // create lil-gui instance
const mesh = new HTMLMesh( gui.domElement );
scene.add( mesh );

导入

HTMLMesh 是一个插件，必须显式导入，请参阅Installation#Addons.

import { HTMLMesh } from 'three/addons/interactive/HTMLMesh.js';

构造函数

new HTMLMesh( dom : HTMLElement )

构造新的 HTML mesh.

dom

要显示为平面网格的 DOM 元素。

方法

.dispose()

释放此实例分配的 GPU 相关资源并删除所有事件侦听器。 只要您的应用程序中不再使用此实例，就调用此方法。

覆盖： Mesh#dispose
