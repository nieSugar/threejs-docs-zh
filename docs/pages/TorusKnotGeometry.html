TorusKnotGeometry

创建一个环面结，其特定形状由一对定义 互质整数 p 和 q。如果 p 和 q 不互质，则结果将 是一个环面链接。

代码示例

const geometry = new THREE.TorusKnotGeometry( 10, 3, 100, 16 );
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const torusKnot = new THREE.Mesh( geometry, material );
scene.add( torusKnot );

构造函数

new TorusKnotGeometry( radius : number, tube : number, tubularSegments : number, radialSegments : number, p : number, q : number )

构造一个新的环面结几何体。

radius

环面结的半径。

默认为1.
tube

管的半径。

默认为0.4.
tubularSegments

管状段数.

默认为64.
radialSegments

径向段数.

默认为 8.
p

该值确定几何体绕其旋转轴缠绕多少次对称性.

默认为2.
q

该值决定几何体在圆环内部绕一圈的次数。

默认为3.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : TorusKnotGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
