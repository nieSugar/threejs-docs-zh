ThreeMFLoader

3D 制造格式 (3MF) 格式的加载程序。

以下功能来自支持核心规范：

  • 3D 模型
  • 对象资源（网格和组件）
  • 材质资源（基础材质）

3MF 仅部分支持材质和属性扩展。

  • 二维纹理
  • 二维纹理组
  • 颜色组（顶点颜色）
  • 金属显示属性（PBR）
  • 梁状格栅

代码示例

const loader = new ThreeMFLoader();
const object = await loader.loadAsync( './models/3mf/truck.3mf' );
object.rotation.set( - Math.PI / 2, 0, 0 ); // z-up conversion
scene.add( object );

导入

ThreeMFLoader 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ThreeMFLoader } from 'three/addons/loaders/3MFLoader.js';

构造函数

new ThreeMFLoader( manager : LoadingManager )

构造一个新的 3MF 加载程序。

manager

加载管理器。

属性

.availableExtensions : Array.<Object>

一系列可用扩展。

方法

.addExtension( extension : Object )

添加 3MF 扩展。

extension

扩展add.

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的URL加载并传递加载的3MF资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( data : ArrayBuffer ) : Group

解析给定的 3MF 数据并返回结果组。

data

作为数组缓冲区的原始 3MF 资产数据。
覆盖： Loader#parse
返回：代表已解析资产的组.
