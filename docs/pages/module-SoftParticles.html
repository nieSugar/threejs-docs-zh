SoftParticles

导入

SoftParticles 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { softParticles } from 'three/addons/tsl/utils/SoftParticles.js';

静态方法

.softParticles( parameters : Object ) : Node.<float>

基于“软粒子”白色计算软粒子的不透明度节点 论文（NVIDIA、Tristan Lorach）.

parameters

配置参数.

默认为 {}.

opacity

精灵的基础不透明度，与软淡入淡出相乘。

默认为float(1).
distance

精灵在场景中淡出的世界空间距离。

默认为1.
contrast

淡入淡出曲线的对比度。 1 是线性的，较高的值会锐化过渡。

默认为2.
viewportDepth

粒子淡入淡出的不透明场景深度。

默认为viewportDepthTexture().
返回：要分配给 material.opacityNode.
