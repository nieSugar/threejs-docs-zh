ProjectorLight

SpotLight 的投影灯版本。只能与 WebGPURenderer 一起使用。

构造函数

new ProjectorLight( color : number | Color | string, intensity : number, distance : number, angle : number, penumbra : number, decay : number )

构造一个新的投影仪灯光。

color

灯光的颜色.

默认为0xffffff.
intensity

光的强度/强度以坎德拉（cd）为单位测量。

默认为1.
distance

光的最大范围。 0 表示无限制。

默认为0.
angle

光色散方向的最大角度，上限为Math.PI/2.

默认为Math.PI/3.
penumbra

由于半影而衰减的聚光锥百分比。值范围为[0,1].

默认为0.
decay

灯光沿距离的变暗量。

默认为2.

属性

.aspect : number

灯光的纵横比。设置为 null 以使用纹理纵横比。

默认为null.
