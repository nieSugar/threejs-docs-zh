ReferenceElementNode

仅当引用的属性类似于数组时，此类才相关。 在这种情况下，ReferenceElementNode 允许引用特定的 通过索引在数据结构内部的元素.

构造函数

new ReferenceElementNode( referenceNode : ReferenceBaseNode | ReferenceNode, indexNode : Node )

构造一个新的引用元素节点.

referenceNode

引用节点.
indexNode

定义元素访问的索引节点。

属性

.isReferenceElementNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.referenceNode : ReferenceBaseNode | ReferenceNode

与ReferenceNode#reference类似，附加一个 对当前节点的属性引用。

默认为null.

方法

.generateNodeType() : string

此方法被覆盖，因为节点类型是从 引用节点的统一类型。

覆盖： ArrayElementNode#generateNodeType
返回： 节点类型。
