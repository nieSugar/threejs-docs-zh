Water

基本的平坦、反射水效果。

注意，此类只能与WebGLRenderer一起使用。 使用 WebGPURenderer 时，请使用 WaterMesh.

参考：

  • Three.js 的平面镜
  • 基于平面镜的水着色器实现
  • WebGL 中的水着色器解释

导入

Water 是一个插件，必须显式导入，请参阅 安装#Addons.

import { Water } from 'three/addons/objects/Water.js';

构造函数

new Water( geometry : BufferGeometry, options : Water~Options )

构造一个新的水实例。

geometry

水的几何形状。
options

配置选项.

属性

.isWater : boolean (readonly)

该标志可用于类型测试。

默认为true.

类型定义

.Options

构造函数选项Water.

textureWidth
number

纹理宽度。值越高，反射越清晰，但成本也越高。

默认为512.
textureHeight
number

纹理高度。值越高，反射越清晰，但成本也越高。

默认为512.
clipBias
number

剪辑偏差。

默认为0.
alpha
number

alpha值.

默认为1.
time
number

时间值.

默认为0.
waterNormals
Texture

水的法线贴图.

默认为null.
sunDirection
Vector3

太阳方向.

默认为(0.70707,0.70707,0.0).
sunColor
number | Color | string

太阳色.

默认为0xffffff.
waterColor
number | Color | string

水彩色.

默认为0x7F7F7F.
eye
Vector3

眼睛向量。
distortionScale
number

畸变比例.

默认为20.
side
FrontSide | BackSide | DoubleSide

水材质的side属性.

默认为 FrontSide.
fog
boolean

水是否应该受到雾的影响.

默认为 false.
