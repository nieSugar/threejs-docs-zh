TextureNode

这种类型的统一节点表示 2D 纹理。

构造函数

new TextureNode( value : Texture, uvNode : Node.<(vec2|vec3)>, levelNode : Node.<int>, biasNode : Node.<float> )

构造一个新的纹理节点。

value

纹理.

默认为EmptyTexture.
uvNode

uv节点.

默认为null.
levelNode

级别节点.

默认为null.
biasNode

偏置节点.

默认为null.

属性

.biasNode : Node.<float>

表示在细节层次计算期间要应用的偏差。

默认为null.

.compareNode : Node.<float>

表示与纹理样本进行比较的参考值。

默认为null.

.depthNode : Node.<int>

使用纹理数组时，深度节点将层定义为select.

默认为null.

.gatherNode : Node.<int>

表示要收集的通道的可选索引常量。 它必须在 [0, 3] 范围内并且是编译时常量。

默认为null.

.gradNode : Array.<Node.<vec2>>

定义时，使用显式渐变对纹理进行采样。

默认为null.

.isTextureNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.levelNode : Node.<int>

表示应选择的 mip 级别。

默认为null.

.offsetNode : Node.<(ivec2|ivec3)>

表示应用于非标准化纹理的可选纹素偏移 采样纹理之前的坐标。

默认为null.

.referenceNode : Node

引用节点.

默认为null.

.sampler : boolean

是否应采样或获取纹理值。

默认为true.

.updateMatrix : boolean

是否应将 uv 变换矩阵 自动更新与否。使用setUpdateMatrix() 如果要更改属性的值。

默认为 false.

.updateType : string

默认情况下，不执行 update() 方法。取决于 是否应用 uv 变换矩阵和/或 FlipY，update() 针对每个对象执行。

中列出了可能的值，默认为'none'.

覆盖： UniformNode#updateType

.uvNode : Node.<(vec2|vec3)>

表示纹理坐标.

默认为null.

.value : Texture

纹理值。

覆盖： UniformNode#value
