PMREMGenerator

此类生成预过滤、Mipmapped 辐射环境贴图 (PMREM) 来自立方体贴图环境纹理。这允许不同级别的 根据材料粗糙度快速访问模糊。它被包装成一个 特殊的 CubeUV 格式允许我们执行自定义插值，以便 我们可以支持非线性格式，例如 RGBE。与传统的 mipmap 不同 链，它只会下降到 LOD_MIN 级别（上面），然后创建额外的 在相同 LOD_MIN 分辨率下进行更多过滤“mips”，与 更高的粗糙度水平。这样我们就可以保持分辨率顺利进行 插值漫射照明，同时限制采样计算。

预过滤使用GGX VNDF（可见正态分布函数） 基于“对可见法线的 GGX 分布进行采样”的重要性采样 （Heitz，2018）生成准确匹配 GGX BRDF 的环境地图 用于基于物理的基于图像的照明的材质渲染。

构造函数

new PMREMGenerator( renderer : WebGLRenderer )

构造一个新的 PMREM 生成器。

renderer

渲染器.

方法

.compileCubemapShader()

预编译立方体贴图着色器。您可以通过在期间调用此方法来获得更快的启动速度 纹理的网络获取以提高并发性。

.compileEquirectangularShader()

预编译等距柱状着色器。您可以通过在期间调用此方法来获得更快的启动速度 纹理的网络获取以提高并发性。

.dispose()

处理 PMREMGenerator 的内部内存。请注意，PMREMGenerator 是一个静态类， 因此您不需要多个 PMREMGenerator 对象。如果这样做，请调用 dispose() 其中一个将导致其他任何一个也变得不可用。

.fromCubemap( cubemap : Texture, renderTarget : WebGLRenderTarget ) : WebGLRenderTarget

从立方体贴图纹理生成 PMREM，可以是 LDR 或 HDR。理想的输入立方体大小是 256 x 256，因为这最匹配 具有 256 x 256 立方体贴图输出。支持的最小输入立方体 每个面的大小为 16 x 16。

cubemap

要转换的立方体贴图纹理。
renderTarget

要使用的渲染目标。

默认为null.
返回： 生成的 PMREM。

.fromEquirectangular( equirectangular : Texture, renderTarget : WebGLRenderTarget ) : WebGLRenderTarget

从等距矩形纹理，可以是 LDR 或 HDR。理想的输入图像大小是 1k (1024 x 512)，因为这最匹配 具有 256 x 256 立方体贴图输出。支持的最小输入图像尺寸 是 64 x 32.

equirectangular

要转换的等距柱状纹理。
renderTarget

要使用的渲染目标。

默认为null.
返回： 生成的 PMREM。

.fromScene( scene : Scene, sigma : number, near : number, far : number, options : Object ) : WebGLRenderTarget

从提供的场景生成 PMREM，这比使用 网络带宽较低时的图像。可选的 sigma 指定模糊半径 以弧度表示，在 PMREM 生成之前应用于场景。可选近 和远平面确保场景完整渲染。

scene

要捕获的场景。
sigma

以弧度为单位的模糊半径。

默认为0.
near

近平面距离。

默认为0.1.
far

远平面距离.

默认为100.
options

配置选项.

默认为 {}.

size

PMREM的纹理大小.

默认为256.
position

渲染场景的内部立方体相机的位置.

默认为origin.
返回： 生成的 PMREM。
