LOD

用于提供基本细节层次（LOD）机制的组件。

每个LOD级别都与一个对象关联，并且可以切换渲染 它们之间按指定的距离。通常你会创建，比如说， 三种网格，一种用于远距离（低细节），一种用于中距离（中等 细节）和特写（高细节）。

代码示例

const lod = new THREE.LOD();
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
//Create spheres with 3 levels of detail and create new LOD levels for them
for( let i = 0; i < 3; i++ ) {
	const geometry = new THREE.IcosahedronGeometry( 10, 3 - i );
	const mesh = new THREE.Mesh( geometry, material );
	lod.addLevel( mesh, i * 75 );
}
scene.add( lod );

构造函数

new LOD()

构造一个新的 LOD。

属性

.autoUpdate : boolean

LOD 对象是否由渲染器每帧自动更新。 如果设置为 false，你必须在渲染循环中自行调用 LOD#update。

默认为true.

.isLOD : boolean (readonly)

该标志可用于类型测试。

默认为true.

.levels : Array.<{object:Object3D, distance:number, hysteresis:number}>

此数组保存 LOD 级别。

方法

.addLevel( object : Object3D, distance : number, hysteresis : number ) : LOD

添加将在一定距离及更大距离处显示的网格。通常 距离越远，网格上的细节越少。

object

在此级别显示的 3D 对象。
distance

显示此细节级别的距离。

默认为0.
hysteresis

用于避免在 LOD 边界闪烁的阈值，作为距离.

默认为0.
返回：对此实例的引用。

.getCurrentLevel() : number

返回当前活动的LOD级别索引。

返回：当前活动的LOD级别索引。

.getObjectForDistance( distance : number ) : Object3D

返回对第一个大于的 3D 对象的引用 给定距离.

distance

LOD距离.
返回：找到的3D对象。 null 如果未找到 3D 对象。

.raycast( raycaster : Raycaster, intersects : Array.<Object> )

计算投射光线与此 LOD 之间的交点。

raycaster

The raycaster.
intersects

保存交点的目标数组。
覆盖： Object3D#raycast

.removeLevel( distance : number ) : boolean

根据距摄像机的距离删除现有关卡。 当关卡被移除时，返回 true。否则 false.

distance

要删除的级别的距离。
返回： 级别是否已删除。

.update( camera : Camera )

通过计算哪个 LOD 级别应可见来更新 LOD 到给定相机的当前距离.

camera

渲染场景的相机。
