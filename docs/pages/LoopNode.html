LoopNode

此模块提供了多种在 TSL 中实现循环的方法。它的基本形式是：

Loop( count, ( { i } ) => {
} );

但是，也可以定义开始和结束范围、数据类型和循环条件：

Loop( { start: int( 0 ), end: int( 10 ), type: 'int', condition: '<' }, ( { i } ) => {
} );

嵌套循环可以以压缩形式定义：

Loop( 10, 5, ( { i, j } ) => {
} );

应该向后运行的循环可以定义为so:

Loop( { start: 10 }, () => {} );

可以用布尔值执行，类似于while语法。

const value = float( 0 ).toVar();
Loop( value.lessThan( 10 ), () => {
	value.addAssign( 1 );
} );

模块还提供Break()和Continue()循环的TSL表达式control.

构造函数

new LoopNode( params : Array.<(LoopNode~Params|loopBodyCallback)> )

构造一个新的循环节点。

params

循环体后跟任意数量的循环参数。

方法

.getProperties( builder : NodeBuilder ) : Object

返回有关此节点的属性。

builder

当前节点构建器.
返回：节点properties.

.getVarName( index : number ) : string

返回基于索引的循环变量名称。模式是 0 = i, 1= j, 2= k 等等on.

index

索引.
返回： 循环变量名称。

类型定义

.ObjectParams

详细的循环配置。

start
number | Node.<int> | Node.<uint>

循环变量的初始值。

默认为0.
end
number | Node.<int> | Node.<uint>

循环变量的比较值。如果省略，则循环从 start - 1 递减计数到 0.
name
string

循环变量的名称。默认为i、j、k等。
type
string

循环变量的数据类型。

默认为'int'.
condition
'<' | '<=' | '>' | '>='

比较运算符。只要比较为真，循环就会运行。如果未设置，则从 start 和 end 推断。
update
string | number | function | Node

定义循环变量在每次迭代后如何更新。如果未设置，则从 condition 和 type 推断出

.Params

循环的参数。数字或 int/uint 节点定义循环的结束值， bool 节点定义 while 循环，对象允许更详细的配置。
