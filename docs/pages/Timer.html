Timer

此类是 Clock 的替代品，具有不同的 API 设计和行为。 目标是避免随着时间的推移在 Clock 中变得明显的概念缺陷。

  • Timer 有一个 update() 方法，可以更新其内部状态。这使得可以在每个仿真步骤中多次调用 getDelta() 和 getElapsed() 而不会得到不同的值。
  • 该类可以利用页面可见性 API 来避免应用程序不活跃时（例如切换标签页或浏览器隐藏）出现较大的时间增量值。

代码示例

const timer = new Timer();
timer.connect( document ); // use Page Visibility API

构造函数

new Timer()

构造一个新计时器。

方法

.connect( document : Document )

将计时器连接到给定文档。调用此方法不是强制的 使用计时器，但启用页面可见性 API 以避免长时间使用 增量值.

document

文档.

.disconnect()

断开计时器与DOM的连接，并禁用页面可见性API的使用。

.dispose()

可用于释放所有内部资源。通常在以下时间调用 不再需要计时器实例。

.getDelta() : number

返回以秒为单位的时间增量。

返回：以秒为单位的时间增量。

.getElapsed() : number

返回以秒为单位的经过时间。

返回：经过的时间第二.

.getTimescale() : number

返回时间刻度。

返回：时间刻度。

.reset() : Timer

重置当前模拟步骤的时间计算。

返回：对此的引用timer.

.setTimescale( timescale : number ) : Timer

设置给定的时间刻度，用于缩放时间增量计算 在update().

timescale

要设置的时间刻度。
返回：对此的引用timer.

.update( timestamp : number ) : Timer

更新定时器的内部状态。这个方法应该被调用 每个模拟步骤一次并且在对计时器执行查询之前 （例如通过getDelta()）.

timestamp

当前时间（以毫秒为单位）。可以获得 来自 requestAnimationFrame 回调参数。如果未提供，则当前 时间将由 performance.now.
返回：对此的引用timer.
