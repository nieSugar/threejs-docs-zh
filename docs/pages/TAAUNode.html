TAAUNode

执行临时抗锯齿放大 (TAAU) 的特殊节点。

与 TRAA 类似，该节点在多个帧上累积抖动样本， 用运动向量重新投影历史。与 TRAA 不同，输入缓冲区 （美感、深度、速度）预计将以较低的分辨率渲染 比渲染器的绘图缓冲区 - 通常通过降低上游 通过 PassNode#setResolutionScale 的决议 — 以及决议 pass 使用 9-tap Blackman-Harris 重建输出分辨率图像 对抖动的输入样本进行过滤（高斯近似）。结果 是 FSR2/3 的替代方案，可在 single pass.

参考：

  • Karis，"高质量时间超采样"，SIGGRAPH 2014，https://advances.realtimerendering.com/s2014/
  • Riley/Arcila，FidelityFX 超分辨率 2，GDC 2022，https://gpuopen.com/download/GDC_FidelityFX_Super_Resolution_2_0.pdf

注意：使用 TAAU 时必须禁用 MSAA。

导入

TAAUNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { taau } from 'three/addons/tsl/display/TAAUNode.js';

构造函数

new TAAUNode( beautyNode : TextureNode, depthNode : TextureNode, velocityNode : TextureNode, camera : Camera )

构造一个新的TAAU节点。

beautyNode

代表输入的纹理节点效果.
depthNode

表示场景深度的节点。
velocityNode

表示场景速度的节点。
camera

渲染场景的相机。

属性

.beautyNode : TextureNode

代表输入的纹理节点效果.

.camera : Camera

渲染场景的相机。

.currentFrameWeight : number

应用于解析中当前帧的基线权重。较低 值会产生更平滑的结果，累积时间较长但速度较慢 排除区域的收敛；添加运动因子 顶部，因此快速移动的像素仍然可以快速响应。

默认为0.025.

.depthNode : TextureNode

表示场景深度的节点。

.depthThreshold : number

当当前和先前深度之间的差异超过此阈值时， 历史记录被视为无效。

默认为 0.0005.

.edgeDepthDiff : number

将像素视为边缘的 3×3 邻域内的深度差。

默认为0.001.

.isTAAUNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.maxVelocityLength : number

当速度的像素长度接近此值时，历史记录将变得无效value.

默认为128.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.velocityNode : TextureNode

表示场景速度的节点。

方法

.clearViewOffset()

清除场景相机的视图偏移。

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( outputWidth : number, outputHeight : number )

设置效果的输出大小（历史和解析目标）。的 前一个深度纹理在 updateBefore() 中独立调整大小 跟踪场景的当前深度纹理。

outputWidth

输出宽度（绘图缓冲区宽度）。
outputHeight

输出高度（绘图缓冲区高度）。

.setViewOffset( inputWidth : number, inputHeight : number )

将 TAAU 的当前抖动定义为相对于场景的视图偏移 相机。抖动被缩小到一个输出像素（而不是一个 输入像素），以便halton序列逐渐填充输出 多个帧上的子像素网格。

inputWidth

相机渲染到的输入缓冲区的宽度。
inputHeight

相机渲染到的输入缓冲区的高度。

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的渲染目标和 TSL代码.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
