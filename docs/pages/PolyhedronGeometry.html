PolyhedronGeometry

多面体是具有平面的三维立体。本班 将获取一系列顶点，将它们投影到球体上，然后 将它们划分到所需的细节级别。

构造函数

new PolyhedronGeometry( vertices : Array.<number>, indices : Array.<number>, radius : number, detail : number )

构造一个新的多面体几何形状。

vertices

描述基本形状的顶点的平面数组。
indices

描述基本形状的索引的平面数组。
radius

几何体的半径shape.

默认为1.
detail

几何体细分多少级。细节越多，形状越平滑。

默认为0.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : PolyhedronGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
