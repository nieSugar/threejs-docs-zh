ArrayCamera

这种类型的相机可用于有效地渲染场景 预定义的摄像机组。这是一个重要的性能方面 渲染 VR 场景。

ArrayCamera 的实例始终具有一组子摄像机。这是强制性的 为每个子摄像机定义 viewport 属性，该属性确定 使用此相机渲染的视口的一部分。

构造函数

new ArrayCamera( array : Array.<PerspectiveCamera> )

构造一个新的阵列相机。

array

透视子相机的数组。

默认为[].

属性

.cameras : Array.<PerspectiveCamera>

透视子相机的数组。

.isArrayCamera : boolean (readonly)

该标志可用于类型测试。

默认为true.

.isMultiViewCamera : boolean (readonly)

该相机是否用于多视图渲染.

默认为 false.
