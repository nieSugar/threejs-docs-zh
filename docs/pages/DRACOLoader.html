DRACOLoader

Draco 格式的加载器。

Draco 是一个开源库压缩 以及解压缩 3D 网格和点云。压缩后的几何体可以明显更小， 以客户端设备上额外的解码时间为代价。

独立的 Draco 文件具有 .drc 扩展名，并包含顶点位置、法线、颜色、 和其他属性。 Draco 文件不包含材质、纹理、动画或节点层次结构 – 要使用这些功能，请将 Draco 几何体嵌入到 glTF 文件中。可以转换普通的glTF文件 使用 glTF-Pipeline 到 Draco 压缩的 glTF 文件。 当Draco与glTF一起使用时，DRACOLoader的实例将被GLTFLoader内部使用。

建议创建一个DRACOLoader实例并重复使用，以避免加载和创建 多个解码器实例。

DRACOLoader 将自动使用 JS 或 WASM 解码库，基于 浏览器功能。

代码示例

const loader = new DRACOLoader();
const geometry = await loader.loadAsync( 'models/draco/bunny.drc' );
geometry.computeVertexNormals(); // optional
loader.dispose();

导入

DRACOLoader 是一个插件，必须显式导入，请参阅Installation#Addons.

import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';

构造函数

new DRACOLoader( manager : LoadingManager )

构造一个新的 Draco loader.

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的 URL 加载并传递加载的 Draco 资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( buffer : ArrayBuffer, onLoad : function, onError : onErrorCallback )

解析给定的 Draco 数据。

buffer

原始 Draco 数据作为数组缓冲区。
onLoad

在加载/解析过程完成时执行完成.
onError

发生错误时执行。
覆盖： Loader#parse

.setDecoderConfig( config : Object ) : DRACOLoader

提供解码器库的配置。解码开始后无法更改配置。

config

解码器配置。
已弃用： 是
返回：对此加载程序的引用。

.setDecoderPath( path : string | Object ) : DRACOLoader

提供解码器库的配置。解码开始后无法更改配置。

path

解码器路径，或每个解码器具有显式 URL 的配置对象file.
返回：对此加载程序的引用。

.setWorkerLimit( workerLimit : number ) : DRACOLoader

设置解码期间要使用的 Web Worker 的最大数量。 如果工作人员还用于应用程序中的其他任务，则较低的限制可能更好。

workerLimit

工作人员限制.
返回：对此加载程序的引用。
