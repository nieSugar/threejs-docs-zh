TeapotGeometry

将 Martin Newell 著名的犹他州茶壶数据库镶嵌成三角形。

茶壶通常应呈现为双面对象，因为对于某些 两侧的补丁都可以看到，例如，盖子周围和喷嘴内部的间隙。

段“n”决定了三角形输出的数量。三角形总数 = 322nn - 8n （顶部和底部尖点的退化被删除）.

基于SPD软件的代码 为 Udacity 课程创建交互式渲染

代码示例

const geometry = new TeapotGeometry( 50, 18 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const teapot = new THREE.Mesh( geometry, material );
scene.add( teapot );

导入

TeapotGeometry 是一个插件，必须显式导入，请参阅安装#Addons.

import { TeapotGeometry } from 'three/addons/geometries/TeapotGeometry.js';

构造函数

new TeapotGeometry( size : number, segments : number, bottom : boolean, lid : boolean, body : boolean, fitLid : boolean, blinn : boolean )

构造一个新的茶壶几何体。

size

茶壶的相对比例。

默认为50.
segments

细分每个面片边缘的线段数。

默认为10.
bottom

是否底部

默认为true.
lid

壶盖是否生成。

默认为true.
body

壶身是否生成。

默认为true.
fitLid

壶盖是否轻微拉伸，防止壶身与壶盖之间出现缝隙。

默认为true.
blinn

是否生成壶身。茶壶垂直缩放是否美观。

默认为true.
