RotateNode

对给定位置节点应用旋转。

构造函数

new RotateNode( positionNode : Node, rotationNode : Node, order : string )

构造一个新的旋转节点。

positionNode

位置node.
rotationNode

表示应用于位置节点的旋转。取决于 无论位置数据是 2D 还是 3D，旋转都表示为单个浮点值或欧拉值。
order

欧拉旋转顺序。仅用于 3D 旋转。

默认为'XYZ'.

属性

.positionNode : Node

位置node.

.rotationNode : Node

表示应用于位置节点的旋转。 根据位置数据是 2D 还是 3D，旋转表示为单个浮点值或欧拉值。

方法

.customCacheKey() : number

通过包含以下内容覆盖默认的 customCacheKey() 实现 Euler 顺序写入缓存键。

覆盖： TempNode#customCacheKey
返回： 哈希值.

.generateNodeType( builder : NodeBuilder ) : string

RotateNode#positionNode 的类型定义节点的type.

builder

当前节点构建器.
覆盖： TempNode#generateNodeType
返回值： 节点类型。

.getOrder() : string

获取欧拉旋转顺序。

返回值： 欧拉旋转顺序。

.setOrder( value : string ) : RotateNode

设置欧拉旋转顺序order.

value

欧拉旋转顺序.
返回：对此节点的引用.
