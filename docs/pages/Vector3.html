Vector3

表示 3D 矢量的类。 3D 向量是有序的三元组数字 （标记为x、y和z），可以用来表示很多东西，比如：

  • 3D 空间中的点.
  • 三维空间中的方向和长度。在 three.js 中，长度始终是从 (0, 0, 0) 到 (x, y, z) 的欧几里得距离（直线距离），方向也从 (0, 0, 0) 指向 (x, y, z)。
  • 任意有序的三元数。

3D向量还可以用来表示其他东西，比如 动量向量等等，但是这些是最重要的 Three.js 中的常见用途.

迭代向量实例将产生其组件 (x, y, z) 相应的顺序。

代码示例

const a = new THREE.Vector3( 0, 1, 0 );
//no arguments; will be initialised to (0, 0, 0)
const b = new THREE.Vector3( );
const d = a.distanceTo( b );
