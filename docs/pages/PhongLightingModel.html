PhongLightingModel

表示 phong 材质的光照模型。用于MeshPhongNodeMaterial.

构造函数

new PhongLightingModel( specular : boolean )

构造新的phong光照模型.

specular

是否支持镜面反射.

默认为true.

属性

.specular : boolean

是否支持镜面反射。如果您是，请将其设置为 false 寻找类似兰伯特的材料，即无光泽的材料 表面，没有镜面高光。

默认为true.

方法

.direct( lightData : Object )

实现直接照明。镜面部分是可选的并且可以控制 带有 PhongLightingModel#specular 标志。

lightData

灯光数据。
覆盖： BasicLightingModel#direct

.indirect( builder : NodeBuilder )

实现间接照明。

builder

当前节点构建器.
覆盖： BasicLightingModel#indirect
