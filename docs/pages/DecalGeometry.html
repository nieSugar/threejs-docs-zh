DecalGeometry

此类可用于创建具有不同用途的贴花网格，例如 向模型添加独特的细节、执行动态视觉环境变化或覆盖接缝。

请注意，在拐角处使用时贴花投影可能会变形。更多信息请访问 此 GitHub 问题：无扭曲的贴花投影.

参考：如何投影贴花

代码示例

const geometry = new DecalGeometry( mesh, position, orientation, size );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );

导入

DecalGeometry 是一个插件，必须显式导入，请参阅安装#Addons.

import { DecalGeometry } from 'three/addons/geometries/DecalGeometry.js';

构造函数

new DecalGeometry( mesh : Mesh, position : Vector3, orientation : Euler, size : Vector3 )

构造新的贴花几何体。

mesh

贴花应投影到的基础网格物体。
position

贴花投影仪的位置。
orientation

贴花的方向投影仪.
size

贴花投影仪的比例.
