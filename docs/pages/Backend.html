Backend

大部分渲染相关逻辑都在 Renderer 模块及相关管理组件。 有时需要执行以下命令 特定于当前的 3D 后端（WebGPU 或 WebGL 2）。 这个抽象基类定义了一个封装了接口 所有与后端相关的逻辑。每个后端的派生类必须 实现接口。

构造函数

new Backend( parameters : Object ) (abstract)

构造一个新的后端。

parameters

保存后端参数的对象。

属性

.coordinateSystem : number (abstract, readonly)

后端的坐标系。

.data : WeakMap.<Object, Object>

这个弱映射保存对象的后端特定数据 例如纹理、属性或渲染目标。

.domElement : HTMLCanvasElement | OffscreenCanvas

对渲染器正在绘制的画布元素的引用。

默认为null.

.hasTimestamp : boolean (readonly)

后端是否支持查询时间戳。

.parameters : Object

后端的参数。

.renderer : Renderer

对渲染器.

默认为null.

.timestampQueryPool : Object

对时间戳查询池的引用。

.trackTimestamp : boolean

是否使用时间戳查询 API 跟踪时间戳。

默认为 false.

方法

返回给定 uid 的查询池。

uid

唯一标识符.
返回：查询池。
