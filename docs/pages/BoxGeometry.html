BoxGeometry

具有给定宽度、高度和深度的矩形长方体的几何类。 创建时，长方体以原点为中心，每条边平行于一个 轴的数量。

代码示例

const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const cube = new THREE.Mesh( geometry, material );
scene.add( cube );

构造函数

new BoxGeometry( width : number, height : number, depth : number, widthSegments : number, heightSegments : number, depthSegments : number )

构造一个新的盒子几何形状。

width

宽度。即平行于X轴的边的长度

默认为1.
height

高度。即平行于Y轴的边的长度。

默认为1.
depth

深度。即，平行于 Z 轴的边的长度。

默认为1.
widthSegments

沿边宽度的分段矩形面的数量。

默认为1.
heightSegments

沿边高度的分段矩形面的数量。

默认为1.
depthSegments

沿边深度的分段矩形面的数量。 side.

默认为1.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : BoxGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
