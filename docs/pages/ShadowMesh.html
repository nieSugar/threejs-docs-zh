ShadowMesh

跟随场景中阴影投射网格的阴影网格， 但仅限于单个平面。该技术可用作 经典阴影贴图的高性能替代品。然而， 它有严重的限制，例如：

  • 阴影只能投射在平面上。
  • 不支持软阴影。

代码示例

const cubeShadow = new ShadowMesh( cube );
scene.add( cubeShadow );

导入

ShadowMesh 是一个插件，必须显式导入，请参阅Installation#Addons.

import { ShadowMesh } from 'three/addons/objects/ShadowMesh.js';

构造函数

new ShadowMesh( mesh : Mesh )

构造一个新的阴影网格物体.

mesh

阴影投射参考网格物体.

属性

.frustumCulled : boolean

覆盖以默认禁用视锥体剔除。

默认为 false.

覆盖： Mesh#frustumCulled

.isShadowMesh : boolean (readonly)

该标志可用于类型测试。

默认为true.

.matrixAutoUpdate : boolean

覆盖以禁用自动矩阵更新。当地的 矩阵在 ShadowMesh#update 中手动计算。

默认为 false.

覆盖： Mesh#matrixAutoUpdate

.meshMatrix : Matrix4

表示参考网格体的世界矩阵。

方法

.update( plane : Plane, lightPosition4D : Vector4 )

更新阴影网格体，以便它遵循其阴影投射参考网格。

plane

投影到阴影网格上的平面。
lightPosition4D

灯光位置。
