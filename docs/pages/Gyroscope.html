Gyroscope

一种特殊类型的 3D 对象，它从场景图层次结构中获取位置 但使用其局部旋转作为世界旋转。它的工作原理就像现实世界的陀螺仪 - 您可以使用层次结构来移动它，同时它的方向保持固定 尊重世界。

导入

Gyroscope 是一个插件，必须显式导入，请参阅Installation#Addons.

import { Gyroscope } from 'three/addons/misc/Gyroscope.js';

构造函数

new Gyroscope()

构造一个新的陀螺仪.
