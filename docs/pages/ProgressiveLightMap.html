ProgressiveLightMap

Progressive Light Map Accumulator，由 zalo 提供。

要使用，只需构造一个ProgressiveLightMap 对象， plmap.addObjectsToLightMap(object) 半静态数组 对象和灯光一次添加到类中，然后调用 plmap.update(camera) 每帧开始累积 照明样本.

这应该开始累积适用于的光照贴图 你的物体，这样你就可以开始抖动照明来实现 您正在寻找的纹理空间效果。

此类只能与WebGLRenderer一起使用。 使用WebGPURenderer时，从ProgressiveLightMapGPU.js.

导入

ProgressiveLightMap导入是一个插件，必须显式导入，请参见Installation#Addons.

import { ProgressiveLightMap } from 'three/addons/misc/ProgressiveLightMap.js';

构造函数

new ProgressiveLightMap( renderer : WebGLRenderer, res : number )

构造一个新的渐进光照贴图。

renderer

渲染器.
res

总光照贴图的边长尺寸。

默认为1024.

属性

.renderer : WebGLRenderer

渲染器.

.res : number

总光照贴图的边长尺寸。

默认为1024.

方法

.addObjectsToLightMap( objects : Array.<Object3D> )

设置这些对象的材质光照贴图并修改其uv1 的.

objects

用于设置光照贴图的对象和灯光数组。

.dispose()

释放所有内部资源。

.showDebugLightmap( visible : boolean, position : Vector3 )

在主场景中绘制光照贴图。添加对象后调用此函数。

visible

调试平面是否可见
position

调试平面应绘制在哪里

.update( camera : Camera, blendWindow : number, blurEdges : boolean )

此函数一次将每个网格渲染到各自的表面贴图中。

camera

渲染场景的相机。
blendWindow

当 >1 时，样本将累积超过time.

默认为100.
blurEdges

是否通过模糊修复UV边缘.

默认为true.
