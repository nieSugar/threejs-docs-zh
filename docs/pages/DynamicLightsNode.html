DynamicLightsNode

LightsNode 的自定义版本，可将受支持的分析灯批量化为 统一数组和循环。

不支持的灯光、节点灯光、阴影投射灯光和投影点 灯光保留默认的每灯光路径。

导入

DynamicLightsNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { DynamicLightsNode } from 'three/addons/tsl/lighting/DynamicLightsNode.js';

构造函数

new DynamicLightsNode( options : Object )

构造一个新的动态灯光节点.

options

动态光照配置。

默认为 {}.

maxDirectionalLights

批量定向光源最大数量。

默认为 8.
maxPointLights

批量最大点数量灯.

默认为16.
maxSpotLights

批量聚光灯最大数量.

默认为16.
maxHemisphereLights

批量半球最大数量灯光.

默认为4.
