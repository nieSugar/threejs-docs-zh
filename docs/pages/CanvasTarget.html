CanvasTarget

CanvasTarget 是一个表示渲染器最终输出目标的类。

构造函数

new CanvasTarget( domElement : HTMLCanvasElement | OffscreenCanvas )

构造一个新的 CanvasTarget。

domElement

要渲染的画布元素to.

属性

.colorTexture : FramebufferTexture

默认帧缓冲区的颜色纹理。

.depthTexture : DepthTexture

默认帧缓冲区的深度纹理。

.domElement : HTMLCanvasElement | OffscreenCanvas

对渲染器正在绘制的画布元素的引用。 该属性的值将自动创建 渲染器.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

Fires:
  • RenderTarget#event:dispose

target

.getPixelRatio() : number

返回像素比率。

返回剪刀矩形.

target

该方法将结果写入此目标对象。
返回值： 剪刀矩形.

返回剪刀测试值.

.getSize( target : Vector2 ) : Vector2

返回渲染器的逻辑像素大小。此方法不支持像素比率。

target

该方法将结果写入此目标对象。
返回：渲染器的逻辑像素大小。

.getViewport( target : Vector4 ) : Vector4

返回视口定义。

target

该方法将结果写入此目标对象。
返回：视口

.setDrawingBufferSize( width : number, height : number, pixelRatio : number )

此方法允许通过指定来定义绘图缓冲区大小 宽度、高度和像素比同时显示。图纸尺寸 缓冲区使用以下公式计算：

size.x = width * pixelRatio;
size.y = height * pixelRatio;
width

以逻辑像素为单位的宽度。
height

以逻辑像素为单位的高度。
pixelRatio

像素比率。

.setPixelRatio( value : number )

设置给定的像素比率并调整画布大小，如果必要的。

value

像素比率。

默认为1.

.setScissor( x : number | Vector4, y : number, width : number, height : number )

定义剪刀矩形。

x

以逻辑像素为单位的框左下角的水平坐标。 该方法不传递四个参数，而是使用单个四维向量。
y

以逻辑像素为单位的框左下角的垂直坐标。
width

以逻辑像素为单位的剪刀框的宽度。
height

以逻辑像素为单位的剪刀框的高度单位.

.setScissorTest( boolean : boolean )

定义剪刀测试.

boolean

是否启用剪刀测试.

.setSize( width : number, height : number, updateStyle : boolean )

设置渲染器的大小.

width

以逻辑像素为单位的宽度。
height

以逻辑像素为单位的高度。
updateStyle

是否更新画布的style属性.

默认为true.

.setViewport( x : number | Vector4, y : number, width : number, height : number, minDepth : number, maxDepth : number )

定义视口.

x

水平坐标以逻辑像素为单位的视口原点左下角。
y

以逻辑像素为单位的视口原点左下角的垂直坐标。
width

以逻辑像素为单位的视口宽度。
height

以逻辑像素为单位的视口高度单位.
minDepth

视口的最小深度值。仅限 WebGPU。

默认为0.
maxDepth

视口的最大深度值。仅限 WebGPU.

默认为1.
