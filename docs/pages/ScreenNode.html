ScreenNode

此节点提供屏幕相关指标的集合。 根据ScreenNode#scope，节点可以表示 分辨率或视口数据以及片段或 uv 坐标。

构造函数

new ScreenNode( scope : 'coordinate' | 'viewport' | 'size' | 'uv' )

构造一个新的屏幕节点。

scope

节点的范围。

属性

.isViewportNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.scope : 'coordinate' | 'viewport' | 'size' | 'uv'

根据选择的范围，节点表示不同的度量。

  • ScreenNode.COORDINATE: 根据 WebGPU 标准的当前片段相对于窗口的坐标。
  • ScreenNode.VIEWPORT: 当前视口定义为一个四维向量。
  • ScreenNode.SIZE: 当前绑定的帧缓冲区的尺寸。
  • ScreenNode.UV: 归一化坐标。

方法

.generateNodeType() : 'vec2' | 'vec4'

自节点以来该方法被覆盖类型取决于所选范围。

覆盖： Node#generateNodeType
返回： 节点类型。

.update( frame : NodeFrame )

ScreenNode 实现 Node#update 来检索视口和大小信息 从当前渲染器.

frame

对当前节点框架的引用。
覆盖： Node#update
