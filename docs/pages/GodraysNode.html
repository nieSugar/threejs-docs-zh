GodraysNode

用于将屏幕空间光线行进的神光应用于场景的后处理节点。

计算神光后，建议应用双边 对结果进行模糊处理，以减轻光线行进和噪声伪影。

场景通道的合成最好使用 depthAwareBlend() 完成， 减轻锯齿和漏光。

限制：

  • 目前仅支持点光源和方向光源。
  • 该效果需要完整的阴影设置。意味着渲染器中必须启用阴影，3D 对象必须投射并接收阴影，并且主光源必须投射阴影。

参考：此节点是 tri-good-godrays.

代码示例

const godraysPass = godrays( scenePassDepth, camera, light );
const blurPass = bilateralBlur( godraysPassColor ); // optional blur
const outputBlurred = depthAwareBlend( scenePassColor, blurPassColor, scenePassDepth, camera, { blendColor, edgeRadius, edgeStrength } ); // composite

导入

GodraysNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { godrays } from 'three/addons/tsl/display/GodraysNode.js';

构造函数

new GodraysNode( depthNode : TextureNode, camera : Camera, light : DirectionalLight | PointLight )

构造一个新的 Godrays 节点。

depthNode

代表场景深度的纹理节点。
camera

渲染场景的相机。
light

Godrays 渲染的光线。

属性

.density : UniformNode.<float>

为神光积累。 较高的值大致等于更潮湿的空气/更浓的雾。

默认为 0.7.

.depthNode : TextureNode

代表美丽通道深度的节点。

.distanceAttenuation : UniformNode.<float>

较高的值会减少神光的累积，距离越远光源.

默认为2.

.maxDensity : UniformNode.<float>

神光的最大密度。 限制神光的最大亮度。

默认为0.5.

.raymarchSteps : UniformNode.<uint>

光线行进步数

默认为60.

.resolutionScale : number

分辨率比例。

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
