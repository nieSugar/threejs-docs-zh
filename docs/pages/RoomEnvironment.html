RoomEnvironment

此类表示具有基本房间设置的场景，可用作 输入 PMREMGenerator#fromScene。生成的 PMREM 代表房间的 照明，可通过将其分配给 Scene#environment 来用于基于图像的照明 或者直接作为 PBR 材质的环境贴图。

实现基于 EnvironmentScene 来自 model-viewer 项目的组件。

代码示例

const environment = new RoomEnvironment();
const pmremGenerator = new THREE.PMREMGenerator( renderer );
const envMap = pmremGenerator.fromScene( environment ).texture;
scene.environment = envMap;

导入

RoomEnvironment 是一个插件，必须显式导入，请参阅 安装#Addons.

import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';

构造函数

new RoomEnvironment()

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要环境时。

覆盖： Scene#dispose
