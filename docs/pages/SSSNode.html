SSSNode

用于将屏幕空间阴影 (SSS) 应用到scene.

屏幕空间阴影（也称为接触阴影）理想情况下应用于补充 传统的阴影贴图。它们最适合渲染较小的细节阴影 更接近尺度的物体，例如高度详细的模型上的复杂阴影。换句话说： 使用阴影贴图作为基础，使用屏幕空间阴影作为细节。

对于某些用例，此实现生成的阴影可能具有太硬的边缘。 使用框、高斯或散列模糊来柔化边缘，然后再使用 美丽通道。代码示例：

限制：

  • 理想情况下，最大阴影长度不应超过 1 米。否则，由于在光线行进过程中评估的样本增多，效果在计算上会变得非常昂贵。你可以通过减少 quality 参数来缓解这个问题。
  • 该效果只能与单向光源一起使用，即场景的主光源。主光通常代表太阳或日光。
  • 像其他屏幕空间技术一样，SSS 只能计算当前在相机视野中可见的对象的阴影。

参考：

  • https://panoskarabelas.com/posts/screen_space_shadows/.
  • https://www.bendstudio.com/blog/inside-bend-screen-space-shadows/.

代码示例

const sssPass = sss( scenePassDepth, camera, mainLight );
const sssBlur = boxBlur( sssPass.r, { size: 2, separation: 1 } ); // optional blur

导入

SSSNode是一个插件，必须显式导入，参见Installation#Addons.

import { sss } from 'three/addons/tsl/display/SSSNode.js';

构造函数

new SSSNode( depthNode : TextureNode, camera : Camera, mainLight : DirectionalLight )

构造一个新的SSS节点.

depthNode

代表场景深度的纹理节点。
camera

渲染场景的相机。
mainLight

场景的主要方向光.

属性

.depthNode : TextureNode

代表美丽通道深度的节点。

.maxDistance : UniformNode.<float>

世界单位的最大阴影长度。较长的阴影会导致更多的计算 开销.

默认为0.1.

.quality : UniformNode.<float>

此参数控制光线行进过程的详细程度。 值范围为 [0,1]，其中 1 表示最佳质量（最大数量 raymarching 迭代/样本）和 0 意味着根本没有样本。

0.5 的质量通常足以满足大多数用例。尝试保留 这个参数越低越好。值越大，效果越显着

默认为0.5.

.resolutionScale : number

分辨率比例。有效值范围为 [0,1]。1 表示最佳质量，但也会导致更多的计算开销。设置为 0.5 表示效果以半分辨率计算。

默认为1.

.shadowIntensity : UniformNode.<float>

阴影强度。必须在[0, 1].

默认为1.0.

.thickness : UniformNode.<float>

深度测试厚度范围内。

默认为0.01.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.useTemporalFiltering : boolean

是否使用时间过滤。将此属性设置为 true 需要使用 TRAANode。这将有助于减少噪音 尽管它引入了典型的 TAA 伪影，例如重影和时间 不稳定性.

默认为 false.

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
