WoodNodeMaterial

使用 TSL（Three.js 着色语言）的程序木质材质。

使用示例：

// 使用预设（推荐用于常见木材类型） const Material = WoodNodeMaterial.fromPreset('walnut', 'gloss');

// 使用自定义参数（用于高级自定义） const 材质 = new WoodNodeMaterial({ 中心尺寸：1.2， 环厚：1/40， darkGrainColor：新三色（'#2a1a0a'）， lightGrainColor: 新的三.Color('#8b4513'), 清漆：1， 清漆粗糙度：0.3 });

// 将预设与自定义覆盖混合 const walnutParams = GetWoodPreset('核桃', '原始'); const 材质 = new WoodNodeMaterial({ ...核桃参数， ringThickness: 1/50, // 覆盖特定参数 透明涂层: 1 // 添加饰面 });

构造函数

new WoodNodeMaterial()
