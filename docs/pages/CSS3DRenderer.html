CSS3DRenderer

此渲染器可用于将分层 3D 转换应用于 DOM 元素 通过 CSS3 transform 属性。 如果您想将 3D 效果应用到没有任何效果的网站，CSS3DRenderer 特别有趣 基于画布的渲染。它还可用于将 DOM 元素与 WebGL 内容结合起来。

然而，有一些重要的限制：

  • 不可能使用 three.js 的材质系统。
  • 也不可能使用几何体。
  • 渲染器只支持 100% 的浏览器和显示器缩放。

所以CSS3DRenderer只关注普通的DOM元素。这些元素被包裹在特殊的 3D 对象（CSS3DObject 或 CSS3DSprite），然后添加到场景图中。

导入

CSS3DRenderer 是一个插件，必须显式导入，请参阅 安装#Addons.

import { CSS3DRenderer } from 'three/addons/renderers/CSS3DRenderer.js';

构造函数

new CSS3DRenderer( parameters : CSS3DRenderer~Parameters )

构造一个新的 CSS3D 渲染器。

parameters

参数.

属性

.domElement : HTMLElement

渲染器附加其属性的 DOM child-elements.

方法

.getSize() : Object

返回包含渲染器宽度和高度的对象。

返回：渲染器的大小。

.render( scene : Object3D, camera : Camera )

渲染给定场景使用给定的相机。

scene

场景或任何其他类型的 3D 对象。
camera

相机.

.setSize( width : number, height : number )

将渲染器的大小调整为给定的宽度和高度。

width

渲染器的宽度。
height

渲染器的高度renderer.

类型定义

.Parameters

CSS3DRenderer.

element
HTMLElement

渲染器附加其子元素的 DOM 元素的构造函数参数。 如果此处未传入，则会创建一个新的 div 元素。
