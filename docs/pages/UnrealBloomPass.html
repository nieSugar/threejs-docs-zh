UnrealBloomPass

此通道的灵感来自虚幻引擎的Bloom通道。它创建了一个 mip 映射绽放纹理链并使用不同的半径对其进行模糊处理。因为 mips 的加权组合，并且因为更大的模糊是在 更高的 mips，此效果可提供良好的质量和性能。

使用此通道时，必须在渲染器设置中启用色调映射。

参考：

  • 在虚幻引擎中使用泛光效果

代码示例

const resolution = new THREE.Vector2( window.innerWidth, window.innerHeight );
const bloomPass = new UnrealBloomPass( resolution, 1.5, 0.4, 0.85 );
composer.addPass( bloomPass );

导入

UnrealBloomPass 是一个插件，必须显式导入，请参阅Installation#Addons.

import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

构造函数

new UnrealBloomPass( resolution : Vector2, strength : number, radius : number, threshold : number )

构造一个新的虚幻绽放通道。

resolution

效果的分辨率。
strength

布隆强度.

默认为1.
radius

绽放半径。
threshold

亮度阈值限制明亮区域的贡献光晕效果。

属性

.clearColor : Color

效果的清晰颜色

默认为(0,0,0).

.needsSwap : boolean

覆盖以禁用交换.

默认为 false.

覆盖： Pass#needsSwap

.radius : number

光晕半径。必须在 [0,1].

.resolution : Vector2

效果的分辨率。

默认为(256,256).

.strength : number

布隆强度.

默认为1.

.threshold : number

亮度阈值限制明亮区域的贡献光晕效果。

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行Bloom pass.

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize
