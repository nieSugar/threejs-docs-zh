XRPlanes

WebXR 平面检测模块的实用程序类。如果飞机 被WebXR检测到，这个类会自动添加它们 当使用下面的代码片段时，作为薄盒网格到场景。

代码示例

const planes = new XRPlanes( renderer );
scene.add( planes );

导入

XRPlanes 是一个插件，必须显式导入，请参阅 安装#Addons.

import { XRPlanes } from 'three/addons/webxr/XRPlanes.js';

构造函数

new XRPlanes( renderer : WebGLRenderer | WebGPURenderer )

构造一个新的XR平面容器.

renderer

渲染器.
