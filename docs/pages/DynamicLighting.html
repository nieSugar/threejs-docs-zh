DynamicLighting

A 自定义照明实现，可将支持的分析灯批量处理为 统一数组，因此光计数更改不会重新编译材质。

代码示例

const lighting = new DynamicLighting( { maxPointLights: 64 } );
renderer.lighting = lighting;

导入

DynamicLighting 是一个插件，必须显式导入，请参阅 安装#Addons.

import { DynamicLighting } from 'three/addons/lighting/DynamicLighting.js';

构造函数

new DynamicLighting( options : Object )

构建新的动态光照系统。

options

动态光照配置。

默认为 {}.

maxDirectionalLights

批量定向光源最大数量。

默认为 8.
maxPointLights

批量最大点数量灯.

默认为16.
maxSpotLights

批量聚光灯最大数量.

默认为16.
maxHemisphereLights

批量半球最大数量灯光.

默认为4.

方法

.createNode( lights : Array.<Light> ) : DynamicLightsNode

为给定的灯光数组创建一个新的动态灯光节点。

lights

要绑定到节点的灯光.
覆盖： Lighting#createNode
返回：动态灯光节点。

.getNode( scene : Scene ) : LightsNode

返回给定场景的灯光节点。

scene

场景.
覆盖： Lighting#getNode
返回：灯光节点.
