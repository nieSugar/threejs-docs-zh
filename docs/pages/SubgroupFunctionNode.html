SubgroupFunctionNode

此类表示一组同步的内置 WGSL 着色器函数 跨计算子组或“扭曲”同步执行操作 或工作组内的片段着色器调用。通常，这些函数 将使用所有活动调用中的数据同步执行操作 在子组内，然后将结果广播给所有活动调用。在 其他图形 API，子组函数也称为波内在函数 (DirectX/HLSL) 或扭曲内在函数 (CUDA).

构造函数

new SubgroupFunctionNode( method : string, aNode : Node, bNode : Node )

构造一个新函数节点。

method

要构造的子组/波内在方法。
aNode

该方法的第一个参数.

默认为null.
bNode

该方法的第二个参数.

默认为null.

属性

.aNode : Node

该方法的第一个参数.

.bNode : Node

该方法的第二个参数.

.method : string

要构造的子组/波内在方法。
