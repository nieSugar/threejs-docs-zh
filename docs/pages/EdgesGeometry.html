EdgesGeometry

可以用作辅助对象来查看几何图形的边缘。

注意：尚无法序列化/反序列化此实例类.

代码示例

const geometry = new THREE.BoxGeometry();
const edges = new THREE.EdgesGeometry( geometry );
const line = new THREE.LineSegments( edges );
scene.add( line );

构造函数

new EdgesGeometry( geometry : BufferGeometry, thresholdAngle : number )

构造一个新的边缘几何体.

geometry

几何体.

默认为null.
thresholdAngle

仅在角度（以度为单位）时渲染边缘 相邻面的面法线之间的距离超过此值。

默认为1.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。
