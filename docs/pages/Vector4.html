Vector4

表示 4D 矢量的类。 4D 向量是有序的四元组数字 （标记为 x、y、z 和 w），可用于表示许多事物，例如：

  • 四维空间中的一点。
  • 在四维空间中的方向和长度。在 three.js 中，长度将始终是从 (0, 0, 0, 0) 到 (x, y, z, w) 的欧几里得距离（直线距离），方向也从 (0, 0, 0, 0) 朝向 (x, y, z, w) 测量。
  • 任意有序的四元数组。

4D 向量还可以用于表示其他事物，但是这些 是 three.js 中最常见的用途。

迭代向量实例将产生其分量 (x, y, z, w) 相应的顺序。

代码示例

const a = new THREE.Vector4( 0, 1, 0, 0 );
//no arguments; will be initialised to (0, 0, 0, 1)
const b = new THREE.Vector4( );
const d = a.dot( b );
