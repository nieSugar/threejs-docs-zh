TextureHelper

可用于显示任何类型纹理的帮助器 调试目的。根据纹理的类型（2D、3D、阵列）， 辅助器变成平面或盒状网格。

此辅助器只能与 WebGLRenderer 一起使用。 使用WebGPURenderer时，从TextureHelperGPU.js.

导入

TextureHelper导入是一个插件，必须显式导入，请参见安装#Addons.

import { TextureHelper } from 'three/addons/helpers/TextureHelper.js';

构造函数

new TextureHelper( texture : Texture, width : number, height : number, depth : number )

构造一个新的纹理助手。

texture

要可视化的纹理。
width

助手的宽度。

默认为1.
height

助手的宽度高度.

默认为1.
depth

助手的深度.

默认为1.

属性

.texture : Texture

要可视化的纹理。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Mesh#dispose
