OBB

表示 3D 空间中的定向边界框 (OBB)。

导入

OBB 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OBB } from 'three/addons/math/OBB.js';

构造函数

new OBB( center : Vector3, halfSize : Vector3, rotation : Matrix3 )

构造一个新的 OBB.

center

OBB 的中心.
halfSize

OBB 的正半宽范围OBB 沿每个轴.
rotation

OBB 的旋转.

属性

.center : Vector3

OBB 的中心.

.halfSize : Vector3

OBB 的正半宽范围OBB 沿每个轴.

.rotation : Matrix3

OBB 的旋转.

方法

.applyMatrix4( matrix : Matrix4 ) : OBB

将给定的变换矩阵应用于此 OBB。这个方法可以是 用于用 3D 对象的世界矩阵变换包围体 为了保持两个实体同步。

matrix

要应用的矩阵。
返回：此 OBB 的引用。

.clampPoint( point : Vector3, target : Vector3 ) : Vector3

将给定点钳制在该 OBB 的边界内。

point

应钳制在该 OBB 的边界内的点OBB.
target

用于存储方法结果的目标向量.
返回：
  • 夹紧点。

.clone() : OBB

返回一个包含此实例中复制值的新 OBB。

返回：此克隆instance.

.containsPoint( point : Vector3 ) : boolean

如果给定点位于此 OBB 内，则返回 true。

point

要测试的点。
返回：
  • 给定点是否位于此 OBB 内。

.copy( obb : OBB ) : OBB

将给定 OBB 的值复制到此实例。

obb

要复制的 OBB。
返回：对此 OBB 的引用。

.equals( obb : OBB ) : boolean

返回true 如果给定的 OBB 等于此 OBB.

obb

要测试的 OBB.
返回： 给定的 OBB 是否等于此 OBB.

.fromBox3( box3 : Box3 ) : OBB

定义一个基于以下的 OBB给定的 AABB.

box3

从 AABB 设置 OBB。
返回：此 OBB 的引用。

.getSize( target : Vector3 ) : Vector3

返回此 OBB 的大小。

target

用于存储方法结果的目标向量.
返回： 大小.

.intersectRay( ray : Ray, target : Vector3 ) : Vector3

执行光线/OBB 相交测试并存储相交点 在给定的 3D 向量中。

ray

要测试的光线。
target

用于存储方法结果的目标向量.
返回： 交点。如果未检测到相交，则返回 null。

.intersectsBox3( box3 : Box3 ) : boolean

如果给定的 AABB 与此 OBB 相交，则返回 true。

box3

要返回的 AABB测试.
返回：
  • 给定的 AABB 是否与此 OBB 相交。

.intersectsOBB( obb : OBB, epsilon : number ) : boolean

如果给定的 OBB 与此 OBB 相交，则返回 true。

obb

要测试的 OBB.
epsilon

防止算术错误的小值。

默认为Number.EPSILON.
返回：
  • 给定的 OBB 是否与此 OBB 相交。

.intersectsPlane( plane : Plane ) : boolean

如果给定平面与此 OBB 相交，则返回 true。

plane

要测试的平面.
返回：给定平面是否与此 OBB 相交。

.intersectsRay( ray : Ray ) : boolean

返回true 如果给定光线与此 OBB 相交。

ray

要测试的光线。
返回： 给定光线是否与此 OBB 相交。

.intersectsSphere( sphere : Sphere ) : boolean

如果给定边界球体则返回 true与此 OBB 相交.

sphere

要测试的边界球.
返回：
  • 给定的边界球是否与此 OBB 相交。

.set( center : Vector3, halfSize : Vector3, rotation : Matrix3 ) : OBB

将 OBB 组件设置为给定值。

center

OBB 的中心.
halfSize

OBB 的正半宽范围OBB 沿每个轴.
rotation

OBB 的旋转.
返回：对此 OBB 的引用。
