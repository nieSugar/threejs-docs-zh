AssignNode

这些节点表示分配操作。表示节点已分配 到另一个节点.

构造函数

new AssignNode( targetNode : Node, sourceNode : Node )

构造一个新的分配节点.

targetNode

目标节点.
sourceNode

源类型.

属性

.isAssignNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.sourceNode : Node

源节点.

.targetNode : Node

目标节点.

方法

.hasDependencies() : boolean

该节点是否使用超过一旦在其他节点的上下文中。这个方法 被覆盖，因为它总是返回 false （分配是唯一的）。

覆盖： TempNode#hasDependencies
返回： 一个标志，指示是否存在多个对其他节点的依赖关系。始终 false.

.needsSplitAssign( builder : NodeBuilder ) : boolean

将源分配给目标时是否需要拆分。当组件长度为 目标和源数据类型不匹配。

builder

当前节点构建器.
返回：将源分配给目标时是否需要拆分.
