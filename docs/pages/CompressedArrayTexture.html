CompressedArrayTexture

基于压缩形式的数据创建纹理二维数组。

这些纹理通常加载CompressedTextureLoader.

构造函数

new CompressedArrayTexture( mipmaps : Array.<Object>, width : number, height : number, depth : number, format : number, type : number )

构造一个新的压缩数组纹理。

mipmaps

该数组保存所有mipmap（包括基础mip） 数据和尺寸.
width

纹理的宽度.
height

纹理的高度.
depth

纹理的深度.
format

最小滤镜值.

默认为RGBAFormat.
type

最小滤镜值.

默认为UnsignedByteType.

属性

.image : Object

压缩纹理的图像属性仅定义其尺寸.

覆盖： CompressedTexture#image

.isCompressedArrayTexture : boolean (readonly)

该标志可用于类型测试。

默认为true.

.layerUpdates : Set.<number>

需要在纹理中更新的所有图层的集合。

.wrapR : RepeatWrapping | ClampToEdgeWrapping | MirroredRepeatWrapping

这定义了纹理如何在深度中包裹并对应于 UVW 贴图中的W。

默认为ClampToEdgeWrapping.

方法

.addLayerUpdate( layerIndex : number )

描述纹理的特定层需要更新。 通常当 Texture#needsUpdate 设置为 true 时， 整个压缩纹理数组被发送到 GPU。标记具体 层将仅传输与某个相关联的所有 mipmap 的子集 数组中的特定深度，通常性能更高。

layerIndex

应更新的图层索引。

.clearLayerUpdates()

重置图层更新注册表。

.copy( source : CompressedArrayTexture ) : CompressedArrayTexture

将给定纹理的值复制到此实例.

source

纹理复制.
覆盖： CompressedTexture#copy
返回：对此实例的引用。
