ClusteredLightsNode

LightsNode 的自定义版本，实现前向+集群着色： 视锥体被细分为簇的 3D 网格（X × Y 屏幕图块 乘以指数间隔的 Z 深度切片集），每个簇都包含 仅球体与其相交的点光源。在着色时每个片段 查找其集群并仅循环该集群的灯光。与 2D 平铺不同 照明，集群着色剔除共享屏幕像素但位于 不同深度 - 适用于具有真实深度复杂性的 3D 场景。

导入

ClusteredLightsNode 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { clusteredLights } from 'three/addons/tsl/lighting/ClusteredLightsNode.js';

构造函数

new ClusteredLightsNode( maxLights : number, tileSize : number, zSlices : number, maxLightsPerCluster : number )

构造一个新的集群灯光节点。

maxLights

最大点光源数量.

默认为1024.
tileSize

屏幕图块大小（以像素为单位）（集群XY大小）.

默认为32.
zSlices

数量指数深度切片。

默认为 24.
maxLightsPerCluster

每集群灯列表容量。

默认为64.

方法

.dispose()

释放该节点分配的GPU资源。

覆盖： LightsNode#dispose
