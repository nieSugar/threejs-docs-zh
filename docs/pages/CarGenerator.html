CarGenerator

具有放样车身、圆形轮拱、弯曲的低多边形车队 挡风玻璃和嵌入式合金轮毂。独立的驾驶室面板定义了 窗户及其框架。两种车身类型（轿车和SUV）混合 确定性地穿过车队，出租车颜色有自己的轿车 屋顶标志，因此停放的一排读作不同的车辆而不是一个模具。

每个几何体每种类型构建一次并共享；汽车按车身分组 使用每个实例绘制类型，因此每个组都是一个单实例绘制 使用烘焙的 partId、面板 UV 和 规范空间掩模。

规范模型的轮子位于 y = 0 上，以 X / Z 为中心，面向 +Z，因此本地 +Z 面向道路的展示位置会将其朝外停放。

代码示例

const cars = new CarGenerator();
scene.add( cars.build( placements ) ); // placements: { matrix: Matrix4, color }[]

构造函数

new CarGenerator()
