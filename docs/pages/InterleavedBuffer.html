InterleavedBuffer

“Interleaved”意味着多个属性，可能是不同类型的， （例如，位置、法线、uv、颜色）被打包到单个数组缓冲区中。

可以在此处找到交错数组的介绍：Interleaved array basics

构造函数

new InterleavedBuffer( array : TypedArray, stride : number )

构造一个新的交错缓冲区。

array

具有存储属性数据的共享缓冲区的类型化数组。
stride

每个顶点的类型化数组元素数。

属性

.array : TypedArray

具有存储属性数据的共享缓冲区的类型化数组。

.count : number (readonly)

总数数组中元素的数量

.isInterleavedBuffer : boolean (readonly)

该标志可用于类型测试。

默认为true.

.needsUpdate : number

Flag 来指示该属性已更改，应重新发送到 GPU。修改数组值时，将其设置为 true。

默认为 false.

.stride : number

每个顶点的类型化数组元素数。

.updateRanges : Array.<Object>

这可用于仅更新存储向量的某些组件（例如，仅更新 与颜色相关的组件）。使用 addUpdateRange() 函数向此数组添加范围。

.usage : StaticDrawUsage | DynamicDrawUsage | StreamDrawUsage | StaticReadUsage | DynamicReadUsage | StreamReadUsage | StaticCopyUsage | DynamicCopyUsage | StreamCopyUsage

定义数据存储的预期使用模式以进行优化。

注意：初次使用缓冲区后，其使用情况无法更改。相反， 实例化一个新版本并在下一次渲染之前设置所需的用法。

默认为 StaticDrawUsage.

.uuid : string (readonly)

交错缓冲区的 UUID。

.version : number

A 版本号，每次将 needsUpdate 设置为true.

方法

.addUpdateRange( start : number, count : number )

在数据数组中添加要在 GPU 上更新的数据范围。

start

开始更新的位置。
count

要更新的组件数量update.

.clearUpdateRanges()

清除更新范围。

.clone( data : Object ) : InterleavedBuffer

返回一个新的交错缓冲区，其中包含从此实例复制的值。

data

具有共享数组缓冲区的对象，允许保留共享结构。
返回：此克隆instance.

.copy( source : InterleavedBuffer ) : InterleavedBuffer

复制值将给定交错缓冲区的向量复制到此实例。

source

要复制的交错缓冲区。
返回：对此实例的引用。

.copyAt( index1 : number, interleavedBuffer : InterleavedBuffer, index2 : number ) : InterleavedBuffer

将向量从给定交错缓冲区复制到此缓冲区。开始 属性缓冲区中的目标位置由 给定索引.

index1

此交错缓冲区的目标索引.
interleavedBuffer

要复制的交错缓冲区.
index2

给定交错缓冲区的源索引.
返回：对此实例的引用。

.onUpload( callback : function ) : InterleavedBuffer

设置渲染器传输后执行的给定回调函数 将数组数据传输到 GPU。可用于执行清理操作 CPU端不再需要数据时的上传。

callback

onUpload()回调。
返回：对此实例的引用。

.onUploadCallback()

渲染器传输属性数组后执行的回调函数 数据传输到 GPU。

.set( value : TypedArray | Array, offset : number ) : InterleavedBuffer

在交错缓冲区中设置给定数组数据。

value

要设置的数组数据。
offset

此交错缓冲区数组中的偏移量。

默认为0.
返回：对此实例的引用。

.setUsage( value : StaticDrawUsage | DynamicDrawUsage | StreamDrawUsage | StaticReadUsage | DynamicReadUsage | StreamReadUsage | StaticCopyUsage | DynamicCopyUsage | StreamCopyUsage ) : InterleavedBuffer

设置此交错缓冲区的使用buffer.

value

设置的用法.
返回： 对此交错缓冲区的引用。

.toJSON( data : Object ) : Object

将交错缓冲区序列化为 JSON.

data

保存有关雾的元信息的可选值序列化.
返回： 表示序列化交错缓冲区的 JSON 对象缓冲区.
