EventDispatcher → Texture →

DepthTexture

该类可用于自动保存物体的深度信息 渲染成纹理.

构造函数

new DepthTexture( width : number, height : number, type : number, mapping : number, wrapS : number, wrapT : number, magFilter : number, minFilter : number, anisotropy : number, format : number, depth : number )

构造新的深度纹理.

width

纹理的宽度.
height

纹理的高度.
type

纹理类型.

默认为UnsignedIntType.
mapping

纹理映射.

默认为 Texture.DEFAULT_MAPPING.
wrapS

wrapS 值.

默认为ClampToEdgeWrapping.
wrapT

wrapT 值.

默认为ClampToEdgeWrapping.
magFilter

mag 滤镜值.

默认为LinearFilter.
minFilter

最小滤镜值.

默认为LinearFilter.
anisotropy

各向异性值.

默认为Texture.DEFAULT_ANISOTROPY.
format

纹理格式.

默认为DepthFormat.
depth

纹理的深度.

默认为1.

属性

.compareFunction : NeverCompare | LessCompare | EqualCompare | LessEqualCompare | GreaterCompare | NotEqualCompare | GreaterEqualCompare | AlwaysCompare

深度比较函数对应的代码.

默认为null.

.flipY : boolean

如果设置为true，纹理沿垂直轴翻转时 上传到GPU.

覆盖并默认设置为false.

默认为 false.

覆盖： Texture#flipY

.generateMipmaps : boolean

是否为纹理生成 mipmap（如果可能）。

覆盖并默认设置为false.

默认为 false.

覆盖： Texture#generateMipmaps

.isDepthTexture : boolean (readonly)

该标志可用于类型测试。

默认为true.
