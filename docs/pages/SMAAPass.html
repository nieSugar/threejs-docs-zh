SMAAPass

申请 SMAA 的通行证。与 FXAAPass 不同，SMAAPass 运行于 linear-srgb 因此此通道必须在 OutputPass.

代码示例

const smaaPass = new SMAAPass();
composer.addPass( smaaPass );

导入

SMAAPass 之前执行，是一个插件，必须显式导入，请参阅 安装#Addons.

import { SMAAPass } from 'three/addons/postprocessing/SMAAPass.js';

构造函数

new SMAAPass()

构造新的 SMAA 通行证。

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行 SMAA 通行证。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize
