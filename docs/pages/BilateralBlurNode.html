BilateralBlurNode

用于创建双边模糊效果的后处理节点。

双边模糊平滑图像，同时保留锐利边缘。不像一个 标准高斯模糊，均匀模糊所有内容，双边模糊 分析相邻像素的强度/颜色。如果邻居也是 与中心像素（表示边缘）不同，被排除 来自模糊过程。

参考： https://en.wikipedia.org/wiki/Bilingual_filter

导入

BilateralBlurNode 是一个插件，并且必须显式导入，请参见Installation#Addons。

import { bilateralBlur } from 'three/addons/tsl/display/BilateralBlurNode.js';

构造函数

new BilateralBlurNode( textureNode : TextureNode, directionNode : Node.<(vec2|float)>, sigma : number, sigmaColor : number )

构造一个新的双边模糊节点。

textureNode

代表输入的纹理节点效果.
directionNode

定义模糊的方向和半径模糊.

默认为null.
sigma

控制模糊滤镜的空间内核。值越高意味着模糊半径越宽。

默认为4.
sigmaColor

控制强度内核。较高的值允许更多的色差被模糊在一起。

默认为0.1.

属性

.directionNode : Node.<(vec2|float)>

定义模糊的方向和半径模糊.

.resolutionScale : number

分辨率比例。

默认为1.

.sigma : number

控制模糊滤镜的空间内核。值越高意味着模糊半径越宽。

.sigmaColor : number

控制颜色/强度内核。值越高，色差越大 变得模糊在一起。较低的值更严格地保留边缘。

.textureNode : TextureNode

代表输入的纹理节点效果.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getTextureNode() : PassTextureNode

以纹理节点的形式返回效果的结果。

返回：表示以下结果的纹理节点效果.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
