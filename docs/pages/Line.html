Line

连续行。该线是通过连接连续的 直线顶点.

代码示例

const material = new THREE.LineBasicMaterial( { color: 0x0000ff } );
const points = [];
points.push( new THREE.Vector3( - 10, 0, 0 ) );
points.push( new THREE.Vector3( 0, 10, 0 ) );
points.push( new THREE.Vector3( 10, 0, 0 ) );
const geometry = new THREE.BufferGeometry().setFromPoints( points );
const line = new THREE.Line( geometry, material );
scene.add( line );

构造函数

new Line( geometry : BufferGeometry, material : Material | Array.<Material> )

构造一条新线.

geometry

线几何图形.
material

线材质.

属性

.geometry : BufferGeometry

线几何图形.

.isLine : boolean (readonly)

该标志可用于类型测试。

默认为true.

.material : Material | Array.<Material>

线材质.

默认为LineBasicMaterial.

.morphTargetDictionary : Object.<string, number> | undefined

表示几何体中变形目标的字典。关键是 morph 目标名称，其属性索引值。该成员是undefined 默认情况下，仅在几何体中检测到变形目标时设置。

默认为undefined.

.morphTargetInfluences : Array.<number> | undefined

通常在 [0,1] 范围内的权重数组，指定变形量 被应用。该成员默认为 undefined 并且仅在变形目标为 在几何体中检测到。

默认为undefined.

方法

.computeLineDistances() : Line

计算渲染虚线所需的距离值数组。 对于几何中的每个顶点，该方法根据 当前点到该行的最开头。

返回： 对此行的引用。

.intersectsFrustum( frustum : Frustum | FrustumArray ) : boolean

如果该行与给定的平截头体相交，则返回 true。

frustum

到的平截头体test.
覆盖： Object3D#intersectsFrustum
返回： 这条线是否与给定的平截头体相交。

.raycast( raycaster : Raycaster, intersects : Array.<Object> )

计算投射光线与此线之间的交点line.

raycaster

The raycaster.
intersects

保存交点的目标数组。
覆盖： Object3D#raycast

.updateMorphTargets()

设置 Line#morphTargetDictionary 和 Line#morphTargetInfluences 的值 确保现有的变形目标可以影响此 3D 对象。
