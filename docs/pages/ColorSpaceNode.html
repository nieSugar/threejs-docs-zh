ColorSpaceNode

此节点表示颜色空间转换。意思是它转换 从源到目标颜色空间的颜色值。

构造函数

new ColorSpaceNode( colorNode : Node, source : string, target : string )

构造一个新的颜色空间节点。

colorNode

表示要转换的颜色。
source

源颜色空间。
target

目标颜色space.

属性

.colorNode : Node

表示要转换的颜色。

.source : string

源颜色空间。

.target : string

目标颜色space.

方法

.resolveColorSpace( builder : NodeBuilder, colorSpace : string ) : string

此方法解析常量 WORKING_COLOR_SPACE 和 OUTPUT_COLOR_SPACE 基于当前配置 颜色管理和渲染器。

builder

当前节点构建器.
colorSpace

要解析的色彩空间。
返回：解析的色彩空间。
