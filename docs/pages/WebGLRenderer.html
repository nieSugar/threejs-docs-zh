WebGLRenderer

此渲染器使用 WebGL 2 显示场景。

WebGL 1 不受支持，因为r163.

构造函数

new WebGLRenderer( parameters : WebGLRenderer~Options )

构造一个新的WebGL渲染器。

parameters

配置参数.

属性

.autoClear : boolean

渲染器是否应在渲染帧之前自动清除其输出。

默认为true.

.autoClearColor : boolean

如果WebGLRenderer#autoClear设置为true，渲染器是否应清除 颜色缓冲区是否。

默认为true.

.autoClearDepth : boolean

如果 WebGLRenderer#autoClear 设置为 true，渲染器是否应清除 深度缓冲区是否。

默认为true.

.autoClearStencil : boolean

如果 WebGLRenderer#autoClear 设置为 true，渲染器是否应清除 是否使用模板缓冲区。

默认为true.

.capabilities : WebGLRenderer~Capabilities

保存有关当前渲染上下文功能的详细信息。

.clippingPlanes : Array.<Plane>

在世界空间中指定的用户定义的剪切平面。这些飞机适用于全球。 空间中与平面的点积为负的点将被切除。

.coordinateSystem : WebGLCoordinateSystem | WebGPUCoordinateSystem (readonly)

定义渲染器的坐标系。

在WebGLRenderer中，该值始终为WebGLCoordinateSystem.

默认为WebGLCoordinateSystem.

.debug : Object

具有调试配置设置的对象。

  • checkShaderErrors：如果是 true，定义在编译和链接过程中是否检查材质着色器程序的错误。在生产环境中，为了提高性能，可能会禁用此检查。强烈建议在开发过程中保持这些检查启用。如果着色器未能编译和链接，它将无法工作，相关材质也将无法渲染。
  • onShaderError(gl, program, glVertexShader,glFragmentShader)：一个可以用于自定义错误报告的回调函数。该回调接收 WebGL 上下文、一个 WebGLProgram 实例以及两个 WebGLShader 实例，分别表示顶点着色器和片段着色器。分配自定义函数将禁用默认的错误报告。

.domElement : HTMLCanvasElement | OffscreenCanvas

渲染器在其中绘制输出的画布。这是由渲染器自动创建的 在构造函数中（如果尚未提供）；您只需将其添加到您的页面，如下所示：

document.body.appendChild( renderer.domElement );

.extensions : Object

提供用于检索和测试 WebGL 扩展的方法。

  • get(extensionName:string)：用于检查 WebGL 扩展是否受支持，并在可用时返回该扩展对象。
  • has(extensionName:string): 如果支持该扩展，则返回 true。

.info : WebGLRenderer~Info

保存一系列有关GPU内存的统计信息 以及渲染过程。对于调试和监视很有用。

默认情况下，这些数据会在每次渲染调用时重置，但是当有 每帧多个渲染通道（例如，使用后处理时） 优先使用自定义模式重置。首先，将 autoReset 设置为 false.

renderer.info.autoReset = false;

每当完成渲染单帧时调用reset()。

renderer.info.reset();

.isWebGLRenderer : boolean (readonly)

该标志可用于类型测试。

默认为true.

.localClippingEnabled : boolean

渲染器是否尊重对象级剪切平面。

默认为 false.

.outputColorSpace : SRGBColorSpace | LinearSRGBColorSpace

定义渲染器的输出颜色空间。

默认为SRGBColorSpace.

.properties : Object

用于跟踪其他对象（如本机 WebGL 对象）的属性。

.renderLists : Object

管理渲染器的渲染列表。

.shadowMap : WebGLRenderer~ShadowMap

管理阴影的接口。

.sortObjects : boolean

渲染器是否应对对象进行排序。

注意：排序用于尝试正确渲染具有某些 透明度。根据定义，对对象进行排序可能并不适用于所有情况 案例。根据应用的需要，可能需要转 关闭排序并使用其他方法来处理透明度渲染，例如 手动确定每个对象的渲染顺序。

默认为true.

.state : Object

用于管理 WebGL 状态的接口。

.toneMapping : NoToneMapping | LinearToneMapping | ReinhardToneMapping | CineonToneMapping | ACESFilmicToneMapping | CustomToneMapping | AgXToneMapping | NeutralToneMapping

渲染器的色调映射技术。

默认为NoToneMapping.

.toneMappingExposure : number

色调映射的曝光级别。

默认为1.

.transmissionResolutionScale : number

传输渲染目标的归一化分辨率比例，以百分比为单位 视口尺寸。降低该值可以显着提高性能 当使用 MeshPhysicalMaterial#transmission.

默认为1.

清除模板缓冲区。相当于调用renderer.clear( false, false, true ).

autoUpdate
boolean

启用场景中阴影的自动更新。 如果不需要动态光照/阴影，可以将其设置为false.

默认为true.
needsUpdate
boolean

当设置为true时，场景中的阴影贴图 将在下一次 render 调用中更新。

默认为 false.
type
BasicShadowMap | PCFShadowMap | VSMShadowMap

定义阴影贴图类型。

默认为 PCFShadowMap.
