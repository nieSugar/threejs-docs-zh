SplitNode

此模块是 TSL 核心的一部分，通常不在应用程序级代码中使用。 SplitNode 表示属性访问操作，这意味着它是 用于在节点对象上实现任何 .xyzw、.rgba 和 stpq 用法。 例如：

代码示例

const redValue = color.r;

构造函数

new SplitNode( node : Node, components : string )

构造一个新的分割节点。

node

应该访问的节点。
components

应该访问的组件。

默认为 'x'.

属性

.components : string

应该访问的组件。

.isSplitNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.node : Node

应该访问的节点。

方法

.generateNodeType( builder : NodeBuilder ) : string

由于节点类型是根据请求推断的，因此该方法被覆盖Components.

builder

当前节点构建器.
覆盖： Node#generateNodeType
返回： 节点类型。

.getComponentType( builder : NodeBuilder ) : string

返回节点类型的组件类型。

builder

当前节点构建器.
返回： 组件类型。

.getScope() : Node

返回节点的范围。

覆盖： Node#getScope
返回：节点的范围。

.getVectorLength() : number

返回基于计算得出的向量长度在请求的组件上.

返回：向量长度.
