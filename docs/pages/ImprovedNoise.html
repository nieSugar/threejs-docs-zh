ImprovedNoise

提供3D噪声功能的实用程序类.

代码基于改善噪音 作者：Ken Perlin，2002.

导入

ImprovedNoise 是一个插件，必须显式导入，请参阅 安装#Addons.

import { ImprovedNoise } from 'three/addons/math/ImprovedNoise.js';

构造函数

new ImprovedNoise()

方法

.noise( x : number, y : number, z : number ) : number

返回给定参数的噪声值。

x

x 坐标。
y

y 坐标。
z

z坐标.
返回：噪声值.
