Controls

控件的抽象基类。

构造函数

new Controls( object : Object3D, domElement : HTMLElement ) (abstract)

构造一个新的控件实例。

object

控件管理的对象。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.domElement : HTMLElement

用于事件侦听器的 HTML 元素。

默认为null.

.enabled : boolean

控件是否响应用户输入或不是.

默认为true.

.keys : Object

此对象定义控件的键盘输入。

.mouseButtons : Object

此对象定义分配给可用鼠标按钮的操作类型。 这取决于控件实现支持哪种类型的鼠标按钮和操作。

.object : Object3D

控件管理的对象。

.state : number

控件的内部状态。

默认为 -1.

.touches : Object

此对象定义将哪种类型的操作分配给哪种触摸交互。 支持哪种触摸交互和操作取决于控件实现。

方法

.connect( element : HTMLElement )

将控件连接到 DOM。这种方法有所谓的“副作用”，因为 它将模块的事件侦听器添加到 DOM。

element

要连接到的 DOM 元素。

.disconnect()

断开控件与 DOM 的连接。

.dispose()

如果不再需要使用控件，请调用此方法。它释放了所有内部 资源并删除所有事件侦听器。

.update( delta : number )

如果控件必须更新其内部状态，则应实现此方法 每个模拟步骤.

delta

以秒为单位的时间增量.
