OBJLoader

OBJ 格式的加载器。

OBJ format 是一种简单的数据格式 以人类可读的格式表示 3D 几何图形，即每个顶点的位置、UV 位置 每个纹理坐标顶点、顶点法线以及使每个多边形定义为列表的面 顶点和纹理顶点。

代码示例

const loader = new OBJLoader();
const object = await loader.loadAsync( 'models/monster.obj' );
scene.add( object );

导入

OBJLoader 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { OBJLoader } from 'three/addons/loaders/OBJLoader.js';

构造函数

new OBJLoader( manager : LoadingManager )

构造一个新的 OBJ 加载器。

manager

加载管理器。

属性

.materials : MaterialCreator

对材质创建器的引用。

默认为null.

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定 URL 加载并传递加载的 OBJ 资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( text : string ) : Group

解析给定的 OBJ 数据并返回结果组。

text

原始 OBJ 数据作为字符串。
覆盖： Loader#parse
返回：解析的OBJ.

.setMaterials( materials : MaterialCreator ) : OBJLoader

设置此 OBJ 的材质创建者。该对象通过 MTLLoader 加载。

materials

为此 OBJ 创建材质的对象.
返回：对此加载程序的引用。
