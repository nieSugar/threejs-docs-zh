Pass

所有后处理通道的抽象基类。

此模块仅与后处理相关WebGLRenderer.

导入

Pass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { Pass } from 'three/addons/postprocessing/Pass.js';

构造函数

new Pass() (abstract)

构造一个新通道。

属性

.clear : boolean

如果设置为true，该通道会在渲染之前清除其缓冲区

默认为 false.

.enabled : boolean

如果设置为true，该pass由composer处理。

默认为true.

.isPass : boolean (readonly)

该标志可用于类型测试。

默认为true.

.needsSwap : boolean

如果设置为true，则该pass表示渲染后交换读写缓冲区。

默认为true.

.renderToScreen : boolean

如果设置为true，则结果pass 被渲染到屏幕上。作曲家的最后一段 无论如何配置此属性，通道链都会自动渲染到屏幕。

默认为 false.

方法

.dispose() (abstract)

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean ) (abstract)

此方法保存通道的渲染逻辑。它必须在所有派生类中实现。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。

.setSize( width : number, height : number ) (abstract)

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
