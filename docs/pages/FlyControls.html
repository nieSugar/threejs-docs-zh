FlyControls

此类支持类似于 Blender 等 DCC 工具中的飞行模式的导航。 您可以在3D空间中任意变换相机，没有任何限制 （例如，专注于特定目标）.

导入

FlyControls 是一个插件，必须显式导入，请参阅 安装#Addons.

import { FlyControls } from 'three/addons/controls/FlyControls.js';

构造函数

new FlyControls( object : Object3D, domElement : HTMLElement )

构造一个新的控件实例。

object

控件管理的对象。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.autoForward : boolean

如果设置为true，相机在初始平移时会自动向前移动（并且不会停止）。

默认为 false.

.dragToLook : boolean

如果设置为true，则只能通过拖动来环顾四周交互.

默认为 false.

.movementSpeed : number

移动速度.

默认为1.

.rollSpeed : number

旋转速度.

默认为0.005.

Events

.change

当相机已被控件转换时触发。

Type:
  • Object
