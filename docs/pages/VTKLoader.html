VTKLoader

VTK 格式的加载器。

目前该加载器仅支持 POLYDATA 数据集格式。其他格式 （结构化点、结构化网格、直线网格、非结构化网格、附加） 不支持。

代码示例

const loader = new VTKLoader();
const geometry = await loader.loadAsync( 'models/vtk/liver.vtk' );
geometry.computeVertexNormals();
const mesh = new THREE.Mesh( geometry, new THREE.MeshLambertMaterial() );
scene.add( mesh );

导入

VTKLoader 是一个插件，必须显式导入，请参阅Installation#Addons.

import { VTKLoader } from 'three/addons/loaders/VTKLoader.js';

构造函数

new VTKLoader( manager : LoadingManager )

构造一个新的VTK loader.

manager

加载管理器。
已弃用：自 r184.

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定 URL 加载并传递加载的 VTK 资源 到onLoad()回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( data : ArrayBuffer ) : BufferGeometry

解析给定的VTK数据并返回结果几何图形。

data

原始VTK数据作为数组缓冲区
覆盖： Loader#parse
返回： 解析的几何图形.
