AnimationUtils

具有各种方法来辅助动画的类。

静态方法

.convertArray( array : TypedArray | Array, type : TypedArray.constructor ) : TypedArray

将数组转换为特定类型

array

数组转换.
type

类型数组的构造函数.
返回：转换后的数组

.flattenJSON( jsonKeys : Array.<number>, times : Array.<number>, values : Array.<number>, valuePropertyName : string )

用于解析AOS关键帧格式.

jsonKeys

JSON列表keyframes.
times

此数组将通过此方法填充关键帧时间。
values

此数组将通过此方法填充关键帧值。
valuePropertyName

要使用的属性的名称。

.getKeyframeOrder( times : Array.<number> ) : Array.<number>

返回一个数组，通过该数组可以指定时间和值排序.

times

关键帧时间值.
返回：数组.

.hasTangents( settings : Object ) : boolean

如果给定关键帧轨道设置保持贝塞尔曲线切线，则返回true data.

settings

关键帧轨迹的设置。
返回：是否定义了两个切线数组。

.isTypedArray( object : any ) : boolean

如果给定对象是类型化的，则返回true数组.

object

要检查的对象.
返回：给定的对象是否是类型化数组。

.makeClipAdditive( targetClip : AnimationClip, referenceFrame : number, referenceClip : AnimationClip, fps : number ) : AnimationClip

将给定动画剪辑的关键帧转换为附加格式。

targetClip

要制作的剪辑附加.
referenceFrame

参考框架.

默认为0.
referenceClip

参考剪辑.

默认为targetClip.
fps

The FPS.

默认为 30.
返回： 现在可累加的更新剪辑。

.sortedArray( values : Array.<number>, stride : number, order : Array.<number> ) : Array.<number>

按之前计算的顺序对给定数组进行排序getKeyframeOrder().

values

要排序的值.
stride

步幅.
order

排序顺序.
返回：排序后的值值.

.subclip( sourceClip : AnimationClip, name : string, startFrame : number, endFrame : number, fps : number ) : AnimationClip

创建一个新剪辑，仅包含给定帧之间原始剪辑的片段。

sourceClip

要排序的值.
name

剪辑的名称。
startFrame

起始帧.
endFrame

结束帧.
fps

The FPS.

默认为 30.
返回： 新的子剪辑.
