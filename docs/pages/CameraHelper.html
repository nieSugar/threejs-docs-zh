CameraHelper

这有助于可视化相机在其视锥体中包含的内容。它 使用线段可视化相机的视锥体。

基于 lightgl.js shadowmap example 中的视锥体可视化。

CameraHelper 必须是场景的子级。

当相机变换或者投影矩阵改变，这是必要的 调用相应帮助器的 update() 方法。

代码示例

const camera = new THREE.PerspectiveCamera( 75, window.innerWidth / window.innerHeight, 0.1, 1000 );
const helper = new THREE.CameraHelper( camera );
scene.add( helper );

构造函数

new CameraHelper( camera : Camera )

构造一个新的箭头助手。

camera

要可视化的相机。

属性

.camera : Camera

正在可视化的相机。

.pointMap : Object.<string, Array.<number>>

这包含用于可视化的点相机.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose

.setColors( frustum : Color, cone : Color, up : Color, target : Color, cross : Color ) : CameraHelper

定义助手的颜色.

frustum

截锥体线颜色.
cone

圆锥线颜色.
up

上线颜色.
target

目标线颜色.
cross

十字线颜色.
返回：对此助手的引用.

.update()

根据相机的投影矩阵更新助手.
