VideoFrameTexture

此类可用作定义视频数据的替代方法。而不是使用 HTMLVideoElement 的实例与 VideoTexture 一样，VideoFrameTexture 期望每个帧是 通过 VideoFrameTexture#setFrame 手动定义。该模块的典型用例是 视频帧使用 WebCodecs API 进行解码。

代码示例

const texture = new THREE.VideoFrameTexture();
texture.setFrame( frame );

构造函数

new VideoFrameTexture( mapping : number, wrapS : number, wrapT : number, magFilter : number, minFilter : number, format : number, type : number, anisotropy : number )

构造新的视频帧纹理。

mapping

纹理映射.

默认为 Texture.DEFAULT_MAPPING.
wrapS

wrapS 值.

默认为ClampToEdgeWrapping.
wrapT

wrapT 值.

默认为ClampToEdgeWrapping.
magFilter

mag 滤镜值.

默认为LinearFilter.
minFilter

最小滤镜值.

默认为LinearFilter.
format

纹理格式.

默认为RGBAFormat.
type

纹理类型.

默认为UnsignedByteType.
anisotropy

各向异性值.

默认为Texture.DEFAULT_ANISOTROPY.

属性

.isVideoFrameTexture : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.setFrame( frame : VideoFrame )

设置视频的当前帧。这将自动更新纹理 因此数据可用于渲染。

frame

视频帧。

.update()

此方法被空实现覆盖 这种类型的纹理通过 setFrame().

覆盖： VideoTexture#update
