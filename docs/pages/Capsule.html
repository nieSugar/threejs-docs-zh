Capsule

胶囊本质上是一个两端都有半球形帽的圆柱体。 它可以被认为是一个扫掠球体，其中球体沿着线段移动。

胶囊通常用作包围体（AABB和包围球旁边）。

导入

Capsule是一个插件，必须显式导入，请参阅Installation#Addons.

import { Capsule } from 'three/addons/math/Capsule.js';

构造函数

new Capsule( start : Vector3, end : Vector3, radius : number )

构造一个新的胶囊。

start

起始向量。
end

结束矢量.
radius

胶囊的半径。

默认为1.

属性

.end : Vector3

结束矢量.

.radius : number

胶囊的半径。

默认为1.

.start : Vector3

起始向量。

方法

.clone() : Capsule

返回一个包含此实例复制值的新胶囊。

返回：此克隆instance.

.copy( capsule : Capsule ) : Capsule

将给定胶囊的值复制到此实例。

capsule

胶囊到copy.
返回：对此胶囊的引用。

.getCenter( target : Vector3 ) : Vector3

返回此胶囊的中心点。

target

用于存储方法结果的目标向量.
返回：中心点。

.intersectsBox( box : Box3 ) : boolean

如果给定的边界框与此相交，则返回 true capsule.

box

要测试的边界框。
返回：给定的边界框是否与此胶囊相交。

.set( start : Vector3, end : Vector3, radius : number ) : Capsule

将胶囊组件设置为给定值。 请注意，此方法仅复制给定对象中的值。

start

起始向量。
end

结束向量
radius

胶囊的半径。
返回：对此胶囊的引用。

.translate( v : Vector3 ) : Capsule

将给定的偏移量添加到此胶囊，有效地在 3D 空间中移动它。

v

应用于平移胶囊的偏移量。
返回：对此胶囊的引用。
