CSM

级联阴影贴图 (CSM) 的实现。

此模块只能与 WebGLRenderer 一起使用。当使用WebGPURenderer时， 使用 CSMShadowNode 代替。

导入

CSM 是一个插件，必须显式导入，请参阅 安装#Addons.

import { CSM } from 'three/addons/csm/CSM.js';

构造函数

new CSM( data : CSM~Data )

构造一个新的CSM实例。

data

CSM数据.

Classes

CSM

属性

.breaks : Array.<number>

数字数组在 [0,1] 范围内定义如何 mainCSM视锥体需要分割.

.camera : Camera

场景相机.

.cascades : number

级联数量.

默认为3.

.customSplitsCallback : function

自定义分割时的回调使用mode='custom'.

.fade : boolean

是否在级联之间淡入淡出.

默认为 false.

.frustums : Array.<CSMFrustum>

表示级联的平截头体数组.

.lightDirection : Vector3

光线方向.

.lightFar : number

光线远值.

默认为2000.

.lightIntensity : number

光照强度.

默认为3.

.lightMargin : number

光照余量.

默认为200.

.lightNear : number

接近值的光。

默认为1.

.lights : Array.<DirectionalLight>

投射阴影的定向光数组 不同的级联。每个都有一个定向灯 级联.

.mainFrustum : CSMFrustum

主视锥体.

.maxFar : number

最大远值.

默认为100000.

.mode : 'practical' | 'uniform' | 'logarithmic' | 'custom'

视锥体分割模式.

默认为'practical'.

.parent : Object3D

父对象，通常是场景.

.shaders : Map.<Material, Object>

A 包含增强材质着色器的地图.

.shadowBias : number

阴影偏差.

默认为0.000001.

.shadowMapSize : number

阴影贴图大小。

默认为 2048.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

.remove()

应用程序在从场景中删除CSM使用时必须调用此方法。

.setupMaterial( material : Material )

应用程序必须调用此方法适用于受 CSM 影响的所有材质。

material

要设置 CSM 支持的材质。

.update()

更新 CSM。必须在动画循环之前调用此方法 调用 renderer.render().

.updateFrustums()

应用程序每次更改相机或 CSM 设置时都必须调用此方法。
