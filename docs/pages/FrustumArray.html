FrustumArray

FrustumArray 用于确定对象在至少一个摄像机中是否可见 来自一系列摄像机。这对于多视图渲染器特别有用。

构造函数

new FrustumArray()

构造一个新的平截头体数组。

属性

.coordinateSystem : WebGLCoordinateSystem | WebGPUCoordinateSystem

要使用的坐标系。

默认为WebGLCoordinateSystem.

方法

.clone() : FrustumArray

返回一个新的视锥体数组，其中包含从此实例复制的值。

返回：此克隆instance.

.containsPoint( point : Vector3 ) : boolean

如果给定点位于任何缓存内，则返回 true截锥体.

FrustumArray#setFromArrayCamera 在此方法之前每次渲染必须调用一次。

point

要测试的点。
返回： 该点在任何相机中是否可见。

.copy( source : FrustumArray ) : FrustumArray

将给定截锥体数组的值复制到此实例.

source

要复制的视锥体数组.
返回：对此视锥体数组的引用。

.intersectsBox( box : Box3 ) : boolean

如果给定的边界框与任何缓存相交，则返回true平截头体.

FrustumArray#setFromArrayCamera 在此方法之前每次渲染必须调用一次。

box

要测试的边界框。
返回： 该框在任何相机中是否可见。

.intersectsObject( object : Object3D ) : boolean

如果 3D 对象的边界球体与任何缓存相交，则返回 true平截头体.

FrustumArray#setFromArrayCamera 在此方法之前每次渲染必须调用一次。

object

要测试的 3D 对象.
返回： 3D 对象在任何相机中是否可见。

.intersectsSphere( sphere : Sphere ) : boolean

如果给定的边界球体与任何缓存相交，则返回 true平截头体.

FrustumArray#setFromArrayCamera 在此方法之前每次渲染必须调用一次。

sphere

要测试的边界球.
返回：球体在任何相机中是否可见。

.intersectsSprite( sprite : Sprite ) : boolean

如果给定的精灵与任何缓存相交，则返回true视锥体.

FrustumArray#setFromArrayCamera 在此方法之前每次渲染必须调用一次。

sprite

要测试的精灵.
返回： 精灵在任何相机中是否可见。

.setFromArrayCamera( cameraArray : ArrayCamera ) : FrustumArray

为给定阵列相机的每个相机计算并缓存视锥体。

cameraArray

其子相机定义了视锥体的阵列相机平截头体.
返回：对此视锥体数组的引用。
