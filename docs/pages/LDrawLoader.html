LDrawLoader

LDraw 格式的加载器。

[LDraw](https://ldraw.org/} (LEGO Draw) 是一个 open format specification 用于描述乐高和其他构造集 3D 模型。

LDraw 资源（通常扩展名为 .ldr、.dat 或 .txt 的文本文件）只能描述单个构造 件，或整个模型。对于模型，LDraw 文件可以引用其他 LDraw 文件，这些文件是 从使用 setPartsLibraryPath 设置的库路径加载。你通常会下载LDraw官方零件库， 解压到一个文件夹并将 setPartsLibraryPath 指向它。

库部件将通过子文件夹“parts”、“p”和“models”中的反复试验来加载。这些文件访问 对于 Web 环境来说不是最佳的，因此已经制作了一个脚本工具来打包 LDraw 文件及其所有依赖项 到一个文件中，加载速度更快。请参阅“打包 LDraw 模型”部分。 LDrawLoader 示例加载 几个打包的文件。官方零件库由于体积较大，未包含在内。

LDrawLoader 支持以下扩展：

  • !COLOUR：颜色和表面处理声明。
  • BFC：背面剔除规范。
  • !类别: 模型/零件类别声明.
  • !关键字: 模型/零件关键字声明.

代码示例

const loader = new LDrawLoader();
loader.setConditionalLineMaterial( LDrawConditionalLineMaterial ); // the type of line material depends on the used renderer
const object = await loader.loadAsync( 'models/ldraw/officialLibrary/models/car.ldr_Packed.mpd' );
scene.add( object );

导入

LDrawLoader 是一个插件，必须显式导入，请参见Installation#Addons.

import { LDrawLoader } from 'three/addons/loaders/LDrawLoader.js';

构造函数

new LDrawLoader( manager : LoadingManager )

构造一个新的 LDraw 加载程序。

manager

加载管理器。

方法

.addDefaultMaterials() : LDrawLoader

使用默认材质初始化加载程序。

返回：对此加载程序的引用。

.addMaterial( material : Material ) : LDrawLoader

添加一个将单一材料添加到装载机的材料库中。

material

要添加的材料。
返回：对此加载程序的引用。

.addMaterials( materials : Array.<Material> ) : LDrawLoader

将材料列表添加到装载机的材料库中。

materials

要添加的材料。
返回：对此加载程序的引用。

.clearMaterials() : LDrawLoader

清除装载机的材料库.

返回：对此加载程序的引用。

.getMainEdgeMaterial() : Material

返回边缘主LDraw颜色的材质。

返回：材质。如果未找到材质，则返回 null。

.getMainMaterial() : Material

返回主 LDraw 颜色的材质。

对于已加载的 LDraw 资源，返回与主颜色代码关联的材质。 此方法可用于修改模型或暴露模型的零件的主要材质。

主要颜色代码是为 LDraw 零件着色的标准方法。三角形是“16”， “24”代表边缘。通常一个完整的模型不会暴露主色（即没有任何部分 在顶层使用代码“16”，因为它们被分配了其他特定颜色）LDraw 另一方面，part 文件会将代码“16”公开为彩色，并且可以有附加的 固定颜色。

返回：材质。如果未找到材质，则返回 null。

.getMaterial( colorCode : string ) : Material

返回给定颜色代码的材质。

colorCode

颜色代码。
返回：材质。如果未找到材质，则返回 null。

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定的 URL 加载并传递加载的 LDraw 资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( text : string, onLoad : function, onError : onErrorCallback )

解析给定的 LDraw 数据并返回结果组。

text

原始 VRML 数据作为字符串。
onLoad

在加载/解析过程完成时执行完成.
onError

发生错误时执行。
覆盖： Loader#parse

.preloadMaterials( url : string ) : Promise (async)

此异步方法从单个 LDraw 文件预加载材质。在官方 零件库有一个特殊文件，总是第一个加载（LDConfig.ldr） 并包含所有标准颜色代码。该方法旨在与 未打包的文件，例如在预加载材料和零件的编辑器中 按需加载。

url

LDraw 材质资源的路径。
返回： 预加载完成后解析的 Promise。

.setConditionalLineMaterial( type : LDrawConditionalLineMaterial.constructor | LDrawConditionalLineNodeMaterial.constructor ) : LDrawLoader

设置取决于所使用的渲染器的条件线条材质类型。 使用 WebGLRenderer 时使用 LDrawConditionalLineMaterial 且 使用WebGPURenderer时的LDrawConditionalLineNodeMaterial__.

type

条件线材质类型。
返回：对此加载程序的引用。

.setFileMap( fileMap : Object.<string, string> ) : LDrawLoader

设置将引用的库文件名映射到新文件名的映射。 如果未指定 fileMap（默认），则将通过试用和访问来访问库部件 子文件夹“parts”、“p”和“models”中出现错误。

fileMap

要设置的文件映射。
返回：对此加载程序的引用。

.setMaterials( materials : Array.<Material> ) : LDrawLoader

设置加载程序的材质库。该方法清除现有的 材料定义.

materials

要设置的材料.
返回：对此加载程序的引用。

.setPartsLibraryPath( path : string ) : LDrawLoader

必须在load()之前调用此方法，除非要加载的模型未引用 库零件（通常它是一个模型，所有零件都打包在一个文件中）。

path

用于加载引用零件的库零件文件的路径。 这与Loader.setPath不同，Loader.setPath指示从.
返回：对此加载程序的引用。
