Object3D

这是 Three.js 中大多数对象的基类，并提供了一组 用于在 3D 空间中操作对象的属性和方法。

构造函数

new Object3D()

构造一个新的 3D 对象。

属性

.animations : Array.<AnimationClip>

保存 3D 对象的动画剪辑的数组。

.castShadow : boolean

当设置为 true 时，将渲染 3D 对象进入阴影贴图。

默认为 false.

.children : Array.<Object3D>

保存此实例的子 3D 对象的数组。

.customDepthMaterial : Material | undefined

渲染到深度图时要使用的自定义深度材质。只能使用 在网格的上下文中。当使用 DirectionalLight 或 SpotLight 进行阴影投射时， 如果要修改顶点着色器中的顶点位置，则必须指定自定义深度 用于正确阴影的材料。

仅与WebGLRenderer上下文相关。

默认为undefined.

.customDistanceMaterial : Material | undefined

与Object3D#customDepthMaterial相同，但与PointLight.

仅与WebGLRenderer上下文相关。

默认为undefined.

.frustumCulled : boolean

当设置为 true 时，3D 对象将通过视锥剔除来实现。

默认为true.

.id : number (readonly)

3D 对象的 ID。

.isObject3D : boolean (readonly)

该标志可用于类型测试。

默认为true.

.layers : Layers

图层3D 对象的成员资格。 3D 对象仅在具有以下特征时才可见 至少有一层与所使用的相机相同。这个属性还可以 用于在使用 Raycaster 时过滤掉光线相交测试中不需要的对象。

.matrix : Matrix4

表示局部空间中对象的变换矩阵。

.matrixAutoUpdate : boolean

当设置为 true 时，引擎自动从位置计算局部矩阵， 每帧旋转和缩放。如果设置为 false，则应用程序负责重新计算 通过调用 updateMatrix().

获取局部矩阵。Object3D.DEFAULT_MATRIX_AUTO_UPDATE.

默认为true.

.matrixWorld : Matrix4

表示对象在世界空间中的变换矩阵。 如果 3D 对象没有父对象，则它与本地变换矩阵相同

.matrixWorldAutoUpdate : boolean

当设置为 true 时，引擎会自动从当前本地计算世界矩阵 矩阵和对象的变换层次结构。如果设置为 false，则应用程序负责 通过直接更新matrixWorld属性来重新计算世界矩阵。

所有3D对象的默认值由Object3D.DEFAULT_MATRIX_WORLD_AUTO_UPDATE定义。

默认为true.

.matrixWorldNeedsUpdate : boolean

当设置为true时，它计算该帧中的世界矩阵并重置此属性 到 false.

默认为 false.

.modelViewMatrix : Matrix4

表示对象的模型视图矩阵。

.name : string

3D 对象的名称。

.normalMatrix : Matrix3

表示对象的法线矩阵.

.parent : Object3D

对父对象的引用.

默认为null.

.pivot : Vector3

旋转和缩放变换的枢轴点。 设置后，旋转和缩放将围绕该点应用 而不是对象的原点。

默认为null.

.position : Vector3

表示对象的本地位置。

默认为(0,0,0).

.quaternion : Quaternion

表示对象的本地旋转为四元数。

.receiveShadow : boolean

当设置为 true 时，3D 对象会受到scene.

默认为 false.

.renderOrder : number

该值允许场景图对象的默认渲染顺序 尽管不透明和透明对象保持独立排序，但已被覆盖。 当为 Group 的实例设置此属性时，所有后代 对象将被排序并一起渲染。排序是从最低到最高 渲染顺序。

默认为0.

.rotation : Euler

以欧拉角表示对象的局部旋转，以弧度为单位。

默认为(0,0,0).

.scale : Vector3

表示对象的局部比例。

默认为(1,1,1).

.static : boolean

3D 对象是否应该是静态的。如果设置为true，则表示 3D 对象在初始渲染器之后不会更改。这包括 几何和材料设置。渲染器可以处理静态 3D 对象 稍微快一些，因为可以绕过某些状态检查。

仅在 WebGPURenderer 的上下文中相关。

默认为 false.

.type : string (readonly)

type属性用于检测对象类型 在序列化/反序列化的上下文中。

.up : Vector3

定义影响 3D 对象的 up 方向 通过 Object3D#lookAt.

等方法确定方向__所有 3D 对象的默认值由 Object3D.DEFAULT_UP.

.userData : Object

定义，该对象可用于存储有关 3D 对象的自定义数据。它 不应保存对函数的引用，因为它们不会被克隆。

.uuid : string (readonly)

3D 对象的 UUID.

.visible : boolean

当设置为 true 时，将渲染 3D 对象。

默认为true.

.DEFAULT_MATRIX_AUTO_UPDATE : boolean

Object3D#matrixAutoUpdate 的默认设置 新创建的 3D 对象。

默认为true.

.DEFAULT_MATRIX_WORLD_AUTO_UPDATE : boolean

默认设置为 Object3D#matrixWorldAutoUpdate 新创建的3D对象。

默认为true.

.DEFAULT_UP : Vector3

对象的默认向上方向，也用作默认方向 DirectionalLight 和 HemisphereLight.

的位置默认为 (0,1,0).

方法

.add( object : Object3D ) : Object3D

将给定 3D 对象作为子项添加到此 3D 对象。任意数量的 可以添加对象。此处传入的对象的任何当前父对象都将是 已删除，因为一个对象最多可以有一个父对象。

object

要添加的 3D 对象。
Fires:
  • Object3D#event:added
  • Object3D#event:childadded
返回：对此实例的引用。

.applyMatrix4( matrix : Matrix4 )

将给定的变换矩阵应用于对象并更新对象的位置， 旋转和缩放。

matrix

变换矩阵。

.applyQuaternion( q : Quaternion ) : Object3D

将给定四元数表示的旋转应用到 3D 对象。

q

四元数。
返回：对此实例的引用。

.attach( object : Object3D ) : Object3D

添加给定 3D 对象作为此 3D 对象的子对象，同时维护对象的世界 转变。此方法不支持具有非均匀缩放节点的场景图。

object

要附加的 3D 对象。
Fires:
  • Object3D#event:added
  • Object3D#event:childadded
返回：对此实例的引用。

Fires:

返回一个新的 3D 对象，其中包含从中复制的值实例.

recursive

默认为true.

.updateMatrix()

通过从当前位置计算来更新局部空间中的变换矩阵 位置、旋转和缩放值。

.updateMatrixWorld( force : boolean )

更新此 3D 对象及其后代在世界空间中的变换矩阵。

为了确保正确的结果，此方法还会重新计算 3D 对象的变换矩阵 本地空间。局部矩阵和世界矩阵的计算可以通过以下方式控制 Object3D#matrixAutoUpdate 和 Object3D#matrixWorldAutoUpdate 标志都是 默认为 true。 如果您需要对更新矩阵过程进行更多控制，请将这些标志设置为 false。

force

当设置为 true 时，甚至会强制重新计算世界矩阵 当 Object3D#matrixWorldNeedsUpdate 是 false.

默认为 false.

.updateWorldMatrix( updateParents : boolean, updateChildren : boolean, force : boolean )

Object3D#updateMatrixWorld 的替代版本，对 更新祖先节点和后代节点。

updateParents

是否应更新祖先节点。

默认为 false.
updateChildren

是否应更新后代节点。

默认为 false.
force

当设置为 true 时，甚至会强制重新计算世界矩阵 当 Object3D#matrixWorldNeedsUpdate 是 false.

默认为 false.
