SSGINode

用于将屏幕空间全局照明（SSGI）应用到场景的后处理节点。

参考：

  • https://github.com/cdrinmatane/SSRT3.
  • https://cdrinmatane.github.io/posts/ssaovb-code/.
  • https://cdrinmatane.github.io/cgspotlight-slides/ssilvb_slides.pdf.

效果的质量和性能主要取决于 sliceCount 和 stepCount。 每个像素的总采样次数为 sliceCount * stepCount * 2。这里有一些推荐的预设，取决于是否使用时间过滤。

使用时间过滤（推荐）：

  • 低：sliceCount 的 1，stepCount 的 12。
  • 媒介：sliceCount的2，stepCount的8。
  • 高：sliceCount的3，stepCount的16。

如果您注意到时间不稳定性（例如闪烁），请使用更高的切片计数。减少样品 然后计数以减轻性能损失。

没有时间过滤：

  • 低：sliceCount的2，stepCount的6。
  • 介质：sliceCount 的 3，stepCount 的 8。
  • 高：sliceCount 的 4，stepCount 的 12。

导入

SSGINode是一个插件，必须显式导入，请参阅安装#Addons.

import { ssgi } from 'three/addons/tsl/display/SSGINode.js';

构造函数

new SSGINode( beautyNode : TextureNode, depthNode : TextureNode, normalNode : TextureNode, camera : PerspectiveCamera )

构造一个新的SSGI节点。

beautyNode

代表美感或场景通道的纹理节点。
depthNode

代表场景深度的纹理节点。
normalNode

代表场景法线的纹理节点.
camera

渲染场景的相机。

属性

.aoIntensity : UniformNode.<float>

Power应用于 AO 的函数，使其显得更暗/更亮。应在 [0, 4].

默认为1.

.backfaceLighting : UniformNode.<float>

背面表面发射的光量范围内。 应在 [0, 1].

默认为0.

.beautyNode : TextureNode

代表美感或场景通道的纹理节点。

.depthNode : TextureNode

表示场景深度的节点。

.expFactor : UniformNode.<float>

范围内控制样本分布。它是在每一步应用的指数，随着距离的增加，步长逐渐增大。 应在 [1, 3].

默认为2.

.giIntensity : UniformNode.<float>

间接漫射光强度范围内。应在 [0, 100].

默认为10.

.normalNode : TextureNode

表示场景法线的节点。如果没有法线传递给 构造函数（因为MRT不可用），法线可以自动 根据着色器中的深度值重建。

.radius : UniformNode.<float>

世界空间中的有效采样半径范围内。 AO和GI只能在该半径范围内产生影响。 应在 [1, 25].

默认为 12.

.sliceCount : UniformNode.<uint>

每像素半球切片数范围内。这会产生很大的性能成本，应尽可能保持较低。 应在 [1, 4].

默认为1.

.stepCount : UniformNode.<uint>

沿给定半球切片一侧采集的样本数范围内。这会产生很大的性能成本，应该 保持尽可能低。 应在 [1, 32].

默认为 12.

.thickness : UniformNode.<float>

屏幕上对象的恒定厚度值（以世界单位表示）范围内。允许光线穿过超过该厚度值的表面。 应在 [0.01, 10] 范围内。

默认为1.

.updateBeforeType : string

自节点渲染以来，updateBeforeType 设置为 NodeUpdateType.FRAME updateBefore().

中每帧效果一次，默认为 'frame'.

覆盖： TempNode#updateBeforeType

.useLinearThickness : UniformNode.<bool>

是否随距离线性增加厚度（避免随距离丢失细节）。

默认为 false.

.useScreenSpaceSampling : UniformNode.<bool>

使样本距离在屏幕空间而不是世界空间中（有助于获得更多细节） close).

默认为true.

.useTemporalFiltering : boolean

是否使用时间过滤。将此属性设置为 true 需要使用 TRAANode。这将有助于减少噪音 尽管它引入了典型的 TAA 伪影，例如重影和时间 不稳定性.

如果将此属性设置为 false，则通过 DenoiseNode 进行手动降噪 为必填项。

默认为true.

方法

.dispose()

释放内部资源。这个方法应该被调用 当不再需要效果时。

覆盖： TempNode#dispose

.getAONode() : PassTextureNode

以纹理节点的形式返回效果的 AO 结果。

返回： 表示效果的 AO 结果的纹理节点。

.getGINode() : PassTextureNode

以纹理的形式返回效果的 GI 结果节点.

返回：表示效果的GI结果的纹理节点.

.setSize( width : number, height : number )

设置效果的大小.

width

效果的宽度.
height

效果的高度.

.setup( builder : NodeBuilder ) : PassTextureNode

此方法用于设置效果的TSL code.

builder

当前节点构建器.
覆盖： TempNode#setup

.updateBefore( frame : NodeFrame )

此方法用于每帧渲染一次效果。

frame

当前节点框架.
覆盖： TempNode#updateBefore
