Reflector

可用于创建像镜子一样的平坦反射表面。

请注意，此类只能与 WebGLRenderer 一起使用。 使用 WebGPURenderer 时，请使用 ReflectorNode.

代码示例

const geometry = new THREE.PlaneGeometry( 100, 100 );
const reflector = new Reflector( geometry, {
	clipBias: 0.003,
	textureWidth: window.innerWidth * window.devicePixelRatio,
	textureHeight: window.innerHeight * window.devicePixelRatio,
	color: 0xc1cbcb
} );
scene.add( reflector );

导入

Reflector 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { Reflector } from 'three/addons/objects/Reflector.js';

构造函数

new Reflector( geometry : BufferGeometry, options : Reflector~Options )

构造一个新的反射器.

geometry

反射器的几何形状.
options

配置选项.

属性

.forceUpdate : boolean

是否强制更新，无论反射器是否 是否在视图中。

默认为 false.

.isReflector : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Mesh#dispose

.getReflectionCamera( camera : Camera ) : Camera

返回给定相机的反射相机。反射相机用于 从反射器的视图渲染场景，以便生成正确的反射。

camera

场景相机.
返回： 相应的反射相机。

.getRenderTarget() : WebGLRenderTarget

返回反射器的内部渲染目标。

返回： 内部渲染target

类型定义

.Options

Reflector的构造函数选项.

color
number | Color | string

反射器的颜色.

默认为0x7F7F7F.
textureWidth
number

纹理宽度。值越高，反射越清晰，但成本也越高。

默认为512.
textureHeight
number

纹理高度。值越高，反射越清晰，但成本也越高。

默认为512.
clipBias
number

剪辑偏差。

默认为0.
shader
Object

可用于传入定义反射视图如何投影到反射器几何体上的自定义着色器。
multisample
number

用于 MSAA 的样本数。 0 禁用 MSAA。

默认为4.
