UniformsUtils

提供用于管理制服的实用程序函数。

静态方法

.cloneUniforms( src : Object ) : Object

通过执行深层复制来克隆给定的制服定义。这意味着 如果uniform的值引用一个像Vector3或Texture这样的对象， 克隆的制服将引用新的对象引用。

src

表示统一定义的对象。
返回： 克隆的统一。

.mergeUniforms( uniforms : Array ) : Object

将给定的统一定义合并到单个对象中。自从 方法内部使用cloneUniforms()，它在以下情况下执行深复制： 生成合并的统一定义。

uniforms

包含统一定义的对象数组。
返回：合并后的制服.
