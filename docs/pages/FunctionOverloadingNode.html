FunctionOverloadingNode

此类允许定义多个重载版本 具有相同的功能。取决于函数的参数 调用时，节点选择最适合的重载版本。

构造函数

new FunctionOverloadingNode( functionNodes : Array.<function()>, …parametersNodes : Node )

构造一个新的函数重载节点。

functionNodes

Fn 函数定义数组。
parametersNodes

参数列表节点.

属性

.functionNodes : Array.<function()>

Fn 函数定义数组。

.global : boolean

此节点被标记为全局.

默认为true.

覆盖： Node#global

.parametersNodes : Array.<Node>

参数列表节点.

方法

.generateNodeType( builder : NodeBuilder ) : string

此方法被覆盖，因为节点类型是从推断的 函数的返回类型。

builder

当前节点构建器.
覆盖： Node#generateNodeType
返回： 节点类型。

.getCandidateFn( builder : NodeBuilder ) : FunctionNode

返回当前参数的候选函数。

builder

当前节点构建器.
返回：候选函数。

.setup( builder : NodeBuilder ) : Node

设置当前参数的节点参数.

builder

当前节点构建器.
覆盖： Node#setup
返回： 设置节点.
