DRACOExporter

使用 Draco 库压缩几何图形的导出器。

Draco 是一个用于压缩和的开源库 解压缩 3D 网格和点云。压缩后的几何体可以明显更小， 以客户端设备上的额外解码时间为代价。

独立的 Draco 文件具有 .drc 扩展名，并包含顶点位置， 法线、颜色和其他属性。 Draco 文件不包含材料， 纹理、动画或节点层次结构 - 要使用这些功能，请嵌入 Draco 几何体 glTF 文件内部。普通的 glTF 文件可以转换为 Draco 压缩的 glTF 文件 使用 glTF-Pipeline.

导出器要求将 Draco 编码器作为全局脚本加载advance:

<script src="https://cdn.jsdelivr.net/gh/google/draco@1.5.7/javascript/draco_encoder.js"></script>

const exporter = new DRACOExporter();
const data = await exporter.parseAsync( mesh, options );

导入

DRACOExporter 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { DRACOExporter } from 'three/addons/exporters/DRACOExporter.js';

构造函数

new DRACOExporter()

属性

.MESH_EDGEBREAKER_ENCODING : number (constant)

Edgebreaker编码.

默认为1.

.MESH_SEQUENTIAL_ENCODING : number (constant)

顺序编码.

默认为0.

方法

.parse()

已弃用：使用DRACOExporter#parseAsync代替。

.parseAsync( object : Mesh | Points, options : DRACOExporter~Options ) : Promise.<Int8Array> (async)

解析给定的网格或点云并生成Draco输出.

object

要导出的网格或点云.
options

导出选项.
返回：使用导出的Draco解析的Promise.

类型定义

.Options

导出选项DRACOExporter.

decodeSpeed
number

指示如何调整编码器的解码速度（0 提供更好的速度但最差的质量）。

默认为5.
encodeSpeed
number

指示如何调整编码器参数（0 提供更好的速度但最差的质量）。

默认为5.
encoderMethod
number

顺序（很少压缩）或破边者。 Edgebreaker 以确定性、螺旋状的方式遍历网格的三角形，这提供了此数据格式的大部分优点。

默认为1.
quantization
Array.<number>

表示按顺序存储在 draco 文件中的每种类型数据的精度（POSITION、NORMAL、COLOR、TEX_COORD、GENERIC）。

默认为[ 16, 8, 8, 8, 8 ].
exportUvs
boolean

是否导出UV.

默认为true.
exportNormals
boolean

是否导出法线.

默认为true.
exportColor
boolean

是否导出颜色.

默认为 false.
