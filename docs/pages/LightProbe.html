LightProbe

光探针是向 3D 场景添加灯光的另一种方法。不像 经典光源（例如定向光、点光源或聚光灯）、光 探头不发光。相反，它们存储有关光的信息 穿过3D空间。在渲染过程中，照射到 3D 物体上的光线 使用来自光探针的数据来近似对象。

光探针通常是从（辐射度）环境贴图创建的。的 类 LightProbeGenerator 可用于创建光探针 立方体纹理或渲染目标。然而，光估计数据也可以 以其他形式提供，例如由 WebXR 提供。这使得能够渲染 对现实世界照明做出反应的增强现实内容。

Three.js 中当前的探针实现支持所谓的漫反射 光探头。这种类型的光探头在功能上相当于 辐照度环境贴图。

构造函数

new LightProbe( sh : SphericalHarmonics3, intensity : number )

构造一个新的光探针。

sh

表示编码的照明信息的球谐函数。
intensity

灯光的强度/强度.

默认为1.

属性

.isLightProbe : boolean (readonly)

该标志可用于类型测试。

默认为true.

.sh : SphericalHarmonics3

A光探针使用球谐函数来编码照明信息。
