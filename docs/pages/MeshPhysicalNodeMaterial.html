MeshPhysicalNodeMaterial

MeshPhysicalMaterial.

构造函数

new MeshPhysicalNodeMaterial( parameters : Object )

的节点材质版本__构造一个新的网格物理节点材料.

parameters

配置参数.

属性

.anisotropyNode : Node.<float>

物理材料的各向异性默认是从 anisotropy 属性。该节点属性允许覆盖默认值 并用节点定义各向异性。

如果您不想覆盖各向异性而是修改现有的 值，请使用 materialAnisotropy.

默认为null.

.attenuationColorNode : Node.<vec3>

物理材质的衰减颜色默认从 attenuationColor 属性。该节点属性允许覆盖默认值 并用节点定义衰减颜色。

如果您不想覆盖衰减颜色而是修改现有的 值，请使用 materialAttenuationColor.

默认为null.

.attenuationDistanceNode : Node.<float>

物理材质的衰减距离默认从 attenuationDistance 属性。该节点属性允许覆盖默认值 并用节点定义衰减距离。

如果您不想覆盖衰减距离而是修改现有的 值，请使用 materialAttenuationDistance.

默认为null.

.clearcoatNode : Node.<float>

物理材质的透明涂层默认从 clearcoat 推断出来 和 clearcoatMap 属性。该节点属性允许覆盖默认值 并用节点定义透明涂层。

如果您不想覆盖透明涂层但修改现有的 值，请使用 materialClearcoat.

默认为null.

.clearcoatNormalNode : Node.<vec3>

物理材质的透明涂层法线默认从 clearcoatNormalMap 推断出来 财产。该节点属性允许覆盖默认值 并用节点定义透明涂层法线。

如果您不想覆盖透明涂层法线但修改现有的 值，请使用 materialClearcoatNormal.

默认为null.

.clearcoatRoughnessNode : Node.<float>

物理材料的透明涂层粗糙度默认从 clearcoatRoughness 推断 和 clearcoatRoughnessMap 属性。该节点属性允许覆盖默认值 并用节点定义透明涂层粗糙度。

如果您不想覆盖透明涂层粗糙度但修改现有的 值，请使用 materialClearcoatRoughness.

默认为null.

.dispersionNode : Node.<float>

默认情况下，物理材质的色散是从 dispersion 属性。该节点属性允许覆盖默认值 并用节点定义分散度。

如果您不想覆盖分散度而是修改现有的分散度 值，请使用 materialDispersion.

默认为null.

.iorNode : Node.<float>

物理材质的 ior 默认情况下从 ior 推断 财产。该节点属性允许覆盖默认值 并用节点定义 ior 。

如果您不想覆盖 ior 但修改现有的 值，请使用 materialIOR.

默认为null.

.iridescenceIORNode : Node.<float>

物理材质的虹彩 IOR 默认从 iridescenceIOR 推断 财产。该节点属性允许覆盖默认值 并用节点定义虹彩 IOR。

如果您不想覆盖虹彩 IOR 但修改现有的 值，请使用 materialIridescenceIOR.

默认为null.

.iridescenceNode : Node.<float>

物理材质的彩虹色默认从 iridescence 推断出来 财产。该节点属性允许覆盖默认值 并用节点定义虹彩。

如果您不想覆盖虹彩但修改现有的 值，请使用 materialIridescence.

默认为null.

.iridescenceThicknessNode : Node.<float>

物理材质的虹彩厚度默认从 iridescenceThicknessRange 推断 和 iridescenceThicknessMap 属性。该节点属性允许覆盖默认值 并用节点定义虹彩厚度。

如果您不想覆盖虹彩厚度但修改现有的 值，请使用 materialIridescenceThickness.

默认为null.

.isMeshPhysicalNodeMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.retroreflectivityNode : Node.<float>

物理材料的逆反射强度默认从 retroreflectivity 属性。该节点属性允许覆盖默认值 并用节点定义逆反射强度。

如果您不想覆盖逆反射强度而是修改现有的 值，请使用 materialRetroreflectivity.

默认为null.

.sheenNode : Node.<vec3>

物理材质的光泽默认从 sheen、sheenColor 推断 和 sheenColorMap 属性。该节点属性允许覆盖默认值 并用节点定义光泽。

如果您不想覆盖光泽但修改现有的光泽 值，请使用 materialSheen.

默认为null.

.sheenRoughnessNode : Node.<float>

物理材质的光泽粗糙度默认从 sheenRoughness 推断出来，并且 sheenRoughnessMap 属性。该节点属性允许覆盖默认值 并用节点定义光泽粗糙度。

如果您不想覆盖光泽粗糙度但修改现有的 值，请使用 materialSheenRoughness.

默认为null.

.specularColorNode : Node.<vec3>

物理材质的镜面反射颜色默认从 specularColor 推断 和 specularColorMap 属性。该节点属性允许覆盖默认值 并用节点定义镜面反射颜色。

如果您不想覆盖镜面反射颜色但修改现有的 值，请使用 materialSpecularColor.

默认为null.

.specularIntensityNode : Node.<float>

物理材质的镜面反射强度默认从 specularIntensity 推断 和 specularIntensityMap 属性。该节点属性允许覆盖默认值 并用节点定义镜面反射强度。

如果您不想覆盖镜面反射强度但修改现有的 值，请使用 materialSpecularIntensity.

默认为null.

.thicknessNode : Node.<float>

物理材料的厚度默认从 thickness 推断出 thicknessMap 属性。该节点属性允许覆盖默认值 并用节点定义厚度。

如果您不想覆盖厚度而是修改现有的 值，请使用 materialThickness.

默认为null.

.transmissionNode : Node.<float>

物理材质的传输默认从 transmission 推断出 transmissionMap 属性。该节点属性允许覆盖默认值 并用节点定义传输。

如果您不想覆盖传输但修改现有的 值，请使用 materialTransmission.

默认为null.

.useAnisotropy : boolean

照明模型是否应使用各向异性。

默认为true.

.useClearcoat : boolean

照明模型是否应使用透明涂层。

默认为true.

.useDispersion : boolean

照明模型是否应使用色散或not.

默认为true.

.useIridescence : boolean

照明模型是否应使用虹彩.

默认为true.

.useRetroreflection : boolean

照明模型是否应使用逆反射.

默认为true.

.useSheen : boolean

照明模型是否应使用光泽.

默认为true.

.useTransmission : boolean

照明模型是否应使用透射或not.

默认为true.
