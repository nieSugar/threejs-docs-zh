LineDashedNodeMaterial

LineDashedMaterial的节点材质版本__.

构造函数

new LineDashedNodeMaterial( parameters : Object )

构造一个新的线虚线节点材质.

parameters

配置参数.

属性

.dashOffset : number

短划线偏移量。

默认为0.

.dashScaleNode : Node.<float>

The默认情况下，破折号材质的比例是从 scale 推断出来的 财产。该节点属性允许覆盖默认值 并用节点定义比例尺。

如果您不想覆盖比例尺而是修改现有的比例尺 值，请使用 materialLineScale.

默认为null.

.dashSizeNode : Node.<float>

默认情况下，从 dashSize 推断出短划线材质的短划线大小 财产。该节点属性允许覆盖默认值 并用节点定义破折号大小。

如果您不想覆盖破折号大小但修改现有的 值，请使用 materialLineDashSize.

默认为null.

.gapSizeNode : Node.<float>

默认情况下，破折号材料的间隙大小是从 gapSize 推断出来的 财产。该节点属性允许覆盖默认值 并用节点定义间隙大小。

如果您不想覆盖间隙大小但修改现有的 值，请使用 materialLineGapSize.

默认为null.

.isLineDashedNodeMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.offsetNode : Node.<float>

破折号材质的偏移量默认从 dashOffset 推断出来 财产。该节点属性允许覆盖默认值 并用节点定义偏移量。

如果您不想覆盖偏移量而是修改现有的 值，请使用 materialLineDashOffset.

默认为null.

方法

.setupVariants( builder : NodeBuilder )

设置破折号特定节点变量。

builder

当前节点构建器.
