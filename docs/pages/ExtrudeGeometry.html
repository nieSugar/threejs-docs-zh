ExtrudeGeometry

从路径形状创建拉伸几何图形。

代码示例

const length = 12, width = 8;
const shape = new THREE.Shape();
shape.moveTo( 0,0 );
shape.lineTo( 0, width );
shape.lineTo( length, width );
shape.lineTo( length, 0 );
shape.lineTo( 0, 0 );
const geometry = new THREE.ExtrudeGeometry( shape );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const mesh = new THREE.Mesh( geometry, material ) ;
scene.add( mesh );

构造函数

new ExtrudeGeometry( shapes : Shape | Array.<Shape>, options : ExtrudeGeometry~Options )

构造新的拉伸几何图形。

shapes

形状或数组形状.
options

拉伸设置.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object, shapes : Array.<Shape> ) : ExtrudeGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
shapes

形状数组.
返回： 一个新实例.

类型定义

.Options

表示几何构造函数的options类型。

curveSegments
number

几何图形上的点数曲线.

默认为 12.
steps
number

用于沿挤出样条线深度细分线段的点数。

默认为1.
depth
number

挤出样条线的深度形状.

默认为1.
bevelEnabled
boolean

是否对形状进行斜切.

默认为true.
bevelThickness
number

斜角进入原始形状的深度。

默认为0.2.
bevelSize
number

距离斜角延伸的形状轮廓。

默认为 bevelThickness-0.1.
bevelOffset
number

距斜角开始的形状轮廓的距离。

默认为0.
bevelSegments
number

斜角层数。

默认为3.
extrudePath
Curve

A形状应沿其挤出的 3D 样条路径。路径挤出不支持斜角。

默认为null.
UVGenerator
Object

为自定义 UV 生成提供 UV 生成器功能的对象。
