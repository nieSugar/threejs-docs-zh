FullScreenQuad

这个模块是需要渲染完整的通道的帮助器 屏幕效果在后期处理中很常见。

预期用途是重用单个全屏四边形进行渲染 随后的传递只需重新分配 material 引用即可。

此模块只能与WebGLRenderer一起使用。

导入

FullScreenQuad 是一个插件，必须显式导入，请参阅 安装#Addons.

import { FullScreenQuad } from 'three/addons/postprocessing/Pass.js';

构造函数

new FullScreenQuad( material : Material )

构造一个新的全屏四边形。

material

渲染全屏四边形的材质.

属性

.material : Material

四边形的Material.

覆盖： Mesh#material

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用程序中不再使用该实例时，都会使用该方法。

覆盖： Mesh#dispose

.render( renderer : WebGLRenderer )

渲染全屏四边形。

renderer

渲染器.
