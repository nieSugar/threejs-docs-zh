UnpackFloatNode

此节点表示从 32 位无符号整数解包值的操作，将结果重新解释为浮点向量

构造函数

new UnpackFloatNode( encoding : 'snorm' | 'unorm' | 'float16', uintNode : Node )

encoding

描述整数值如何映射到浮点数的数字编码range
uintNode

要解包的uint节点

属性

.encoding : string

数值编码.

.isUnpackFloatNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.layout : '2x16' | '4x8'

打包整数的组件布局。

默认为'2x16'.

.uintNode : Node

要解包的无符号整数
