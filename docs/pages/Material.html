Material

材质的抽象基类。

材质定义可渲染 3D 对象的外观。

构造函数

new Material() (abstract)

构造一个新的材质.

属性

.allowOverride : boolean

是否可以使用Scene#overrideMaterial覆盖材质。

默认为true.

.alphaHash : boolean

启用 alpha 哈希透明度，这是 Material#transparent 或 Material#alphaTest 的一种替代方法。如果不透明度低于随机阈值，材料将不会被渲染。随机化会引入一些颗粒或噪点，但可以在不涉及排序问题的情况下近似 alpha 混合。使用 TAA 可以减少由此产生的噪点。

默认为 false.

.alphaTest : number (readonly)

设置运行 alpha 测试时要使用的 alpha 值。材质 如果不透明度低于此值，则不会渲染。

默认为0.

.alphaToCoverage : boolean

是否应启用 alpha 覆盖。只能与启用 MSAA 的上下文一起使用 （意味着当使用设置为 true 的 antialias 参数创建渲染器时）。启用此功能 将平滑剪辑平面边缘和 alphaTest 剪辑边缘上的锯齿。

默认为 false.

.blendAlpha : number

表示常量混合颜色的 alpha 值。

此属性仅在使用自定义混合时有效 ConstantAlpha 或OneMinusConstantAlpha.

默认为0.

.blendColor : Color

表示常量混合颜色的 RGB 值。

此属性仅在使用自定义混合与 ConstantColor 或OneMinusConstantColor.

默认为(0,0,0).

.blendDst : ZeroFactor | OneFactor | SrcColorFactor | OneMinusSrcColorFactor | SrcAlphaFactor | OneMinusSrcAlphaFactor | DstAlphaFactor | OneMinusDstAlphaFactor | DstColorFactor | OneMinusDstColorFactor | SrcAlphaSaturateFactor | ConstantColorFactor | OneMinusConstantColorFactor | ConstantAlphaFactor | OneMinusConstantAlphaFactor

定义混合目标因子。

默认为 OneMinusSrcAlphaFactor.

.blendDstAlpha : ZeroFactor | OneFactor | SrcColorFactor | OneMinusSrcColorFactor | SrcAlphaFactor | OneMinusSrcAlphaFactor | DstAlphaFactor | OneMinusDstAlphaFactor | DstColorFactor | OneMinusDstColorFactor | SrcAlphaSaturateFactor | ConstantColorFactor | OneMinusConstantColorFactor | ConstantAlphaFactor | OneMinusConstantAlphaFactor

定义混合目标 Alpha 因子。

默认为null.

.blendEquation : AddEquation | SubtractEquation | ReverseSubtractEquation | MinEquation | MaxEquation

定义混合方程。

默认为AddEquation.

.blendEquationAlpha : AddEquation | SubtractEquation | ReverseSubtractEquation | MinEquation | MaxEquation

定义alpha通道的混合方程。

默认为null.

.blendSrc : ZeroFactor | OneFactor | SrcColorFactor | OneMinusSrcColorFactor | SrcAlphaFactor | OneMinusSrcAlphaFactor | DstAlphaFactor | OneMinusDstAlphaFactor | DstColorFactor | OneMinusDstColorFactor | SrcAlphaSaturateFactor | ConstantColorFactor | OneMinusConstantColorFactor | ConstantAlphaFactor | OneMinusConstantAlphaFactor

定义混合源因子。

默认为 SrcAlphaFactor.

.blendSrcAlpha : ZeroFactor | OneFactor | SrcColorFactor | OneMinusSrcColorFactor | SrcAlphaFactor | OneMinusSrcAlphaFactor | DstAlphaFactor | OneMinusDstAlphaFactor | DstColorFactor | OneMinusDstColorFactor | SrcAlphaSaturateFactor | ConstantColorFactor | OneMinusConstantColorFactor | ConstantAlphaFactor | OneMinusConstantAlphaFactor

定义混合源 Alpha 因子。

默认为null.

.blending : NoBlending | NormalBlending | AdditiveBlending | SubtractiveBlending | MultiplyBlending | CustomBlending

定义材质的混合类型。

如果自定义混合属性如下，则必须将其设置为 CustomBlending Material#blendSrc、Material#blendDst 或 Material#blendEquation 应该有任何效果。

默认为NormalBlending.

.clipIntersection : boolean

更改剪裁平面的行为，以便只有它们的交集是

默认为 false.

.clipShadows : boolean

定义是否根据指定的剪切平面剪切阴影 在此材质上。

默认为 false.

.clippingPlanes : Array.<Plane>

用户定义的剪裁平面指定为世界中的 THREE.Plane 对象 空间。这些平面适用于该材质所附着的对象。 空间中到平面的符号距离为负的点将被剪裁 （未渲染）。这需要 WebGLRenderer#localClippingEnabled 来 为 true.

默认为null.

.colorWrite : boolean

是否渲染材质的颜色.

这个可以与Object3D#renderOder结合使用来创建不可见 遮挡其他对象的对象。

默认为true.

.depthFunc : NeverDepth | AlwaysDepth | LessDepth | LessEqualDepth | EqualDepth | GreaterEqualDepth | GreaterDepth | NotEqualDepth

定义深度函数。

默认为LessEqualDepth.

.depthTest : boolean

渲染此材质时是否启用深度测试。 当深度测试被禁用时，深度写入也将被隐式禁用。

默认为true.

.depthWrite : boolean

渲染此材质是否对深度缓冲区有任何影响。

绘制 2D 叠加时，禁用深度写入可能很有用 为了将多个物体分层在一起而不创建 z 索引工件。

默认为true.

.dithering : boolean

是否对颜色应用抖动以消除条带的外观。

默认为 false.

.forceSinglePass : boolean

是否应使用单通道渲染双面透明对象。

引擎通过两次绘制调用（返回）渲染双面透明对象首先是脸， 然后是正面）以减轻透明度伪影。然而，在某些情况下，这 方法不会产生质量增益，但仍然使绘制调用加倍，例如渲染平面时 像草精灵一样的植被。在这些情况下，请将 forceSinglePass 标志设置为 true 以 禁用两通道渲染以避免性能问题。

默认为 false.

.id : number (readonly)

材质的 ID。

.isMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.name : string

材质的名称。

.needsUpdate : boolean

将此属性设置为 true 表示引擎材质 需要重新编译。

默认为 false.

.opacity : number

定义材质的透明度。 值为 0.0 表示完全透明，1.0 表示完全不透明。

如果 Material#transparent 未设置为 true， 材质将保持完全不透明，并且该值只会影响其颜色。

默认为1.

.polygonOffset : boolean

是否使用多边形偏移。启用后，每个片段的深度值将 从适当顶点的深度值插值后进行偏移。 在执行深度测试之前和写入值之前添加偏移量 进入深度缓冲区。

对于渲染隐藏线图像、将贴花应用到表面以及 渲染具有突出显示边缘的实体。

默认为 false.

.polygonOffsetFactor : number

指定用于为每个多边形创建可变深度偏移的比例因子。

默认为0.

.polygonOffsetUnits : number

乘以特定于实现的值以创建恒定深度偏移。

默认为0.

.precision : 'highp' | 'mediump' | 'lowp'

为此覆盖渲染器的默认精度材质.

默认为null.

.premultipliedAlpha : boolean

是否预乘alpha（透明度）值。

默认为 false.

.shadowSide : FrontSide | BackSide | DoubleSide

定义面的哪一侧投射阴影。如果 null，则侧面投射阴影 确定如下：

  • 当 Material#side 设置为 FrontSide 时，背面会投射阴影。
  • 当 Material#side 设置为 BackSide 时，正面会投射阴影。
  • 当 Material#side 设置为 DoubleSide 时，两个面都会投射阴影。

默认为null.

.side : FrontSide | BackSide | DoubleSide

定义将渲染面的哪一侧 - 正面、背面或两者。

默认为 FrontSide.

.stencilFail : ZeroStencilOp | KeepStencilOp | ReplaceStencilOp | IncrementStencilOp | DecrementStencilOp | IncrementWrapStencilOp | DecrementWrapStencilOp | InvertStencilOp

比较函数返回时执行哪个模板操作false.

默认为 KeepStencilOp.

.stencilFunc : NeverStencilFunc | LessStencilFunc | EqualStencilFunc | LessEqualStencilFunc | GreaterStencilFunc | NotEqualStencilFunc | GreaterEqualStencilFunc | AlwaysStencilFunc

要使用的模板比较函数.

默认为AlwaysStencilFunc.

.stencilFuncMask : number

与模板缓冲区进行比较时使用的位掩码。

默认为0xff.

.stencilRef : number

执行模板比较时使用的值或模板操作。

默认为0.

.stencilWrite : boolean

是否针对模板缓冲区执行模板操作。在 为了对模板缓冲区执行写入或比较 值必须是 true.

默认为 false.

.stencilWriteMask : number

写入模板缓冲区时要使用的位掩码。

默认为0xff.

.stencilZFail : ZeroStencilOp | KeepStencilOp | ReplaceStencilOp | IncrementStencilOp | DecrementStencilOp | IncrementWrapStencilOp | DecrementWrapStencilOp | InvertStencilOp

比较函数返回时要执行的模板操作 true 但深度测试失败。

默认为 KeepStencilOp.

.stencilZPass : ZeroStencilOp | KeepStencilOp | ReplaceStencilOp | IncrementStencilOp | DecrementStencilOp | IncrementWrapStencilOp | DecrementWrapStencilOp | InvertStencilOp

比较函数返回时执行哪个模板操作 true 并且深度测试通过。

默认为 KeepStencilOp.

.toneMapped : boolean

定义此材质是否根据渲染器的色调映射设置进行色调映射。

在渲染到渲染目标或使用后期处理、或使用 WebGPURenderer 时，此功能将被忽略。在所有这些情况下，所有材质都会被色调映射处理。

默认为true.

.transparent : boolean

定义此材质是否透明。这有影响 渲染为透明物体需要特殊处理并渲染 在非透明物体之后。

当设置为true时，材质透明的程度为 由 Material#opacity.

默认为 false.

.type : string (readonly)

type属性用于检测对象类型 在序列化/反序列化的上下文中。

.userData : Object

控制，可用于存储有关材质的自定义数据的对象。它 不应保存对函数的引用，因为它们不会被克隆。

.uuid : string (readonly)

材质的 UUID。

.version : number (readonly)

这从 0 开始，并计算 Material#needsUpdate 设置为的次数true.

默认为0.

.vertexColors : boolean

如果设置为 true，则应使用顶点颜色。

引擎支持 RGB 和 RGBA 顶点颜色，具体取决于三 (RGB) 或 使用四个 (RGBA) 分量颜色缓冲区属性。

默认为 false.

.visible : boolean

定义使用此材质的 3D 对象是否可见。

默认为true.
