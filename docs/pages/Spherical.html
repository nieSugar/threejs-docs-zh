Spherical

此类可用于将 3D 空间中的点表示为 球面坐标.

构造函数

new Spherical( radius : number, phi : number, theta : number )

构造一个新的球面。

radius

从点到点的半径，或欧氏距离（直线距离）原点.

默认为1.
phi

距 y（上）轴的极角（以弧度为单位）。

默认为0.
theta

围绕 y（上）轴的赤道/方位角（以弧度为单位）。

默认为0.

属性

.phi : number

距 y（上）轴的极角（以弧度为单位）。

默认为0.

.radius : number

从点到点的半径，或欧氏距离（直线距离）原点.

默认为1.

.theta : number

围绕 y（上）轴的赤道/方位角（以弧度为单位）。

默认为0.

方法

.clone() : Spherical

返回一个新的球面，其中包含从此球面复制的值实例.

返回：此克隆instance.

.copy( other : Spherical ) : Spherical

将给定球面的值复制到此实例。

other

要复制的球面.
返回：对此球面的引用。

.makeSafe() : Spherical

限制极角[page:.phi phi] 位于 0.000001 和 pi 之间 - 0.000001.

返回：对此球面的引用。

.set( radius : number, phi : number, theta : number ) : Spherical

通过复制给定值设置球面分量。

radius

The半径.
phi

极角。
theta

方位角。
返回：对此球面的引用。

.setFromCartesianCoords( x : number, y : number, z : number ) : Spherical

设置来自给定笛卡尔坐标的球面分量。

x

x 值.
y

y值.
z

z 值.
返回：对此球面的引用。

.setFromVector3( v : Vector3 ) : Spherical

设置来自假定保持的给定向量的球面分量 笛卡尔坐标.

v

要设置的向量。
返回：对此球面的引用。
