Plane

在 3D 空间中无限延伸的二维表面，表示 在 Hessian normal form 中 由单位长度法线向量和常数组成。

构造函数

new Plane( normal : Vector3, constant : number )

构造一个新平面。

normal

定义平面法线的单位长度向量。

默认为(1,0,0).
constant

从原点到平面的有符号距离。

默认为0.

属性

.constant : number

从原点到平面的有符号距离。

默认为0.

.isPlane : boolean (readonly)

该标志可用于类型测试。

默认为true.

.normal : Vector3

定义平面法线的单位长度向量。

方法

.applyMatrix4( matrix : Matrix4, optionalNormalMatrix : Matrix4 ) : Plane

将 4x4 矩阵应用于平面。该矩阵必须是仿射齐次变换。

可选的法线矩阵可以像这样预先计算：

const optionalNormalMatrix = new THREE.Matrix3().getNormalMatrix( matrix );
matrix

变换矩阵。
optionalNormalMatrix

预先计算的法线矩阵。
返回：对此平面的引用。

.clone() : Plane

返回具有从此实例复制的值的新平面。

返回：此克隆instance.

.coplanarPoint( target : Vector3 ) : Vector3

通过计算 原点法线在平面上的投影。

target

用于存储方法结果的目标向量.
返回：共面点。

.copy( plane : Plane ) : Plane

将给定平面的值复制到此实例。

plane

要复制的平面。
返回：对此平面的引用。

.distanceToPoint( point : Vector3 ) : number

返回带符号的平面从给定点到该平面的距离。

point

计算距离的点。
返回： 有符号距离。

.distanceToSphere( sphere : Sphere ) : number

返回从给定球体到该平面的有符号距离。

sphere

到的球体计算距离.
返回： 有符号距离。

.equals( plane : Plane ) : boolean

如果此平面与给定平面相等，则返回true.

plane

要测试相等的平面.
返回：此平面是否与给定平面相等一.

.fromJSON( json : Object ) : Plane

根据给定的JSON设置平面属性.

json

用于设置平面的序列化json.
返回：对此平面的引用。

.intersectLine( line : Line3, target : Vector3, clampToLine : boolean ) : Vector3

返回传递的直线和平面的交点。退货 null 如果直线不相交。如果满足以下条件，则返回线的起点 该线与平面共面。

line

要计算相交的线。
target

用于存储方法结果的目标向量.
clampToLine

是否将交点钳位到线段上。

默认为true.
返回：交点。如果未检测到相交，则返回 null。

.intersectsBox( box : Box3 ) : boolean

如果给定边界框与平面相交，则返回 true。

box

要测试的边界框。
返回： 给定边界框是否与平面相交not.

.intersectsLine( line : Line3 ) : boolean

如果给定线段与平面相交（穿过），则返回 true。

line

要测试的线。
返回：给定的线段是否与平面相交。

.intersectsSphere( sphere : Sphere ) : boolean

如果给定的边界球体与平面相交，则返回 true plane.

sphere

要测试的边界球.
返回：给定的边界球体是否与平面相交。

.translate( offset : Vector3 ) : Plane

将平面平移给定偏移向量定义的距离。 请注意，这仅影响平面常数，不会影响法线向量.
