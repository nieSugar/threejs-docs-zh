InputNode

用于表示数据输入节点的基类。

构造函数

new InputNode( value : any, nodeType : string )

构造一个新的输入节点。

value

此节点的值。这可以是任何 JS 原语、函数、数组缓冲区甚至是 Three.js 对象（向量、矩阵、颜色）。
nodeType

节点类型。如果未定义显式类型，节点会尝试从其值派生类型。

默认为null.

属性

.isInputNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.precision : 'low' | 'medium' | 'high'

着色器中值的精度。

默认为null.

.value : any

此节点的值。这可以是任何 JS 原语、函数、数组缓冲区甚至是 Three.js 对象（向量、矩阵、颜色）。

方法

.getInputType( builder : NodeBuilder ) : string

返回节点的输入类型，默认为节点类型。派生模块 可能会覆盖此方法并使用固定类型或分析计算。

不同输入和节点类型的典型示例是纹理。 a 的输入类型 普通 RGBA 纹理为 texture，而其节点类型为 vec4.

builder

当前节点构建器.
返回： 输入类型.

.setPrecision( precision : 'low' | 'medium' | 'high' ) : InputNode

将精度设置为给定值。方法可以是 如果必须计算最终精度，则在派生类中覆盖 解析.

precision

着色器中输入值的精度.
返回：对此节点的引用.
