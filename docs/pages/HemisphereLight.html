HemisphereLight

直接位于场景上方的光源，颜色从 天空颜色到地面颜色。

此灯光不能用于投射阴影。

代码示例

const light = new THREE.HemisphereLight( 0xffffbb, 0x080820, 1 );
scene.add( light );

构造函数

new HemisphereLight( skyColor : number | Color | string, groundColor : number | Color | string, intensity : number )

构造一个新的半球灯光。

skyColor

灯光的天空颜色。

默认为0xffffff.
groundColor

灯光的地面颜色颜色.

默认为0xffffff.
intensity

灯光的强度/强度.

默认为1.

属性

.groundColor : Color

灯光的地面颜色颜色.

.isHemisphereLight : boolean (readonly)

该标志可用于类型测试。

默认为true.
