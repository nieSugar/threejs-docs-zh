XRManager

XR 管理器构建在 WebXR 设备 API 之上 使用渲染器后端管理 XR 会话。

构造函数

new XRManager( renderer : Renderer, multiview : boolean )

构造一个新的 XR 管理器。

renderer

渲染器.
multiview

如果设备支持，则启用多视图。

默认为 false.

属性

.cameraAutoUpdate : boolean

XR 相机是否应自动更新。

默认为true.

.enabled : boolean

此标志全局启用XR 渲染.

默认为 false.

.isPresenting : boolean (readonly)

XR 设备当前是否呈现。

默认为 false.

方法

.createCylinderLayer( radius : number, centralAngle : number, aspectratio : number, translation : Vector3, quaternion : Quaternion, pixelwidth : number, pixelheight : number, rendercall : function, attributes : Object ) : Mesh

此方法可用于 XR 应用程序中创建呈现单独的圆柱层 渲染场景.

radius

以世界单位表示的圆柱体半径。
centralAngle

以弧度表示的圆柱体圆心角。
aspectratio

纵横比。
translation

以世界单位表示的图层平面的位置/平移。
quaternion

表示为图层平面的方向四元数.
pixelwidth

图层渲染目标的宽度（以像素为单位）。
pixelheight

图层渲染目标的高度（以像素为单位）。
rendercall

渲染图层的回调函数。类似于中的代码 默认动画循环，此方法可用于更新/转换图层场景中的 3D 对象。
attributes

允许配置图层的渲染目标。

默认为 {}.

samples

场景 MSAA 样本计数。默认为渲染器的样本计数。
返回： 表示圆柱形 XR 层的网格。应将此网格添加到 XR 场景中。

.createQuadLayer( width : number, height : number, translation : Vector3, quaternion : Quaternion, pixelwidth : number, pixelheight : number, rendercall : function, attributes : Object ) : Mesh

此方法可在 XR 应用程序中用于创建呈现单独的二次层 渲染的场景。

width

以世界单位表示的图层平面的宽度。
height

以世界单位表示的图层平面的高度。
translation

以世界单位表示的图层平面的位置/平移。
quaternion

表示为图层平面的方向四元数.
pixelwidth

图层渲染目标的宽度（以像素为单位）。
pixelheight

图层渲染目标的高度（以像素为单位）。
rendercall

渲染图层的回调函数。类似于中的代码 默认动画循环，此方法可用于更新/转换图层场景中的 3D 对象。
attributes

允许配置图层的渲染目标。

默认为 {}.

samples

场景 MSAA 样本计数。默认为渲染器的样本计数。
返回：表示二次 XR 图层的网格。应将该网格添加到 XR 场景中。

.foveateBoundTexture( renderTarget : RenderTarget )

将 WebXR 固定注视点应用于内部后处理渲染目标 在合成到投影层之前由第一个 XR 渲染通道使用。

浏览器端 XRWebGLBinding.foveateBoundTexture() 失败被视为 非致命，因此它们不会中断渲染。

renderTarget

内部渲染目标。

.getBaseLayer() : XRWebGLLayer | XRProjectionLayer

返回当前基础层。

当目标 XR 设备支持时，这是一个 XRProjectionLayer WebXR Layers API，或 XRWebGLLayer 否则。

返回： XR 基础层。

.getBinding() : XRWebGLBinding

返回当前的 XR 绑定。

如果需要，则创建新绑定，并且浏览器会 能够这样做。

返回： XR 绑定。如果无法创建，则返回 null。

.getCamera() : ArrayCamera

返回 XR 相机。

返回： XR 相机。

.getController( index : number ) : Group

返回表示转换的 THREE.Group 的实例 目标射线空间中的 XR 控制器。所请求的控制器已定义 按给定索引。

index

XR 控制器的索引。
返回： 表示控制器变换的组。

.getControllerGrip( index : number ) : Group

返回表示变换的 THREE.Group 的实例 握持空间中的 XR 控制器。所请求的控制器已定义 按给定索引。

index

XR 控制器的索引。
返回： 表示控制器变换的组。

.getEnvironmentBlendMode() : 'opaque' | 'additive' | 'alpha-blend' | undefined

从当前 XR 会话返回环境混合模式。

返回：环境混合模式。在 XR 会话外部使用时，返回 undefined。

.getFoveation() : number | undefined

返回注视点值。

返回：注视点值。

.getFrame() : XRFrame

返回当前 XR 帧。

返回： XR 帧。在 XR 会话外部使用时，返回 null。

.getFramebufferScaleFactor() : number

返回帧缓冲区比例因子.

返回：帧缓冲区比例因子.

.getHand( index : number ) : Group

返回表示转换的THREE.Group的实例 手部空间中的 XR 控制器。所请求的控制器已定义 按给定索引。

index

XR 控制器的索引。
返回： 表示控制器变换的组。

.getReferenceSpace() : XRReferenceSpace

返回 XR 参考空间。

返回： XR 参考space.

.getReferenceSpaceType() : XRReferenceSpaceType

返回参考空间类型。

返回： 参考空间类型。

.getSession() : XRSession

返回当前 XR 会话。

返回： XR 会话。在 XR 会话外使用时返回 null。

.getWebGPUBinding() : XRGPUBinding

返回当前 XR WebGPU 绑定。

如果需要，则创建新绑定，并且浏览器会 能够这样做。

返回： XR WebGPU 绑定。如果无法创建，则返回 null。

.renderLayers()

渲染先前添加到场景中的 XR 图层。

通常在渲染之前在动画循环中调用此方法 通过renderer.render( scene, camera );的实际场景。

.setFoveation( foveation : number )

设置注视点值。

foveation

范围内的数字[0,1]，其中0表示无注视点（全分辨率） 1 表示最大注视点（边缘以较低分辨率渲染）。

.setFramebufferScaleFactor( factor : number )

设置帧缓冲区比例因子。

在 XR 会话期间不能使用此方法。

factor

帧缓冲区比例因子.

.setReferenceSpace( space : XRReferenceSpace )

设置自定义XR参考空间。

space

XR参考空间。

.setReferenceSpaceType( type : XRReferenceSpaceType )

设置参考空间类型。

在 XR 会话期间不能使用此方法。

type

参考空间类型.

.setSession( session : XRSession ) : Promise (async)

通常使用*Button模块之一请求XR会话后，它 使用此方法注入渲染器。该方法触发启动 实际的 XR 渲染。

session

要设置的 XR 会话。
返回： 设置会话后解析的 Promise。

.updateCamera( camera : PerspectiveCamera )

此方法由渲染器每帧调用并更新XR相机 以及基于给定相机的子相机。给定的相机是“用户” 在应用程序级别创建并用于非 XR 渲染的相机。

camera

相机.

.useMultiview() : boolean

如果引擎渲染到多视图目标，则返回 true。

返回： 引擎是否渲染到多视图渲染目标或不是.
