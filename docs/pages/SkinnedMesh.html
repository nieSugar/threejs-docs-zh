SkinnedMesh

具有 Skeleton 的网格，然后可用于对 具有蒙皮/骨架动画的几何体的顶点。

在有效骨架旁边，蒙皮网格需要蒙皮索引和权重 作为其几何形状中的缓冲区属性。这些属性定义哪些骨骼影响单个 顶点到一定程度。

通常蒙皮网格体不是手动创建的，而是像 GLTFLoader 这样的加载器创建 或 FBXLoader 导入相应模型。

构造函数

new SkinnedMesh( geometry : BufferGeometry, material : Material | Array.<Material> )

构造一个新的蒙皮网格。

geometry

网格体几何形状。
material

网格材质。

属性

.bindMatrix : Matrix4

用于绑定骨骼变换的基础矩阵。

.bindMatrixInverse : Matrix4

用于重置绑定骨骼的基础矩阵Transforms.

.bindMode : AttachedBindMode | DetachedBindMode

AttachedBindMode 表示蒙皮网格与骨架共享相同的世界空间。 当使用 DetachedBindMode 时，情况并非如此，这在共享骨架时很有用 跨多个蒙皮网格体。

默认为 AttachedBindMode.

.boundingBox : Box3

蒙皮网格体的边界框。可以通过SkinnedMesh#computeBoundingBox.

默认为null.

.boundingSphere : Sphere

蒙皮网格的边界球体进行计算。可以通过 SkinnedMesh#computeBoundingSphere.

默认为null.

.isSkinnedMesh : boolean (readonly)

该标志可用于类型测试。

默认为true.

方法

.applyBoneTransform( index : number, target : Vector3 | Vector4 ) : Vector3 | Vector4

计算将与给定索引关联的骨骼变换应用于给定 矢量。可用于通过提供来变换位置或方向向量 w 分量分别为 1 或 0 的 Vector4。返回更新后的向量。

index

顶点索引。
target

用于存储方法结果的目标对象。
返回：更新后的顶点属性数据。

.bind( skeleton : Skeleton, bindMatrix : Matrix4 )

将给定骨架绑定到蒙皮网格。

skeleton

要绑定的骨架。
bindMatrix

绑定矩阵。如果没有提供绑定矩阵， 将使用蒙皮网格物体的世界矩阵。

.computeBoundingBox()

计算蒙皮网格物体的边界框，并更新SkinnedMesh#boundingBox。 边界框不是由引擎自动计算的；此方法必须由您的应用程序调用。 如果蒙皮网格是动画的，则应每帧重新计算边界框以反映 当前动画状态。

.computeBoundingSphere()

计算蒙皮网格的边界球体，并更新SkinnedMesh#boundingSphere。 边界球体在需要时由引擎自动计算一次，例如用于射线投射 并视锥体剔除。如果蒙皮网格是动画的，则应重新计算边界球体 每帧以反映当前动画状态。

.normalizeSkinWeights()

标准化定义为缓冲区属性的蒙皮权重 在蒙皮网格的几何体中。

.pose()

此方法将蒙皮网格设置为静止姿势).
