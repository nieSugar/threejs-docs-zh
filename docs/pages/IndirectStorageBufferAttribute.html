IndirectStorageBufferAttribute

这种特殊类型的缓冲区属性适用于计算着色器。 它可用于对间接绘制调用的绘制参数进行编码。

注意：这种类型的缓冲区属性只能与WebGPURenderer一起使用 和一个 WebGPU 后端。

构造函数

new IndirectStorageBufferAttribute( count : number | Uint32Array, itemSize : number )

构造一个新的存储缓冲区属性。

count

项目计数。将 Uint32Array 作为参数传递也是有效的。 随后的参数将被废弃。
itemSize

项目大小。

属性

.isIndirectStorageBufferAttribute : boolean (readonly)

该标志可用于类型测试。

默认为true.
