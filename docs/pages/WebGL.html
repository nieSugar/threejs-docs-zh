WebGL

具有基本 WebGL 2 功能测试的实用程序模块。

导入

WebGL 是一个插件，必须显式导入，请参阅 Installation#Addons.

import WebGL from 'three/addons/capabilities/WebGL.js';

静态方法

.getWebGL2ErrorMessage() : HTMLDivElement

返回一个 div 元素，表示可以附加到的格式化错误消息 如果不支持 WebGL 2，则为网站。

返回： div 元素，表示不支持 WebGL 2 的格式化错误消息。

.isColorSpaceAvailable( colorSpace : string ) : boolean

如果给定的色彩空间可用，则返回 true。该方法只能在支持 WebGL 2 时使用。

colorSpace

要测试的颜色空间。
返回： 给定的颜色空间是否可用。

.isWebGL2Available() : boolean

如果支持 WebGL 2，则返回 true可用.

返回： WebGL 2 是否可用.
