AnimationAction

AnimationAction 的一个实例安排动画的播放，该动画是 存储在 AnimationClip.

构造函数

new AnimationAction( mixer : AnimationMixer, clip : AnimationClip, localRoot : Object3D, blendMode : NormalAnimationBlendMode | AdditiveAnimationBlendMode )

构造一个新的动画动作。

mixer

此动作控制的混合器。
clip

保存实际关键帧的动画剪辑。
localRoot

The执行此操作的根对象。

默认为null.
blendMode

混合模式。

属性

.blendMode : NormalAnimationBlendMode | AdditiveAnimationBlendMode

定义当两个或多个动画时动画如何混合/组合 同时播放。

.clampWhenFinished : boolean

如果设置为 true，动画将在最后一帧自动暂停。

如果设置为 false，AnimationAction#enabled 将自动切换 当动作的最后一个循环完成时，到 false ，这样这个动作就完成了 没有进一步的影响。

注意：如果操作被中断，该成员没有影响（它 仅当最后一个循环真正完成时才有效）。

默认为 false.

.enabled : boolean

如果设置为 false，则该操作被禁用，因此它没有Impact.

重新启用该操作时，动画从当前位置继续 时间（将enabled设置为false不会重置操作）。

默认为true.

.loop : LoopRepeat | LoopOnce | LoopPingPong

循环模式，通过AnimationAction#setLoop设置。

默认为LoopRepeat.

.paused : boolean

如果设置为true，则暂停播放动作。

默认为 false.

.repetitions : number

在此动作过程中执行剪辑的重复次数。 可以通过 AnimationAction#setLoop 设置。

如果 AnimationAction#loop 设置为 THREE:LoopOnce.

默认为 Infinity.

.time : number

此操作的本地时间（以秒为单位，从0).

该值被钳制或包裹到 [0,clip.duration] （根据 循环状态）.

默认为 Infinity.

.timeScale : number

AnimationAction#time 的缩放因子。 0 的值会导致 动画暂停。负值导致动画向后播放。

默认为1.

.weight : number

此动作的影响程度（在区间[0, 1]中）。价值观 0（无影响）和 1（完全影响）之间可用于混合 几个动作。

默认为1.

.zeroSlopeAtEnd : boolean

启用平滑插值，无需单独的剪辑开始、循环和结束。

默认为true.

.zeroSlopeAtStart : boolean

启用平滑插值，无需单独的剪辑开始、循环和结束。

默认为true.

方法

.crossFadeFrom( fadeOutAction : AnimationAction, duration : number, warp : boolean ) : AnimationAction

导致此动作淡入，给定动作淡出， 在经过的时间间隔内.

fadeOutAction

要淡出的动画动作.
duration

淡入淡出的持续时间.
warp

是否应使用扭曲.

默认为 false.
返回：对此动画的引用action.

.crossFadeTo( fadeInAction : AnimationAction, duration : number, warp : boolean ) : AnimationAction

导致此操作淡出并且给定的操作淡入， 在经过的时间间隔内。

fadeInAction

要淡入的动画动作。
duration

淡入淡出的持续时间.
warp

是否应使用扭曲.

默认为 false.
返回：对此动画的引用action.

.fadeIn( duration : number ) : AnimationAction

通过逐渐增加其权重从0到1来淡入动画， 在经过的时间间隔内。

duration

淡入淡出的持续时间.
返回：对此动画的引用action.

.fadeOut( duration : number ) : AnimationAction

通过逐渐减小其权重从1到0来淡出动画， 在传递的时间间隔内。

duration

淡入淡出的持续时间.
返回：对此动画的引用action.

返回：动画是否正在运行是否运行。

调用AnimationAction#play时，返回true。

返回：动画是否被调度。

启动动画动画的播放。

重置动画的播放。

设置此动作的单个循环的持续时间。

duration

要设置的持续时间。
返回：对此动画的引用action.

.setEffectiveTimeScale( timeScale : number ) : AnimationAction

设置此动作的有效时间尺度动作.

动作没有效果，因此当 动作已暂停。

timeScale

要设置的时间刻度。
返回：对此动画的引用action.

设置此动作的有效权重。

动作没有效果，因此有效权重为零。 动作被禁用。

要设置的权重。

配置该动作的循环设置。

mode

循环模式。
repetitions

重复次数。
返回：对此动画的引用action.

.startAt( time : number ) : AnimationAction

定义动画应开始的时间。

time

开始时间（以秒为单位）。

停止播放动画。

.stopFading() : AnimationAction

返回：对此动画的引用action.

返回：对此动画的引用action.

将此动作与传递的其他动作同步.

要同步的动作.
返回：对此动画的引用action.

.warp( startTimeScale : number, endTimeScale : number, duration : number ) : AnimationAction

通过修改在传递的时间间隔内更改播放速度 AnimationAction#timeScale 逐渐从 startTimeScale 到 endTimeScale.

startTimeScale

开始时间刻度.
endTimeScale

结束时间刻度.
duration

持续时间。
返回：对此动画的引用action.
