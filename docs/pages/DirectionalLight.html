DirectionalLight

沿特定方向发射的光。该灯将表现 仿佛它是无限远的，它发出的光线都是 平行。常见的用例是模拟日光；太阳是 足够远以至于它的位置可以被认为是无限的，并且 来自它的所有光线都是平行的。

平行光的一个常见混淆点是设置 旋转没有影响。这是因为 Three.js 的 DirectionalLight 是 相当于其他领域通常所说的“目标直射光” applications.

这意味着其方向被计算为从光的指向 Object3D#position 到 DirectionalLight#target 位置 （与仅具有旋转的“自由直射光”相反 组件）.

此灯光可以投射阴影 - 有关详细信息，请参阅 DirectionalLightShadow。

代码示例

// White directional light at half intensity shining from the top.
const directionalLight = new THREE.DirectionalLight( 0xffffff, 0.5 );
scene.add( directionalLight );

构造函数

new DirectionalLight( color : number | Color | string, intensity : number )

构造一个新的定向灯光。

color

灯光的颜色.

默认为0xffffff.
intensity

灯光的强度/强度.

默认为1.

属性

.isDirectionalLight : boolean (readonly)

该标志可用于类型测试。

默认为true.

.shadow : DirectionalLightShadow

此属性保存灯光的阴影配置.

.target : Object3D

从其位置到的定向光点 目标位置.

用于将目标位置更改为其他任何位置 比默认的，必须添加到场景中。

也可以将目标设置为另一个3D对象 场景中。灯光现在将跟踪目标物体。
