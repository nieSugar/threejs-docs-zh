BezierInterpolant

使用带有 2D 控制点的三次贝塞尔曲线的贝塞尔插值。

此插值支持 COLLADA/Maya 风格的贝塞尔动画，其中 每个关键帧都有明确的输入/输出切线控制点，指定为 2D 坐标（时间、值）.

从插值器上的 inTangents 和 outTangents 读取切线数据 （由 KeyframeTrack.InterpolantFactoryMethodBezier 填充）.

对于具有 N 个关键帧和步幅 S 的轨道：

  • 每个切线数组包含 N * S * 2 个值
  • 布局: [k0_c0_time, k0_c0_value, k0_c1_time, k0_c1_value, ..., k0_cS_time, k0_cS_value, k1_c0_time, k1_c0_value, ...]

构造函数

new BezierInterpolant()
