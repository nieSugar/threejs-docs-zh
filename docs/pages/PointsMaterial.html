PointsMaterial

用于渲染点图元的材质。

材质定义可渲染 3D 对象的外观。

代码示例

const vertices = [];
for ( let i = 0; i < 10000; i ++ ) {
	const x = THREE.MathUtils.randFloatSpread( 2000 );
	const y = THREE.MathUtils.randFloatSpread( 2000 );
	const z = THREE.MathUtils.randFloatSpread( 2000 );
	vertices.push( x, y, z );
}
const geometry = new THREE.BufferGeometry();
geometry.setAttribute( 'position', new THREE.Float32BufferAttribute( vertices, 3 ) );
const material = new THREE.PointsMaterial( { color: 0x888888 } );
const points = new THREE.Points( geometry, material );
scene.add( points );

构造函数

new PointsMaterial( parameters : Object )

构造一个新的点材质。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.alphaMap : Texture

Alpha 贴图是一个灰度纹理，用于控制整个网格的不透明度 表面（黑色：完全透明；白色：完全不透明）.

仅使用纹理的颜色，如果有则忽略 alpha 通道 存在。对于 RGB 和 RGBA 纹理，渲染器将使用绿色通道 当采样该纹理时，由于提供了额外的精度 DXT 压缩和未压缩 RGB 565 格式中为绿色。仅亮度和 亮度/alpha 纹理也仍将按预期工作。

alphaMap 表示非颜色数据。分配的任何纹理都必须具有 texture.colorSpace = NoColorSpace（默认）.

默认为null.

.color : Color

材质的颜色。

默认为(1,1,1).

.fog : boolean

材质是否受雾影响。

默认为true.

.isPointsMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.map : Texture

颜色图。可以选择包含 alpha 通道，通常是组合的 与 Material#transparent 或 Material#alphaTest。纹理贴图 颜色由漫反射color.

map 表示颜色数据，并且必须为纹理分配一个 Texture#colorSpace。大多数 map 纹理设置 texture.colorSpace = SRGBColorSpace。

默认为null.

.size : number

定义点的大小Pixels.

如果值超过硬件相关参数，例如 gl.ALIASED_POINT_SIZE_RANGE.

默认为1.

.sizeAttenuation : boolean

指定各个点的大小是否因相机深度而衰减（仅限透视相机）。

默认为true.
