ComputeNode

表示计算着色器节点。

构造函数

new ComputeNode( computeNode : Node, workgroupSize : Array.<number> )

构造一个新的计算节点。

computeNode

定义计算着色器的节点逻辑.
workgroupSize

定义计算着色器执行的工作组的X、Y和Z维度的数组。

属性

.computeNode : Node

定义计算着色器的节点逻辑.

.count : number | Array.<number>

要执行的线程（调用）总数。如果是数字，则会使用它 自动生成针对 instanceIndex 的边界检查。

.countNode : UniformNode

保存调度计数以进行边界检查的统一节点。 当 count 为数字时自动创建。

.dispatchSize : number | Array.<number>

X、Y 和 Z 轴上工作组的调度大小。 如果没有提供count，则直接使用。

.isComputeNode : boolean (readonly)

该标志可用于类型测试。

默认为true.

.name : string

制服的名称或标签。

默认为 ''.

覆盖： Node#name

.onInitFunction : function

计算节点完成初始化时执行的回调。

.updateBeforeType : string

将updateBeforeType设置为NodeUpdateType.FRAME 因为节点计算 每帧一次。

中每帧效果一次，默认为 'frame'.

覆盖： Node#updateBeforeType

.version : number

节点的版本。

覆盖： Node#version

.workgroupSize : Array.<number>

定义计算着色器执行的工作组的X、Y和Z维度的数组。

默认为[ 64 ].

方法

.getUpdateBeforeType( frame : NodeFrame ) : NodeUpdateType

返回更新类型Node#updateBefore.

frame

当前节点框架.
覆盖： Node#getUpdateBeforeType
返回： 更新类型。

.label( name : string ) : ComputeNode

设置ComputeNode#name 属性.

name

制服的名称.
已弃用： 是
返回：对此节点的引用.

.onInit( callback : function ) : ComputeNode

设置在初始化期间运行的回调。

callback

回调函数.
返回：对此节点的引用.

.setName( name : string ) : ComputeNode

设置ComputeNode#name 属性.

name

制服的名称.
返回：对此节点的引用.

.updateBefore( frame : NodeFrame )

该方法执行此节点的计算.

frame

对当前节点框架的引用。
覆盖： Node#updateBefore
