Path

A 2D 路径表示。该类提供了创建路径的方法 和类似于 2D Canvas API 的 2D 形状的轮廓。

代码示例

const path = new THREE.Path();
path.lineTo( 0, 0.8 );
path.quadraticCurveTo( 0, 1, 0.2, 1 );
path.lineTo( 1, 1 );
const points = path.getPoints();
const geometry = new THREE.BufferGeometry().setFromPoints( points );
const material = new THREE.LineBasicMaterial( { color: 0xffffff } );
const line = new THREE.Line( geometry, material );
scene.add( line );

构造函数

new Path( points : Array.<Vector2> )

构造一条新路径。

points

定义路径的 2D 点数组。

属性

.currentPoint : Vector2

路径的当前偏移量。添加的任何新曲线都将从此处开始。

方法

.absarc( aX : number, aY : number, aRadius : number, aStartAngle : number, aEndAngle : number, aClockwise : boolean ) : Path

将绝对定位的弧作为 EllipseCurve 的实例添加到路径中。

aX

弧中心的 x 坐标。

默认为0.
aY

弧中心的 y 坐标arc.

默认为0.
aRadius

圆弧的半径。

默认为1.
aStartAngle

以弧度为单位的起始角度。

默认为0.
aEndAngle

以弧度为单位的结束角度。

默认为 Math.PI*2.
aClockwise

是否顺时针或顺时针扫描圆弧not.

默认为 false.
返回：对此路径的引用。
