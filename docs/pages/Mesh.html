Mesh

表示基于三角形多边形网格的对象的类。

代码示例

const geometry = new THREE.BoxGeometry( 1, 1, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );

构造函数

new Mesh( geometry : BufferGeometry, material : Material | Array.<Material> )

构造一个新网格。

geometry

网格体几何形状。
material

网格材质。

属性

.count : number

此网格的实例数。 只能与 WebGPURenderer 一起使用。

默认为1.

.geometry : BufferGeometry

网格体几何形状。

.isMesh : boolean (readonly)

该标志可用于类型测试。

默认为true.

.material : Material | Array.<Material>

网格材质。

默认为 MeshBasicMaterial.

.morphTargetDictionary : Object.<string, number> | undefined

表示几何体中变形目标的字典。关键是 morph 目标名称，其属性索引值。该成员是undefined 默认情况下，仅在几何体中检测到变形目标时设置。

默认为undefined.

.morphTargetInfluences : Array.<number> | undefined

通常在 [0,1] 范围内的权重数组，指定变形量 被应用。该成员默认为 undefined 并且仅在变形目标为 在几何体中检测到。

默认为undefined.

方法

.getVertexPosition( index : number, target : Vector3 ) : Vector3

返回给定索引处顶点的局部空间位置，考虑 考虑变形目标和蒙皮的当前动画状态。

index

顶点索引。
target

用于存储方法结果的目标对象。
返回：局部空间中的顶点位置。

.intersectsFrustum( frustum : Frustum | FrustumArray ) : boolean

如果此网格与给定相交，则返回 true frustum.

frustum

到的平截头体test.
覆盖： Object3D#intersectsFrustum
返回： 该网格是否与给定的视锥体相交。

.raycast( raycaster : Raycaster, intersects : Array.<Object> )

计算投射光线与此线之间的交点line.

raycaster

The raycaster.
intersects

保存交点的目标数组。
覆盖： Object3D#raycast

.updateMorphTargets()

设置 Mesh#morphTargetDictionary 和 Mesh#morphTargetInfluences 的值 确保现有的变形目标可以影响此 3D 对象。
