Skeleton

用于表示 three.js 中的骨架的类。骨架 由骨骼层次结构定义。

代码示例

const bones = [];
const shoulder = new THREE.Bone();
const elbow = new THREE.Bone();
const hand = new THREE.Bone();
shoulder.add( elbow );
elbow.add( hand );
bones.push( shoulder , elbow, hand);
shoulder.position.y = -5;
elbow.position.y = 0;
hand.position.y = 5;
const armSkeleton = new THREE.Skeleton( bones );

构造函数

new Skeleton( bones : Array.<Bone>, boneInverses : Array.<Matrix4> )

构造一个新骨骼。

bones

骨骼数组。
boneInverses

骨骼逆矩阵数组。 如果未提供，这些矩阵将通过 Skeleton#calculateInverses.

属性

.boneInverses : Array.<Matrix4>

骨骼逆矩阵数组自动计算。

.boneMatrices : Float32Array

保存骨骼数据的数组缓冲区。 Skeleton#boneTexture.

默认为null.

.boneTexture : DataTexture

A 纹理的输入数据，该纹理保存要使用的骨骼数据 在顶点着色器中。

默认为null.

.bones : Array.<Bone>

定义骨架的骨骼数组。

方法

.calculateInverses()

计算骨骼逆矩阵。该方法重置Skeleton#boneInverses 并用新矩阵填充它。

.clone() : Skeleton

返回一个包含此实例复制值的新骨架。

返回：此克隆instance.

.computeBoneTexture() : Skeleton

计算数据纹理以将骨骼数据传递到顶点着色器。

返回：对此的引用实例.

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

.fromJSON( json : Object, bones : Object.<string, Bone> ) : Skeleton

通过给定的JSON和骨骼设置骨架.

json

序列化JSON的骨架.
bones

骨骼数组。
返回：对此的引用实例.

.getBoneByName( name : string ) : Bone | undefined

搜索骨架的骨骼数组并返回第一个 匹配名称.

name

骨骼的名称.
返回：找到的骨骼。 undefined 如果没有找到骨头。

.init()

初始化骨架。该方法由构造函数自动调用 但根据骨架的创建方式，可能有必要调用此方法 手动.

.pose()

将骨架重置为基础姿势。

.toJSON() : Object

将骨架序列化为JSON.

参见：
  • ObjectLoader#parse
返回：表示序列化骨架的JSON对象.

.update()

将骨架重置为基础姿势。
