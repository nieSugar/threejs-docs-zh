PLYLoader

PLY PLY 格式（称为 Polygon）的加载器 文件格式或斯坦福三角格式）。

限制：

  • ASCII 解码假定文件为 UTF-8。

代码示例

const loader = new PLYLoader();
const geometry = await loader.loadAsync( './models/ply/ascii/dolphins.ply' );
scene.add( new THREE.Mesh( geometry ) );

导入

PLYLoader 是一个插件，必须显式导入，请参阅 安装#Addons.

import { PLYLoader } from 'three/addons/loaders/PLYLoader.js';

构造函数

new PLYLoader( manager : LoadingManager )

构造一个新的PLY加载器。

manager

加载管理器。

方法

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

从给定的URL开始加载并传递加载的PLY资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( data : ArrayBuffer ) : BufferGeometry

解析给定的 PLY 数据并返回结果几何图形。

data

作为数组缓冲区的原始 PLY 数据。
覆盖： Loader#parse
返回： 解析的几何图形.

.setCustomPropertyNameMapping( mapping : Object )

位置、uv、法线默认值之外的自定义属性 可以使用 setCustomPropertyNameMapping 方法添加颜色属性。 例如，以下映射元素属性“custom_property_a” 和“custom_property_b”到项目大小为 2 的属性“customAttribute”。 属性项大小是根据属性数组中元素属性的数量设置的。

loader.setCustomPropertyNameMapping( {
	customAttribute: ['custom_property_a', 'custom_property_b'],
} );
mapping

映射字典。

.setPropertyNameMapping( mapping : Object )

设置映射默认属性名称的属性名称映射 到定制的。例如，以下映射属性 文件中的“diffuse_(red|green|blue)”为标准颜色名称.

loader.setPropertyNameMapping( {
	diffuse_red: 'red',
	diffuse_green: 'green',
	diffuse_blue: 'blue'
} );
mapping

映射字典。
