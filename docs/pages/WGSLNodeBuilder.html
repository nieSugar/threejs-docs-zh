WGSLNodeBuilder

针对 WGSL 的节点构建器。

此模块从节点材质生成 WGSL 着色器代码，并且还 生成相应的绑定和顶点缓冲区定义。这些 渲染器稍后使用数据来创建渲染和计算管道 用于渲染对象。

构造函数

new WGSLNodeBuilder( object : Object3D, renderer : Renderer )

构造一个新的 WGSL 节点生成器渲染器。

object

3D对象.
renderer

渲染器.

属性

.allowEarlyReturns : boolean

指示允许提前返回的标志。

默认为true.

.allowGlobalVariables : boolean

指示允许全局变量的标志。

默认为true.

.builtins : Object.<string, Map.<string, Object>>

为每个着色器暂存映射的字典内置函数。

.directives : Object.<string, Set.<string>>

为每个着色器阶段保存一组指令的字典。

.scopedArrays : Map.<string, Object>

用于管理范围数组的映射。仅与使用时相关 WorkgroupInfoNode 在计算着色器的上下文中。

.uniformGroups : Object.<string, Object.<string, NodeUniformsGroup>>

保存每个着色器阶段（“顶点”、“片段”、“计算”）的字典 另一个字典，用于管理每个组的 UBO（“渲染”、“帧”、“对象”）。

.uniformGroupsBindings : Object.<string, {index: number, id: number}>

一个字典，用于保存每个统一组分配的绑定索引。 这可确保在所有着色器阶段使用相同的绑定索引。
