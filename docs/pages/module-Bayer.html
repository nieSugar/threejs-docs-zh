Bayer

导入

Bayer 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { bayer16 } from 'three/addons/tsl/math/Bayer.js';

静态方法

.bayer16( uv : Node.<vec2> ) : Node.<vec4>

此 TSL 函数可用于对 Bayer16 纹理进行采样，该纹理是具有拜耳矩阵图案的 16x16 纹理。 它可用于抖动效果，也可作为蓝噪声的替代品。与射线行进一起使用时 特别是在 VolumeNodeMaterial#offsetNode 中，它减少了条带问题，从而能够使用 更少的步骤，而不影响视觉效果。

uv

对 bayer16 纹理进行采样的 uv。
返回： 采样的拜耳值。

.bayerDither( color : Node.<vec3>, steps : Node.<float> ) : Node.<vec3>

此 TSL 函数将拜耳抖动应用于颜色输入。它使用 4x4 拜耳矩阵 模式在颜色量化之前添加结构化噪声，这有助于减少可见光 限制颜色深度时的色带。

color

要应用抖动的输入颜色。
steps

每个通道的颜色步数。

默认为32.
返回：准备量化的抖动颜色。
