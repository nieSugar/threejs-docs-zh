AnimationPathHelper

基于位置关键帧可视化动画对象的运动路径 来自 AnimationClip.

代码示例

const clip = model.animations[ 0 ];
const helper = new AnimationPathHelper( model, clip, object );
scene.add( helper );

导入

AnimationPathHelper 是一个插件，必须显式导入，请参阅Installation#Addons.

import { AnimationPathHelper } from 'three/addons/helpers/AnimationPathHelper.js';

构造函数

new AnimationPathHelper( root : Object3D, clip : AnimationClip, object : Object3D, options : Object )

构造一个新的动画路径助手.

root

包含动画剪辑的根对象.
clip

包含位置关键帧的动画剪辑.
object

显示路径的特定对象.
options

Configuration options.

默认为 {}.

color

路径线颜色.

默认为0x00ff00.
markerColor

关键帧标记颜色。

默认为0xff0000.
divisions

平滑路径的样本数插值.

默认为100.
showMarkers

是否在关键帧位置显示标记.

默认为true.
markerSize

关键帧标记的大小（以像素为单位）.

默认为5.

属性

.clip : AnimationClip

包含位置关键帧的动画剪辑.

.divisions : number

平滑路径的样本数插值.

默认为100.

.isAnimationPathHelper : boolean (readonly)

该标志可用于类型测试。

默认为true.

.line : Line

表示动画路径的线。

.object : Object3D

正在可视化路径的对象。

.points : Points | null

标记关键帧位置的点。

.root : Object3D

包含动画剪辑的根对象.

方法

.dispose()

释放由此实例。

覆盖： Object3D#dispose

.setColor( color : number | Color | string )

设置路径线颜色。

color

新颜色。

.setMarkerColor( color : number | Color | string )

设置关键帧标记color.

color

新颜色。

.updateMatrixWorld( force : boolean )

更新助手的变换以匹配对象的父对象。

force

强制矩阵更新.
覆盖： Object3D#updateMatrixWorld
