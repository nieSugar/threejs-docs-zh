SimplifyModifier

此类可用于通过简化来修改几何图形。典型用途 这种修改器的情况是自动 LOD 生成。

实现基于 meshoptimizer。 如果只需要简化的索引缓冲区，请直接使用MeshoptSimplifier。

代码示例

const modifier = new SimplifyModifier();
geometry = await modifier.modify( geometry, count );

导入

SimplifyModifier是一个插件，必须显式导入，请参见Installation#Addons.

import { SimplifyModifier } from 'three/addons/modifiers/SimplifyModifier.js';

构造函数

new SimplifyModifier()

方法

.modify( geometry : BufferGeometry, count : number ) : Promise.<BufferGeometry> (async)

返回给定几何图形的新的简化版本。顶点缓冲区 结果的仅包含简化索引引用的顶点。

geometry

要修改的几何图形。
count

要删除的顶点的大致数量。
返回：使用新的、修改后的几何体解析的承诺。
