WebGPURenderer

此渲染器是 WebGLRenderer 的新替代品。 WebGPURenderer 有能力 针对不同的后端。默认情况下，如果满足以下条件，渲染器会尝试使用 WebGPU 后端： 浏览器支持 WebGPU。如果没有，WebGPURenderer 会退回到 WebGL 2 后端。

构造函数

new WebGPURenderer( parameters : WebGPURenderer~Options )

构造一个新的 WebGPU 渲染器。

parameters

配置参数.

属性

.isWebGPURenderer : boolean (readonly)

该标志可用于类型测试。

默认为true.

.library : StandardNodeLibrary

通用默认值将被覆盖 用于类型映射的标准节点库。

覆盖： Renderer#library

类型定义

.Options

WebGPURenderer 选项.

logarithmicDepthBuffer
boolean

是否启用对数深度缓冲区。

默认为 false.
reversedDepthBuffer
boolean

是否启用反向深度缓冲区。

默认为 false.
alpha
boolean

默认帧缓冲区（表示画布的最终内容）是否应该透明或不透明。

默认为true.
depth
boolean

默认帧缓冲区是否应具有深度缓冲区。

默认为true.
stencil
boolean

默认帧缓冲区是否应该有模板缓冲区。

默认为 false.
antialias
boolean

是否应启用 MSAA 作为默认抗锯齿功能。

默认为 false.
samples
number

当 antialias 为默认使用 true、4 样本。将此参数设置为 0 以外的任何其他整数值以覆盖默认值。

默认为0.
forceWebGL
boolean

如果设置为 true，渲染器将使用 WebGL 2 后端，无论是否支持 WebGPU。

默认为 false.
multiview
boolean

如果设置为 true，渲染器将在 WebXR 渲染期间使用多视图（如果支持）。

默认为 false.
outputType
number

输出到画布的纹理类型。默认情况下，使用设备的首选格式；其他格式可能会产生开销。
outputBufferType
number

定义输出缓冲区的类型。建议使用默认的 HalfFloatType 以获得最佳效果 质量。为了节省内存和带宽，可以使用UnsignedByteType。但这会降低渲染质量。

默认为HalfFloatType.
