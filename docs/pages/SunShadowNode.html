SunShadowNode

表示SunLight的级联阴影贴图.

两个级联相机由SunLightShadow和呈现 进入单个阴影贴图集的视口。每个片段都行走在 从后到前级联，混合它们之间的淡入淡出带。

导入

SunShadowNode 是一个插件，必须显式导入，请参阅 安装#Addons.

import { sunShadow } from 'three/addons/lights/SunShadowNode.js';

构造函数

new SunShadowNode( light : SunLight, shadow : SunLightShadow )

构造一个新的太阳阴影节点。

light

投射太阳光的阴影。
shadow

可选的太阳光阴影。

默认为null.

方法

.renderShadow( frame : NodeFrame )

将两个级联渲染到阴影贴图图集.

frame

对当前节点框架的引用。
覆盖： ShadowNode#renderShadow

.setupRenderTarget( shadow : SunLightShadow, builder : NodeBuilder ) : Object

覆盖默认实现以将渲染目标调整为级联图集大小。

shadow

光阴影对象.
builder

对当前节点构建器的引用。
返回： 包含阴影贴图和深度纹理的对象。

.setupShadow( builder : NodeBuilder ) : Node.<float>

设置图集渲染目标和阴影输出节点。

builder

对当前节点构建器的引用。
覆盖： ShadowNode#setupShadow
返回： 阴影输出节点.

.vsmPass( renderer : Renderer )

作为无操作覆盖，因为级联阴影贴图不支持 VSM。

renderer

对当前材质的引用渲染器.
覆盖： ShadowNode#vsmPass
