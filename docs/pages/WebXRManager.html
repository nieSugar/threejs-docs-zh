WebXRManager

此类表示 WebXR 设备 API 的抽象，并且是 由 WebGLRenderer 内部使用。 WebXRManager 还提供了一个公共 允许用户启用/禁用 XR 并执行 XR 相关操作的接口 例如检索控制器之类的任务。

属性

.cameraAutoUpdate : boolean

管理器的 XR 相机是否应自动更新。

默认为true.

.enabled : boolean

此标志通知渲染器已准备好进行 XR 渲染。将其设置为 true 如果您要在应用程序中使用 XR。

默认为 false.

.isPresenting : boolean (readonly)

XR 呈现是否处于活动状态。

默认为 false.

方法

.getBaseLayer() : XRWebGLLayer | XRProjectionLayer

返回当前基础层。

当目标 XR 设备支持时，这是一个 XRProjectionLayer WebXR Layers API，或 XRWebGLLayer 否则。

返回： XR 基础层。

.getBinding() : XRWebGLBinding

返回当前的 XR 绑定。

如果需要，则创建新绑定，并且浏览器会 能够这样做。

返回： XR 绑定。如果无法创建，则返回 null。

.getCamera() : ArrayCamera

返回代表 XR 相机的 ArrayCamera 的实例 活动 XR 会话的数量。对于每个视图，它都有一个单独的相机对象。

相机的fov当前未使用，并且不反映fov XR 相机。如果您需要应用程序级别的 fov，则必须计算 手动从 XR 相机的投影矩阵中获取。

返回： XR 相机。

.getCameraTexture( xrCamera : XRCamera ) : Texture

从视图对齐的 XRCamera 检索不透明纹理。 仅在当前动画循环期间可用。

xrCamera

要查询的相机。
返回：表示当前原始相机帧的不透明纹理。

.getController( index : number ) : Group

返回表示 XR 控制器的 target ray 空间的组。 使用此空间可视化支持用户指向的 3D 对象 UI 交互等任务。

index

控制器的索引。
返回： 代表 target ray 空间的组。

.getControllerGrip( index : number ) : Group

返回代表XR 控制器的 grip 空间。 使用此空间可视化支持用户指向的 3D 对象 像 UI 交互这样的任务。

注意：如果你想在用户手中展示一些东西并提供一个 同时指向光线，您需要附加手持物体 到 getControllerGrip() 返回的组以及到 getController() 返回的组。这个想法是有两个 同一 WebXR 的两个不同坐标空间中的不同组 控制器.

index

控制器的索引。
返回：代表grip空间的组。

.getDepthSensingMesh() : Mesh

返回深度传感网格。

参见WebXRDepthSensing#getMesh.

返回：深度感应网格。

.getDepthTexture() : Texture

返回通过深度感应计算的当前深度纹理。

参见WebXRDepthSensing#getDepthTexture.

返回：深度纹理。

.getEnvironmentBlendMode() : 'opaque' | 'additive' | 'alpha-blend' | undefined

从当前 XR 会话返回环境混合模式。

返回：环境混合模式。在 XR 会话外部使用时，返回 undefined。

.getFoveation() : number | undefined

返回 XR 合成器用于投影层的注视点数量。

返回： foveation.

.getFrame() : XRFrame

返回当前 XR 帧。

返回： XR 帧。在 XR 会话外部使用时，返回 null。

.getHand( index : number ) : Group

返回表示 XR 控制器的 hand 空间的组。 使用此空间可视化支持用户指向的 3D 对象 UI 交互等任务。

index

控制器的索引。
返回： 代表 hand 空间的组。

.getReferenceSpace() : XRReferenceSpace

返回 XR 参考空间。

返回： XR 参考space.

.getSession() : XRSession

返回当前 XR 会话。

返回： XR 会话。在 XR 会话外使用时返回 null。

.hasDepthSensing() : boolean

如果支持深度感应，则返回 true。

返回： 是否支持深度感应或not.

.setFoveation( value : number )

设置注视点值。

value

范围内的数字[0,1]，其中0表示无注视点（全分辨率） 1 表示最大注视点（边缘以较低分辨率渲染）。

.setFramebufferScaleFactor( value : number )

设置帧缓冲区比例因子。

在 XR 会话期间不能使用此方法。

value

帧缓冲区比例因子.

.setReferenceSpace( space : XRReferenceSpace )

设置自定义XR参考空间。

space

XR参考空间。

.setReferenceSpaceType( value : string )

设置参考空间类型。可用于配置与用户身体的空间关系 环境。根据用户在 3D 空间中的移动方式，设置适当的参考空间可以 改善跟踪。默认为 local-floor。有效值可以在这里找到 https://developer.mozilla.org/en-US/docs/Web/API/XRReferenceSpace#reference_space_types.

在 XR 会话期间不能使用此方法。

value

参考空间类型.

.setSession( value : XRSession ) : Promise (async)

通常使用*Button模块之一请求XR会话后，它 使用此方法注入渲染器。该方法触发启动 实际的 XR 渲染。

value

要设置的 XR 会话。
返回： 设置会话后解析的 Promise。

.updateCamera( camera : Camera )

更新 XR 相机的状态。如果您在应用程序级别使用此方法 将 cameraAutoUpdate 设置为 false。该方法需要非 XR 场景的摄像机作为参数。传入相机的变换 通话时自动调整至XR摄像头的位置 这个方法.

camera

相机.
