RenderPipeline

此模块负责管理应用程序中的渲染管道设置。 您通常创建此类的单个实例并使用它来定义 渲染管线和后处理效果链的输出。

注意：此模块只能与 WebGPURenderer 一起使用。

代码示例

const renderPipeline = new RenderPipeline( renderer );
const scenePass = pass( scene, camera );
renderPipeline.outputNode = scenePass;

构造函数

new RenderPipeline( renderer : Renderer, outputNode : Node.<vec4> )

构造新的渲染管线管理模块。

renderer

对渲染器.
outputNode

可选输出节点.

属性

.isRenderPipeline : boolean (readonly)

该标志可用于类型测试。

默认为true.

.needsUpdate : Node.<vec4>

当输出节点更改时必须设置为true。

.outputColorTransform : boolean

是否默认输出色调映射和颜色 应启用或不启用空间变换。

默认情况下启用此功能，但必须禁用它 预计在色调映射和颜色之后执行的效果 空间转换。一个典型的例子是 FXAA 需要 sRGB 输入。

当设置为 false 时，应用程序必须控制输出 使用 RenderOutputNode.

const outputPass = renderOutput( scenePass );

.outputNode : Node.<vec4>

A 节点进行转换，定义渲染的最终输出 管道。这通常是链中的最后一个节点 效果节点数。

.renderer : Renderer

对渲染器.

方法

.dispose()

释放内部resources.

.render()

当RenderPipeline用于应用渲染管线和后处理效果时， 应用程序必须在内部使用此版本的 render() 它的动画循环（不是来自渲染器的动画循环）。

.renderAsync() : Promise (async)

当 RenderPipeline 用于应用渲染管道和后处理效果时， 应用程序必须在内部使用此版本的 renderAsync() 它的动画循环（不是渲染器中的动画循环）.

已弃用： 是
返回：渲染完成后解析的Promise完成.
