CapsuleGeometry

用于表示胶囊的几何类。

代码示例

const geometry = new THREE.CapsuleGeometry( 1, 1, 4, 8, 1 );
const material = new THREE.MeshBasicMaterial( { color: 0x00ff00 } );
const capsule = new THREE.Mesh( geometry, material );
scene.add( capsule );

构造函数

new CapsuleGeometry( radius : number, height : number, capSegments : number, radialSegments : number, heightSegments : number )

构造一个新的胶囊几何形状。

radius

胶囊的半径胶囊.

默认为1.
height

中间部分的高度。

默认为1.
capSegments

用于构建每个帽的曲线段的数量。

默认为4.
radialSegments

围绕胶囊圆周的分段面的数量。必须是整数 >= 3.

默认为 8.
heightSegments

沿中间部分高度的面行数。必须是整数 >= 1.

默认为1.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : CapsuleGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
