HydrantGenerator

经典的铸铁消防栓：一个位于喇叭形底座上的粗桶，顶部有一个 圆顶阀盖和六角操作螺母，带有两个侧出口喷嘴和一个更大的 前泵喷嘴。构建一次并在展示位置列表中实例化，穿着 用一种廉价的材料在烘烤的 partId （风化的红铁， 裸金属盖).

规范模型位于 y = 0 上，以 X / Z 为中心，带有泵喷嘴 面向 +Z，因此本地 +Z 面向道路的放置会将其呈现给交通。

代码示例

const hydrants = new HydrantGenerator();
scene.add( hydrants.build( placements ) ); // placements: Matrix4[]

构造函数

new HydrantGenerator()
