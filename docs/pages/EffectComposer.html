EffectComposer

用于在 Three.js 中实现后处理效果。 该类管理一系列后处理通道以产生最终的视觉结果。 后处理通道按照添加/插入的顺序执行。 最后一遍会自动渲染到屏幕上。

此模块只能与WebGLRenderer一起使用。

代码示例

const composer = new EffectComposer( renderer );
// adding some passes
const renderPass = new RenderPass( scene, camera );
composer.addPass( renderPass );
const glitchPass = new GlitchPass();
composer.addPass( glitchPass );
const outputPass = new OutputPass()
composer.addPass( outputPass );
function animate() {
	composer.render(); // instead of renderer.render()
}

导入

EffectComposer是一个插件，必须显式导入，请参阅安装#Addons.

import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';

构造函数

new EffectComposer( renderer : WebGLRenderer, renderTarget : WebGLRenderTarget )

构造一个新的效果编辑器。

renderer

渲染器.
renderTarget

此渲染目标和克隆将 用作内部读取和写入缓冲区。如果没有给出，作曲家将创建 自动缓冲区。

属性

.passes : Array.<Pass>

代表后处理通道（有序）链的数组。

.readBuffer : WebGLRenderTarget

对内部读取缓冲区的引用。通行证通常读取 此缓冲区的先前渲染结果。

.renderToScreen : boolean

最终通道是否渲染到屏幕（默认帧缓冲区）。

默认为true.

.renderer : WebGLRenderer

渲染器.

.writeBuffer : WebGLRenderTarget

对内部写入缓冲区的引用。通行证通常会写 将结果放入此缓冲区中。

方法

.addPass( pass : Pass )

将给定的通道添加到通道链中。

pass

要添加的通道。

.dispose()

释放此实例分配的与 GPU 相关的资源。打电话给这个 每当您的应用程序中不再使用作曲家时，都会使用该方法。

.insertPass( pass : Pass, index : number )

在给定索引处插入给定通道。

pass

要插入的通道。
index

通道链中的索引。

.isLastEnabledPass( passIndex : number ) : boolean

返回true 如果给定索引的传递是传递链中最后一个启用的传递。

passIndex

传递索引.
返回：给定索引的传递是否是传递链中的最后一个传递。

.removePass( pass : Pass )

删除传递链中的给定传递。

pass

要删除的传递。

.render( deltaTime : number )

执行所有启用的后处理传递以生成最终帧。

deltaTime

以秒为单位的增量时间。如果没有给出，作曲家会计算 它自己的时间增量值。

.reset( renderTarget : WebGLRenderTarget )

重置 EffectComposer 的内部状态。

renderTarget

此渲染目标具有相同的用途，如 来自构造函数的一个。如果设置，则用于设置读取和写入缓冲区。

.setPixelRatio( pixelRatio : number )

设置设备像素比。这通常用于 HiDPI 设备以防止输出模糊。 设置像素比率将自动调整 Composer 的大小。

pixelRatio

要设置的像素比率。

.setSize( width : number, height : number )

调整内部读写缓冲区以及所有通道的大小。类似于WebGLRenderer#setSize， 此方法遵循当前像素比率。

width

以逻辑像素为单位的宽度。
height

以逻辑像素为单位的高度。

.swapBuffers()

交换内部读/写缓冲区。
