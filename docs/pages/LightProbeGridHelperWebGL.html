LightProbeGridHelperWebGL

通过在每个位置渲染一个球体来可视化 LightProbeGridWebGL 探头位置，用探头的 L2 球谐函数着色。

对所有探头使用单个 InstancedMesh 绘制调用。

代码示例

const helper = new LightProbeGridHelperWebGL( probes );
scene.add( helper );

导入

LightProbeGridHelperWebGL 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { LightProbeGridHelperWebGL } from 'three/addons/helpers/LightProbeGridHelperWebGL.js';

构造函数

new LightProbeGridHelperWebGL( probes : LightProbeGridWebGL, sphereSize : number )

构造一个新的辐照度探头网格助手。

probes

要可视化的探头网格。
sphereSize

每个探头的半径sphere.

默认为 0.12.

属性

.probes : LightProbeGridWebGL

要可视化的探头网格。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： InstancedMesh#dispose

.update()

从当前探针重建实例矩阵和 UVW 属性网格。 更改 probes 或重新烘焙后调用此函数。
