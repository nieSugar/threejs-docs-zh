RawShaderMaterial

该类的工作方式与 ShaderMaterial 类似，但定义不同 内置制服和属性不会自动添加到 GLSL 着色器代码。

RawShaderMaterial 只能与 WebGLRenderer 一起使用。

构造函数

new RawShaderMaterial( parameters : Object )

构造新的原始着色器材质。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.isRawShaderMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.
