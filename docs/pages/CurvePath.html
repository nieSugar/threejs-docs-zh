CurvePath

扩展 Curve 的基类。 CurvePath 只是一个 连接曲线数组，但保留曲线的API。

构造函数

new CurvePath()

构造一条新的曲线路径。

属性

.autoClose : boolean

路径是否应自动闭合 通过直线曲线。

默认为 false.

.curves : Array.<Curve>

定义 路径.

方法

.add( curve : Curve )

向此曲线路径添加一条曲线.

curve

要添加的曲线.

.closePath() : CurvePath

添加一条直线曲线以闭合路径.

返回：对此曲线的引用path.

.getCurveLengths() : Array.<number>

返回已定义曲线的累积曲线长度列表。

返回：曲线长度。

.getPoint( t : number, optionalTarget : Vector2 | Vector3 ) : Vector2 | Vector3

此方法返回 2D 或 3D 空间中的向量（取决于曲线定义） 对于给定的插值因子.

t

表示曲线上位置的插值因子。必须在 [0,1] 范围内。
optionalTarget

结果写入的可选目标向量。
覆盖： Curve#getPoint
返回：曲线上的位置。它可以是 2D 或 3D 向量，具体取决于曲线定义。
