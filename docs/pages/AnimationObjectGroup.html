AnimationObjectGroup

接收共享动画的一组对象状态.

用法：

  • 将原本会作为 AnimationMixer 构造函数或 .clipAction 方法的 'root' 传入的对象添加到其中。
  • 改为将该对象作为 'root' 传入。
  • 在混合器运行时，你也可以随后添加或移除对象。

注意：

  • 该类的对象在混合器中表现为一个整体对象，因此对单个对象的缓存控制必须在组上进行。

限制：

  • 组中所有对象的动画属性必须兼容。
  • 单个属性可以通过目标组或直接控制，但不能同时使用两者。

构造函数

new AnimationObjectGroup( …arguments : Object3D )

构造一个新的动画组。

arguments

共享相同动画的任意数量的3D对象状态.

属性

.isAnimationObjectGroup : boolean (readonly)

该标志可用于类型测试。

默认为true.

.uuid : string (readonly)

3D 对象的 UUID.

方法

.add( …arguments : Object3D )

向该动画组添加任意数量的对象。

arguments

要添加的 3D 对象.

.remove( …arguments : Object3D )

向该动画删除任意数量的对象group

arguments

要删除的 3D 对象.

.uncache( …arguments : Object3D )

为该动画组传递的 3D 对象释放所有内存资源。

arguments

要取消缓存的 3D 对象.
