RapierHelper

此类在轮廓中显示所有剑杆碰撞器。

导入

RapierHelper 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { RapierHelper } from 'three/addons/helpers/RapierHelper.js';

构造函数

new RapierHelper( world : RAPIER.world )

构造一个新的 Rapier 调试助手。

world

要可视化的 Rapier 世界。

属性

.world : RAPIER.world

要可视化的 Rapier 世界。

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： LineSegments#dispose

.update()

在渲染循环中调用此函数更新轮廓.
