Rhino3dmLoader

Rhinoceros 3D 文件和对象的加载器。

Rhinoceros 是一个 3D 建模器，用于创建、编辑、分析、记录、渲染、 制作动画并翻译 NURBS 曲线、曲面、brep、挤压、点云、 以及多边形网格和 SubD 对象。 rhino3dm.js 编译为 WebAssembly 来自开源几何库openNURBS。加载器当前使用 rhino3dm.js 8.32.1.

代码示例

const loader = new Rhino3dmLoader();
loader.setLibraryPath( 'https://cdn.jsdelivr.net/npm/rhino3dm@8.32.1/' );
const object = await loader.loadAsync( 'models/3dm/Rhino_Logo.3dm' );
scene.add( object );

导入

Rhino3dmLoader 是一个插件，必须显式导入，请参阅 安装#Addons.

import { Rhino3dmLoader } from 'three/addons/loaders/3DMLoader.js';

构造函数

new Rhino3dmLoader( manager : LoadingManager )

构造一个新的Rhino 3DM加载器。

manager

加载管理器。

方法

._geometryFromData()

从工作负载构建BufferGeometry。通过快速路径解码的网格 作为可传输类型数组 (format: 'buffers') 到达并直接组装； 其他一切都回到由生成的 Three.js BufferGeometry JSON toThreejsJSON()（较旧的 rhino3dm、点云、曲线等）。

.debug()

将调试消息打印到浏览器控制台。

.decodeObjects( buffer : ArrayBuffer, url : string ) : Promise.<Object3D>

使用 Web Worker 解码 3DM 资产数据。

buffer

原始 3DM 资产数据为数组缓冲区。
url

资产 URL.
返回： 使用解码的 3D 对象解析的 Promise。

.dispose()

释放内部资源。这个方法应该被调用 当不再需要加载器时。

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback )

开始从给定 URL 加载并传递加载的 3DM 资产 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

加载过程完成时执行。
onProgress

加载正在进行时执行。
onError

发生错误时执行。
覆盖： Loader#load

.parse( data : ArrayBuffer, onLoad : function, onError : onErrorCallback )

解析给定的 3DM 数据并传递加载的 3DM 资源 到 onLoad() 回调。

data

原始 3DM 资产数据为数组缓冲区。
onLoad

加载过程完成时执行。
onError

发生错误时执行。
覆盖： Loader#parse

.parseAsync( data : ArrayBuffer ) : Promise.<Object3D>

解析给定的 3DM 数据并返回一个通过加载的资源解析的 Promise。

data

原始 3DM 资产数据为数组缓冲区。
返回：一个通过解码的 3D 解析的 Promise object.

.setLibraryPath( path : string ) : Rhino3dmLoader

包含 JS 和 WASM 库的文件夹的路径。

path

要设置的库路径。
返回：对此加载程序的引用。

.setSubdivisionLevel( level : number ) : Rhino3dmLoader

设置在 SubD 对象之前应用到的全局细分数 网格化以供显示。默认值为 3。具有许多 SubD 对象的大型模型可能 受益于较低的值以保持顶点计数易于管理。

level

细分级别。
返回：对此加载程序的引用。

.setWorkerLimit( workerLimit : number ) : Rhino3dmLoader

设置解码期间要使用的 Web Worker 的最大数量。 如果工人还从事其他工作，则较低的限制可能更好 应用程序中的任务.

workerLimit

工作人员限制.
返回：对此加载程序的引用。
