OrbitControls

轨道控件允许摄像机围绕目标旋转。

OrbitControls 执行轨道、移动（缩放）和平移。与 TrackballControls 不同， 它保持“向上”方向object.up（默认为+Y）。

  • 旋转：左键鼠标 / 触摸：单指移动。
  • 缩放：中键，或鼠标滚轮 / 触控：双指扩展或捏合。
  • 平移：右键鼠标，或者左键鼠标 + ctrl/meta/shift键，或者方向键 / 触摸：双指移动。

代码示例

const controls = new OrbitControls( camera, renderer.domElement );
// controls.update() must be called after any manual changes to the camera's transform
camera.position.set( 0, 20, 100 );
controls.update();
function animate() {
	// required if controls.enableDamping or controls.autoRotate are set to true
	controls.update();
	renderer.render( scene, camera );
}

导入

OrbitControls是一个插件，必须显式导入，请参阅Installation#Addons.

import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

构造函数

new OrbitControls( object : Object3D, domElement : HTMLElement )

构造一个新的控件实例。

object

控件管理的对象。
domElement

用于事件侦听器的 HTML 元素。

默认为null.

属性

.autoRotate : boolean

设置为 true 以自动围绕目标旋转

注意，如果启用此功能，则必须在动画循环中调用 update()。 如果您希望自动旋转速度独立于帧速率（刷新 率），则必须将时间 deltaTime（以秒为单位）传递给 update().

默认为 false.

.autoRotateSpeed : number

如果 autoRotate 为 true，则围绕目标旋转的速度有多快。默认值等于 30 秒 每轨速度为 60fps。

请注意，如果启用 autoRotate，则必须在动画循环中调用 update()。

默认为2.

.cursor : Vector3

minTargetRadius 的焦点和maxTargetRadius 限制。 可以随时手动更新以更改兴趣中心 对于target.

.cursorStyle : 'auto' | 'grab'

定义光标的视觉表示。

默认为'auto'.

.dampingFactor : number

使用的阻尼惯性，如果enableDamping 设置为 true.

注意，要使其工作，您必须在动画循环中调用 update()。

默认为0.05.

.enableDamping : boolean

设置为true以启用阻尼（惯性），可以用来给人一种重量感 到控件。请注意，如果启用此功能，则必须在动画中调用 update() 循环.

默认为 false.

.enablePan : boolean

启用或禁用相机平移。

默认为true.

.enableRotate : boolean

启用或禁用相机的水平和垂直旋转.

注意，可以通过设置相机的最小值和最大值来禁用单个轴 minPolarAngle 或 minAzimuthAngle 为相同值，这会导致垂直 或固定为该值的水平旋转。

默认为true.

.enableZoom : boolean

启用或禁用摄像机的缩放（移动）。

默认为true.

.keyPanSpeed : number

使用键盘时平移摄像机的速度有多快 每次按键的像素数。

默认为7.

.keyRotateSpeed : number

使用键盘时旋转相机的速度。

默认为1.

.keys : Object

此对象包含对用于控制相机平移的键码的引用。

controls.keys = {
	LEFT: 'ArrowLeft', //left arrow
	UP: 'ArrowUp', // up arrow
	RIGHT: 'ArrowRight', // right arrow
	BOTTOM: 'ArrowDown' // down arrow
}
覆盖： Controls#keys

.maxAzimuthAngle : number

你可以水平运行多远，上限。如果设置，则间隔 [ min, max ] 必须是 [ - 2 PI, 2 PI ] 的子区间，其中 ( max - min < 2 PI ).

默认为 -Infinity.

.maxDistance : number

可以推出多远（透视相机）仅).

默认为 Infinity.

.maxPolarAngle : number

你可以垂直轨道运行多远，上限。范围为 [0, Math.PI] 弧度。

默认为 Math.PI.

.maxTargetRadius : number

您可以将目标从 3D 移动多远cursor.

默认为 Infinity.

.maxZoom : number

您可以缩小多远（仅限正交相机）。

默认为 Infinity.

.minAzimuthAngle : number

您可以水平轨道运行多远，下限。如果设置，则间隔 [ min, max ] 必须是 [ - 2 PI, 2 PI ] 的子区间，其中 ( max - min < 2 PI ).

默认为 -Infinity.

.minDistance : number

您可以移动多远（仅限透视相机）.

默认为0.

.minPolarAngle : number

您可以垂直轨道移动多远，下限。范围为 [0, Math.PI] 弧度.

默认为0.

.minTargetRadius : number

您可以使目标距离 3D cursor.

默认为0.

.minZoom : number

您可以放大多远（正交相机）仅).

默认为0.

.mouseButtons : Object

此对象包含对控件使用的鼠标操作的引用。

controls.mouseButtons = {
	LEFT: THREE.MOUSE.ROTATE,
	MIDDLE: THREE.MOUSE.DOLLY,
	RIGHT: THREE.MOUSE.PAN
}
覆盖： Controls#mouseButtons

.panSpeed : number

平移速度。

默认为1.

.position0 : Vector3

由 saveState() 和内部使用reset().

.rotateSpeed : number

旋转速度.

默认为1.

.screenSpacePanning : boolean

定义平移时摄像机位置的平移方式。如果 true，则相机平移 在屏幕空间中。否则，相机将在与相机向上正交的平面上平移 方向。

默认为true.

.target : Vector3

控件的焦点 object 围绕此点运行。 可以随时手动更新以更改控件的焦点。

.target0 : Vector3

由 saveState() 和内部使用reset().

.touches : Object

此对象包含对控件使用的触摸操作。

controls.mouseButtons = {
	ONE: THREE.TOUCH.ROTATE,
	TWO: THREE.TOUCH.DOLLY_PAN
}
覆盖： Controls#touches

.zoom0 : number

由 saveState() 和内部使用reset().

.zoomSpeed : number

缩放/移动速度。

默认为1.

.zoomToCursor : boolean

将此属性设置为true 允许缩放到光标的位置。

默认为 false.

方法

.dollyIn( dollyScale : number )

以编程方式推拉（放大透视相机）。

dollyScale

推拉比例因子。

.dollyOut( dollyScale : number )

以编程方式推拉（缩小以透视相机）.

dollyScale

推拉比例因子。

.getAzimuthalAngle() : number

获取当前水平旋转角度，单位为弧度。

返回：当前水平旋转角度，单位为弧度。

.getDistance() : number

返回从相机到相机的距离target.

返回值：相机到目标的距离。

.getPolarAngle() : number

获取当前垂直旋转角度，单位为弧度。

返回值：当前垂直旋转角度，单位为弧度。 radians.

.listenToKeyEvents( domElement : HTMLElement )

向给定的 DOM 元素添加关键事件侦听器。 window 是使用此方法的推荐参数。

domElement

DOM 元素

.pan( deltaX : number, deltaY : number )

以编程方式平移相机。

deltaX

以像素为单位的水平平移量。
deltaY

以像素为单位的垂直平移量像素.

.reset()

将控件重置为上次 saveState() 的状态 被调用，或初始状态。

.rotateLeft( angle : number )

以编程方式向左旋转相机（绕垂直轴）。

angle

以弧度为单位的旋转角度。

.rotateUp( angle : number )

以编程方式向上旋转相机（绕水平轴）。

angle

以弧度为单位的旋转角度。

.saveState()

保存当前状态控件。稍后可以使用 reset() 恢复。

.stopListenToKeyEvents()

删除先前使用 listenToKeyEvents().

Events

当相机已被控件转换时触发。

Type:
  • Object

.end

当交互发生时触发完成.

Type:
  • Object

.start

启动交互时触发.

Type:
  • Object
