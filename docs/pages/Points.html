Points

用于显示点或点云的类。

构造函数

new Points( geometry : BufferGeometry, material : Material | Array.<Material> )

构造一个新的点云。

geometry

点几何图形。
material

The点材质.

属性

.geometry : BufferGeometry

点几何图形。

.isPoints : boolean (readonly)

该标志可用于类型测试。

默认为true.

.material : Material | Array.<Material>

线材质.

默认为PointsMaterial.

.morphTargetDictionary : Object.<string, number> | undefined

表示几何体中变形目标的字典。关键是 morph 目标名称，其属性索引值。该成员是undefined 默认情况下，仅在几何体中检测到变形目标时设置。

默认为undefined.

.morphTargetInfluences : Array.<number> | undefined

通常在 [0,1] 范围内的权重数组，指定变形量 被应用。该成员默认为 undefined 并且仅在变形目标为 在几何体中检测到。

默认为undefined.

方法

.intersectsFrustum( frustum : Frustum | FrustumArray ) : boolean

如果此点云与给定的相交，则返回true平截头体.

frustum

到的平截头体test.
覆盖： Object3D#intersectsFrustum
返回： 该点云是否与给定的平截头体相交。

.raycast( raycaster : Raycaster, intersects : Array.<Object> )

计算投射射线与该点云之间的交点。

raycaster

The raycaster.
intersects

保存交点的目标数组。
覆盖： Object3D#raycast

.updateMorphTargets()

设置Points#morphTargetDictionary 和 Points#morphTargetInfluences 确保现有的变形目标可以影响此 3D 对象。
