InstancedBufferAttribute

缓冲区属性的实例化版本。

构造函数

new InstancedBufferAttribute( array : TypedArray, itemSize : number, normalized : boolean, meshPerAttribute : number )

构造一个新的实例化缓冲区属性。

array

保存属性数据的数组。
itemSize

项目大小。
normalized

数据是否标准化或不是.

默认为 false.
meshPerAttribute

此缓冲区属性的值应该多久出现一次Repeated.

默认为1.

属性

.isInstancedBufferAttribute : boolean (readonly)

该标志可用于类型测试。

默认为true.

.meshPerAttribute : number

定义此缓冲区属性的值应重复的频率。一个 值为 1 表示实例化属性的每个值都用于 单个实例。值为二表示每个值用于两个 连续实例（依此类推）.

默认为1.
