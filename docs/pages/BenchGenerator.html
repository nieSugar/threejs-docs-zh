BenchGenerator

公共街道长凳：木板条承载在两个铸铁端框架上， 蜷缩在扶手上，并配有倾斜的板条靠背。构建一次并实例化 跨越一系列的展示位置，用一种廉价的材料装饰，在一个分支上 烘烤partId（温暖的染色木材，深色铁）。

规范模型站在y = 0上，以X / Z为中心，沿着X和座椅运行 朝向 +Z，因此本地 +Z 面向道路的位置上坐着一个路人 俯视它.

代码示例

const benches = new BenchGenerator();
scene.add( benches.build( placements ) ); // placements: Matrix4[]

构造函数

new BenchGenerator()
