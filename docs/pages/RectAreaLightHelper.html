RectAreaLightHelper

为矩形区域灯创建视觉辅助。

RectAreaLightHelper 必须添加为light.

代码示例

const light = new THREE.RectAreaLight( 0xffffbb, 1.0, 5, 5 );
const helper = new RectAreaLightHelper( light );
light.add( helper );

导入

RectAreaLightHelper 是一个插件，必须显式导入，请参阅Installation#Addons.

import { RectAreaLightHelper } from 'three/addons/helpers/RectAreaLightHelper.js';

构造函数

new RectAreaLightHelper( light : RectAreaLight, color : number | Color | string )

构造一个新的矩形区域光助手.

light

可视化的光.
color

助手的颜色。 如果没有设置，助手将采用灯光的颜色。

属性

.color : number | Color | string | undefined

助手的颜色。如果undefined，助手将采用灯光的颜色。

.light : RectAreaLight

可视化的光.

方法

.dispose()

释放分配的GPU相关资源通过这个例子。打电话给这个 每当您的应用程序中不再使用此实例时，方法。

覆盖： Line#dispose
