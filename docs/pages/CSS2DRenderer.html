CSS2DRenderer

此渲染器是 CSS3DRenderer 的简化版本。唯一的转变是 支持平移和 2D 旋转。

如果您想将基于 HTML 的标签与 3D 对象结合起来，渲染器非常有用。这里也是， 各个 DOM 元素被包装到 CSS2DObject 的实例中并添加到 场景图。所有其他类型的可渲染 3D 对象（例如网格或点云）都将被忽略。

CSS2DRenderer 仅支持 100% 浏览器和显示缩放。

导入

CSS2DRenderer 是一个插件，必须显式导入，请参阅Installation#Addons.

import { CSS2DRenderer } from 'three/addons/renderers/CSS2DRenderer.js';

构造函数

new CSS2DRenderer( parameters : CSS2DRenderer~Parameters )

构造一个新的 CSS2D 渲染器。

parameters

参数.

属性

.domElement : HTMLElement

渲染器附加其属性的 DOM child-elements.

.sortObjects : boolean

控制渲染器是否将 z-index 值分配给 CSS2DObject DOM 元素。 如果设置为 true，则首先根据 renderOrder 分配 z 索引值 其次 - 到相机的距离。如果设置为 false，则不分配 z 索引值。

默认为true.

方法

.getSize() : Object

返回包含渲染器宽度和高度的对象。

返回：渲染器的大小。

.render( scene : Object3D, camera : Camera )

渲染给定场景使用给定的相机。

scene

场景或任何其他类型的 3D 对象。
camera

相机.

.setSize( width : number, height : number )

将渲染器的大小调整为给定的宽度和高度。

width

渲染器的宽度。
height

渲染器的高度renderer.

类型定义

.Parameters

CSS2DRenderer.

element
HTMLElement

渲染器附加其子元素的 DOM 元素的构造函数参数。 如果此处未传入，则会创建一个新的 div 元素。
