PointLight

从单个点向各个方向发射的光。一个常见的 其用例是复制从裸露的光发出的光 灯泡.

此灯光可以投射阴影 - 有关详细信息，请参阅PointLightShadow。

代码示例

const light = new THREE.PointLight( 0xff0000, 1, 100 );
light.position.set( 50, 50, 50 );
scene.add( light );

构造函数

new PointLight( color : number | Color | string, intensity : number, distance : number, decay : number )

构造一个新的点光源。

color

灯光的颜色.

默认为0xffffff.
intensity

光的强度/强度以坎德拉（cd）为单位测量。

默认为1.
distance

光的最大范围。 0 表示无限制。

默认为0.
decay

灯光沿距离的变暗量。

默认为2.

属性

.decay : number

灯光沿灯光距离变暗的量。在上下文中 物理正确渲染默认值不应更改。

默认为2.

.distance : number

当距离为零时，光线将按平方反比衰减 法则到无限远。当距离非零时，光会衰减 根据平方反比定律直到接近距离截止，其中 然后将快速平滑地衰减至 0。本质上，截止值不是 物理上正确。

默认为0.

.isPointLight : boolean (readonly)

该标志可用于类型测试。

默认为true.

.power : number

灯的功率。功率是以流明 (lm) 为单位测量的光的发光功率。 改变功率也会改变光的强度。

.shadow : PointLightShadow

此属性保存灯光的阴影配置.
