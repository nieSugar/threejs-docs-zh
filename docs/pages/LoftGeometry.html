LoftGeometry

此类可用于通过放样（蒙皮）曲面来生成几何体 通过一系列的横截面。每个部分都是 3D 中的点数组 空间和所有部分必须具有相同数量的点。

LoftGeometry 是 LatheGeometry 等几何图形的一般情况 （绕轴旋转固定轮廓）或 TubeGeometry （沿着路径扫过圆形部分）：这些部分可以有任何 形状，并且可以改变形状、大小、位置和方向 剖面到下一个。

剖面围绕放样，因此生成的面法线指向外侧 当每个部分从末端看逆时针排序时 阁楼，回望起点。如果表面翻过来， 反转每个部分的点顺序。

代码示例

const sections = [];
for ( let i = 0; i <= 10; i ++ ) {
	const points = [];
	const radius = 2 + Math.sin( i * 0.8 );
	for ( let j = 0; j < 32; j ++ ) {
		const angle = j / 32 * Math.PI * 2;
		points.push( new THREE.Vector3( Math.sin( angle ) * radius, i, Math.cos( angle ) * radius ) );
	}
	sections.push( points );
}
const geometry = new LoftGeometry( sections, { capStart: true, capEnd: true } );
const material = new THREE.MeshStandardMaterial( { color: 0x00ff00 } );
const mesh = new THREE.Mesh( geometry, material );
scene.add( mesh );

导入

LoftGeometry 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { LoftGeometry } from 'three/addons/geometries/LoftGeometry.js';

构造函数

new LoftGeometry( sections : Array.<Array.<Vector3>>, options : Object )

Constructs新的放样几何体。

sections

蒙皮的横截面。至少 需要两个截面，并且所有截面必须具有相同的点数。
options

放样选项。

默认为 {}.

closed

是否将每个截面视为一个截面 闭合环（例如机身）或开放条带（例如丝带）.

默认为true.
capStart

第一节是否闭合 是否带帽

默认为 false.
capEnd

最后一段是否封闭 有无帽子.

默认为 false.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。
