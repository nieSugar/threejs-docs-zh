TrafficlightGenerator

A NYC 交通信号：路边的圆杆，带有水平桅杆臂 越过道路到达一个垂直的三部分信号头，加上一个 杆上的行人信号箱。构建一次并在一系列列表中实例化 放置，用一种廉价的材料装饰，在烘烤的 partId 上分支 （深色金属，三色镜片）.

规范模型站在y = 0上，以X / Z为中心，手臂伸直 朝向 +Z，因此本地 +Z 面向道路的放置会抛出头部 镜头对准迎面驶来的车辆。

代码示例

const lights = new TrafficlightGenerator();
scene.add( lights.build( placements ) ); // placements: Matrix4[]

构造函数

new TrafficlightGenerator()
