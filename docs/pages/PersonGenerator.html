PersonGenerator

低多边形行人人群，具有成形的头部、夹克和高高的四肢。 两个共同的姿势站立或行走，袖子和裤子掠过 他们的关节。每个位置都有确定的比例和一个小的 在两次抽签中，其肤色、发型和服装的种子属性。

该材料将图形分割为烘焙的 partId 和散列上的区域 每个区域的种子，从小调色板中绘制衣服、皮肤和头发。 局部 UV 使面部特征、袖口和鞋底附着在其部件上 如图所示。

规范人物站在 y = 0 上，以 X / Z 为中心，高约 1.75 m， 面向+Z，因此放置将其转向面向道路。

代码示例

const people = new PersonGenerator();
scene.add( people.build( placements ) ); // placements: Matrix4[]

构造函数

new PersonGenerator()
