Clock

用于跟踪时间的类。

构造函数

new Clock( autoStart : boolean )

构造一个新时钟。

autoStart

是否在以下情况下自动启动时钟 getDelta() 首次调用。

默认为true.
已弃用：自 r183 起。

属性

.autoStart : boolean

如果设置为 true，则时钟在以下情况下自动启动getDelta() 被调用 第一次。

默认为true.

.elapsedTime : number

跟踪时钟运行的总时间。

默认为0.

.oldTime : number

保存时钟的 start()、getElapsedTime() 或 getDelta() 方法最后一次调用。

默认为0.

.running : boolean

时钟是否正在运行。

默认为true.

.startTime : number

保存时钟的 start() 方法最后一次调用的时间调用.

默认为0.

方法

.getDelta() : number

返回以秒为单位的增量时间。

返回：增量时间。

.getElapsedTime() : number

返回以秒为单位的经过时间。

返回：经过的时间.

.start()

启动时钟。当autoStart设置为true时，该方法自动 由类调用.

.stop()

停止时钟.
