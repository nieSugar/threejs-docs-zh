MaterialXLoader

MaterialX 格式的加载器。

使用此加载器加载的节点材质只能与WebGPURenderer 一起使用。 除了普通的 .mtlx 文档外，加载程序还接受 .mtlx.zip 捆绑了 及其纹理的文档。

代码示例

const loader = new MaterialXLoader().setPath( SAMPLE_PATH );
const { materials } = await loader.loadAsync( 'standard_surface_brass_tiled.mtlx' );

导入

MaterialXLoader 是一个插件，必须显式导入，请参阅Installation#Addons.

import { MaterialXLoader } from 'three/addons/loaders/MaterialXLoader.js';

构造函数

new MaterialXLoader( manager : LoadingManager )

构造一个新的MaterialX 加载器.

manager

加载管理器。

方法

.dispose() : MaterialXLoader

释放上次加载的存档的资源。

返回：对此加载程序的引用。

.load( url : string, onLoad : function, onProgress : onProgressCallback, onError : onErrorCallback, options : Object ) : MaterialXLoader

开始从给定 URL 加载并传递加载的 MaterialX 资源 到 onLoad() 回调。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onLoad

在加载过程完成时执行。接收解析结果，参见MaterialXLoader#parse.
onProgress

加载正在进行时执行。
onError

发生错误时执行。
options

解析选项，参见MaterialXLoader#parse.
覆盖： Loader#load
返回：对此加载程序的引用。

.loadAsync( url : string, onProgress : onProgressCallback | Object, options : Object ) : Promise.<Object>

MaterialXLoader#load的异步版本。进度回调可以是 省略，解析选项作为第二个参数传递。

url

要加载的文件的路径/URL。这也可以是数据 URI。
onProgress

在加载过程中执行，或解析选项。
options

解析选项，参见MaterialXLoader#parse.
覆盖： Loader#loadAsync
返回： 解析结果的 Promise。

.parse( text : string, options : Object ) : Object

解析给定的 MaterialX 文档并返回结果材质 与翻译日志一起。

text

作为字符串的原始 MaterialX 数据。
options

解析选项。

path

用于解析纹理等资源的基本路径。默认为加载器的路径。
materialName

仅翻译具有此名称的材料。默认为所有材质。
uvSpace

文档纹理的 UV 空间，'bottom-left' 或 'top-left'.

默认为 'bottom-left'。
interfaceValidator

验证节点接口，参见MaterialXInterfaceValidation.js中的createStrictInterfaceValidator().
throwOnErrors

翻译错误是否抛出或仅在日志中报告。

默认为true.
覆盖： Loader#parse
返回：按名称和翻译键入的材料log.

.parseBuffer( data : ArrayBuffer | Uint8Array | string, url : string, options : Object ) : Object

解析原始MaterialX文档或.mtlx.zip存档并返回结果材料。

data

MaterialX文档或存档.
url

加载数据的URL，用于解析相关资源paths.

默认为 ''.
options

解析选项，参见MaterialXLoader#parse.
返回：解析结果，参见MaterialXLoader#parse.
