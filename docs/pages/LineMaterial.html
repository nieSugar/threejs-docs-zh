LineMaterial

用于绘制线框样式几何图形的材质。

与LineBasicMaterial不同，它支持任意线宽并允许使用世界单位 而不是屏幕空间单位。该材质与LineSegments2和Line2一起使用。

该模块只能与WebGLRenderer一起使用。当使用WebGPURenderer时， use Line2NodeMaterial.

导入

LineMaterial 是一个插件，必须显式导入，请参阅 安装#Addons.

import { LineMaterial } from 'three/addons/lines/LineMaterial.js';

构造函数

new LineMaterial( parameters : Object )

构造一个新的线段几何图形。

parameters

具有一个或多个属性的对象 定义材料的外观。材料的任何属性 （包括继承材料的任何财产）可以通过 在这里。颜色值可以传递任何接受的类型的值 by Color#set.

属性

.alphaToCoverage : boolean

是否使用alphaToCoverage。启用后，这可以改善 使用 MSAA 时线边缘的抗锯齿。

覆盖： ShaderMaterial#alphaToCoverage

.color : Color

材质的颜色.

默认为(1,1,1).

.dashOffset : number

破折号循环中破折号开始的位置。

默认为0.

.dashScale : number

破折号和的比例间隙.

默认为1.

.dashSize : number

破折号的大小.

默认为1.

.dashed : boolean

线条是虚线还是实线.

默认为 false.

.gapSize : number

间隙的大小。

默认为0.

.isLineMaterial : boolean (readonly)

该标志可用于类型测试。

默认为true.

.linewidth : number

当worldUnits为false时控制CSS像素单位的线条粗细（默认）， 或当 worldUnits 为 true.

默认为1.

覆盖： ShaderMaterial#linewidth

.opacity : number

The不透明度.

默认为1.

覆盖： ShaderMaterial#opacity

.resolution : Vector2

视口的大小（以屏幕像素为单位）时，采用世界单位。必须不断更新才能使 屏幕空间渲染准确。 LineSegments2.onBeforeRender 回调 对可见对象执行更新。

.worldUnits : boolean

材质的尺寸（宽度、破折号间隙）是否采用世界单位。

默认为 false.
