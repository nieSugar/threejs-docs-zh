StorageBufferAttribute

这种特殊类型的缓冲区属性适用于计算着色器。 在早期的 Three.js 版本中，只能更新属性数据 通过JavaScript将数据上传到CPU，然后将数据上传到GPU。随着 新的材质系统和渲染器现在可以使用计算着色器 在 GPU 上更有效地计算属性的数据。

想法是创建此类的实例并将其作为输入提供 至 StorageBufferNode.

注意：此类缓冲区属性只能与 WebGPURenderer.

构造函数

new StorageBufferAttribute( count : number | TypedArray, itemSize : number, typeClass : TypedArray.constructor )

构造一个新的存储缓冲区属性。

count

项目计数一起使用。将类型化数组作为参数传递也是有效的。 随后的参数将被废弃。
itemSize

项目大小。
typeClass

A 类型化数组构造函数。

默认为 Float32Array.

属性

.isStorageBufferAttribute : boolean (readonly)

该标志可用于类型测试。

默认为true.
