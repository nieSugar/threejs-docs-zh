FlakesTexture

用于生成薄片纹理图像的实用程序类。这张图片可能会用到 作为法线贴图来产生类似汽车油漆的效果。

导入

FlakesTexture 是一个插件，必须显式导入，请参阅 安装#Addons.

import { FlakesTexture } from 'three/addons/textures/FlakesTexture.js';

构造函数

new FlakesTexture( width : number, height : number ) : HTMLCanvasElement

生成一个新的薄片纹理图像。结果是画布 可以用作 CanvasTexture.

width

图像的宽度.

默认为512.
height

图像的高度.

默认为512.
返回： 生成的图片.
