HueSaturationShader

导入

HueSaturationShader 是一个插件，必须显式导入，请参阅 安装#Addons.

import { HueSaturationShader } from 'three/addons/shaders/HueSaturationShader.js';

属性

.HueSaturationShader : ShaderMaterial~Shader (inner, constant)

色调和饱和度调整，https://github.com/evanw/glfx.js.

hue：-1 到 1 （-1是负方向180度，0是没有变化，等等。 饱和度：-1到1（-1为纯灰色，0为无变化，1为最大对比度）
