LatheGeometry

创建像花瓶一样轴对称的网格。车床绕 Y 轴旋转。

代码示例

const points = [];
for ( let i = 0; i < 10; i ++ ) {
	points.push( new THREE.Vector2( Math.sin( i * 0.2 ) * 10 + 5, ( i - 5 ) * 2 ) );
}
const geometry = new THREE.LatheGeometry( points );
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const lathe = new THREE.Mesh( geometry, material );
scene.add( lathe );

构造函数

new LatheGeometry( points : Array.<(Vector2|Vector3)>, segments : number, phiStart : number, phiLength : number )

构造新的车床几何形状。

points

2D 空间中的点数组。每个点的 x 坐标 必须大于零。
segments

要生成的圆周段数。

默认为 12.
phiStart

以弧度为单位的起始角度。

默认为0.
phiLength

车削部分 2PI 的弧度（0 到 2PI）范围是 闭式车床，小于2PI为一部分。

默认为 Math.PI*2.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : LatheGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
