SSAARenderPass

Supersample 抗锯齿渲染通道。

这种 SSAA 手动方法通过相机抖动重新渲染每个样本的场景并累积结果.

代码示例

const ssaaRenderPass = new SSAARenderPass( scene, camera );
ssaaRenderPass.sampleLevel = 3;
composer.addPass( ssaaRenderPass );

导入

SSAARenderPass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { SSAARenderPass } from 'three/addons/postprocessing/SSAARenderPass.js';

构造函数

new SSAARenderPass( scene : Scene, camera : Camera, clearColor : number | Color | string, clearAlpha : number )

构造新的 SSAA 渲染通过.

scene

要渲染的场景.
camera

相机.
clearColor

渲染通道的清除颜色。

默认为0x000000.
clearAlpha

渲染通道的清除alpha。

默认为0.

属性

.camera : Camera

相机.

.clearAlpha : number

渲染通道的清除alpha。

默认为0.

.clearColor : number | Color | string

渲染通道的清除颜色。

默认为0x000000.

.sampleLevel : number

样本关卡。指定为 n，其中数量 样本是2^n，所以sampleLevel = 4，是2^4个样本，16.

默认为4.

.scene : Scene

要渲染的场景.

.stencilBuffer : boolean

是否使用模板缓冲区。这个属性不能 第一次渲染后更改。

默认为 false.

.unbiased : boolean

通道是否应该是无偏的。该楼盘拥有最多 渲染到 RGBA8 缓冲区时可见效果，因为它减轻了 舍入误差。默认情况下使用 RGBA16F。

默认为true.

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行 SSAA 渲染通道。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render

.setSize( width : number, height : number )

设置通道的大小。

width

要设置的宽度。
height

要设置的高度。
覆盖： Pass#setSize
