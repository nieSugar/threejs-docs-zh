FilmPass

此通道可用于创建胶片颗粒效果。

代码示例

const filmPass = new FilmPass();
composer.addPass( filmPass );

导入

FilmPass 是一个插件，必须显式导入，请参阅 Installation#Addons.

import { FilmPass } from 'three/addons/postprocessing/FilmPass.js';

构造函数

new FilmPass( intensity : number, grayscale : boolean )

构造新的胶片通道。

intensity

范围内的颗粒强度[0,1]（0 = 无效果，1 = 完全） effect).

默认为0.5.
grayscale

是否应用灰度效果。

默认为 false.

属性

.material : ShaderMaterial

通道材质.

.uniforms : Object

通行证制服。如果您想更新，请使用此对象 intensity 或 grayscale 运行时的值。

pass.uniforms.intensity.value = 1;
pass.uniforms.grayscale.value = true;

方法

.dispose()

释放此实例分配的 GPU 相关资源。打电话给这个 每当您的应用中不再使用该通道时，都会调用该方法。

覆盖： Pass#dispose

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

执行胶片通道。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
