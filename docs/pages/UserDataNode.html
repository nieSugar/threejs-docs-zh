UserDataNode

一种特殊类型的引用节点，允许链接以下值 userData 字段到节点对象。

由于 UserDataNode 是从 ReferenceNode 扩展而来，因此节点值 当 rotation 用户数据字段更改时，将自动更新。

代码示例

sprite.userData.rotation = 1; // stores individual rotation per sprite
const material = new THREE.SpriteNodeMaterial();
material.rotationNode = userData( 'rotation', 'float' );

构造函数

new UserDataNode( property : string, inputType : string, userData : Object )

构造新的用户数据节点。

property

节点应引用的属性名称。
inputType

引用的节点数据类型。
userData

对userData对象的引用。如果未提供，则评估使用节点材质的 3D 对象的 userData 属性。

默认为null.

属性

.userData : Object

对 userData 对象的引用。如果未提供，则 userData 评估使用节点材质的 3D 对象的属性。

默认为null.

方法

.updateReference( state : NodeFrame | NodeBuilder ) : Object

覆盖以确保 ReferenceNode#reference 指向正确的 userData 字段.

state

要评估的当前状态.
覆盖： ReferenceNode#updateReference
返回： 对 userData 字段的引用.
