SetNode

此模块是 TSL 核心的一部分，通常不在应用程序级代码中使用。 SetNode 表示集合操作，这意味着它用于实现任何 节点对象上的 setXYZW()、setRGBA() 和 setSTPQ() 方法调用。 例如：

代码示例

materialLine.colorNode = color( 0, 0, 0 ).setR( float( 1 ) );

构造函数

new SetNode( sourceNode : Node, components : string, targetNode : Node )

构造一个新的集合节点。

sourceNode

应更新的节点.
components

应该更新的组件。
targetNode

值节点。

属性

.components : string

应该更新的组件。

.sourceNode : Node

应更新的节点.

.targetNode : Node

值节点。

方法

.generateNodeType( builder : NodeBuilder ) : string

由于节点类型是从推断的，因此该方法被覆盖SetNode#sourceNode.

builder

当前节点构建器.
覆盖： TempNode#generateNodeType
返回： 节点类型。
