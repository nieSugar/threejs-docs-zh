SphereGeometry

用于生成球体几何图形的类。

代码示例

const geometry = new THREE.SphereGeometry( 15, 32, 16 );
const material = new THREE.MeshBasicMaterial( { color: 0xffff00 } );
const sphere = new THREE.Mesh( geometry, material );
scene.add( sphere );

构造函数

new SphereGeometry( radius : number, widthSegments : number, heightSegments : number, phiStart : number, phiLength : number, thetaStart : number, thetaLength : number )

构造一个新的球体几何图形。

radius

球体radius.

默认为1.
widthSegments

水平线段的数量。最小值为3.

默认为32.
heightSegments

垂直段的数量。最小值为 2.

默认为16.
phiStart

以弧度为单位的水平起始角度。

默认为0.
phiLength

以弧度为单位的水平扫角大小。

默认为 Math.PI*2.
thetaStart

以弧度为单位的垂直起始角度。

默认为0.
thetaLength

垂直扫角尺寸.

默认为 Math.PI.

属性

.parameters : Object

保存已经被构造的构造函数参数 用于生成几何图形。任何修改 实例化后不会更改几何形状。

静态方法

.fromJSON( data : Object ) : SphereGeometry

用于从给定创建此类实例的工厂方法 JSON 对象.

data

表示序列化几何图形的 JSON 对象.
返回： 一个新实例.
