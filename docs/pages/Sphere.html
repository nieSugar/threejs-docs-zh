Sphere

由中心和半径定义的分析 3D 球体。这门课主要是 用作 3D 对象的边界球。

构造函数

new Sphere( center : Vector3, radius : number )

构造一个新球体。

center

球体的中心

默认为(0,0,0).
radius

球体的半径。

默认为 -1.

属性

.center : Vector3

球体的中心

.isSphere : boolean (readonly)

该标志可用于类型测试。

默认为true.

.radius : number

球体的半径。

point

.isEmpty() : boolean

返回true 如果球体为空（半径设置为负数）。
