ReadbackBuffer

读回缓冲区用于将数据从 GPU 传输到 CPU。 它主要用于读回计算着色器结果。

构造函数

new ReadbackBuffer( maxByteLength : number )

构造一个新的读回缓冲区。

maxByteLength

要读回的缓冲区的最大大小。

属性

.buffer : ArrayBuffer | null

映射的读回数组缓冲区。

.isReadbackBuffer : boolean (readonly)

该标志可用于类型测试。

默认为true.

.maxByteLength : number

要读回的缓冲区的最大大小。

.name : string

用于调试目的的名称。

方法

.dispose()

释放内部resources.

.release()

释放映射的缓冲区数据，以便 GPU 缓冲区可以 GPU 再次使用。

注意：与此读回缓冲区关联的任何 ArrayBuffer 数据 调用此方法后将被删除且无法再访问。
