MaskPass

此通道可用于在后处理期间定义掩码。 意味着仅后续后处理的区域受到影响 位于该通道的掩蔽区域中。在内部，掩蔽 使用模板缓冲区实现。

代码示例

const maskPass = new MaskPass( scene, camera );
composer.addPass( maskPass );

导入

MaskPass 是一个插件，必须显式导入，请参阅 安装#Addons.

import { MaskPass } from 'three/addons/postprocessing/MaskPass.js';

构造函数

new MaskPass( scene : Scene, camera : Camera )

构造一个新的遮罩通道。

scene

该场景中的3D对象将定义遮罩。
camera

相机.

属性

.camera : Camera

相机.

.clear : boolean

默认覆盖以执行清除操作。

默认为true.

覆盖： Pass#clear

.inverse : boolean

是否反转遮罩.

默认为 false.

.needsSwap : boolean

覆盖以禁用交换.

默认为 false.

覆盖： Pass#needsSwap

.scene : Scene

该场景定义遮罩。

方法

.render( renderer : WebGLRenderer, writeBuffer : WebGLRenderTarget, readBuffer : WebGLRenderTarget, deltaTime : number, maskActive : boolean )

使用配置的场景和相机执行遮罩通道。

renderer

渲染器.
writeBuffer

写入缓冲区。该缓冲区旨在作为渲染 传递的目的地。
readBuffer

读缓冲区。该通行证可以访问结果 此缓冲区的上一次传递。
deltaTime

以秒为单位的增量时间。
maskActive

屏蔽是否处于活动状态。
覆盖： Pass#render
