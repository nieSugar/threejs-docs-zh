在浏览器中截取画布截图

实际上有两种函数可以截取截图。 旧的方式 canvas.toDataURL 以及新的更好的方式 canvas.toBlob

所以你可能会认为，只需添加一些代码就可以轻松截取截图

<canvas id="c"></canvas>
+<button id="screenshot" type="button">Save...</button>

const elem = document.querySelector('#screenshot');
elem.addEventListener('click', () => {
  canvas.toBlob((blob) => {
    saveBlob(blob, `screencapture-${canvas.width}x${canvas.height}.png`);
  });
});

const saveBlob = (function() {
  const a = document.createElement('a');
  document.body.appendChild(a);
  a.style.display = 'none';
  return function saveData(blob, fileName) {
     const url = window.URL.createObjectURL(blob);
     a.href = url;
     a.download = fileName;
     a.click();
  };
}());

防止画布被清除

假设你想让用户用一个动画对象进行绘画。当你创建preserveDrawingBuffer: true时，需要传入WebGLRenderer。这可以防止浏览器清除画布。你还需要告诉 three.js 不要清除画布。

const canvas = document.querySelector('#c');
-const renderer = new THREE.WebGLRenderer({antialias: true, canvas});
+const renderer = new THREE.WebGLRenderer({
+  canvas,
+  preserveDrawingBuffer: true,
+  alpha: true,
+});
+renderer.autoClearColor = false;

click here to open in a separate window

请注意，如果你认真想制作一个绘图程序，这并不是一个解决方案，因为每当我们改变画布的分辨率时，浏览器仍然会清除画布。我们改变的是基于显示尺寸的分辨率。当窗口大小变化时，其显示尺寸也会变化。这包括用户下载文件时，即使在另一个标签页中，以及浏览器添加状态栏时。它也包括用户旋转手机，浏览器从竖屏切换到横屏时。

如果你真的想制作一个绘图程序，你可以使用渲染目标渲染到纹理。

获取键盘输入

在这些教程中，我们经常将事件监听器附加到 canvas 上。虽然许多事件都能正常工作，但默认情况下不能工作的一个是键盘事件。

要获取键盘事件，请将画布的 tabindex 设置为 0 或更大的值。例如 

<canvas tabindex="0"></canvas>

不过这样会引发一个新问题。任何设置了 tabindex 的元素在获得焦点时都会被高亮。要解决此问题，将其焦点 CSS 轮廓设置为无 

canvas:focus {
  outline:none;
}

为了演示，这里有 3 个画布 

<canvas id="c1"></canvas>
<canvas id="c2" tabindex="0"></canvas>
<canvas id="c3" tabindex="1"></canvas>

以及仅针对最后一个画布的一些 CSS 

#c3:focus {
    outline: none;
}

让我们将相同的事件监听器附加到它们所有人

document.querySelectorAll('canvas').forEach((canvas) => {
  const ctx = canvas.getContext('2d');

  function draw(str) {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.fillText(str, canvas.width / 2, canvas.height / 2);
  }
  draw(canvas.id);

  canvas.addEventListener('focus', () => {
    draw('has focus press a key');
  });

  canvas.addEventListener('blur', () => {
    draw('lost focus');
  });

  canvas.addEventListener('keydown', (e) => {
    draw(`keyCode: ${e.keyCode}`);
  });
});

注意，你无法让第一个画布接受键盘输入。 第二个画布可以接受，但会被高亮显示。第三个画布同时应用了两种解决方案。

使画布透明

默认情况下，THREE.js会使画布不透明。如果你想让画布透明，在创建alpha:true时传入参数WebGLRenderer。

const canvas = document.querySelector('#c');
-const renderer = new THREE.WebGLRenderer({antialias: true, canvas});
+const renderer = new THREE.WebGLRenderer({
+  canvas,
+  alpha: true,
+});

你可能还想告诉它，你的结果不使用预乘 alpha。

const canvas = document.querySelector('#c');
const renderer = new THREE.WebGLRenderer({
  canvas,
  alpha: true,
+  premultipliedAlpha: false,
});

Three.js 默认情况下 canvas 使用 premultipliedAlpha: true，但默认材料输出 premultipliedAlpha: false。

如果你想更好地理解何时使用或不使用预乘 alpha，这里有一篇 很好的相关文章。

让你的背景成为一个 three.js 动画

一个常见的问题是如何让 three.js 动画成为网页的背景。

有两种明显的方法。

  • 将画布 CSS position 设置为 fixed，如
#c {
 position: fixed;
 left: 0;
 top: 0;
 ...
}

您基本上可以在前面的示例中看到这个确切的解决方案。只需将 z-index 设置为 -1，立方体就会出现在文本后面。

这个解决方案的一小个缺点是您的 JavaScript 必须与页面集成，如果您的页面复杂，则需要确保 three.js 可视化中的 JavaScript 不与页面中执行其他操作的 JavaScript 冲突。

  • 使用一个 iframe

这是在本站首页使用的解决方案。

在您的网页中只需插入一个 iframe，例如

<iframe id="background" src="responsive.html">
<div>
  Your content goes here.
</div>

然后将 iframe 样式设置为填充窗口并置于背景中，这基本上与我们上面为 canvas 使用的代码相同，只是我们还需要将 border 设置为 none，因为 iframe 默认有边框。

#background {
    position: fixed;
    width: 100%;
    height: 100%;
    left: 0;
    top: 0;
    z-index: -1;
    border: none;
    pointer-events: none;
}
