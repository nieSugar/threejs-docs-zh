让我们再生成两组数据。一组是男性人数多于女性人数的地方，另一组是女性人数多于男性人数的地方。

首先，让我们编写一个函数，给定一个像之前一样的二维数组，它将遍历该数组以生成一个新的二维数组

function mapValues(data, fn) {
  return data.map((row, rowNdx) => {
    return row.map((value, colNdx) => {
      return fn(value, rowNdx, colNdx);
    });
  });
}

像普通的 Array.map 函数一样，mapValues 函数会对二维数组中的每个值调用一个函数 fn。它会传入该值以及行和列的索引。

现在让我们编写一些代码来生成一个新文件，这个文件是两个文件之间的比较

function makeDiffFile(baseFile, otherFile, compareFn) {
  let min;
  let max;
  const baseData = baseFile.data;
  const otherData = otherFile.data;
  const data = mapValues(baseData, (base, rowNdx, colNdx) => {
    const other = otherData[rowNdx][colNdx];
      if (base === undefined || other === undefined) {
        return undefined;
      }
      const value = compareFn(base, other);
      min = Math.min(min === undefined ? value : min, value);
      max = Math.max(max === undefined ? value : max, value);
      return value;
  });
  // make a copy of baseFile and replace min, max, and data
  // with the new data
  return {...baseFile, min, max, data};
}

上面的代码使用 mapValues 来生成一组新的数据，这组数据是基于传入的 compareFn 函数进行的比较。它还跟踪了 min 和 max 的比较结果。最后，它生成一个新文件，拥有与 baseFile 相同的所有属性，但具有新的 min、max 和 data。

有很多想法。

  • 只需使用 Material.opacity

    在它们之间淡入淡出。这个解决方案的问题是立方体完全重叠，这意味着会有深度冲突问题。我们可能可以通过更改深度函数并使用混合来解决它。我们可能应该研究一下。

  • 放大我们想看到的集合并缩小其他集合

    因为所有的盒子它们的原点都在行星的中心，如果我们将它们缩放到小于1.0，它们会沉入行星。起初这听起来像是个好主意，但问题是所有低高度的盒子几乎会立即消失，直到新的数据集缩放到1.0时才会被替换。这使得过渡不是很顺畅。我们也许可以用一个花哨的自定义着色器来解决这个问题。

  • 使用Morphtargets

    Morphtargets是一种我们为几何体的每个顶点提供多个值的方法，然后在它们之间形态变化或线性插值（lerp）。Morphtargets最常用于3D角色的面部动画，但这不是它们的唯一用途。

我们也应该在渲染循环的每一帧中调用 TWEEN.update，但这暴露了一个问题。"tween.js" 是为连续渲染设计的，但我们是按需渲染。我们可以切换到连续渲染，但有时候仅按需渲染也不错，因为那样可以在没有活动时停止使用用户的电力，所以让我们看看是否可以按需动画。

我们将创建一个 TweenManager 来帮助。我们将用它来创建 Tween 并跟踪它们。它将有一个 update 方法，如果我们需要再次调用它会返回 true，如果所有动画都完成则返回 false。

class TweenManger {
  constructor() {
    this.numTweensRunning = 0;
  }
  _handleComplete() {
    --this.numTweensRunning;
    console.assert(this.numTweensRunning >= 0);
  }
  createTween(targetObject) {
    const self = this;
    ++this.numTweensRunning;
    let userCompleteFn = () => {};
    // create a new tween and install our own onComplete callback
    const tween = new TWEEN.Tween(targetObject).onComplete(function(...args) {
      self._handleComplete();
      userCompleteFn.call(this, ...args);
    });
    // replace the tween's onComplete function with our own
    // so we can call the user's callback if they supply one.
    tween.onComplete = (fn) => {
      userCompleteFn = fn;
      return tween;
    };
    return tween;
  }
  update() {
    TWEEN.update();
    return this.numTweensRunning > 0;
  }
}

注意：我们可以尝试只绘制男性百分比或女性百分比，或者原始差异，但根据我们显示信息的方式——从地面生长出的立方体——我们希望大多数立方体比较低。如果我们使用这些其他比较，大多数立方体大约是它们最高高度的一半，这不会产生好的可视化效果。可以将 amountGreaterThan 中的 Math.max(a - b, 0) 改为类似 (a - b) "原始差异" 或 a / (a + b) "百分比"，然后你就会明白我的意思。
