Uniform 类型

每个 uniform 都必须有一个 `value` 属性。其值的类型必须对应于 GLSL 代码中 uniform 变量的类型，如下表中为基本 GLSL 类型所指定的那样。还支持 uniform 结构体和数组。基本类型的 GLSL 数组必须要么被指定为相应的 THREE 对象数组，要么被指定为包含所有对象数据的平面数组。换句话说；数组中的 GLSL 基本类型不能用数组来表示。此规则不具有传递性。长度为五个向量的 `vec2` 数组的数组，必须是数组的数组，要么是五个 `Vector2` 对象的数组，要么是十个 `number` 的数组。

结构化统一变量

有时候你可能希望在着色器代码中将 uniform 组织为 `structs`。 必须使用以下样式，`three.js` 才能处理结构化的 uniform 数据。 

uniforms = {
  data: { 
    value: {
      position: new Vector3(), 
      direction: new Vector3( 0, 0, 1 ) 
    } 
  } 
};
This definition can be mapped on the following GLSL code: 
struct Data { 
  vec3 position;
  vec3 direction;
};
uniform Data data;

带数组的结构化 Uniforms

也可以在数组中管理 `structs`。这种用法的语法如下所示： 

const entry1 = {
  position: new Vector3(),
  direction: new Vector3( 0, 0, 1 )
};
const entry2 = {
  position: new Vector3( 1, 1, 1 ),
  direction: new Vector3( 0, 1, 0 )
};

uniforms = {
  data: {
    value: [ entry1, entry2 ]
  }
};
This definition can be mapped on the following GLSL code: 
struct Data { 
  vec3 position; 
  vec3 direction; 
};
uniform Data data[ 2 ];
