创建文本

有时您可能需要在 Three.js 应用程序中使用文本 - 以下是 有几种方法可以做到这一点。

1.DOM+CSS

使用 HTML 通常是添加文本最简单、最快的方式。这是方法 用于大多数 Three.js 示例中的描述性覆盖。

您可以将内容添加到

<div id="info">Description</div>

并使用 CSS 标记绝对定位在高于所有其他位置的位置 z-index 特别是当您全屏运行 Three.js 时。

#info {
  position: absolute;
  top: 10px;
  width: 100%;
  text-align: center;
  z-index: 100;
  display:block;
}

2.使用`CSS2DRenderer`或`CSS3DRenderer`

使用这些渲染器将 DOM 元素中包含的高质量文本绘制到您的 Three.js 场景中。 这与 1. 类似，只不过使用这些渲染器可以将元素更紧密、更动态地集成到场景中。

3. 将文本绘制到画布上并用作“纹理”

如果您希望在 Three.js 场景中的平面上轻松绘制文本，请使用此方法。

4。在您最喜欢的 3D 应用程序中创建模型并导出到 Three.js

如果您更喜欢使用 3d 应用程序并将模型导入到 Three.js.

5，请使用此方法。程序文本几何

如果您更喜欢纯粹在 THREE.js 中工作或创建程序化和动态 3D 文本几何图形，您可以创建一个网格，其几何图形是 THREE.TextGeometry 的实例：

new THREE.TextGeometry( text, parameters );

但是，为了使其正常工作，您的 TextGeometry 将需要 THREE.Font 的实例 在其“字体”参数上设置。 有关如何完成此操作的更多信息，请参阅“TextGeometry”页面以及每个部分的描述 接受的参数，以及 THREE.js 发行版本身附带的 JSON 字体列表。

6. 位图字体

BMFonts（位图字体）允许将字形批处理到单个 BufferGeometry 中。 BMF字体渲染 支持标准的自动换行、字母间距、字距调整、符号距离字段 导数、多通道符号距离场、多纹理字体等等。 请参阅[link:https://github.com/felixmariotto/three-mesh-ui three-mesh-ui]或[link:https://github.com/Jam3/three-bmfont-text three-bmfont-text]。

库存字体可用于以下项目 [link:https://github.com/etiennepinchon/aframe-fonts A-Frame Fonts]，或者您可以创建自己的字体 来自任何 .TTF 字体，优化以仅包含项目所需的字符。

一些有用的工具：

  • [link:http://msdf-bmfont.donmccurdy.com/ msdf-bmfont-web] （基于网络）
  • [link:https://github.com/soimy/msdf-bmfont-xml msdf-bmfont-xml] （命令行）
  • [link:https://github.com/libgdx/libgdx/wiki/Hiero hiero] （桌面应用程序）

7。三驾马车文本

[link:https://www.npmjs.com/package/troika-three-text troika-three-text] 包渲染 使用与 BMFonts 类似的技术提供高质量的抗锯齿文本，但可直接与任何 .TTF 一起使用 或 .WOFF 字体文件，这样您就不必离线预生成字形纹理。它还添加了 能力包括：

  • 描边、阴影和曲率等效果
  • 能够应用任何 Three.js 材质，甚至是自定义 ShaderMaterial
  • 支持字体连字、带有连接字母的脚本以及从右到左/双向布局
  • 针对大量动态文本进行优化，在Web Worker中的主线程中执行大部分工作
