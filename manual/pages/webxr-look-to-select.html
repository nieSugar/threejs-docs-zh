VR - 注视选择

注意：本页示例需要支持 VR 的设备。没有设备的话无法运行。请参见上一篇文章了解原因

在上一篇文章中，我们展示了一个使用 three.js 的非常简单的 VR 示例，并讨论了各种类型的 VR 系统。

最简单且可能最常见的 VR 是 Google Cardboard 风格的 VR，本质上就是将手机放入一个 5 美元到 50 美元的面罩中。这种 VR 没有控制器，所以人们必须想出创造性的解决方案来实现用户输入。

最常见的解决方案是“看即选”，即用户将头部指向某个对象一会儿时，该对象就会被选中。

让我们实现“看即选”吧！我们将从上一篇文章的示例开始，为此我们将添加在拾取文章中制作的PickHelper。如下所示：

class PickHelper {
  constructor() {
    this.raycaster = new THREE.Raycaster();
    this.pickedObject = null;
    this.pickedObjectSavedColor = 0;
  }
  pick(normalizedPosition, scene, camera, time) {
    // restore the color if there is a picked object
    if (this.pickedObject) {
      this.pickedObject.material.emissive.setHex(this.pickedObjectSavedColor);
      this.pickedObject = undefined;
    }

    // cast a ray through the frustum
    this.raycaster.setFromCamera(normalizedPosition, camera);
    // get the list of objects the ray intersected
    const intersectedObjects = this.raycaster.intersectObjects(scene.children);
    if (intersectedObjects.length) {
      // pick the first object. It's the closest one
      this.pickedObject = intersectedObjects[0].object;
      // save its color
      this.pickedObjectSavedColor = this.pickedObject.material.emissive.getHex();
      // set its emissive color to flashing red/yellow
      this.pickedObject.material.emissive.setHex((time * 8) % 2 > 1 ? 0xFFFF00 : 0xFF0000);
    }
  }
}

关于代码的解释，请参见拾取文章。

通常我们不希望选择是立即生效的。相反，我们需要用户将摄像头对准他们想要选择的物体几秒钟，以便给他们机会避免意外选择物体。

为此，我们需要某种计量器、仪表或某种方式来传达用户必须持续注视以及持续多长时间。

一个简单的方法是制作一个双色纹理，并使用纹理偏移将纹理在模型上滑动。

function makeDataTexture(data, width, height) {
  const texture = new THREE.DataTexture(data, width, height, THREE.RGBAFormat);
  texture.minFilter = THREE.NearestFilter;
  texture.magFilter = THREE.NearestFilter;
  texture.needsUpdate = true;
  return texture;
}

THREE.MathUtils.mapLinear 取一个介于 fromStart 和 fromEnd 之间的值，并将其映射到介于 toStart 和 toEnd 之间的值。在上述情况下，我们取 time % 2，其意味着一个从 0 到 2 的值，并将其映射到一个从 -0.5 到 0.5 的值。

纹理 使用归一化的纹理坐标映射到几何体上，纹理坐标的范围是从 0 到 1。这意味着我们的 2x1 像素图像，如果设置为默认的环绕模式 THREE.ClampToEdge，如果将纹理坐标调整为 -0.5，则整个网格将显示第一个颜色；如果将纹理坐标调整为 +0.5，则整个网格将显示第二个颜色。在两者之间，当过滤模式设置为 THREE.NearestFilter 时，我们将能够在几何体上移动两种颜色之间的过渡。

有几点需要注意并且尝试的地方并尝试。

  • 我们将 cursorMaterial 的 blending、blendSrc 和 blendDst 属性设置如下

      blending: THREE.CustomBlending,
  blendSrc: THREE.OneMinusDstColorFactor,
  blendDst: THREE.OneMinusSrcColorFactor,

    这会产生一种反向类型的效果。注释掉那三行，你就能看到差异。我只是猜测反向效果在这里最好，因为这样我们希望无论光标位于哪种颜色上都能看到它。

  • 我们使用TorusGeometry而不是RingGeometry

    出于某种原因，RingGeometry使用的是平面UV映射方案。因此如果我们使用RingGeometry，纹理会在环的水平方向上滑动，而不是像上面那样绕环旋转。

    试一下，把 TorusGeometry 改成 RingGeometry（上面的示例中只是被注释掉了），你就会明白我的意思。

    适当的做法（根据某种“适当”的定义）是，要么使用 RingGeometry，但修正纹理坐标，使它们绕环走。要么，自己生成一个环几何体。但，圆环扭体（torus）也完全可以正常工作。将其直接放置在相机前，用 MeshBasicMaterial 它看起来就和一个环完全一样，纹理坐标绕环走，所以满足我们的需求。
