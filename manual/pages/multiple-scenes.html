多个画布 多个场景

一个常见的问题是如何在多个画布中使用 THREE.js。 假设你想制作一个电子商务网站，或者想制作一个包含大量 3D 图表的页面。乍一看，这似乎很容易。 只需在每个需要图表的地方创建一个画布。 对于每个画布，创建一个 Renderer。

但是你很快会发现会遇到问题。

  1. 浏览器对你可以拥有的 WebGL 上下文数量有限制。

    通常该限制大约为 8 个。一旦你创建第 9 个上下文，最旧的上下文将会丢失。

  2. WebGL 资源不能在上下文之间共享

    这意味着如果你想将一个 10 兆的模型加载到两个画布中，并且该模型使用了 20 兆的纹理，你的 10 兆模型将不得不加载两次，纹理也会被加载两次。不同的上下文之间不能共享任何东西。这也意味着必须初始化两次，着色器编译两次，等等。随着画布数量增加，情况会变得更糟。

那么解决方案是什么？

解决方案是在背景中使用一个填充视口的画布，并使用其他元素表示每个“虚拟”画布。我们创建一个单独的 Renderer，然后为每个虚拟画布创建一个 Scene。随后我们检查虚拟画布元素的位置，如果它们在屏幕上，我们会告诉 THREE.js 在正确的位置绘制它们的场景。

使用这种解决方案，只有一个画布，因此可以解决上述问题 1 和 2。我们不会遇到 WebGL 上下文限制，因为我们只会使用一个上下文。出于同样的原因，我们也不会遇到共享问题。

现在我们将制作两个场景，每个场景都有一个灯光和一个摄像机。一个场景中我们添加一个立方体，另一个场景中添加一个钻石。

function makeScene(elem) {
  const scene = new THREE.Scene();

  const fov = 45;
  const aspect = 2;  // the canvas default
  const near = 0.1;
  const far = 5;
  const camera = new THREE.PerspectiveCamera(fov, aspect, near, far);
  camera.position.z = 2;
  camera.position.set(0, 1, 2);
  camera.lookAt(0, 0, 0);

  {
    const color = 0xFFFFFF;
    const intensity = 1;
    const light = new THREE.DirectionalLight(color, intensity);
    light.position.set(-1, 2, 4);
    scene.add(light);
  }

  return {scene, camera, elem};
}

function setupScene1() {
  const sceneInfo = makeScene(document.querySelector('#box'));
  const geometry = new THREE.BoxGeometry(1, 1, 1);
  const material = new THREE.MeshPhongMaterial({color: 'red'});
  const mesh = new THREE.Mesh(geometry, material);
  sceneInfo.scene.add(mesh);
  sceneInfo.mesh = mesh;
  return sceneInfo;
}

function setupScene2() {

然后我们将创建一个函数，仅当元素在屏幕上时才渲染每个场景。我们可以通过开启scissor测试来告诉THREE.js只渲染画布的一部分，方法是使用Renderer.setScissorTest，然后使用Renderer.setViewport和Renderer.setScissor设置剪裁和视口。

function renderSceneInfo(sceneInfo) {
  const {scene, camera, elem} = sceneInfo;

  // get the viewport relative position of this element
  const {left, right, top, bottom, width, height} =
      elem.getBoundingClientRect();

  const isOffscreen =
      bottom < 0 ||
      top > renderer.domElement.clientHeight ||
      right < 0 ||
      left > renderer.domElement.clientWidth;

  if (isOffscreen) {
    return;
  }

  camera.aspect = width / height;
  camera.updateProjectionMatrix();

  const positiveYUpBottom = canvasRect.height - bottom;
  renderer.setScissor(left, positiveYUpBottom, width, height);
  renderer.setViewport(left, positiveYUpBottom, width, height);

  renderer.render(scene, camera);
}

然后我们的渲染函数将首先清空屏幕，然后渲染每个场景。

function render(time) {
  time *= 0.001;

  resizeRendererToDisplaySize(renderer);

  renderer.setScissorTest(false);
  renderer.clear(true, true);
  renderer.setScissorTest(true);

  sceneInfo1.mesh.rotation.y = time * .1;
  sceneInfo2.mesh.rotation.y = time * .1;

  renderSceneInfo(sceneInfo1);
  renderSceneInfo(sceneInfo2);

  requestAnimationFrame(render);
}

然后我们将设置画布的变换，使其移动到画布顶部与页面当前滚动到的部分顶部对齐。

  ...

  const transform = `translateY(${window.scrollY}px)`;
  renderer.domElement.style.transform = transform;

position: fixed 完全阻止了画布滚动，而页面的其他部分则可以在其上方滚动。position: absolute 将允许画布随页面一起滚动，这意味着无论我们绘制什么，都会随页面滚动，即使我们渲染得太慢。当我们最终有机会渲染时，我们会移动画布，使其与页面已滚动的位置匹配，然后重新渲染。这意味着窗口的边缘只会短暂显示一些未渲染的部分，但 页面中间的内容应该会匹配，并且不会滑动。这是新方法效果的一个视图，慢放了10倍。

使其更通用

既然我们已经让多个场景能够运行了，让我们把它做得稍微通用一些。

我们可以让主渲染函数，也就是管理画布的那个函数，只维护一个元素及其关联渲染函数的列表。对于每个元素，它会检查该元素是否在屏幕上，如果在，则调用对应的渲染函数。通过这种方式，我们将拥有一个通用系统，其中各个场景实际上并不知道自己正在被渲染在某个小区域中。

这是主渲染函数

const sceneElements = [];
function addScene(elem, fn) {
  sceneElements.push({elem, fn});
}

function render(time) {
  time *= 0.001;

  resizeRendererToDisplaySize(renderer);

  renderer.setScissorTest(false);
  renderer.setClearColor(clearColor, 0);
  renderer.clear(true, true);
  renderer.setScissorTest(true);

  const transform = `translateY(${window.scrollY}px)`;
  renderer.domElement.style.transform = transform;

  for (const {elem, fn} of sceneElements) {
    // get the viewport relative position of this element
    const rect = elem.getBoundingClientRect();
    const {left, right, top, bottom, width, height} = rect;

    const isOffscreen =
        bottom < 0 ||
        top > renderer.domElement.clientHeight ||
        right < 0 ||
        left > renderer.domElement.clientWidth;

    if (!isOffscreen) {
      const positiveYUpBottom = renderer.domElement.clientHeight - bottom;
      renderer.setScissor(left, positiveYUpBottom, width, height);
      renderer.setViewport(left, positiveYUpBottom, width, height);

      fn(time, rect);
    }
  }

  requestAnimationFrame(render);
}

你可以看到它循环遍历 sceneElements，它期望这是一个对象数组，每个对象都有 elem 和 fn 属性。

它检查元素是否在屏幕上。如果在屏幕上，它会调用 fn 并传递当前时间和它的矩形。

现在，每个场景的设置代码只是将自己添加到场景列表中
