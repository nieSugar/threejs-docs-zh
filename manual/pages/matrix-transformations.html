矩阵变换

Three.js 使用 `矩阵` 来编码 3D 变换——平移（位置）、旋转和缩放。每个 `Object3D` 实例都有一个 `matrix`，它存储该对象的位置、旋转和缩放。本页描述了如何更新对象的变换。

便捷属性和 `matrixAutoUpdate`

有两种方法可以更新对象的变换：

  1. 修改对象的 `position`、`quaternion` 和 `scale` 属性，让 three.js 根据这些属性重新计算对象的矩阵： 
    object.position.copy( start_position );
object.quaternion.copy( quaternion );
    默认情况下，`matrixAutoUpdate` 属性为 true，矩阵会自动重新计算。如果对象是静态的，或希望手动控制重新计算的时机，可以将该属性设为 false，以获得更好的性能： 
    object.matrixAutoUpdate = false;
    更改属性后，手动更新矩阵： 
    object.updateMatrix();
  2. 直接修改对象的矩阵。`Matrix4` 类提供了多种修改矩阵的方法： 
    object.matrix.makeRotationFromQuaternion( quaternion );
object.matrix.setPosition( start_position );
object.matrixAutoUpdate = false;
    注意，在这种情况下必须将 `matrixAutoUpdate` 设为 `false`，并确保不要调用 `updateMatrix`。调用 `updateMatrix` 会覆盖对矩阵所做的手动更改，并根据 `position`、`scale` 等属性重新计算矩阵。

对象矩阵和世界矩阵

对象的矩阵存储对象相对于其父对象的变换；要获取对象在世界坐标中的变换，必须访问对象的世界矩阵。

当父对象或子对象的变换发生变化时，可以通过调用 `object.updateMatrixWorld()` 来请求更新子对象的世界矩阵。

一个对象可以通过 `applyMatrix4()` 进行变换。注意：在底层，该方法依赖于 `Matrix4.decompose()`，并非所有矩阵都可以以这种方式分解。例如，如果一个对象的父对象进行了非均匀缩放，那么该对象的世界矩阵可能无法分解，此方法可能不适用。

旋转与四元数

Three.js 提供了两种表示 3D 旋转的方法：欧拉角和四元数，以及用于在两者之间转换的方法。欧拉角存在一个称为“万向锁”的问题，在某些配置下可能会失去一个自由度（阻止对象绕某个轴旋转）。因此，对象的旋转 总是储存在对象的四元数中。

库的早期版本包含一个 `useQuaternion` 属性，当设置为 false 时，会导致对象的矩阵从欧拉角计算。这种做法已不推荐——相反，你应该使用 `object.setRotationFromEuler()` 方法，这将更新四元数。
