如何创建 VR 内容

本指南简要概述了基于 Web 的 VR 应用程序的基本组件 用three.js 制作。

工作流程

首先，您必须包含[link:https://github.com/mrdoob/three.js/blob/master/examples/jsm/webxr/VRButton.js VRButton.js] 到你的项目中。

import { VRButton } from 'three/addons/webxr/VRButton.js';

*VRButton.createButton()* 做了两件重要的事情： 它创建一个按钮，指示 VR 兼容性。此外，如果用户激活按钮，它还会启动 VR 会话。你唯一拥有的东西 要做的是将以下代码行添加到您的应用程序中。

document.body.appendChild( VRButton.createButton( renderer ) );

接下来，您必须告诉“WebGLRenderer”实例启用 XR 渲染。

renderer.xr.enabled = true;

最后，你必须调整你的动画循环，因为我们不能使用我们众所周知的 *window.requestAnimationFrame()* 函数。对于 VR 项目，我们使用 renderer.setAnimationLoop()。 最小的代码如下所示： 

renderer.setAnimationLoop( function () {

  renderer.render( scene, camera );

} );
