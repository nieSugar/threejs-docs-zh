注意：本页的示例需要具有指向设备的VR设备。没有这些设备示例将无法运行。具体原因请参见本文

在上一篇文章中，我们介绍了一个非常简单的 VR 示例，其中我们让用户通过凝视来选择物体。在本文中，我们将进一步扩展，让用户可以使用指点设备

进行选择。Three.js 提供了两个 VR 控制器对象，使其相对简单，并尝试处理单个 3DOF 控制器和两个 6DOF 控制器的情况。每个控制器都是Object3D对象，可提供该控制器的方向和位置。当用户开始按下、正在按下、以及停止按下（结束）控制器上的“主”按钮时，它们还会提供selectstart、select和selectend事件。

从上一篇文章的最后一个示例开始，让我们将 PickHelper 改为 ControllerPickHelper。

我们的新实现将触发一个 select 事件，它会返回我们选中的对象，因此要使用它，我们只需要这样做。

记住，在我们之前的代码中 meshToMeshMap 将我们的盒子和球体相互映射，所以如果我们有其中一个，我们可以通过 meshToMeshMap 查找到它的对应对象，所以这里我们只是在隐藏选中的对象并显示其对应对象。

至于 ControllerPickHelper 的实际实现，首先我们需要将 VR 控制器对象添加到场景中，并在这些对象上添加一些三维线条，用于显示用户指向的位置。我们保存控制器和它们的线条。

class ControllerPickHelper {
  constructor(scene) {
    const pointerGeometry = new THREE.BufferGeometry().setFromPoints([
      new THREE.Vector3(0, 0, 0),
      new THREE.Vector3(0, 0, -1),
    ]);

    this.controllers = [];
    for (let i = 0; i < 2; ++i) {
      const controller = renderer.xr.getController(i);
      scene.add(controller);

      const line = new THREE.Line(pointerGeometry);
      line.scale.z = 5;
      controller.add(line);
      this.controllers.push({controller, line});
    }
  }
}

仅仅这样做而不做其他操作，就可以在场景中显示 1 或 2 条线，显示用户的指向设备的位置及其指向方向。

接下来，我们添加一些代码来从控制器中进行选择。这是我们第一次使用非摄像头的方式进行选择。在我们的关于选择的文章中，用户使用鼠标或手指进行选择，这意味着选择是从摄像头进入屏幕的。在上一篇文章中，我们是根据用户的视线方向来进行选择，所以这也是来自摄像头。不过这一次，我们是根据控制器的位置进行选择，所以不使用摄像头。

+  update(pickablesParent, time) {
+    this.reset();
+    for (const {controller, line} of this.controllers) {
+      // cast a ray through the from the controller
+      this.tempMatrix.identity().extractRotation(controller.matrixWorld);
+      this.raycaster.ray.origin.setFromMatrixPosition(controller.matrixWorld);
+      this.raycaster.ray.direction.set(0, 0, -1).applyMatrix4(this.tempMatrix);
+      // get the list of objects the ray intersected
+      const intersections = this.raycaster.intersectObjects(pickablesParent.children);
+      if (intersections.length) {

+        // make the line touch the object
+        line.scale.z = intersection.distance;
+        // pick the first object. It's the closest one
+        const pickedObject = intersection.object;
+        // save which object this controller picked
+        this.controllerToObjectMap.set(controller, pickedObject);
+        // highlight the object if we haven't already
+        if (this.objectToColorMap.get(pickedObject) === undefined) {
+          // save its color
+          this.objectToColorMap.set(pickedObject, pickedObject.material.emissive.getHex());
+          // set its emissive color to flashing red/yellow
+          pickedObject.material.emissive.setHex((time * 8) % 2 > 1 ? 0xFF2000 : 0xFF0000);
+        }
+      } else {
+        line.scale.z = 5;
+      }
+    }
+  }

现在让我们修改代码，当我们接收到 selectstart 事件时，将所选对象从场景中移除，并将其设为控制器的子对象。 这意味着它会随着控制器一起移动。当我们接收到 selectend 事件时，会将它放回场景中。

+const controllerToSelection = new Map();
+pickHelper.addEventListener('selectstart', (event) => {
+  const {controller, selectedObject} = event;
+  const existingSelection = controllerToSelection.get(controller);
+  if (!existingSelection) {
+    controllerToSelection.set(controller, {
+      object: selectedObject,
+      parent: selectedObject.parent,
+    });
+    controller.attach(selectedObject);
+  }
+});
+
+pickHelper.addEventListener('selectend', (event) => {
+  const {controller} = event;
+  const selection = controllerToSelection.get(controller);
+  if (selection) {
+    controllerToSelection.delete(controller);
+    selection.parent.attach(selection.object);
+  }
+});

当一个对象被选中时，我们会保存该对象及其原始父对象。当用户完成操作后，我们可以将对象放回去。

我们使用 Object3D.attach 来重新设定所选对象的父对象。这些函数允许我们在不改变对象在场景中的方向和位置的情况下更改对象的父对象。
