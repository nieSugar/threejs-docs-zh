如何更新对象

默认情况下，所有对象如果已添加到场景中，则会自动更新其矩阵

const object = new THREE.Object3D();
scene.add( object );
or if they are the child of another object that has been added to the scene: 
const object1 = new THREE.Object3D();
const object2 = new THREE.Object3D();

object1.add( object2 );
scene.add( object1 ); //object1 and object2 will automatically update their matrices

但是，如果您知道该对象将是静态的，则可以禁用此功能并在需要时手动更新变换矩阵。

object.matrixAutoUpdate = false;
object.updateMatrix();

BufferGeometry

BufferGeometry 存储信息（例如顶点位置、面索引、法线、颜色、 UV 和任何自定义属性）在属性缓冲区中 - 也就是说， [link:https://developer.mozilla.org/en-US/docs/Web/JavaScript/Typed_arrays typed arrays]。 这使得它们通常比标准几何图形更快，但代价是更难 与. 一起工作。

关于更新 BufferGeometries，最重要的是要理解： 你不能调整缓冲区的大小（这是非常昂贵的，基本上相当于创建一个新的几何体）。 但是，您可以更新缓冲区的内容。

这意味着如果您知道 BufferGeometry 的某个属性将会增长，例如顶点数量， 您必须预先分配一个足够大的缓冲区来容纳可能创建的任何新顶点。的 当然，这也意味着您的 BufferGeometry 将有一个最大大小 - 有 无法创建可以有效无限扩展的 BufferGeometry。

我们将使用在渲染时延长的线的示例。我们会分配空间 在缓冲区中包含 500 个顶点，但首先使用“BufferGeometry.drawRange”仅绘制两个。

const MAX_POINTS = 500;

// geometry
const geometry = new THREE.BufferGeometry();

// attributes
const positions = new Float32Array( MAX_POINTS * 3 ); // 3 floats (x, y and z) per point
geometry.setAttribute( 'position', new THREE.BufferAttribute( positions, 3 ) );

// draw range
const drawCount = 2; // draw the first 2 points, only
geometry.setDrawRange( 0, drawCount );

// material
const material = new THREE.LineBasicMaterial( { color: 0xff0000 } );

// line
const line = new THREE.Line( geometry, material );
scene.add( line );

接下来，我们将使用如下模式随机向线上添加点：

const positionAttribute = line.geometry.getAttribute( 'position' );

let x = 0, y = 0, z = 0;

for ( let i = 0; i < positionAttribute.count; i ++ ) {

    positionAttribute.setXYZ( i, x, y, z );

    x += ( Math.random() - 0.5 ) * 30;
    y += ( Math.random() - 0.5 ) * 30;
    z += ( Math.random() - 0.5 ) * 30;

}

如果您想更改第一次渲染后渲染的点数，请执行以下操作：

line.geometry.setDrawRange( 0, newValue );

如果您想在第一次渲染后更改位置数据值，您需要 像这样设置 needUpdate 标志：

positionAttribute.needsUpdate = true; // required after the first render

如果在初始渲染后更改位置数据值，则可能需要重新计算 包围体，以便引擎的其他功能（例如视锥体剔除或助手）正常工作。

line.geometry.computeBoundingBox();
line.geometry.computeBoundingSphere();

材料

所有制服值都可以自由更改（例如颜色、纹理、不透明度等），每帧值都会发送到着色器。

此外，GLstate 相关参数可以随时更改（深度测试、混合、多边形偏移等）。

以下属性在运行时无法轻松更改（一旦材质至少渲染一次）：

  • 制服的数量和类型
  • 是否存在
    • texture
    • fog
    • 顶点颜色
    • 变形
    • 阴影贴图
    • alpha测试
    • 透明

这些变化需要构建新的着色器程序。您需要设置

material.needsUpdate = true

请记住，这可能会非常慢并导致帧速率不稳定（尤其是在Windows上，因为DirectX中的着色器编译比OpenGL慢）。

为了获得更流畅的体验，您可以通过使用“虚拟”值（例如零强度光、白色纹理或零密度）来在某种程度上模拟这些功能的变化folg.

您可以自由更改用于几何块的材质，但是您无法更改对象划分块的方式（根据面材质）。

如果在运行时需要有不同的材质配置：

如果材质/块的数量很少，您可以预先对对象进行预划分（例如，人的头发/脸/身体/上衣/裤子，汽车的前部/侧面/顶部/玻璃/轮胎/内饰）。

如果数量很大（例如，每个面可能不同），请考虑不同的解决方案，例如使用属性/纹理来驱动不同的每个面外观。

Cameras

相机的位置和目标会自动更新。如果你需要改变

  • 视场
  • 方面
  • 靠近
  • 远的

那么你需要重新计算投影矩阵： 

camera.aspect = window.innerWidth / window.innerHeight;
camera.updateProjectionMatrix();

InstancedMesh

`InstancedMesh` 是一个在 ` Three.js` 中方便访问实例化渲染的类。某些库功能，例如视锥体剔除或 光线投射依赖于最新的包围体（包围球体和包围盒）。由于“InstancedMesh”的工作方式，该类 有自己的“boundingBox”和“boundingSphere”属性，它们取代几何级别上的包围体。

与几何图形类似，每当更改基础数据时，您都必须重新计算边界框和球体。在 `InstancedMesh` 的上下文中， 当您通过“setMatrixAt()”转换实例时会发生。您可以使用与几何图形相同的图案。

instancedMesh.computeBoundingBox();
instancedMesh.computeBoundingSphere();

蒙皮网格

“SkinnedMesh”遵循与边界体积上下文中的“InstancedMesh”相同的原则。意味着该类有自己的版本 `boundingBox` 和 `boundingSphere` 正确包围动画网格。 当调用“computeBoundingBox()”和“computeBoundingSphere()”时，该类根据当前的情况计算各自的边界体积 骨骼变换（或者换句话说，当前动画状态）。
