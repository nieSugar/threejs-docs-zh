材料

本文是关于 three.js 系列文章的一部分。第一篇文章是 three.js 基础。如果你还没有阅读过，并且你是 three.js 新手，你可能想从那里开始。

Three.js 提供了多种类型的材质。它们定义了对象在场景中的呈现方式。你使用哪种材质取决于你想要实现的效果。

设置大多数材质属性有两种方式。一种是在创建时设置，我们之前已经见过。

const material = new THREE.MeshPhongMaterial({
  color: 0xFF0000,    // red (can also use a CSS color string here)
  flatShading: true,
});

另一种是在创建之后设置

const material = new THREE.MeshPhongMaterial();
material.color.setHSL(0, 1, .5);  // red
material.flatShading = true;

注意，类型为 THREE.Color 的属性有多种设置方式。

material.color.set(0x00FFFF);    // same as CSS's #RRGGBB style
material.color.set(cssString);   // any CSS color, eg 'purple', '#F32',
                                 // 'rgb(255, 127, 64)',
                                 // 'hsl(180, 50%, 25%)'
material.color.set(someColor)    // some other THREE.Color
material.color.setHSL(h, s, l)   // where h, s, and l are 0 to 1
material.color.setRGB(r, g, b)   // where r, g, and b are 0 to 1

在创建时，你可以传递十六进制数字或 CSS 字符串

const m1 = new THREE.MeshBasicMaterial({color: 0xFF0000});         // red
const m2 = new THREE.MeshBasicMaterial({color: 'red'});            // red
const m3 = new THREE.MeshBasicMaterial({color: '#F00'});           // red
const m4 = new THREE.MeshBasicMaterial({color: 'rgb(255,0,0)'});   // red
const m5 = new THREE.MeshBasicMaterial({color: 'hsl(0,100%,50%)'}); // red

。所以让我们来看看 three.js 的材质集合。

为什么要同时拥有三者，当 MeshPhongMaterial 可以做 MeshBasicMaterial 和 MeshLambertMaterial 的同样事情？原因是更复杂的材质需要更多的 GPU 功率来进行渲染。在 GPU 较慢的设备上，比如说手机上，你可能想通过使用较不复杂的材质来减少渲染场景所需的 GPU 功率。同样地，如果你不需要额外的功能，那么就使用最简单的材质。如果你不需要光照和镜面高光，那么就使用 MeshBasicMaterial。

MeshToonMaterial 类似于 MeshPhongMaterial，但有一个很大的区别。它不是平滑着色，而是使用渐变贴图（一个 X 乘 1 的纹理）来决定如何着色。默认使用的渐变贴图在前 70% 区域亮度为 70%，之后为 100%，但你可以提供自己的渐变贴图。最终效果呈现出类似卡通的双色调外观。

接下来是两个 基于物理的渲染 材质。基于物理的渲染通常缩写为 PBR。

上面的材料使用简单的数学来制作看起来是3D的材料，但它们并不是现实世界中实际发生的情况。两种PBR材料使用更复杂的数学来接近现实世界中实际发生的情况。

第一个是 MeshStandardMaterial。MeshPhongMaterial 和 MeshStandardMaterial 最大的区别是它使用了不同的参数。MeshPhongMaterial 有一个 shininess 设置。MeshStandardMaterial 有两个设置 roughness 和 metalness。

在基本层面上，roughness 是 shininess 的相反。具有高粗糙度的物体，例如棒球，不会有强烈的反射，而不粗糙的物体，例如台球，非常光亮。粗糙度的范围是从 0 到 1。

另一个设置，metalness，表示材料的金属程度。金属的行为与非金属不同。非金属为 0，金属为 1。

各种标准材质的处理速度从快到慢依次为 MeshBasicMaterial ➡ MeshLambertMaterial ➡ MeshPhongMaterial ➡ MeshStandardMaterial ➡ MeshPhysicalMaterial。较慢的材质可以制作出更逼真的场景，但您可能需要在低性能或移动设备上设计代码以使用速度更快的材质。

有三种材料具有特殊用途。ShadowMaterial用于获取由阴影产生的数据。我们还没有讲到阴影。当我们讲到时，我们将使用这种材料来看看幕后发生了什么。

MeshDepthMaterial渲染每个像素的深度，其中摄像机负near处的像素为0，负far处的像素为1。某些特殊效果可以使用这些数据，我们将在另一个时间讨论。

这MeshNormalMaterial将向你展示正常人几何学的。法线是特定三角形或像素所面向的方向。MeshNormalMaterial绘制视图空间法线（相对于相机的法线）。x 是红色的, y 是绿色的，并且z 是蓝色的所以面向右边的东西将是粉色左边将是水色,向上将会浅绿色,向下将会紫色，并且朝向屏幕将会是薰衣草.

ShaderMaterial 用于使用 three.js 着色器系统制作自定义材质。RawShaderMaterial 用于制作完全自定义的着色器，不依赖 three.js 的帮助。这两个主题都很庞大，将在后面讲解。

大多数材质共享一组由 Material 定义的设置。查看文档 了解所有设置，但我们先来看看两个最常用的属性。

flatShading：对象是看起来有棱角还是平滑。默认值 = false。

flatShading: false
flatShading: true

side：显示三角形的哪一面。默认是 THREE.FrontSide。其他选项是 THREE.BackSide 和 THREE.DoubleSide（双面）。在 Three.js 中绘制的大多数 3D 对象可能是透明固体，因此背面（面向固体内部的面）不需要绘制。设置 side 的最常见原因是用于平面或其他非固体对象，在这些对象中通常可以看到三角形的背面。

在材质方面真的有很多需要考虑的地方，实际上我们还有很多工作要做。特别是我们大多忽略了纹理，这将打开一整系列的选项。但在我们讲纹理之前，我们需要先休息一下并讲一下设置开发环境。

material.needsUpdate

这个话题很少影响大多数 three.js 应用，但仅供参考…… three.js 在使用材质时会应用材质设置，其中“使用”是指“渲染使用该材质的某些内容”。有些材质设置只会应用一次，因为更改它们需要 three.js 做大量工作。 在这种情况下，您需要设置 material.needsUpdate = true 来告诉 three.js 应用您的材质更改。如果在使用材质后更改设置，最常见需要设置 needsUpdate 的设置有：

  • flatShading
  • 添加或移除纹理

    更换纹理是可以的，但如果想从不使用纹理切换为使用纹理，或者从使用纹理切换为不使用纹理， 那么您需要设置 needsUpdate = true。

    在从有纹理到无纹理的情况下，通常最好使用一个1x1像素的白色纹理。

如上所述，大多数应用程序从未遇到这些问题。大多数应用程序不会在平面着色和非平面着色之间切换。大多数应用程序也要么使用纹理，要么使用给定材质的纯色，它们很少会从使用一种切换到使用另一种。
