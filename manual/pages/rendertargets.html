渲染目标

three.js 中的渲染目标基本上是一个可以渲染到的纹理。在渲染到它之后，你可以像使用其他纹理一样使用该纹理。

让我们做一个简单的示例。我们将从关于响应性的文章中的一个示例开始。

将渲染输出到渲染目标几乎与普通渲染完全相同。首先我们创建一个 WebGLRenderTarget.

const rtWidth = 512;
const rtHeight = 512;
const renderTarget = new THREE.WebGLRenderTarget(rtWidth, rtHeight);

然后我们需要一个 Camera 和一个 Scene

const rtFov = 75;
const rtAspect = rtWidth / rtHeight;
const rtNear = 0.1;
const rtFar = 5;
const rtCamera = new THREE.PerspectiveCamera(rtFov, rtAspect, rtNear, rtFar);
rtCamera.position.z = 2;

const rtScene = new THREE.Scene();
rtScene.background = new THREE.Color('red');

注意我们将宽高比设置为渲染目标的宽高比，而不是画布的。应使用的正确宽高比取决于我们渲染的用途。在这种情况下，我们将在立方体的一侧使用渲染目标的纹理。由于立方体的面是方形的，所以我们希望宽高比为 1.0。

现在在渲染时，首先我们将渲染目标场景渲染到渲染目标中。

function render(time) {

  // rotate all the cubes in the render target scene
  rtCubes.forEach((cube, ndx) => {
    const speed = 1 + ndx * .1;

  // draw render target scene to render target

立方体是红色的，因为我们将 background 的 rtScene 设置为红色，因此渲染目标的纹理被清除为红色。

渲染目标用于各种用途。阴影 使用渲染目标。拾取可以使用渲染目标。各种后期处理效果需要渲染目标。在车内渲染后视镜或在 3D 场景内的显示器上显示实时画面可能会使用渲染目标。

使用 WebGLRenderTarget 的一些注意事项。

  • 默认情况下，WebGLRenderTarget 会创建两种纹理。一个是颜色纹理，一个是深度/模板纹理。如果你不需要深度或模板纹理，可以通过传入选项来请求不创建它们。示例：

      const rt = new THREE.WebGLRenderTarget(width, height, {
    depthBuffer: false,
    stencilBuffer: false,
  });

  • 你可能需要更改渲染目标的大小

    在上面的例子中，我们创建了一个固定大小为 512x512 的渲染目标。对于诸如后期处理之类的情况，你通常需要创建一个与画布相同大小的渲染目标。在我们的代码中，这意味着当我们更改画布大小时，也会更新渲染目标的大小以及我们在渲染到渲染目标时使用的相机。示例：

    function render(time) {
  time *= 0.001;

  if (resizeRendererToDisplaySize(renderer)) {
    const canvas = renderer.domElement;
    camera.aspect = canvas.clientWidth / canvas.clientHeight;
    camera.updateProjectionMatrix();

+    renderTarget.setSize(canvas.width, canvas.height);
+    rtCamera.aspect = camera.aspect;
+    rtCamera.updateProjectionMatrix();
