加载3D模型

3D模型有数百种文件格式，每种都有不同的用途、各种特点和不同的复杂性。虽然three.js提供了许多加载器，选择合适的格式和工作流程可以在后期节省时间和避免挫折。有些格式难以处理、在实时体验中效率低，或者目前根本不完全支持。

本指南提供了推荐给大多数用户的工作流程，并给出了在出现问题时可尝试的方法建议。

在我们开始之前

如果你是本地服务器的新手，请首先从安装开始。通过正确托管文件，可以避免许多查看3D模型时的常见错误。

推荐的工作流程

在可能的情况下，我们推荐使用glTF（GL传输格式）。该格式的.GLB和.GLTF版本都得到了良好的支持。由于glTF专注于运行时资产传输，它在传输上非常紧凑，加载速度快。其功能包括网格、材质、纹理、蒙皮、骨骼、形态目标、动画、灯光和摄像机。

公开领域的 glTF 文件可以在像 Sketchfab 这样的网站上找到，或者各种工具也支持 glTF 导出：

  • Blender（由 Blender Foundation 开发）
  • Substance Painter（由 Allegorithmic 开发）
  • Modo（由 Foundry 开发）
  • Toolbag 由 Marmoset
  • Houdini 由 SideFX
  • Cinema 4D 由 MAXON
  • COLLADA2GLTF 由 Khronos Group
  • FBX2GLTF 由 Facebook
  • OBJ2GLTF 由 Analytical Graphics Inc
  • ……以及 更多

如果您常用的工具不支持 glTF，可以考虑向作者请求 glTF 导出，或在 glTF 路线图讨论串 上发帖。

当 glTF 不可行时，FBX、OBJ 或 COLLADA 等流行格式同样可用，且定期维护。

加载中

默认情况下，three.js 只包含少量加载器（例如 `ObjectLoader`）——其他加载器需要你单独添加到你的应用中。 

import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

一旦你导入了加载器，就可以将模型添加到场景中。不同加载器的语法各不相同——使用其他格式时，请查阅该加载器的示例和文档。对于 glTF，在使用全局脚本时的用法如下： 

const loader = new GLTFLoader();

loader.load( 'path/to/model.glb', function ( gltf ) {

  scene.add( gltf.scene );

}, undefined, function ( error ) {

  console.error( error );

} );

排查故障

你花了几个小时制作了一件精美的工艺杰作，现在将它加载到网页里，结果——哎呀！😭 它要么扭曲，要么颜色不对，甚至完全不显示。 从以下故障排查步骤开始：

  1. 检查 JavaScript 控制台是否有错误，并确保在调用 `.load()` 时使用了 `onError` 回调来记录结果。
  2. 在其他应用程序中查看模型。对于 glTF，有拖放查看器可用于 three.js 和 babylon.js。如果模型在一个或多个应用程序中显示正常，向 three.js 提交一个错误报告。如果模型无法在任何应用程序中显示，我们强烈建议向用于创建模型的应用程序提交错误报告。
  3. 尝试将模型按1000倍进行放大或缩小。许多模型的缩放不同，如果摄像机在模型内部，大型模型可能看不到。
  4. 尝试添加并定位光源。模型可能会因为黑暗而看不见。
  5. 在网络选项卡中查看失败的纹理请求，例如 `"C:\Path\To\Model\texture.jpg"`。请改为使用相对于模型的路径，例如 `images/texture.jpg` — 这可能需要在文本编辑器中编辑模型文件。

请求帮助

如果你已经按照上述故障排除流程操作过，但你的模型仍然无法正常工作，那么正确的求助方法会让你更快找到解决方案。你可以在 three.js 论坛 上发布问题，并且在可能的情况下，附上你的模型（或带有相同问题的简化模型）以及你拥有的任意格式。提供足够的信息，以便其他人能够快速复现问题 —— 理想情况是提供一个在线演示。
