按需渲染

这个话题对很多人来说可能很明显，但以防万一……大多数 Three.js 示例都是连续渲染的。换句话说，它们设置了一个 requestAnimationFrame 循环或类似这样的“rAF 循环”

function render() {
  ...
  requestAnimationFrame(render);
}
requestAnimationFrame(render);

对于一些会动画的东西，这很有道理，但对于一些不会动画的东西又如何呢？在这种情况下，持续渲染是对设备电力的浪费，如果用户使用的是便携设备，还会浪费用户的电池。

解决这个问题最明显的方法是在一开始渲染一次，然后仅在有变化时渲染。变化包括纹理或模型最终加载完成、外部来源的数据到达、用户调整设置或相机，或者提供其他相关输入。

让我们从响应性文章中举一个例子，并修改为按需渲染。

然后我们需要渲染一次

每当 OrbitControls 更改相机设置时，我们都需要进行渲染。幸运的是，OrbitControls 会在任何事情发生变化时派发 change 事件。

controls.addEventListener('change', render);

我们还需要处理用户调整窗口大小的情况。以前由于我们在连续渲染，这一点是自动处理的，但现在由于我们不是连续渲染，因此我们需要在窗口大小改变时进行渲染。

window.addEventListener('resize', render);

就这样，我们得到了按需渲染的效果。

OrbitControls 有一些选项可以增加一种惯性，使它们感觉不那么生硬。我们可以通过将 enableDamping 属性设置为 true 来启用它。

controls.enableDamping = true;

在开启 enableDamping 时，我们需要在渲染函数中调用 controls.update，以便 OrbitControls 能继续为我们提供新的摄像机设置，同时平滑移动。但是，这意味着我们不能直接从 render 事件中调用 change，因为这样会导致无限循环。控件会向我们发送 change 事件并调用 render，render 会调用 controls.update。controls.update 会发送另一个 change 事件。

我们可以通过使用 requestAnimationFrame 来调用 render 来解决这个问题，但我们需要确保只有在尚未请求新帧时才请求新帧，这可以通过维护一个变量来跟踪我们是否已经请求过帧来实现。

+let renderRequested = false;

function render() {
+  renderRequested = false;

  if (resizeRendererToDisplaySize(renderer)) {
    const canvas = renderer.domElement;
    camera.aspect = canvas.clientWidth / canvas.clientHeight;
    camera.updateProjectionMatrix();
  }

  renderer.render(scene, camera);
}
render();

+function requestRenderIfNotRequested() {
+  if (!renderRequested) {
+    renderRequested = true;
+    requestAnimationFrame(render);
+  }
+}

-controls.addEventListener('change', render);
+controls.addEventListener('change', requestRenderIfNotRequested);

我们还可以添加一个简单的 lil-gui GUI，并使其更改按需渲染。

import * as THREE from 'three';
import {OrbitControls} from 'three/addons/controls/OrbitControls.js';
+import {GUI} from 'three/addons/libs/lil-gui.module.min.js';

让我们允许设置每个立方体的颜色和 x 轴缩放。为了能够设置颜色，我们将使用我们在灯光文章中创建的 ColorGUIHelper。

首先，我们需要创建一个 GUI

const gui = new GUI();

，然后为每个立方体创建一个文件夹，并添加两个控制项，一个用于 material.color，另一个用于 cube.scale.x。

function makeInstance(geometry, color, x) {
  const material = new THREE.MeshPhongMaterial({color});

  const cube = new THREE.Mesh(geometry, material);
  scene.add(cube);

  cube.position.x = x;

+  const folder = gui.addFolder(`Cube${x}`);
+  folder.addColor(new ColorGUIHelper(material, 'color'), 'value')
+      .name('color')
+      .onChange(requestRenderIfNotRequested);
+  folder.add(cube.scale, 'x', .1, 1.5)
+      .name('scale x')
+      .onChange(requestRenderIfNotRequested);
+  folder.open();

  return cube;
}

你可以看到上面的 lil-gui 控件有一个 onChange 方法，你可以传入一个回调，当 GUI 改变值时调用它。在我们的例子中，我们只需要它调用 requestRenderIfNotRequested。调用 folder.open 会让文件夹默认展开。
