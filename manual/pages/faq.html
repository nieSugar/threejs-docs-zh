FAQ

哪种 3D 模型格式最受支持？

导入和导出资源的推荐格式是 glTF（GL 传输格式）。由于 glTF 专注于运行时资产交付，因此传输紧凑且加载速度快。

Three.js 还为许多其他流行格式（如 FBX、Collada 或 OBJ）提供了加载器。尽管如此，您应该始终首先尝试在项目中建立基于 glTF 的工作流程。

为什么示例中有元视口标签？

<meta name="viewport" content="width=device-width, user-scalable=no, minimum-scale=1.0, maximum-scale=1.0">

这些标签控制移动浏览器的视口大小和比例（其中页面内容可能以与可见大小不同的大小呈现）视口）.

如何在调整大小时保留场景比例？

我们希望所有物体，无论它们与摄像机的距离如何，都能呈现相同的大小，即使窗口被调整大小。 解决这个问题的关键公式是给定距离下可见高度的公式： 

visible_height = 2 * Math.tan( ( Math.PI / 180 ) * camera.fov / 2 ) * distance_from_camera;
如果我们将窗口高度增加一定百分比，那么我们希望所有距离的可见高度都按相同的百分比增加。 这不能通过改变摄像机位置来实现。相反，你必须改变摄像机的视野。 [link:http://jsfiddle.net/Q4Jpu/ Example]。

为什么我的对象的一部分不可见？

这可能是由于面剔除引起的。面有一个方向，决定哪一面是正面。剔除在正常情况下会移除背面。 要查看这是否是你的问题，请将材质面设置为 THREE.DoubleSide。 

material.side = THREE.DoubleSide

为什么 Three.js 有时会因无效输入返回奇怪的结果？

出于性能原因，Three.js 在大多数情况下不会验证输入。您的应用程序有责任确保所有输入都有效。

我可以在 Node.js 中使用 Three.js 吗？

因为 Three.js 是为 Web 构建的，所以它依赖于浏览器和 DOM API，而 Node.js 中并不总是存在这些 API。其中一些问题可以通过使用垫片来避免，例如 [link:https://github.com/stackgl/headless-gl headless-gl] 和 [link:https://github.com/rstacruz/jsdom-global jsdom-global]，或者通过替换 `TextureLoader` 等组件 与定制的替代方案。其他 DOM API 可能与使用它们的代码深深地交织在一起，并且更难解决。我们欢迎简单且可维护的拉动 请求改进 Node.js 支持，但建议首先打开一个问题来讨论您的改进。
